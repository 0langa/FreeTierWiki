You call Vatcheckapi.com with a GET request and an API key from any language. The docs list official libraries, an MCP server, and a status endpoint for your quota. It suits developers who add VAT checks to a checkout or billing tool.

## What the free plan gives you

The Free plan costs $0.00 a month and is for testing and personal projects. You get 150 validations a month, unlimited API keys, and a rate limit of 10 requests per minute. The home page says the service covers 29 countries.

One call checks the format, the checksum, and the registration of a VAT number, and returns the company behind it. Every plan can also validate IBANs, and each IBAN counts as one request.

Only successful calls use your quota. Server errors and rejected requests, such as a missing parameter, do not count. A successful answer reporting an invalid VAT, EORI, or IBAN number does count.

## When you hit a limit

When you pass the monthly quota, the API returns a 429 status code. You then upgrade your plan or wait until the end of the month. When you pass 10 requests in a minute on the free plan, you also get a 429 code and must wait until the minute ends.

Response headers tell you the quota you have left. The Status endpoint shows it too and does not count against your quota. The pricing page explicitly says no card is required for the free plan, and paid plans start at $9.99 a month.

## Gotchas

- The free plan has no sandbox keys. Sandbox keys come with the Medium plan and above.
- Paid plans remove the rate limit. The free plan keeps it, so a burst of checks can fail.
- Requests with a country code the API does not support fail with a 422 validation error.

## Questions people ask

### Is Vatcheckapi free?

Yes. The Free plan costs $0.00 a month and includes 150 validations, unlimited API keys, and 10 requests per minute.

### What happens when I go over the Vatcheckapi limit?

The API returns a 429 status code. You either upgrade your plan or wait until the end of the month. The per-minute limit also returns a 429 code until the minute ends.

### Does Vatcheckapi validate UK VAT numbers?

Yes. The home page says it checks any EU or UK VAT number and returns the registered company name and address.
