BootForm handles the receiving end of a form you wrote yourself. Point the form at its endpoint and use the dashboard to view submissions or set up notifications. This fits a static site where the page can serve HTML but you do not want to run a server to process each submission.

## What the free plan gives you

The plan includes 250 submissions per month for the account. You can create forms subject to fair use, and they all draw from that account allowance. Free includes form validation, spam checks, and email and Discord notifications. The dashboard keeps your submissions and supports export, so you can take the data out without adding an integration.

The API and MCP server are available on Free. The getting-started guide also describes generating an endpoint and posting a test without signing up first. Claim the form for your account to manage its settings and submissions in the dashboard.

## When you hit a limit

BootForm rejects additional submissions when the monthly allowance is used up. The provider sends a usage warning as you approach the cap and another at the limit. If one form attracts a burst of legitimate submissions it can consume quota for the rest of the account. Paid plans have larger bundles and optional metered overage, which is a separate choice.

## Gotchas

- File uploads require a paid tier. Use ordinary text fields if you want to stay on Free.
- The API and the public form endpoint have separate rate limits. Consult the API guide if you are submitting programmatically or handling bursts.
- BootForm branding appears in email notifications on the Free plan. Some notification channels and advanced routing rules also require an upgrade.

## Questions people ask

### Is BootForm free?

Yes. The ongoing Free plan includes 250 submissions per account each month, with no credit card.

### Do I get 250 submissions for each form?

The allowance is for the account. All the forms in it share the same pool.

### Can I accept file attachments on BootForm Free?

File uploads start on Starter. For a free form, use fields that submit text.
