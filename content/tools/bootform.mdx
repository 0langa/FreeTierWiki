BootForm handles the receiving end of a form you wrote yourself. Point the form at its endpoint and use the dashboard to view submissions or set up notifications. This fits a static site where the page can serve HTML but you do not want to run a server to process each submission.

## What the free plan gives you

Free includes 250 monthly account submissions. The fair-use ceiling is 1,000 forms, and they all draw from that account allowance. Free includes form validation, spam checks, and email and Discord notifications. Free allows two verified email addresses. Full submission access and CSV/JSON export last 30 days. Older submissions show only a title/snippet and require an upgrade to open, export or modify; they are permanently deleted after six months, measured from arrival.

The API and MCP server are available on Free. The getting-started guide also describes generating an endpoint and posting a test without signing up first. Claim the form before publishing its ID: whoever claims it first owns it. Unclaimed forms hold up to 10 submissions for 48 hours from the first arrival. Keep full-access account API keys on your server; the public form endpoint does not need one.

## When you hit a limit

BootForm rejects additional submissions when the monthly allowance is used up. The provider sends a usage warning as you approach the cap and another at the limit. If one form attracts a burst of legitimate submissions it can consume quota for the rest of the account. Paid plans have larger bundles and optional metered overage, which is a separate choice.

## Gotchas

- File uploads require a paid tier. Use ordinary text fields if you want to stay on Free. BootForm branding appears in email notifications on the Free plan. Webhooks, Slack, Telegram, autoresponders and advanced notification routing require an upgrade.
- Downgrading applies the shorter retention window to existing submissions; data older than the new storage window is deleted within a day. Export before downgrading.
- The account API shares a 60-request/minute limit across keys and dashboard use. Public submissions allow 5/minute per IP per form and 30/minute per IP across forms; Free also has a 500/hour/form ceiling, still subject to its 250/month account quota.

## Questions people ask

### Is BootForm free?

Yes. The ongoing Free plan includes 250 submissions per account each month, with no credit card.

### Do I get 250 submissions for each form?

The allowance is for the account. All the forms in it share the same pool.

### Can I accept file attachments on BootForm Free?

File uploads start on Starter. For a free form, use fields that submit text.
