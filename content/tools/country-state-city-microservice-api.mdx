You call four public endpoints with plain GET requests from any language. The docs show Python examples that use the requests library. It suits developers who need location data for dropdowns, forms, and small apps.

## What the free plan gives you

The free tier allows up to 100 requests per day. The site says this is enough for development and small projects. There is no price on the free tier page, and the docs examples call the public endpoints with no API key.

The four endpoints list countries, list the states of a country, list the cities of a state, and find the state and cities for a postal code within a country. The site also links to a free geocoding API and a Python examples page that uses the requests library.

## When you hit a limit

The free tier page does not say what happens after you pass 100 requests in a day. It does not describe overage charges or an error code. It asks you to email the provider for larger projects and for information about higher usage plans.

Because the page lists no paid plan and no billing step, a charge looks unlikely. Still, plan for requests to fail or be refused above the daily limit. Cache the country and state lists in your app so each page view does not use a request.

## Gotchas

- The free tier page only gives the daily request count. It does not set out uptime promises or support terms.
- Higher usage plans are not listed. You must contact the provider to ask about them.
- The endpoints take database IDs, such as an id for a country, so you call countries first and then use the returned IDs for states and cities.
