You install Insomnia on your computer, build requests in collections, and send them. It suits developers who test APIs daily and want collections, environments, and CI runs.

## What the free plan gives you

The Essentials plan costs $0 per user per month. It includes unlimited Cloud and Local projects for all users, and unlimited Git Sync projects for up to 3 users. Collection runs and environments are unlimited. You also get the Inso CLI for CI/CD automation, end-to-end encryption, custom linting rules, and plugins.

The plan comes with 1,000 mock server requests per month. The home page lists free HTTP, gRPC, GraphQL, Socket.io, WSS, and SSE. The pricing page says you can skip login and use the local-only Scratch Pad, which is free forever.

## When you hit a limit

Mock server requests are the metered part. After 1,000 a month, the optional add-on costs $10 for every 25,000 requests. The pricing page does not say what happens if you do not buy the add-on.

The other limits are plan features. Git Sync is free for up to 3 users. Pro costs $12 per user per month and gives all users Git Sync access, plus role-based access control and 10,000 mock requests. Enterprise costs $45 per user per month.

## Gotchas

- Free Git Sync is for up to 3 users. Larger teams need Pro.
- Role-based access control is a Pro feature, not part of Essentials.
- Native vault integrations with AWS, GCP, Hashicorp, and Azure are an Enterprise feature.

## Questions people ask

### Is Insomnia free?

Yes. The Essentials plan is $0 per user per month. It has unlimited collection runs and environments and 1,000 mock server requests a month.

### Does Insomnia need a login?

No. The pricing page says you can download Insomnia and start with the local-only, free forever Scratch Pad. A login unlocks Cloud and Git Sync projects.

### How many people can use Git Sync for free?

Up to 3 users. The Pro plan at $12 per user per month gives every user access to Git Sync projects.
