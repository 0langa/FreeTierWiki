You use Cal.com in the browser: connect a calendar, create event types, and share the link. Developers can also use the API v2, an OAuth client, or embeds to put scheduling inside an app.

## What the free plan gives you

The Individuals plan is free forever and is meant for one person. The pricing page lists one user, unlimited event types and calendars, and email notifications. SMS functionality is available, but the credit-system docs give Free users no included messaging credits: every SMS or WhatsApp message requires purchased credits. Unlimited usage refers to bookings, not API throughput or messaging. The feature table also lists unlimited meetings, several duration options per event type, custom meeting locations, availability rules, time zone detection with conflict checking, and cancel and reschedule links for attendees.

Paid plans add team features such as shared availability, round-robin scheduling, and removing Cal.com branding. The Teams plan starts with a 14 day free trial.

## When you hit a limit

Bookings are unlimited for one user. API keys have a standard rate of 120 requests per minute; higher rates can require support and extra charges. SMS and WhatsApp stop when prepaid credits run out, with email fallback; Free users must buy credits manually. Shared team availability needs Teams. Hosted signup needs no card, and a paid team trial lasts 14 days.

## Gotchas

- Only templated workflows come with the free plan, so custom reminder flows may need an upgrade.
- The open source edition is now called Cal.diy. Its docs call it the open source community edition for self-hosting, say Teams, Organizations, Insights, Workflows, and SSO/SAML have been removed, and recommend it only for personal, non-production use.
- Branding and custom sub-domain options sit in the paid feature list, so free booking pages may show Cal.com branding.

## Questions people ask

### Is Cal.com free?

Yes. The Individuals plan is free forever for one user, with unlimited event types and calendars. Paid plans are for teams.

### Does Cal.com need a credit card?

No. The site says no credit card is required, and offers sign-up with email.

### Is Cal.com open source?

Partly. The community edition, Cal.diy, is on GitHub for self-hosting. The hosted Cal.com has enterprise features that Cal.diy removed.
