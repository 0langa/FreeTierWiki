You call the REST API over HTTPS and get JSON back. Version 3 uses OAuth 2.0, and the docs suggest Postman as the quickest way to try the endpoints.

## What the free plan gives you

The docs list no fee for non-commercial apps. Each registered application can make about 12,500 requests per day, or about 1,250 uploads per day. Imgur calls this a credit allocation system.

You also get a second limit for each user. Imgur counts users by IP address for each application. Every response carries rate limit headers, such as `X-RateLimit-ClientRemaining`, so your code can track the credits left. For public reads and anonymous uploads you only need to send your client ID in an `Authorization` header.

## When you hit a limit

If a user hits the per-user limit, Imgur stops that user from requesting more data for an hour. If your app reaches its daily limit five times in one month, Imgur blocks the app for the rest of that month.

The docs list no bill for non-commercial use. Commercial use works differently: you register with RapidAPI, pick a pricing plan there, and send requests to a RapidAPI endpoint with a key. The docs treat an app as commercial if it makes money, including in-app advertising, or belongs to a company.

## Gotchas

- You must register an application and use a client ID even if you only want anonymous uploads.
- The free limits are approximate, and five days over the daily limit in a month blocks the app until the next month.
- An access token is valid for about a month, so your code must renew it.

## Questions people ask

### Is the Imgur API free?

The docs list no fee for non-commercial apps. Each app gets about 12,500 requests or about 1,250 uploads per day.

### What happens when I go over the Imgur API limit?

Imgur stops a user for an hour if they pass the per-user limit. If your app hits the daily limit five times in a month, it is blocked for the rest of the month.

### Can I use the Imgur API in a commercial app?

Not on the free route. You register your app, sign up with RapidAPI, choose a plan there, and use the RapidAPI endpoint with a key.
