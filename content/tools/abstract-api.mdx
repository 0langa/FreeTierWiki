You work with it in two places: a web dashboard for keys and plans, and plain HTTPS calls from your code. It suits developers who need a few lookups or checks and want to start without a card.

## What the free plan gives you

Every API has its own free plan, and Abstract bills each API on its own. The pricing FAQ describes 1,000 free IP geolocation requests at signup, limited to 1 request per second. Email and phone validation each include 100 requests at signup, at 3 requests per second. The Free cards show $0 per month, but their request allowances are explicitly described as signup credits. A monthly refill is not promised.

The free plans return the full API response for evaluation. Paid plans differ by included fields: Starter covers core validation, Standard adds enrichment, and Professional adds risk signals. Check the fields in your chosen paid tier before moving a tested integration to production. No credit card is needed to sign up.

## When you hit a limit

The free plans are quotas, not bills. The docs list two errors for free plans. A 422 error means you ran out of credits. A 429 error means you sent more than the allowed requests per second; on free plans that limit is 1 per second for the IP API.

The pricing page does not promise a reset of the signup allowance. The API FAQ mentions per-call overage fees without identifying a plan. The IP Intelligence reference gives the specific Free behavior: exhausted Free credits return HTTP 422.

## Gotchas

- Each API has its own key. Your IP key will not work for the email API. The free plans are small. A single bulk list clean will use up the 100 email requests quickly.
- The FAQ on the API page says free tiers may not be used in commercial projects. A paid tier may be used in a commercial project.
- IP credits count requests, including requests containing an invalid IP address; they are not limited to successful responses.

## Questions people ask

### Is Abstract API free?

Each API has a no-card free option: 1,000 IP requests or 100 email/phone requests at signup. A recurring refill is unconfirmed.

### What happens when I go over the Abstract API free limit?

The docs say requests fail with a 422 error when you run out of credits, and with a 429 error when you send more than 1 request per second on the free IP plan. The pricing page does not describe a bill for free users.

### Can I use the Abstract API free plan in a commercial project?

The FAQ on the API page says no. Free tiers are for testing. Move to a paid plan before you ship a commercial product.
