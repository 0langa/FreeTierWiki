You work with it in two places: a web dashboard for keys and plans, and plain HTTPS calls from your code. It suits developers who need a few lookups or checks and want to start without a card.

## What the free plan gives you

Every API has its own free plan, and Abstract bills each API on its own. The free IP geolocation plan gives you 1,000 requests a month and a limit of 1 request per second. The free email validation plan and the free phone validation plan give you 100 requests a month each, at 3 requests per second.

The free plans return the full API response, the same payload that paid plans return. Abstract says you can test the real data before you pay. No credit card is needed to sign up. Free plans have no priority support.

## When you hit a limit

The free plans are quotas, not bills. The docs list two errors for free plans. A 422 error means you ran out of credits. A 429 error means you sent more than the allowed requests per second; on free plans that limit is 1 per second for the IP API.

The pricing page does not say what happens to usage over the monthly free quota. An FAQ on the API page says a paid plan pays a fee for each call over its limit. Your free plan has no card on file, so the usual outcome is that calls fail until the next month.

## Gotchas

- Each API has its own key. Your IP key will not work for the email API.
- The FAQ on the API page says free tiers may not be used in commercial projects. The pricing page lists a commercial license only on the custom plan.
- The free plans are small. A single bulk list clean will use up the 100 email requests quickly.

## Questions people ask

### Is Abstract API free?

Yes, within limits. Each API has a permanent free plan, with 1,000 IP requests or 100 email or phone requests a month. No credit card is needed.

### What happens when I go over the Abstract API free limit?

The docs say requests fail with a 422 error when you run out of credits, and with a 429 error when you send more than 1 request per second on the free IP plan. The pricing page does not describe a bill for free users.

### Can I use the Abstract API free plan in a commercial project?

The FAQ on the API page says no. Free tiers are for testing. Move to a paid plan before you ship a commercial product.
