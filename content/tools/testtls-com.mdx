You use it in a browser: enter a host and, if needed, a port and protocol, then read the results. It suits admins who run mail or other TLS services as well as websites.

## What the free plan gives you

Test TLS is a free online scanner for the TLS configuration of servers. You enter a domain name or an IP address. The tool checks the server's configuration settings and security vulnerabilities, and you can download the server's X.509 certificate.

It is not limited to websites. Under Advanced Options you set the TCP port and choose how to connect: plain SSL/TLS, or STARTTLS for services such as FTP, SMTP, POP3, IMAP, LDAP, MySQL, XMPP, and Postgres. By default it detects the protocol from the port. You can also force an IP address. The site is a project by Oliver Brahmstädt, and it builds on the open source testssl.sh tool.

## When you hit a limit

The page lists no price, no account, and no scan quota. The page also does not say if there is a rate limit or what happens if you scan very often. The practical limit is reach: an online scanner can only test servers it can connect to from the internet. The site also warns that it cannot guarantee that results are correct or complete, so treat a clean result as one input, not as proof.

## Gotchas

- An online scanner can only test servers it can reach from the internet.
- The site gives no guarantee that its results are correct or complete.
- The page describes a web form only and mentions no API, so it is not a fit for automated checks.

## Questions people ask

### Is TestTLS.com free?

Yes. It is a free online scanner for the TLS configuration of servers, and the page shows no sign-up or price.

### Can TestTLS.com test a mail server?

Yes. Set the port in Advanced Options and pick a STARTTLS protocol such as SMTP, POP3, or IMAP, or let it detect the protocol from the port.

### Are TestTLS.com results guaranteed?

No. The site says it cannot give any guarantee that results are correct or complete.
