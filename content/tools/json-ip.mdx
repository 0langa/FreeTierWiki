You request `jsonip.com` from a browser, a script, or a web page and read the `ip` field in the answer. It suits small tools that need their own public address and nothing else.

## What the free plan gives you

The home page calls JSON IP a free, unlimited API. It mentions no account, key, card, or paid plan, and the examples send no key. It returns the client's address as an IPv4 or IPv6 value in a JSON object.

A web page can call it directly. The API sends the header that allows any origin, so the JavaScript Fetch API works with CORS turned on. JSONP also works: add a callback name to the path or use the callback parameter. You can use the API to update dynamic DNS when your address changes.

You can ask for one address family. The host `ipv4.jsonip.com` returns only IPv4, and `ipv6.jsonip.com` returns only IPv6. An IPv4-only client cannot connect to the IPv6 host.

## When you hit a limit

The site documents no limit, no quota, and no paid plan, so there is no stated point where you get blocked or billed. It also gives no uptime promise.

The home page does not say how the service treats very heavy use. If your script calls the API often, store the answer and refresh it only when you need to. For location data, the page points to IPinfo, a service from another company.

## Gotchas

- Requests are secured by default. A request to the plain HTTP address gets a 301 redirect to HTTPS. Use the `no-tls.jsonip.com` host if you need plain HTTP.
- The answer is the address your request comes from. Behind a proxy, VPN, or shared network, that may not be your own machine.
- The response has the IP address only. The page title mentions geolocation, but the about endpoint says the service provides an IP address in a JSON object.

## Questions people ask

### Is JSON IP free?

Yes. The site calls it a free, unlimited API and mentions no sign-up, key, card, or paid plan.

### Does JSON IP have a rate limit?

The site documents none. It also gives no uptime promise, so cache the result in scripts.

### Can I call JSON IP from a browser?

Yes. The API allows cross-origin requests, so `fetch` with CORS works, and JSONP is also supported.
