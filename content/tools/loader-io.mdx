You use Loader.io from a web dashboard, or its API, to register a host and run tests against it. It suits developers who want a fast load check without setting up their own load generator.

## What the free plan gives you

The pricing page says to use the Free plan forever and upgrade to Pro anytime. The Free plan is $0 a month and allows 10,000 clients per test, 1 target host, 1 minute tests, and 2 URLs per test.

You choose from three test types: Clients per test, Clients per second, and Maintain client load. The advanced settings let you set an error threshold, timeouts, and basic authentication. Free users see aggregated stats for all URLs, and the home page calls Loader.io a free load testing service.

## When you hit a limit

The pricing page does not describe an error or a bill when you reach a free limit. Published limits cover client count,host count,URL count and test length; their exact UI/error enforcement is not documented. To go beyond them, you move to Pro.

Pro costs $99.95 a month. It allows 100,000 clients per test, unlimited target hosts, unlimited 10 minute tests, and 10 URLs per test. It adds advanced analytics, concurrent tests, DNS verification, team features, and priority support.

## Gotchas

- Verify the target host before testing. Use token-file verification on Free; DNS verification appears among paid-plan features.
- All tests run from Amazon's US-east datacenter, and the pages list no other test location.
- Free users do not get per-URL response times or response codes. Those are advanced analytics on paid plans.

## Questions people ask

### Is Loader.io free?

Yes. The Free plan is $0 a month with 10,000 clients per test and 1 target host. Tests run for 1 minute.

### How much does Loader.io Pro cost?

Pro is $99.95 a month. It raises the limit to 100,000 clients per test and unlimited target hosts.

### Where do Loader.io tests run from?

The pricing FAQ says all tests run from Amazon's US-east datacenter.
