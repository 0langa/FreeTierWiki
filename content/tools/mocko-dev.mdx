You create mocks in the Mocko web app or as files, and clients call the host you get. You can also run the open-source command line tool on your machine. It suits developers who want a mock that can pass unmatched requests through to a real backend.

## What the free plan gives you

Mocko Cloud gives each project its own public HTTPS host in the form `slug.free.mockoapp.net`. You choose the slug, and it must be at least four characters. A mock is live the moment you save it. A project owns its mocks, its flags, its request logs, and its members, and you can invite teammates by GitHub username.

You can also install the open-source command line tool with npm and run mocks locally, or define them as code in files. A project can have an optional proxy URL. Requests that no mock matches go to the real backend, and the real response comes back.

## When you hit a limit

The Mocko pages give no usage limits, quotas, or prices for Mocko Cloud, so they do not say what happens at a limit. The home page links to free hosted mocks, but the reviewed pages do not explicitly establish the cloud account card policy or quota enforcement. Without a proxy URL, a request that matches no mock just returns a not-found response. For hard guarantees, run the open-source version yourself.

## Gotchas

- No usage limits are published in the Mocko pages, so plan for a change.
- Changing a project slug changes its public host, so update any clients that use the old address.
- Without a proxy URL, unmatched requests return a not-found response.

## Questions people ask

### Is Mocko free?

The home page offers a free way to create mock APIs with public URLs, and an open-source version runs locally. The Mocko pages list no prices.

### Does Mocko need a credit card?

The reviewed pages do not explicitly state the cloud card policy. GitHub sign-in instructions alone do not prove no card is required.

### Does Mocko have a local version?

Yes. You install the open-source command line tool with npm, run it, and call the mocks on your own machine.
