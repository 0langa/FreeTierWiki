You use Copilot Free as an extension in editors such as Visual Studio Code, JetBrains IDEs, and Visual Studio, through the Copilot CLI, and on github.com. It suits individual developers, students, and hobbyists who want to try AI help without paying.

## What the free plan gives you

Copilot Free costs $0. The plans page does not mention a credit card for it. It allows 2,000 inline code completions per month. Chat, agent mode, and the CLI draw on a monthly allowance of GitHub AI Credits. The plans page shows this as "Limited chat and agent usage" and gives no fixed number of chat requests.

Free includes agent mode in supported editors, the Copilot CLI, MCP server integration, custom instructions, and Copilot Spaces. Copilot Free is only for individuals. A person with a Copilot Business or Enterprise seat is not eligible.

## When you hit a limit

Inline suggestions stop at 2,000 completions per month on Free. For chat and agent use, the docs say you can upgrade, wait for the next monthly cycle, or pay for more credits. The plans table lists buying extra AI credits as not included on Free, so a free account cannot run up a bill. The allowance resets each month. Pro costs $10 per month and has unlimited completions and 1,500 total AI credits.

## Gotchas

- Free has no pull request reviews and no cloud agent. Those start on the Pro plan.
- The Free page gives no exact credit amount, so you cannot predict how many chats it covers.
- How fast chat and agent use drains your credits depends on the model you choose and the task.

## Questions people ask

### Is GitHub Copilot free?

Yes, for individuals. Copilot Free gives you 2,000 code completions per month and a monthly allowance of AI credits for chat and agents. The plans page does not mention a credit card for Free.

### What happens when I hit the Copilot Free limit?

Completions stop after 2,000 in a month. Chat and agent use run on credits that reset each month. Free accounts cannot buy extra credits.

### Is GitHub Copilot free for students?

Students can use Copilot Free like any individual. The plans page also says people with Pro access through a verified student, faculty, or open source account may choose Free instead. The page does not describe a separate student plan.
