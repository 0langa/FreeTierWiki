Quay.io is a hosted registry for container images. You push images to it with Docker or another OCI client, or let it build them on each commit from GitHub, Bitbucket, GitLab, or a self-hosted Git server. Teams, robot accounts, and audit logs control who can push and pull. Red Hat also sells Quay for self-hosting.

## What the free plan gives you

There is no named free plan, but the plans page FAQ answers the question directly: you can use Quay for free, with unlimited storage and serving of public repositories. A public repository gets a public download page for your container, and the page calls public repositories free.

The plans page says all plans include continuous integration builds from Git pushes, robot accounts for automated deployments, teams, SSL encryption between Quay and your servers, and logging and auditing of API and UI actions. The page does not say which of these apply to an account with only public repositories.

## When you hit a limit

Public repositories have no stated limits, so the boundary is privacy rather than usage. A private repository needs a paid plan: Developer is $15 a month for 5 private repositories, Micro is $30 for 10, and Small is $60 for 20, all with unlimited public repositories. Larger plans run up to thousands of private repositories.

Your first 30 days on a paid plan are free. You can change plans at any time and the account is pro-rated for the difference. The plans page does not say what happens to private repositories if a trial ends without payment.

## Gotchas

- Anything in a public repository can be pulled by anyone, so check images for secrets before pushing.
- Private repositories are never free, even one, so a small private project starts at the Developer plan.
- Paid plans count private repositories, not users or storage, so splitting images across many repositories raises the bill.

## Questions people ask

### Is Quay.io free?

Yes, for public repositories. Quay offers unlimited storage and serving of public repositories at no cost.

### Can I have a private repository on Quay.io for free?

No. Private repositories need a paid plan, starting with Developer at $15 a month for 5 private repositories, after a 30-day free trial.

### Can Quay.io build my images?

Yes. The plans page says Quay can build containers on each commit, with GitHub, Bitbucket, GitLab, and self-hosted Git repositories supported.
