You call FreeIPAPI over plain HTTP from any language, and the free server needs no API key. It suits small projects that need quick location data for an IP address.

## What the free plan gives you

The free API lives at `free.freeipapi.com` and answers in JSON or XML. It allows 10 requests per 10 seconds, up to 60 requests per minute. You need no account, API key, or whitelisting. The service says it is free for commercial and non-commercial use.

A lookup returns the country, region, city, coordinates, time zone, currency, language, phone code, ASN, and a proxy flag. The site also lists helper endpoints for countries, phone codes, time zones, languages, and the distance between two IPs. A bulk lookup takes up to 50 IP addresses in one request.

## When you hit a limit

The rate limit page says to spread your requests across the intervals, not send the whole minute at once. It does not say what the server returns when you go over.

The allowance is shared. Requests from a website count against that domain, and requests from a server count against its public outgoing IP. Visitors do not get a separate allowance each. Paid plans remove the limits, but you must call a regional paid server on the `/api/` path and use an API key or a whitelisted IP or domain.

## Gotchas

- Free and paid plans use different URLs. Only the free server uses `/api/v1/`, so paid access does not work there.
- Browser calls from your site share one allowance for the whole domain, so a busy page can use it up for every visitor.
- Paying does not lift the limits on the free server. You must send requests to a paid server to get unlimited access.

## Questions people ask

### Is FreeIPAPI free?

Yes. The free API needs no account, key, or card. It is limited to 60 requests per minute, with a burst limit of 10 requests per 10 seconds.

### Can I use FreeIPAPI for commercial projects?

Yes. The home page says the service is free for commercial and non-commercial uses. If you need more than the free rate limit, you can subscribe to a paid plan.

### What happens when I go over the FreeIPAPI limit?

The pages do not say what the free server returns. They tell you to spread requests across the intervals. Paid plans have no rate limits.
