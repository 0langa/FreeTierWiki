You build the API in a browser-like builder, optionally recording requests with a Chrome extension. After you publish, other code calls it with regular HTTP requests. It suits developers who are comfortable reading a site's network requests.

## What the free plan gives you

The free plan gives you 30,000 API calls per month on shared infrastructure. In return, your APIs are public. They must be shared with the community, and other users can build complementary APIs or clone yours.

The pricing page describes the free plan as everything WrapAPI offers while contributing back to the community. You can use the builder, the Chrome extension, and the published endpoint. The page lists no card rule for the free plan, and the paid plans have no listed price.

## When you hit a limit

The pricing page does not say what happens after 30,000 calls in a month. The free plan is listed at no price and the page shows no card step, so a bill is unlikely. If you need more calls, the page points you to the paid plans and a contact form.

The paid plans are Business and a fully managed plan. Both list private APIs and unlimited API calls, and the prices are on request. A further plan offers a private cloud-hosted version.

## Gotchas

- Free APIs are public, so do not wrap anything that needs a private login or customer data.
- The Chrome extension is optional, but it helps WrapAPI find which request values should become inputs.
- A published endpoint is called at `wrapapi.com/use`, so your app depends on WrapAPI staying online.

## Questions people ask

### Is WrapAPI free?

Yes, there is a free plan with 30,000 API calls per month on shared infrastructure. APIs you build on it must be public.

### Can I keep my WrapAPI APIs private on the free plan?

No. The free plan requires public APIs that are shared with the community. Private APIs are part of the paid plans.

### What happens if I go over the WrapAPI free limit?

The pricing page does not say. It lists unlimited API calls on the paid plans, with prices on request.
