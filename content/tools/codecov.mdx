You add an upload step to your CI. After each test run it sends the coverage report to Codecov, which comments on the pull request and updates a dashboard. It suits open source projects and solo developers.

## What the free plan gives you

The Developer plan is free. It allows 1 user. Public repositories are unlimited, and so are public repository uploads. Private repositories are also unlimited, but you get 250 private repository uploads per month.

A private repository upload is one coverage report uploaded from a closed-source repository, usually during CI. A build can send more than one upload per commit if you run tests in parallel or use flags. Open source uploads do not count against the monthly 250. A user is anyone who authors a pull request on a private repository with Codecov coverage, or who uses advanced features on a private repository. The Developer plan is best for open source projects or for single-user teams with small private repositories.

## When you hit a limit

The pricing page does not say what happens after the 250th private upload in a month. It also does not say what happens when a second user appears on a private repository. The pricing FAQ says the Developer plan is for single-user teams, and the Team plan is for up to 10 users.

To go beyond the free plan, the Team plan costs $5 per user per month and allows 2500 uploads per month. It shows patch coverage only. The Pro plan costs $12 per user per month, needs at least two users, and adds flags, carry forward flags, components, and project coverage. You can try all Pro features free for 14 days.

## Gotchas

- Parallel CI jobs and flags send several uploads per commit, so private repositories can reach 250 uploads faster than you expect.
- GitHub users must install the Codecov GitHub app for their organization, and may need an organization admin to approve it.
- The Team plan shows patch coverage only. Project coverage and the trend charts need the Pro plan.

## Questions people ask

### Is Codecov free?

Yes, the Developer plan is free for 1 user. It covers unlimited public repositories and uploads, and private repositories with up to 250 uploads per month.

### How much does Codecov cost for teams?

The Team plan costs $5 per user per month for up to 10 users. The Pro plan costs $12 per user per month, and it has a 14-day free trial.

### Does Codecov work with GitLab and Bitbucket?

Yes. The quick start covers GitHub, GitLab, and Bitbucket. GitLab and Bitbucket users add a Team Bot so Codecov can communicate with the code host.
