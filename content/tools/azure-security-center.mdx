You use Defender for Cloud in the Azure portal. You search for it, open the overview page, and read the recommendations and the Secure Score. It suits Azure users who want a first security baseline, and teams that also run AWS or Google Cloud.

## What the free plan gives you

The free part is called Foundational CSPM, short for cloud security posture management. Microsoft lists it as available at no cost. It covers continuous security assessment, security recommendations, the Secure Score, an asset inventory, and regulatory compliance checks against the Microsoft cloud security benchmark. You can connect AWS and Google Cloud accounts too.

The free plan has no resource quota on the pages. It also shows basic Azure DevOps recommendations. Deeper features, such as attack path analysis and pull request annotations, need the paid Defender CSPM plan.

## When you hit a limit

Foundational CSPM has no usage limit to hit. The cost risk comes from the paid plans. Microsoft says they are free for the first 30 days, or until a usage limit is reached, whichever comes first. After that, charges begin for the plans you enabled. The Enable all button in Environment settings turns on every plan, so leave it alone unless you want paid protection. Malware scanning in Defender for Storage is charged from the first day.

## Gotchas

- You need an Azure subscription, and viewing resources needs the Owner, Contributor, or Reader role.
- Defender CSPM bills only for compute, database, storage, and serverless resources, but it protects workloads across clouds.
- Defender for Cloud is also moving into the Microsoft Defender portal, so some screens differ between the two portals.

## Questions people ask

### Is Microsoft Defender for Cloud free?

Partly. Foundational CSPM is free, with recommendations and a Secure Score. The paid plans are free for the first 30 days, then they bill.

### Do I need a credit card for Defender for Cloud?

You need an Azure subscription, and this atlas treats Azure sign-up as needing a card. The Foundational CSPM plan itself has no charge.

### Does Defender for Cloud cover AWS and Google Cloud?

Yes. The free Foundational CSPM plan assesses Azure, AWS, and GCP resources once you connect the accounts.
