You use Numlookupapi.com with a GET request and an API key from any language, or with the client SDKs the docs list. It suits developers who add phone checks to a sign-up form or clean a contact list.

## What the free plan gives you

The Free plan costs $0 a month and is meant for testing and personal projects. You get 100 requests per month, unlimited API keys that share that quota, and a rate limit of 10 requests per minute. Batch validation is included, with up to 100 numbers in one HTTP request. Each distinct number consumes one request of quota, so 100 different numbers use the entire free monthly allowance. Commercial use starts on Basic.

Each lookup returns the carrier and line type, such as mobile, landline, or toll-free. It also flags VoIP and other special number types, which helps against fake sign-ups. The service covers more than 230 countries. The site says the free plan is enough to build and test your integration before you pay.

## When you hit a limit

The quota documentation says requests return HTTP 429 once you exceed the monthly allowance. Upgrade or wait until the end of the month. Exceeding the minute limit also returns HTTP 429; wait until the minute ends. Only successful requests count toward quota, and the status endpoint is free.

The rate limit is separate. Paid plans have no rate limit, so more than 10 requests in a minute is a reason to upgrade. The paid plans start with Basic at $9.99 a month, and you can cancel from your dashboard.

## Gotchas

- 100 requests a month runs out fast in a live sign-up form. Treat the free plan as a test setup.
- API keys are unlimited on every plan and all share the plan's quota. Sandbox keys start on Pro.
- Email support starts on paid plans. The free plan lists no support.

## Questions people ask

### Is Numlookupapi free?

Yes, up to a point. The Free plan costs $0 a month and includes 100 requests, unlimited API keys, and 10 requests per minute.

### What happens when I go over the Numlookupapi free limit?

Requests return HTTP 429 at the monthly quota. Wait for the monthly reset or upgrade. At the minute limit, wait until that minute ends.

### Does Numlookupapi need a credit card?

No. The pricing page explicitly says Free needs no credit card; a card is needed only when upgrading to a paid plan.
