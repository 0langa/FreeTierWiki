You install the kogiQA desktop app, record a test by clicking through your site, and replay it. A JavaScript SDK lets you drive the same tests from code. It suits developers and QA staff who want less selector upkeep.

## What the free plan gives you

The pricing page says you pay only for what you use, with a free tier. The first 500 actions per month are free. Cloud runner usage, unlimited users, and all functions are included. There is also a free 30 day trial with no credit card.

The desktop app and JavaScript SDK support local and cloud browsers. The SDK needs an API access token from the Access settings in the desktop client, while the website offers a playground to try without an account. The desktop app needs Windows 10 or later, or macOS 10.15 or later, with 8 GB of RAM and an internet connection.

## When you hit a limit

The published rate beyond the first 500 monthly actions is $0.002 per action, or $0.20 per 100. The getting-started guide explicitly says signup needs no card or other payment information. Neither source explains how billing is activated, whether tests stop first, or the trial-to-ongoing-tier transition. A hard stop before paid usage is not confirmed.

The page offers a 50% discount for open source and nonprofit use. The page says kogiQA is a small bootstrapped company and tries to keep prices fair.

## Gotchas

- kogiQA is a desktop application, not a browser extension, so you install it on your machine.
- The free allowance is counted in actions, not in tests, so long tests use it faster.
- The SDK needs an API access token from the Access settings in the desktop client.

## Questions people ask

### Is kogiQA free?

Partly. The first 500 actions per month are free, with unlimited users and all functions. Beyond that it costs $0.002 per action.

### Does kogiQA need a credit card?

No card or payment information is needed to sign up, according to the current getting-started guide. Pricing also labels the 30-day trial no-card.

### Do I need to write selectors in kogiQA?

No. The home page says tests work without selectors, so you type what you see on the page.
