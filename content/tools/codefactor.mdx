You log in with GitHub or Bitbucket, import repositories, and read the report in the CodeFactor web app. It also posts a status on pull requests. It suits open source maintainers and students who want a quality grade.

## What the free plan gives you

The Community plan costs $0 per month. It includes unlimited users and unlimited public repositories. It includes 0 private repositories, so it covers public code only.

CodeFactor runs many open source analysis tools. Its home page lists tools such as ESLint, Pylint, RuboCop, Checkstyle, Bandit, Hadolint, and ShellCheck, and a duplication checker. Languages include Python, JavaScript, TypeScript, Java, Go, PHP, C#, Ruby, and more. Features on the pricing page include fast analysis, pull request integration, and code autofix. The docs also describe GitHub Checks and branch badges.

## When you hit a limit

The Community plan simply has no private repositories. You cannot add one without moving to a paid plan. The pricing page says paid plans are priced by the number of private repositories, and the exact prices are not readable in the page text.

Two free routes exist. Students can get a Pro plan with 5 private repositories free of charge by sending a request. Non-profits can also get a free Pro plan with 5 private repositories. For larger needs, non-profits get a 20% discount. To qualify, an organization must be non-government, non-academic, non-commercial in nature, and have no religious affiliation.

## Gotchas

- A repository can run in Reduced Feature Mode if there is no webhook. Then it is analyzed on demand only, and pull requests get no status.
- Only a GitHub or Bitbucket admin can create the webhook. If you are the admin, click FIX IT.
- The cheaper Pro plan covers 2 branches per repository. The larger Pro plan has unlimited branches, subject to a Fair Use Policy.

## Questions people ask

### Is CodeFactor free?

Yes, for public repositories. The Community plan costs $0 per month with unlimited users and unlimited public repositories. It has 0 private repositories.

### Is CodeFactor free for students?

Yes. The pricing page says the Pro plan with 5 private repositories is free for students, and you request it with a form.

### Does CodeFactor work with GitLab?

No. The docs say CodeFactor supports GitHub and Bitbucket as repository sources for now.
