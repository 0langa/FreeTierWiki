You call Zipcodestack with a GET request and an API key, and the docs also list client SDKs. Pass the key in a header or as a query parameter. It suits developers who add postal code checks and autocomplete to forms and checkouts.

## What the free plan gives you

The Free plan costs $0 a month and is described as for testing and personal projects. It includes 1,000 requests a month, one API key, and a limit of 10 requests per minute. The home page says no credit card is needed.

Endpoints count different numbers of requests. Search counts 1 request per postal code found. Validate, autocomplete, reverse, and match count 1 request per call; distance counts 1 per successful calculation. Radius and polygon calls count 10 requests each. City and state lists count 1 request per 10 postal codes returned. The status endpoint, the provinces list, and the coverage list are free.

Only successful calls count. Errors on the provider's side and validation errors do not use your quota.

## When you hit a limit

When you use all 1,000 requests, the API returns a 429 status code. You then upgrade your plan or wait until the end of the month. If you pass 10 requests in a minute on the free plan, you also get a 429 code and must wait until the minute ends.

Response headers show your remaining monthly and per-minute quota. The docs list only these two limits, with no daily cap. Every paid plan can turn on optional overage up to a monthly spending cap, while the free plan has none and stops at its limit.

## Gotchas

- A radius call counts as 10 requests, so 100 of them use up a free month.
- The free plan has no sandbox keys; those start on the Medium plan. The paid plans are the ones marked for commercial use.
- Sending the key as a query parameter can expose it in access logs. The docs recommend a request header.

## Questions people ask

### Is Zipcodestack free?

Yes. The Free plan costs $0 a month and includes 1,000 requests, one API key, and 10 requests per minute. It is for testing and personal projects.

### What happens when I go over the Zipcodestack free limit?

The API returns a 429 status code. You upgrade or wait until the end of the month. The per-minute limit also gives a 429 code until the minute ends.

### Does Zipcodestack need a credit card?

No. The home page says no credit card is required, and you get instant access to an API key.
