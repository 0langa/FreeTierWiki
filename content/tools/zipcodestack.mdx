You call Zipcodestack with a GET request and an API key, and the docs also list client SDKs. Pass the key in a header or as a query parameter. It suits developers who add postal code checks and autocomplete to forms and checkouts.

## What the free plan gives you

The Free plan costs $0 a month and is described as for testing and personal projects. It includes 300 credits a month, 1 API key, and a limit of 10 requests per minute. The home page says no credit card is needed.

Endpoints cost different amounts of credits. Search costs 1 credit per postal code found. Validate, autocomplete, and reverse lookups cost 1 credit per request. Radius and polygon requests cost 10 credits each. City and state lists cost 1 credit per 10 postal codes returned. The status endpoint, the provinces list, and the coverage list are free.

Only successful calls count. Errors on the provider's side and validation errors do not use your quota.

## When you hit a limit

When you use all 300 credits, the API returns a 429 status code. You then upgrade your plan or wait until the end of the month. If you pass 10 requests in a minute on the free plan, you also get a 429 code and must wait until the minute ends.

Response headers show your remaining monthly and per-minute quota. The docs list only these two limits, with no daily cap. Overage billing exists only on plans that have it enabled, and the free plan is not one of them.

## Gotchas

- A radius request costs 10 credits, so a few of them can use up a free month.
- The free plan has 1 API key and no sandbox keys. The paid plans are the ones marked for commercial use.
- Sending the key as a query parameter can expose it in access logs. The docs recommend a request header.

## Questions people ask

### Is Zipcodestack free?

Yes. The Free plan costs $0 a month and includes 300 credits, 1 API key, and 10 requests per minute. It is for testing and personal projects.

### What happens when I go over the Zipcodestack free limit?

The API returns a 429 status code. You upgrade or wait until the end of the month. The per-minute limit also gives a 429 code until the minute ends.

### Does Zipcodestack need a credit card?

No. The home page says no credit card is required, and you get instant access to an API key.
