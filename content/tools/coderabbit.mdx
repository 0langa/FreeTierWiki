You install CodeRabbit on your Git platform and it comments on each new pull request. You can also use it in VS Code, Cursor, Windsurf, or from a command line. It suits maintainers who want a quick AI review.

## What the free plan gives you

CodeRabbit's open-source plan is free forever. You sign up with GitHub or GitLab, install CodeRabbit on a public repository, and get reviews with Team features and no credit card.

The Free plan covers public and private repositories, also with no credit card. On pull requests it gives summaries only. Code reviews on Free run in the VS Code extension and the CLI. New organizations start on a 14-day Advanced trial and revert to Free if they do not subscribe.

Paid plans add full pull request reviews on private repositories. Essentials costs $24 per developer per month billed annually, Team costs $48, and Advanced costs $72 with continuous security monitoring. The docs list sign-up through GitHub, GitLab, Azure DevOps, Bitbucket Cloud, and Bitbucket Data Center.

## When you hit a limit

The plans docs enforce review limits per developer over rolling hourly windows. Open source allows 1 to 10 pull request reviews per hour depending on the repository, with 100 to 300 files per review. Free allows 1 pull request summary and 3 IDE and 3 CLI reviews per hour, with 150 files per review.

Paid plans allow 5 pull request reviews per developer per hour on Essentials, 8 on Team, and 10 on Advanced, with no total cap on pull requests or repositories.

Usage-based reviews can continue past the hourly allowance on paid plans at $0.25 per reviewed file, with a monthly spending cap you set.

## Gotchas

- Free pull request reviews apply to public repositories only. On a private repository, the Free plan gives summaries, and full pull request reviews need a paid plan or the trial.
- The paid prices on the page assume annual billing. Essentials costs $30 per developer per month when billed monthly.
- CodeRabbit Engineer for cloud coding tasks, Slack, and automations is separate and costs $0.40 per agent minute after trial and free minutes.

## Questions people ask

### Is CodeRabbit free?

Yes, for public repositories. Sign up with GitHub or GitLab and install CodeRabbit on a public repository for free reviews forever. On private repositories, the Free plan gives pull request summaries and editor or CLI reviews, and full pull request reviews need a paid plan.

### How much does CodeRabbit cost for private repositories?

Essentials costs $24 per developer per month billed annually. Team costs $48 and Advanced costs $72, and the paid plans have a 14-day trial.

### Does CodeRabbit need a credit card?

No. The quickstart docs say no credit card is required to create your CodeRabbit account, and the plans docs say the same for the Free and open-source plans.
