Utterances is a lightweight comments widget built on GitHub issues. You add one script tag to your page template, and the widget shows a comment thread for each page, backed by an issue in a GitHub repository you choose. It is open source, but you do not have to host anything: the widget script and the utterances GitHub app are run for you.

## What the free plan gives you

Utterances has no paid plan. Its site says it is open source, has no tracking and no ads, and is always free. There is no lock-in, because all data is stored in GitHub issues in your own repository. The widget is styled with Primer, GitHub's CSS toolkit, offers a dark theme and several other themes, and is written in vanilla TypeScript without font downloads or frameworks.

When the widget loads, it uses the GitHub issue search API to find the issue that matches the page by URL, pathname, title, or another mapping you choose. If no issue exists yet, utterances-bot creates one the first time someone comments.

## When you hit a limit

Utterances publishes no usage limits of its own. Comments live in GitHub, so what you can store and how the issue search behaves follow GitHub's rules rather than an Utterances plan. The site does not describe a quota or a stop.

The practical limits are access ones. The repository must be public, otherwise readers cannot see the issues and comments, and the utterances app must be installed on it, otherwise readers cannot post. Readers comment by authorizing the utterances app through GitHub OAuth, or by commenting on the issue directly.

## Gotchas

- Every commenter needs a GitHub account, which suits developer audiences and shuts out most others.
- If the repository is a fork, you must turn on the issues feature in its settings first.
- Labels you ask Utterances to attach must already exist in the repository; it cannot create them.

## Questions people ask

### Is Utterances free?

Yes. The site says it is always free, with no tracking and no ads.

### Do I have to host Utterances myself?

No. You add a script tag from utteranc.es and install the utterances GitHub app on your repository; the comments are stored as GitHub issues.

### Can readers comment without a GitHub account?

No. Readers authorize the utterances app with GitHub OAuth, or comment on the GitHub issue directly.
