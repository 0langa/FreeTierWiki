Budibase is an open source platform for building internal apps, automations, and AI agents on top of your data. You can self-host it for free or use Budibase Cloud. This entry covers Budibase Cloud, which offers a trial rather than a free plan.

## What the free plan gives you

Budibase Cloud has no always-free plan. Each cloud plan starts with a 14-day free trial. The smallest plan, Pro, costs $19 per month and includes 2K Budibase AI credits, 1 creator, 1 workspace, 1 day of logs, unlimited agents, and synchronous automations. Pro allows 50,000 Budibase DB rows, unlimited datasources, and unlimited end users through an add-on.

Usage is measured in actions: an agent step, an automation node run, or saving or deleting a row. Custom SQL queries and API requests are not counted as actions. Budibase also offers a fully open source self-hosted plan that is free to use indefinitely.

## When you hit a limit

Budibase says actions are hard monthly limits based on your plan. When you reach the limit, you need to move to a higher tier to continue running agents and automations. Budibase chose hard limits over overage billing so costs stay predictable.

The pricing page does not say what happens when the 14-day trial ends, or whether the trial asks for a card.

## Gotchas

- There is no free hosted plan; after the trial, staying free means self-hosting.
- Pro includes 0 end users; each end user is an add-on at $5 per user per month on yearly billing.
- Pro keeps automation and agent logs for 1 day only.

## Questions people ask

### Is Budibase free?

The self-hosted open source edition is free to use indefinitely. Budibase Cloud is paid, with a 14-day free trial.

### Are Budibase actions a hard limit?

Yes. Actions are hard monthly limits, and when you reach yours you need a higher tier to keep running agents and automations.

### Do API requests count as Budibase actions?

No. Custom SQL queries and API requests are not counted as actions.
