You sign in with your Git host, import a repository, and read the findings on the Codeac dashboard and in pull requests. It suits maintainers of public repositories, including ones full of Terraform or Ansible files.

## What the free plan gives you

The Open-source plan costs $0 and is free forever. It covers unlimited public repositories. Private repositories are not part of it. The pricing page says to get started for free with an easy setup and no credit card.

Codeac finds static analysis issues, code duplication, and possible security vulnerabilities in every commit. The docs list tool setups for ESLint, Pylint, RuboCop, PMD, and more. For infrastructure-as-code, they list Ansible Linter, CloudFormation Linter, and TFSec. The docs also describe pull request analysis, code coverage thresholds, and Autofix. Supported Git servers are GitHub, Bitbucket, and GitLab.

## When you hit a limit

The free plan has no usage cap on public repositories. The line is private code. For that, you need the Pro plan, which costs $21 per user per month when billed annually, or $25 per user per month when billed monthly. The annual price is 16% lower. The Pro plan includes unlimited private repositories and priority support.

The Pro plan has a 14-day free trial with no credit card. The pricing page does not say what happens to a private repository on the free plan, so plan to switch to Pro before you add one.

## Gotchas

- You need admin rights on a repository the first time you add it, because Codeac registers a webhook there. After that, anyone with read access can see it.
- Codeac says it will not make changes to your code or repository without your consent.
- Codeac announced that its default TypeScript analysis moved from TSLint to ESLint, so old TSLint settings may need a check.

## Questions people ask

### Is Codeac free?

Yes, for public repositories. The Open-source plan costs $0 forever and covers unlimited public repositories. Private repositories need the Pro plan.

### How much is Codeac for private repositories?

The Pro plan costs $21 per user per month billed annually, or $25 billed monthly. It includes unlimited private repositories.

### Does Codeac need a credit card?

No. The pricing page says to get started for free with no credit card, and the 14-day trial of Pro needs none either.
