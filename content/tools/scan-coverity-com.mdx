You register your project on scan.coverity.com, build it with Coverity's software on your own machine, and upload the build. Scan then analyzes it in Black Duck's service and shows the defects. It suits maintainers of open source code.

## What the free plan gives you

Coverity Scan is free for registered open source projects. Black Duck offers the analysis results at no charge to registered open source developers. The service finds defects in Java, C/C++, C#, JavaScript, Ruby, and Python code. Examples include resource leaks, NULL pointer dereferences, incorrect API use, use of uninitialized data, and memory corruption.

The number of builds you can submit each week depends on project size. A project under 100K lines of code can submit up to 28 builds per week, with 4 per day. A project of 100K to 500K lines gets 21 per week, and 500K to 1 million lines gets 14. A project over 1 million lines gets 7 per week, with 1 per day.

## When you hit a limit

Once a project reaches the maximum builds per week, Scan rejects extra build requests. You can submit the build again the following week. The FAQ asks you to email Scan if you have special requirements.

There is no bill, because the service is free for approved open source projects. The API request that uploads a build has a 500MB limit, and a separate endpoint handles larger builds. Scan is only for registered open source projects. For closed-source code, the FAQ points you to Black Duck sales.

## Gotchas

- Projects must meet an open source definition based on the Open Source Initiative. Projects run by for-profit companies may still be approved at Black Duck's discretion.
- Access to detailed results is usually limited to approved project members, so defects can be fixed before the public sees them. Black Duck may set a date to publish full results.
- You run the build yourself with Coverity's software. Scan analyzes what you upload, so it does not scan your repository on its own.

## Questions people ask

### Is Coverity Scan free?

Yes, for registered open source projects. Black Duck provides the analysis results at no charge to registered open source developers.

### How many builds can I submit to Coverity Scan?

It depends on code size. A project under 100K lines gets up to 28 builds per week, and a project over 1 million lines gets up to 7.

### Can I use Coverity Scan for private code?

No. Scan is only for open source projects registered with the service. For a non-open-source codebase, the FAQ points you to Black Duck sales.
