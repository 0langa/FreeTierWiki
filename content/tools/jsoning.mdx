JSONing provides open-source software for mocking REST APIs from JSON resources. You can run the official project locally, control its test data, and simulate errors before your real backend exists. A hosted read-only sample endpoint is also available, and the Mock API page can build a custom hosted API from your resources and rules.

## What the free plan gives you

The official JSONing API repository provides the source under the MIT license. Its README describes local installation, JSON resource configuration, CRUD routes, pagination, and custom response rules. Rules match a request's method, path, headers, or payload and adjust the response status, headers, or body.

The Mock API page says you can also create a custom API online by entering resources and rules in its editors, and that it is available immediately. It does not mention an account or a fee. The generator page returned a server error in the earlier review and loads now; creating an API there was not tested.

The hosted public products endpoint returns sample JSON without authentication. It is read-only, so use the local version when tests need to create or modify data.

## When you hit a limit

There is no numeric hosted request allowance. The Mock API page asks you to limit the number of your calls and to create a local API otherwise. It also says hosted custom APIs are deleted once a day, and that you can return to the page to recreate yours.

A local installation uses your own machine's resources and lifecycle. Keep fixtures under your control and reset the mock as tests require. Neither the page nor the repository gives a hosted uptime promise or a billing policy, and no strict hosted cap is confirmed here.

## Gotchas

- Hosted custom APIs are deleted once a day, so keep the resources and rules you paste in somewhere you control.
- A public demo cannot hold changing test state. Keep private fixtures and credentials out of public requests.
- Mock responses test frontend assumptions; they do not prove that the eventual production backend behaves identically.

## Questions people ask

### Is JSONing free?

The official mock API source is available under the MIT license. The public read-only products endpoint is accessible without authentication.

### Can I create a hosted custom API?

The Mock API page says you can, with resources and rules entered in its editors, and that the API is available immediately. It is deleted once a day and can be recreated on the page.

### Does JSONing publish a request limit?

No numeric hosted quota is published. The page asks you to limit your calls, so run the open-source mock locally for repeatable or heavier tests.
