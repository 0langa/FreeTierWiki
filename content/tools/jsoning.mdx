You use JSONing in the browser. Paste JSON, and the page gives you a working endpoint you can call from any front end, script, or test. You can also download the open-source API from GitHub and run it on your own machine.

## What the free plan gives you

JSONing is free and open source. You can create a custom API online with no account. Define your resources as a JSON object, and the API is immediately available with routes to list, read, create, update, and delete items.

A rule engine lets you set the HTTP status, headers, and body for requests that match a method, path, headers, or payload. For example, a rule can return a 401 for one path.

A free public API is also open for testing. It is read-only and holds sample data: 10 products, 5 carts, 5 users, and 5 coupons. A status route simulates HTTP status codes.

## When you hit a limit

JSONing publishes no request quota. The page says that APIs are deleted once a day, and you can return to the page to recreate yours. It also asks you to limit your calls and to create a local API if you need more.

The hosted version has no account, so no bill can arrive. Heavy use is a reason to move to the local version, which you get from the source code on GitHub.

## Gotchas

- Custom APIs are wiped once a day, so keep your JSON and rules somewhere safe and paste them back to recreate the API.
- The public demo API is read-only. You cannot change its data.
- Rules run before the API reads, writes, or deletes data. If several rules match, only the first one runs, and a rule can override the API response.
