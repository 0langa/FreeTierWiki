JSONing provides a free, open-source mock/fake API generator plus JSON utility tools (formatter, validator, JSONPath, and more). Custom mock APIs are live instantly with no signup, but their data is wiped once a day — great for prototyping and testing, not for real data persistence. The source is on GitHub for anyone who wants a permanent, self-hosted copy.
