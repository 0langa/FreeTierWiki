JDoodle runs code in the browser for many languages, and offers the same engine as a Compiler API you can call from your own app. Students and teachers use the IDE for practice and assessments; developers use the API to add a run-code feature to a course, quiz, or docs site.

## What the free plan gives you

The free platform plan costs US$0 and needs no credit card. Signing up gives 1,000 code executions per day across 114 languages, frameworks, and databases, 100 saved projects, a standard workspace, 15 AI credits daily up to 30 a month, 3 collaborators per project, unlimited embedded IDEs, and unlimited students, assessments, and questions.

The Compiler API is a separate subscription. Its Free tier gives 20 credits a day, and every tier includes the REST API, WebSocket, and all 114 languages. One run costs one credit, while checking your balance and listing languages are free. A free platform account can hold any API tier.

## When you hit a limit

API credit counts reset at midnight UTC. A WebSocket connection, uploading a multi-file project, and giving code internet access each add one credit, though the free tier has no internet access. The pricing page does not say exactly what an API call returns once the day's credits are gone.

If you need more API runs, the Starter tier is $10 a month for 1,000 credits a day. Without signing in, the IDE allows a limited number of runs per session; signing up lifts that to 1,000 a day.

## Gotchas

- The free API tier allows 20 runs a day, which suits building and testing an integration but not a public feature with real traffic.
- Opening a WebSocket costs an extra credit for the token, so the interactive API uses the free allowance faster.
- The free API tier cannot give running code internet access, so programs that fetch URLs fail there.

## Questions people ask

### Is JDoodle free?

Yes. The free plan gives 1,000 code executions per day in the IDE, and the Compiler API has a free tier of 20 credits a day. The pricing page says the free plan is not a trial and does not expire.

### How many free JDoodle API calls do I get?

20 credits a day on the free tier. Each code run costs one credit, and counts reset at midnight UTC.

### Do I need a credit card for JDoodle?

No. The pricing page says the free plan does not need a card.
