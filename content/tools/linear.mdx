You use Linear in its web and desktop apps, with a GitHub integration, an API, and webhooks. It suits small software teams who want a fast, focused tracker and a short backlog.

## What the free plan gives you

The Free plan costs $0 and the pricing page says it is free for everyone. It has unlimited members, 2 teams, 250 issues, and a 10MB limit on file uploads. The core product covers issues, projects, cycles, and initiatives. Linear's docs also describe GitHub integration features such as pull request linking, commit linking with magic words, and issue status automation.

On free plans, every user is an Admin of the workspace. Linear's other features, such as customer requests, API and webhook access, and sub-initiatives, are listed in the plan comparison, but the text version of the table does not show which plan has each one, so check the pricing page before you rely on them.

## When you hit a limit

The cap is 250 issues. The billing docs say that if you cancel a paid plan and have over 250 issues, nothing is deleted, but you can no longer create new issues. The pricing page does not spell out what you see when you reach the cap on Free. The next step is the Basic plan at $10 per user per month, which has 5 teams, unlimited issues, unlimited file uploads, and admin roles. The Free plan does not ask for a card.

## Gotchas

- The issue cap is 250, so a busy project fills the free plan quickly.
- Everyone is an admin on a free workspace, because roles are a paid feature.
- Private teams and guests start at the Business plan, which costs $16 per user per month.

## Questions people ask

### Is Linear free?

Yes. The Free plan is $0 with unlimited members, 2 teams, and 250 issues. Basic costs $10 per user per month.

### What happens when I reach 250 issues in Linear?

The pricing page lists 250 issues as the free cap and Basic as the plan with unlimited issues. Billing docs say that over 250 issues you cannot create new ones, and nothing is deleted.

### Does Linear need a credit card?

Not for the free plan. You create a workspace with your work email, and billing starts only if you upgrade.
