You connect repositories in the GitGuardian web dashboard and review incidents there. The open-source ggshield command-line tool runs locally, in CI, or as a pre-commit hook. It suits developers and small security teams.

## What the free plan gives you

The Starter plan costs $0 and is free always, with no credit card required. It includes internal secrets monitoring for up to 25 developers. You get unlimited real-time scanning and up to 500 historical scan detections. The pricing page also lists 10K API calls per month. Its API FAQ specifies a rolling month rather than a calendar-month reset.

The comparison table lists a repository scanning capacity of 1 GB on Starter, against 12 GB on Growth and 60 GB on Enterprise. Starter has limited ggshield CLI and pre-commit hook support. The current plan guide excludes endpoint scanning from Starter. Growth and Enterprise include endpoints up to the paid seat count; endpoints beyond that are add-ons.

## When you hit a limit

The plan guide says exceeding 25 contributing developers automatically starts a trial if available. If that trial has already been redeemed and expired, business repositories are no longer monitored; upgrading is required to restore that coverage. A contributor has authored a commit to a counted business repository within the last 90 days. Public and individual-account GitHub repositories do not count toward this developer limit.

The pricing page lists no Starter overage tariff. Exact handling of the historical-detection and API-call allowances is not separately stated here. Check Plan & usage in the workspace for your contributor count, plan, and remaining allowances.

## Gotchas

- Repository scanning capacity is 1 GB on Starter, so a very large repo may need a paid plan.
- ggshield sends files to the GitGuardian public API for scanning. The docs say only metadata is stored, and incidents from a ggshield scan do not show in your dashboard.
- Public secrets monitoring is limited on Growth and unlimited only on Enterprise, so the free plan does not watch public GitHub for your leaks.

## Questions people ask

### Is GitGuardian free?

Yes. The Starter plan is free always, with no credit card required, for up to 25 developers. It includes unlimited real-time scanning and up to 500 historical scan detections.

### Is ggshield free to use?

ggshield is open source. The docs say it works on macOS, Linux, and Windows, and it needs a GitGuardian API key to authenticate. The pricing page says Starter has limited CLI support.

### How big a repository can GitGuardian scan on the free plan?

The comparison table lists a repository scanning capacity of 1 GB on Starter. Growth lists 12 GB and Enterprise lists 60 GB.
