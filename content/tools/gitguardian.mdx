You connect repositories in the GitGuardian web dashboard and review incidents there. The open-source ggshield command-line tool runs locally, in CI, or as a pre-commit hook. It suits developers and small security teams.

## What the free plan gives you

The Starter plan costs $0 and is free always, with no credit card required. It includes internal secrets monitoring for up to 25 developers. You get unlimited real-time scanning and up to 500 historical scan detections. The scan API allowance is 10,000 calls per workspace in a rolling month. A call to the single-document scan or the multi-scan endpoint uses one unit.

The comparison table lists a repository scanning capacity of 1 GB on Starter, against 12 GB on Growth and 60 GB on Enterprise. Starter has limited ggshield CLI and pre-commit hook support. The current plan guide excludes endpoint scanning from Starter. Growth and Enterprise include endpoints up to the paid seat count; endpoints beyond that are add-ons.

## When you hit a limit

Exceeding 25 contributing developers starts a trial if available. If the trial has already expired, business repositories lose monitoring until you upgrade. A contributor has authored a commit to a counted business repository in the last 90 days. Public and individual-account GitHub repositories do not count.

At the scan quota, all workspace keys stop processing scans. Each used call returns to the allowance after 30 days. Free personal access tokens also have a 50-request-per-minute limit, which returns HTTP 429. Pricing gives no Starter overage tariff or exact handling at the historical-detection cap.

## Gotchas

- Repository scanning capacity is 1 GB on Starter, with a separate maximum scanned file size of 1 MB. Free workspaces allow up to five personal access tokens.
- ggshield sends data to the GitGuardian API for scanning. GitGuardian SaaS logs each secret detection and quota and access metadata. Scan API requests do not create workspace incidents.
- Public secrets monitoring is limited on Growth and unlimited only on Enterprise, so the free plan does not watch public GitHub for your leaks.

## Questions people ask

### Is GitGuardian free?

Yes. The Starter plan is free always, with no credit card required, for up to 25 developers. It includes unlimited real-time scanning and up to 500 historical scan detections.

### Is ggshield free to use?

ggshield is open source. The docs say it works on macOS, Linux, and Windows, and it needs a GitGuardian API key to authenticate. The pricing page says Starter has limited CLI support.

### How big a repository can GitGuardian scan on the free plan?

The comparison table lists a repository scanning capacity of 1 GB on Starter. Growth lists 12 GB and Enterprise lists 60 GB.
