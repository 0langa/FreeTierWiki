You get a key from the dashboard, then call one GET endpoint from any language. It suits developers who need a quick location lookup in a web app, a back end, or a script.

## What the free plan gives you

The free plan gives you 1,000 requests a month at 1 request per second. It returns the full API response, the same fields that paid plans return, such as location, timezone, flag, currency, and ASN. No credit card is needed to start.

Abstract says its database covers more than 4 billion IPv4 and IPv6 addresses and refreshes daily. Paid plans start at $17 a month and raise the rate limit to 3 requests per second. The free plan has no uptime SLA; the page ties the 99.99% SLA to Enterprise plans.

## When you hit a limit

The docs list two errors for free plans. A 422 error means the request stopped because you ran out of credits. A 429 error means you sent more than the allowed requests per second, which is 1 per second on free plans. Your code should wait and retry after a 429.

The pricing page does not say whether a free account is billed for extra requests. No card is on file for a free account, so the practical result is that calls fail until the next month.

## Gotchas

- IP location points to a network, not a person. VPNs, proxies, and mobile networks make results less exact, so check the flags in the response.
- The API key is per API. A key from the IP API does not work for Abstract's email or phone APIs.
- Old logs give you where an address resolves today, not where it resolved when you logged it.

## Questions people ask

### Is the Abstract IP Geolocation API free?

Yes, within limits. The free plan gives you 1,000 requests a month with the full response and needs no credit card.

### What happens when I go over the free IP Geolocation API limit?

The docs say a request fails with a 422 error when you run out of credits. A 429 error means you passed 1 request per second.

### Does the IP Geolocation API need a credit card?

No. The page says no credit card is required to get a free API key.
