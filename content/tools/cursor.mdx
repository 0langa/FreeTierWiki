You use Cursor as a desktop app, and you can also run the agent from a CLI. It suits developers who want to try an agent-first editor before they pay.

## What the free plan gives you

The Hobby plan is free, and the pricing page says no credit card is required. It lists two things: limited Agent requests, and access to Composer, which is Cursor's own model. That is all the page says about the free plan.

The page does not publish a number for the Agent limit. You cannot tell in advance how many requests you get. Treat the plan as a way to try the editor, not as a daily work tool.

Paid plans start at $20 per month. They add extended Agent limits, generous limits for Grok, and access to frontier models. The pricing page calls Hobby the plan for the tinkerer and the paid plan the one for the agent-curious.

## When you hit a limit

The pricing page does not say what happens when Hobby Agent requests run out. The Cursor docs describe the limit behavior only for paid plans. On those plans, you can add on-demand usage billed monthly, or move to a higher tier.

Hobby has no card on file, so the docs give no sign of an automatic bill. Because the exact Hobby behavior is not written down, the safest plan is to check your usage dashboard in the editor settings.

## Gotchas

- The pricing page gives no exact numbers for Hobby Agent requests, so limits may feel different from week to week.
- On-demand usage and extended limits are paid features, not part of Hobby.
- The docs say every plan has a set amount of model usage, and any extra usage is billed in arrears on plans that allow it.

## Questions people ask

### Is Cursor free?

Yes, there is a free Hobby plan. It includes limited Agent requests and access to Composer, and it needs no credit card.

### How many requests does the Cursor free plan include?

The pricing page does not say. It only calls the Agent requests limited.

### What happens when I go over the Cursor Hobby limit?

The pricing page does not say. On paid plans, the docs say you can add on-demand usage or upgrade to a higher plan.
