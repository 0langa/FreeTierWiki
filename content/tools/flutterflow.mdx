FlutterFlow Studio is the visual builder for laying out screens, adding logic, and connecting Firebase or Supabase. FlutterFlow also offers a separate builder that creates apps from prompts. Both use the same account and subscription.

## What the free plan gives you

The Free plan is for building and testing your app and costs $0. It includes the visual development environment, 1,000+ prebuilt templates, API and data integration, and web publishing. You can have up to 2 projects and up to 2 API endpoints, with Firebase and Supabase integration.

The free agent allowance is shared across FlutterFlow and Studio and shown as a percentage. FlutterFlow includes one free first build and then renews the agent allowance every seven days. Web publishing allows two custom FlutterFlow subdomains, with project-generated URLs excluded from that count. Free has 1 editor, the main branch only, and automated snapshot backups up to 1 hour prior. Code download, APK download, and a custom domain start on Basic at $39 per month.

## When you hit a limit

Studio limits Free accounts to two active projects and archives other projects when you downgrade. You can restore them by upgrading. When the AI allowance runs out, FlutterFlow saves your work and pauses new agent work and pushes until the next weekly renewal or an upgrade. Basic allows unlimited Studio projects, and Pro and Max sell AI refills. Students and educators at colleges and universities can apply for a free year of Studio.

## Gotchas

- You cannot download the generated Flutter code or an APK on Free, so the app stays inside FlutterFlow until you pay.
- The size of the free AI allowance is not published, so do not plan around a fixed number of AI requests.
- One-click app store deployment and the Local Run desktop emulator need Basic or higher.

## Questions people ask

### Is FlutterFlow free?

Yes. The Free plan lets you build and test apps with up to 2 projects and publish web apps on up to 2 free subdomains.

### Can I export my code on FlutterFlow's Free plan?

No. Code download and APK download start on the Basic plan at $39 per month.

### How many AI requests does FlutterFlow Free include?

FlutterFlow gives one free first build and a shared AI allowance that renews every seven days. You can see the percentage remaining. FlutterFlow gives no fixed request count.
