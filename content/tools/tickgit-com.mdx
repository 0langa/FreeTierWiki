You use the hosted site in a browser for a repository you pick, or run the open source `tickgit` command in a terminal. The project is built mainly for software engineers.

## What the free plan gives you

Public repositories are free, and you do not need to log in. The site shows an example, and you can try a repository of your own by entering it.

For private repositories, the site charges $3 per month and offers a 3 day free trial. You sign in with GitHub to start. The page does not mention a credit card, and it does not describe how billing starts.

Tickgit scans a codebase for TODO items in comments. It reports where each TODO is, and it uses git history to show how long ago it was added and by whom. The authors say the tool does not replace project tools such as Jira or Trello. It adds a way to keep work next to the code.

## When you hit a limit

The site lists no usage limit, so there is nothing to hit on public repositories. The line is private versus public. The pricing text does not say what happens when the 3 day trial ends beyond the $3 per month price.

The site also does not say what happens to a private repository if you do not pay. The command line tool is separate and can scan a local folder on your own machine.

## Gotchas

- Only TODO comments are matched. The README lists FIXME, XXX, HACK, and custom phrases as not done yet.
- The private repository trial starts with Login with GitHub.
- The home page and the README are the only sources of detail, so check the home page before you rely on a feature.

## Questions people ask

### Is Tickgit free?

For public repositories, yes. They are free with no login. Private repositories cost $3 per month after a 3 day free trial.

### What does Tickgit scan for?

TODO comments in a codebase. The README says FIXME, XXX, HACK, and custom phrases are planned.

### Can I run Tickgit on my own machine?

Yes. The project has an open source command line tool you can install with Homebrew and run on a local folder.
