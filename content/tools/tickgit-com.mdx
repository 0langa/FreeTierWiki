Tickgit offers a hosted scanner and documents a separate open-source `tickgit` command for local repositories.

## What the free plan gives you

Tickgit advertises free scans for public repositories without login. Its React and Kubernetes examples both returned a network error on November 15, 2026, so current hosted availability is unconfirmed.

The homepage advertises private repository scans for $3 per month after a three-day trial and links to GitHub sign-in. It does not say whether the trial needs a card or how billing starts.

Tickgit scans a codebase for TODO items in comments. It reports where each TODO is, and it uses git history to show how long ago it was added and by whom. The authors say the tool does not replace project tools such as Jira or Trello. It adds a way to keep work next to the code.

## When you hit a limit

The site publishes no public-repository usage allowance or enforcement rule. No login is needed for that free public route; this does not promise unlimited throughput. The line is private versus public. The pricing text does not say what happens when the 3 day trial ends beyond the $3 per month price.

The site also does not say what happens to a private repository if you do not pay. The command line tool is separate and can scan a local folder on your own machine.

## Gotchas

- Only TODO comments are matched. The README lists FIXME, XXX, HACK, and custom phrases as not done yet.
- The private repository trial starts with Login with GitHub.
- The README documents how to scan a local folder with the open-source CLI.

TODO comments in a codebase. The README says FIXME, XXX, HACK, and custom phrases are planned.

### Can I run Tickgit on my own machine?

Yes. The project has an open source command line tool you can install with Homebrew and run on a local folder.
