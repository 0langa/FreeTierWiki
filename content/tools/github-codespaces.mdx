You start a codespace from a repository page on GitHub and work in the browser version of VS Code. You can also connect from VS Code on your computer or from the GitHub CLI. It suits students, contributors, and anyone who wants a quick ready-made setup.

## What the free plan gives you

All personal GitHub accounts include free Codespaces usage each month. On GitHub Free, that is 120 hours of compute and 15 GB-month of storage. GitHub Pro raises this to 180 hours and 20 GB-month.

The compute hours scale with the machine size. A 2-core machine uses 2 included hours for each hour, so the quota lasts half as many real hours on a 2-core machine. A 4-core machine uses it twice as fast again. Your included compute resets at the start of each billing cycle.

Organization and enterprise plans do not include a free quota.

## When you hit a limit

If your account has no valid payment method, usage is blocked once you use up the quota. If you cannot resume a codespace, you can export your changes to a branch, add a payment method, or wait for the next billing cycle.

With a payment method on file, usage above the quota is billed to your account. Compute starts at $0.18 per hour for a 2-core machine, and storage costs $0.07 per GB-month. You can set a budget to control spending.

## Gotchas

- A codespace that stays running is billed for the time it was active, even if you were not using it. It stops after 30 minutes of inactivity by default, and you can set between 5 and 240 minutes.
- A codespace has a maximum lifetime of 12 hours, whatever your idle timeout.
- Storage keeps counting while a codespace exists, so delete codespaces you no longer need.

## Questions people ask

### Is GitHub Codespaces free?

Yes, for personal accounts, within a monthly quota. GitHub Free includes 120 hours of compute and 15 GB-month of storage.

### Does GitHub Codespaces need a credit card?

Not for the free quota. Without a payment method, usage is blocked when the quota runs out. With one, extra usage is billed.

### What happens when my Codespaces hours run out?

Usage is blocked if you have no payment method. You can export your changes to a branch, add a payment method, or wait for the quota to reset.
