You sign up on the website, copy a token from the dashboard, and send GET requests with `curl` or any HTTP client. There is also an MCP server for AI agents. It suits developers who need to decode a VIN or look up a vehicle in a prototype.

## What the free plan gives you

The Free plan gives you 100 requests per month and access to all API endpoints. The paid plans differ only in volume: Starter has 5,000 requests a month for 29 EUR, Professional has 25,000 for 89 EUR, and Business has 100,000 for 249 EUR.

The site lists 16 endpoints with US and EU coverage. They include VIN decode, plate to VIN, stolen vehicle check, vehicle inspection records, listings, photos, valuation, mileage history, recalls, and EV charging stations. The docs also list OCR endpoints that read a VIN or a license plate from a photo.

## When you hit a limit

The API answers with HTTP status 429 and the code `quota_exceeded` when you use up your monthly quota. The message includes a reset date, and the response headers `X-RateLimit-Remaining` and `X-RateLimit-Reset` let you track usage.

The pricing page lists no overage fee. The free plan stops at the quota instead of billing you. To get more requests before the reset, pick one of the paid plans.

## Gotchas

- The 100 requests are shared across all endpoints, so a few VIN decodes and photo lookups use up the month fast.
- The example request in the docs puts your key in a `token` query parameter, so keep calls on your server and out of front-end code.
- Some endpoints cover only some regions. Recalls cover U.S. records, and inspection records come from European countries.

## Questions people ask

### Is CarAPI.dev free?

Yes, within limits. The Free plan gives you 100 requests a month to all endpoints. Paid plans start at 29 EUR a month for 5,000 requests.

### What happens when I go over the CarAPI.dev free limit?

The API returns a 429 status with the code `quota_exceeded` and the date your quota resets. The pricing page lists no overage fee.

### Does CarAPI.dev have an MCP server?

The docs list an MCP Server page and an AI Agents page, and the home page says the API is MCP-ready.
