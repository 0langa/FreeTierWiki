You sign up, copy a private API key from your dashboard, and call REST endpoints such as realtime and forecast from your own code. It suits developers who build weather widgets, single-location alerts, or small dashboards.

## What the free plan gives you

The Free plan is for individuals or teams just getting started. It includes a 5-day forecast, weather timelines and trendlines, core weather data layers, and industry-based insight templates. It also gives you 24 hours of historical weather data, 1 automatically monitored location, and 1 weather-based alert.

The plan also limits how many requests you can make per day, per hour, and per second. The provider's support article on free plan rate limits holds the figures, but this check could not open it. Look up your exact limits there or in your dashboard before you build on them.

The pricing page does not state a card requirement or a price for the Free plan.

## When you hit a limit

The docs say each plan has a request limit per hour and per day. When you pass it, the API answers with a 429 error. Only Enterprise accounts get headers that show the remaining limit, so on the free plan you must count your own calls.

Each API key has its own rate limits. If you need a higher limit, the docs tell you to contact the provider. The pages show no pay-as-you-go charge for the free plan, so going over means failed requests, not a bill.

## Gotchas

- Your API key has full privileges. Keep it on a server and do not put it in browser code.
- A request without a valid key returns a 403 error.
- The free plan watches one location and sends one alert. More locations and alerts need a paid plan.

## Questions people ask

### Is Tomorrow.io Weather API free?

Yes, there is a Free plan. It gives a 5-day forecast, core data layers, 24 hours of history, 1 monitored location, and 1 alert.

### What happens when I go over the Tomorrow.io free limit?

You get a 429 error until your limit window passes. The docs say to contact the provider if you need a higher limit.

### Does Tomorrow.io Weather API need a credit card?

The pricing page does not say. You sign up for an account and take an API key from your dashboard.
