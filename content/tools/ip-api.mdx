You call the API with a plain HTTP GET or POST from a script, a browser, or `curl`. There is no sign-up and no key for the free endpoint. It suits hobby projects and learning, but not commercial sites.

## What the free plan gives you

The free endpoint needs no API key and no registration. The site says it will never require either. It allows 45 HTTP requests per minute from one IP address. You can pass an IP, a domain name, or nothing, in which case the API uses your own address.

A response can hold country, region, city, zip code, latitude, longitude, timezone, currency, ISP, organization, AS number, and flags for mobile, proxy, and hosting. The `fields` parameter limits what comes back. The batch endpoint takes up to 100 addresses in one POST request.

## When you hit a limit

If you pass 45 requests per minute, the API throttles you with HTTP 429 until the rate window resets. The terms add that your access is blocked for a while. Repeated overages can get your IP address banned for up to 1 hour.

The site sells a pro service for unlimited queries, SSL, and commercial use. The free endpoint never bills you.

## Gotchas

- The free endpoint is HTTP only. SSL access is part of the pro service.
- Commercial use is not allowed on the free endpoint. The terms name local currency for a shop, geo-targeted ads, and fraud prevention for orders as forbidden uses.
- Browser pages served over HTTPS may block calls to a plain HTTP endpoint, so call it from your server.

## Questions people ask

### Is ip-api free?

Yes, for non-commercial use. The free endpoint needs no API key and allows 45 requests per minute from one IP address.

### Can I use ip-api on a commercial website?

No. The terms limit the free endpoint to non-commercial use. Commercial use needs a pro subscription.

### Does the ip-api free endpoint support HTTPS?

No. The free endpoint runs over HTTP. The pro service adds SSL access.
