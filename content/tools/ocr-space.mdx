You can try it with no account in the web form on the home page. For code, register for a free key and send files to the POST endpoint, or pass a file URL in a GET request. This page covers the free API key.


## What the free plan gives you

The free API plan allows 25,000 requests per month. Each file can be up to 1MB, and a PDF can have up to 3 pages. The paid PRO plan raises the file limit to 5MB.

OCR Engine 3 is the newest engine and has its own quota. The free plan includes 1,000 Engine 3 conversions on top of the monthly requests for Engine 1 and 2. Engine 1 is deprecated, so use Engine 2 or 3.

The free web form on the home page needs no registration. It accepts files up to 5MB. The site says this form is for hands-on use, not for scraping.

## When you hit a limit

The free plan has a rate limit of 500 requests per day per IP address. The site says this stops accidental spamming. PRO plans do not have that limit.

The site warns that someone could use up all your free conversions if they find your key. It suggests the POST version of the API for that reason. The pages do not say what happens after you use the monthly quota, and they list no overage price for the free plan.

## Gotchas

- The free API key needs registration. If someone finds your key, they can use up your free conversions, so keep it out of public code.
- Engine 3 gives the best accuracy, including handwriting and tables, but it is slower on larger files and has the smaller quota.
- The free file limit is 1MB through the API, but the web form accepts 5MB. Do not test with the form and expect the same result from the API.

## Questions people ask

### Is OCR.Space free?

Yes. The free API plan gives you 25,000 requests per month, and the web form needs no registration. Paid PRO plans start at $30 per month.

### What is the OCR.Space free file size limit?

The free API takes files up to 1MB and PDFs up to 3 pages. The free web form allows 5MB per document.

### What is the OCR.Space daily limit?

The free plan allows 500 requests per day per IP address. PRO plans do not have this daily limit.
