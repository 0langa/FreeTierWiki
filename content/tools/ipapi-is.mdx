You call `api.ipapi.is` over HTTP from any language, with an optional API key. It suits developers who want one lookup that mixes location with security flags.

## What the free plan gives you

The Free plan costs $0 and allows 1,000 requests per day, every day. It is not a trial. You get the full API output, the same as every paid plan, and commercial use is allowed for products, SaaS, plugins, and client work. You need a free account and an API key, but no payment details.

Each response can include the ASN, the owning company, a location with a time zone, and flags for datacenter, Tor, proxy, VPN, and abuse. The free key also unlocks bulk lookups and ASN queries.

Without a key the API still answers, but the pricing page says only 30 requests a day, and with a minimal response of ownership and location. The developer docs give 100 lookups per client IP per UTC day for keyless use, so treat that mode as a quick test.

## When you hit a limit

With a key, going over the daily quota returns HTTP 429 with the code ERR_QUOTA_EXCEEDED. You are not billed for the free plan. The quota resets daily.

Keyless clients get HTTP 429 with ERR_FREE_TIER_EXHAUSTED and a Retry-After header. A client that ignores 50 of these notices is blocked at the firewall for 12 hours.

If you need more, you can buy one-time credits, with every dollar giving 30,000 requests, and they never expire. Subscriptions start at $20 a month for 20,000 requests a day. Each day, your free 1,000 requests are spent first.

## Gotchas

- Only one free account per person or company is allowed. Making several accounts to multiply the quota breaks the terms.
- A bulk request costs one lookup for each address it resolves, not one lookup for the request, and it holds at most 100 unique entries.
- The pricing page and the developer docs give different keyless limits, so always send a key from production code.

## Questions people ask

### Is ipapi.is free?

Yes. The Free plan gives 1,000 requests a day with a free account and API key. It includes the full output and allows commercial use.

### What happens when I go over the ipapi.is limit?

The API returns HTTP 429 until the next day. Paid options are one-time credits that never expire, or a monthly subscription.

### Does ipapi.is need a credit card?

No. The pricing page says no payment details are needed for the Free plan. You do need a free account and API key for the full response.
