You push result files from your CI job with the Testspace client, and read them on a dashboard. Manual tests are Markdown files you can keep in your repository.

## What the free plan gives you

The Free plan costs $0 per month and is meant for open source. It runs on a GitHub personal account and gives unlimited public projects and 200 sessions. You sign up through the GitHub Marketplace.

A session is a published collection of test cases in a single result record. For example, one CI run is one session. The docs say Testspace also merges results from parallel jobs in the same run.

The Basic plan costs $32 per month and has 4 users, 2 private projects, unlimited public projects, and 200 sessions. Premium costs $120 per month with 20 users and unlimited projects. Both have a 14 day free trial. Enterprise has custom pricing and unlimited sessions.

## When you hit a limit

The pricing page does not say what happens when you pass 200 sessions. It lists unlimited sessions only for the Enterprise plan, so a busy project may need to move up. Each CI run counts as one session, so a busy repository can reach the cap.

The pricing FAQ also says accounts that generate over 1 million test cases a month need an Enterprise account. For very high volume open source, it points to open enterprise accounts through contact.

## Gotchas

- Private projects are not part of Free. Basic is the first plan with private projects.
- The pricing page lists a GitHub personal account for the Free plan. It does not list a GitHub organization.
- You can cancel at any time. The pricing page says mid-month changes are prorated.

## Questions people ask

### Is Testspace free?

Yes, for open source. The Free plan gives unlimited public projects and 200 sessions on a GitHub personal account.

### What is a Testspace session?

A session is a published collection of test cases in one result record. A single CI run is one session.

### Does Testspace support private projects?

Not on Free. The Basic plan costs $32 per month and includes 2 private projects and 4 users.
