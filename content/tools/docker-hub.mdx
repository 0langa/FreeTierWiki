You use Docker Hub through the website, Docker Desktop, or the `docker` command line. Pull images to run them, and push your own images to a repository to share them. It suits solo developers, open-source maintainers, and small teams.

## What the free plan gives you

Docker Personal costs $0. The usage docs list a pull rate limit of 200 per 6 hours for a logged-in Personal user, unlimited public repositories, and up to 1 private repository. The pricing page also lists 1 Docker Scout-enabled repo.

Without logging in you can pull, but the limit is 100 per 6 hours for each IPv4 address or IPv6 /64 subnet. The pricing page words the Personal pull limit as 100 pulls per hour, which differs from the docs. This entry uses the docs, because they spell out the 6-hour window.

A pull of a multi-arch image counts as one pull for each architecture.

## When you hit a limit

When you pass the pull rate limit, the pull fails with a message that you have reached your pull rate limit. The message says you can raise the limit by authenticating and upgrading. The pull rate limit is calculated over 6 hours.

Docker also has an abuse rate limit that applies to every account level equally. It is in the order of thousands of requests per minute. Docker says excessive pulls, data transfer, or storage can lead to throttling or extra charges under its fair use rules.

## Gotchas

- Shared IP addresses matter without login. A CI runner or an office network can share one 100-pull allowance.
- The pricing page and the usage docs give different pull numbers for Personal, so check the docs page before you plan around a limit.
- You must be signed in to push an image. Name it with your Docker ID, for example `YOUR-USERNAME/nginx-custom`.

## Questions people ask

### Is Docker Hub free?

Yes. Docker Personal costs $0 and gives you unlimited public repositories and 1 private repository.

### What is the Docker Hub pull limit for free accounts?

The usage docs say 200 pulls per 6 hours for a logged-in Personal user, and 100 per 6 hours for users who are not logged in. The pricing page words it as 100 pulls per hour.

### Does Docker Hub need a credit card?

The pricing page shows Personal at $0 and lists no payment step.
