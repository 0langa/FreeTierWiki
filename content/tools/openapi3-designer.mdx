You work in the browser with tabs for Info, Servers, Schemas, Paths, Security, and Preview. There is nothing to install and no code to write. It suits developers who want a form-based way to draft or fix an OpenAPI file.

## What the free plan gives you

The site shows no pricing page and no paid plan. The editor page offers Import, Save to account, Sign in, and Create account buttons. The definition you are editing stays in your browser and survives a reload. The docs say nothing blocks a download, so you can export without finishing the definition.

The editor reads OpenAPI 3 and edits OpenAPI 3.0; any 3.x definition imports and keeps its own version string. It lets you edit GET, POST, PUT, PATCH, and DELETE operations. Preview shows the result as JSON or YAML, and you can download it at any time.

## When you hit a limit

The site states no quotas, so there is no usage limit to hit. The real limits are in what the editor can do. It refuses a Swagger 2.0 document. Some keywords, such as oneOf, examples, and tags, cannot be created in the forms. The editor also lists as not yet supported: validation keywords, composition (oneOf, anyOf, allOf), examples and defaults, tags and summaries, server variables, OAuth2 flows, and some content types. OPTIONS, HEAD, TRACE, and QUERY operations are kept and exported but not editable.

## Gotchas

- The open definition is kept in this browser. Download your file before you clear browser data.
- Composition keywords (oneOf, anyOf, allOf), examples, defaults, and tags are listed as not yet supported.
- Only GET, POST, PUT, PATCH, and DELETE operations are editable.

## Questions people ask

### Is OpenAPI Designer free?

The site shows no pricing page and no paid plan.

### Do I need an account for OpenAPI Designer?

The docs list no account requirement for editing or downloading. The editor page has Save to account, Sign in, and Create account buttons. The open definition is kept in your browser.

### Does OpenAPI Designer support Swagger 2.0?

No. It refuses a Swagger 2.0 document. It edits OpenAPI 3.0 and imports any 3.x definition.
