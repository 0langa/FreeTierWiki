You work in the browser with tabs for Info, Servers, Schemas, Paths, Security, and Preview. There is nothing to install and no code to write. It suits developers who want a form-based way to draft or fix an OpenAPI file.

## What the free plan gives you

The site shows no pricing page and no paid plan. The editor works without an account. The definition you are editing stays in your browser and survives a reload. An account is optional, and you need it only to save definitions to the server.

The editor reads any OpenAPI 3.x definition and edits OpenAPI 3.0. It lets you edit GET, POST, PUT, PATCH, and DELETE operations. Preview shows the result as JSON or YAML, and you can download it at any time.

## When you hit a limit

The site states no quotas, so there is no usage limit to hit. The real limits are in what the editor can do. It refuses a Swagger 2.0 document. Some keywords, such as oneOf, examples, and tags, cannot be created in the forms. When an imported file already contains them, the editor keeps them and exports them unchanged. Without an account, the only copy of your work lives in this browser.

## Gotchas

- Nothing is saved on the server unless you create an account and choose Save to account. Download your file before you clear browser data.
- Schemas with oneOf, allOf, or anyOf open read-only, so you cannot change them in the forms.
- A parameter's required flag is computed from its location when you save, so a required header becomes optional.

## Questions people ask

### Is OpenAPI Designer free?

The site shows no pricing page and no paid plan. The editor works without an account.

### Do I need an account for OpenAPI Designer?

No. An account is only needed to save definitions to the server. Without one, your work stays in your browser.

### Does OpenAPI Designer support Swagger 2.0?

No. It refuses a Swagger 2.0 document. It edits OpenAPI 3.0 and imports any 3.x definition.
