You call The IP API with a GET request and an API key, from curl or a language such as Python, JavaScript, or PHP. A batch endpoint takes a POST request for many addresses at once. It suits developers who add location checks to apps, logins, or analytics.

## What the free plan gives you

The Free plan costs $0, lasts forever, and needs no card. It allows 1,000 requests per day. All plans include commercial use, daily data updates, and both IPv4 and IPv6 addresses.

The API returns country, city, latitude, longitude, ASN, and the company that owns the address. The batch endpoint takes up to 100 IP addresses in one request. Each unique IP in a batch counts as one request, and repeated IPs count once.

The pricing page says there are no hidden fees and no surprise overages. Paid plans start at $19 a month for 600,000 requests a month.

## When you hit a limit

The docs say the Free plan limit resets daily, and an over-limit request gets a 429 error. The pricing page lists no overage charge, so the free plan stops instead of billing you.

A batch is checked before it runs. If you do not have enough quota left for all its unique IPs, the whole batch is rejected with a 429 error. The docs advise you to back off and track your usage. The dashboard shows your usage. Caching frequent lookups in your app saves requests.

## Gotchas

- A batch with one invalid IP address is rejected in full, because the API validates every address first.
- The batch endpoint needs a POST request. A GET request returns a 405 error.
- Paid plans reset monthly, but the Free plan resets daily. Plan your bursts around that.

## Questions people ask

### Is The IP API free?

Yes. The Free plan costs $0 forever and allows 1,000 requests per day. It needs no card, and it allows commercial use.

### What happens when I go over The IP API free limit?

You get a 429 error until the daily limit resets. The pricing page lists no overage charges.

### Does The IP API need a credit card?

No. The pricing page says no card is required to start on the free plan. You sign up for an account to get your API key.
