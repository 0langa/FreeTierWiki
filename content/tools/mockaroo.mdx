Mockaroo is a web tool for generating realistic fake data. You define a schema of fields, such as names, emails, dates, and addresses, and download the rows as CSV, JSON, SQL, or Excel. It also has a Generate API and configurable mock APIs, so front end work can start before the real back end exists.

## What the free plan gives you

The free plan limits each generated file to 1,000 rows, with no daily limit on the number of files you download from the browser. Generation runs at 1x speed. The API is open to free accounts too, with a limit of 200 API requests per day.

The docs say both the Generate API and mock APIs need an API key, passed as a query string parameter called key or as an X-API-Key header, and you sign up to get one. Mock APIs let you control URLs, handle request parameters, and simulate errors, which helps when you build a front end against an API that is not ready.

## When you hit a limit

The row limit applies per file, so a bigger dataset means several downloads or a paid plan. Silver is $60 a year for up to 100,000 rows per file and 1M records a day through the API, and Gold is $500 a year for up to 10M rows per file.

The docs explain that free plans are limited to 200 requests per day, while Silver and Gold are limited by the total number of records per day with no request limit. The pricing page and docs do not say what the API returns once the free daily requests are used.

## Gotchas

- The API limit counts requests, not rows, so many small requests from a test suite use the free 200 quickly.
- Each file tops out at 1,000 rows, so seeding a large table means repeating the download.
- Paid plans are priced per year, not per month, so there is no cheap one-month upgrade for a single big job.

## Questions people ask

### Is Mockaroo free?

Yes. The free plan generates files of up to 1,000 rows and allows 200 API requests a day.

### How many rows can I generate for free?

Up to 1,000 rows per file, with no daily limit on how many files you download from the browser.

### Does the Mockaroo API need an API key?

Yes. Both the Generate API and mock APIs need a key passed in the query string or the X-API-Key header, and you get one by signing up.
