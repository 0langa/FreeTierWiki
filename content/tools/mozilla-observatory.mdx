You use it in a browser by typing a domain into the scan box on MDN. A command-line scanner and a self-hosted server are also available. It suits developers and site owners who want to fix security headers.

## What the free plan gives you

The tool is free and needs no account. Anyone can scan any domain. MDN says it has served over 6.9 million websites through 47 million scans since 2016. A scan checks the HTTP headers and other key security settings of a site and returns a score and a letter grade, with recommendations shown together on one page.

Every site starts at a score of 100, then penalties and bonuses apply. The highest possible score is currently 145, and an A+ needs 100 or more. There is also an open-source command-line scanner you can run with `npx`.

## When you hit a limit

There is no plan to outgrow and no bill. The one limit is timing: a site can be scanned, and a new result returned, only once every 60 seconds. If you open a deep link to a report and the last scan is older than 24 hours, it starts a new scan. The pages do not give a cap on the number of scans per day.

## Gotchas

- Scan history for each domain is public. The old private option is gone, and there is no way to hide a scan.
- An A+ does not mean a site is secure. The tool does not test for outdated software, SQL injection, weak password storage, and more.
- The old Mozilla Observatory, which also had TLS and SSH tests, was sunset in October 2024. This tool covers HTTP behaviour only.

## Questions people ask

### Is HTTP Observatory free?

Yes. It is free to use, and you need no account or card. Anyone can scan any domain.

### Can other people see my HTTP Observatory results?

Yes. The scan history for each domain is public. The tool does not store user data related to each scan.

### Can I scan an API with HTTP Observatory?

You can, but it is designed for websites, so the results may not reflect the real security of the API. MDN gives a recommended header set for APIs that return only data.
