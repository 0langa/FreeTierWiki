HTTP Observatory (built by Mozilla, now hosted on MDN) is a free online tool that helps users assess and improve the security of their web applications by analyzing HTTP headers and TLS configuration. It has scanned over 6.9 million websites through 47 million scans. It is ideal for quick checks, educational purposes, and benchmarking security improvements, but is not suitable for private scans.
