You use News API from your own code. Register for a key, then send GET requests to the top headlines or everything endpoint, or use one of the client libraries the docs link to. It suits developers and students who want news data in a prototype.

## What the free plan gives you

The Developer plan costs $0 and needs no credit card. You get 100 requests per day. Any single HTTP request to any endpoint counts as one request. The number of results or the parameters you use do not change that count.

The free plan has a few data limits. Articles arrive with a delay of 24 hours. Search reaches back only about a month. The plan has no uptime guarantee. Caching helps your budget: identical requests made soon after each other return a cached result that does not use up your allowance. The cache lasts 5 minutes by default.

The plan is for development and testing only. The pricing page says you may not use it in a staging or production environment, not even an internal one.

## When you hit a limit

The pricing page says the Developer plan has no extra requests available. When you use your 100 daily requests, you have to wait. The page offers no way to buy more on this plan, and the plan takes no card, so you cannot get a surprise bill.

To run outside development, you must move to a paid plan. Paid plans bill per request above their included amount, but the free plan has no such option.

## Gotchas

- The free plan is only for a development environment. Using it in staging or production, even for an internal tool, needs an upgrade.
- Articles on the free plan are 24 hours old, so it does not suit anything that needs breaking news.
- The API does not return the full article text. You get a link with each result and must fetch the page yourself.

## Questions people ask

### Is News API free?

Yes, for development. The Developer plan costs nothing and needs no credit card. You may use it for development and testing only.

### What happens when I go over the News API free limit?

The free plan has no extra requests available, so you have to wait for the next day. Paid plans are the only way to get more.

### Can I use the News API free plan in production?

No. The pricing page says the Developer plan cannot run in a staging or production environment, including internal use. You need a paid plan for that.
