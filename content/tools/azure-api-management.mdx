You set it up in the Azure portal, or with PowerShell, the Azure CLI, or a REST API, then import your APIs and add policies. It suits teams that run APIs on Azure, on premises, or in other clouds and want one place for keys, limits, and docs.

## What the free plan gives you

The Consumption tier includes the first 1 million API operations per month, per subscription. It is a lightweight, serverless version of the service that is billed per execution. A billing unit is one operation within an HTTP request. For normal REST and SOAP APIs, one request is one operation.

Microsoft's FAQ says only the Developer tier is unfit for production because it has no SLA, so the Consumption tier can carry production traffic. The page shows no free allowance for the other classic tiers.

## When you hit a limit

There is no hard stop. After 1 million operations, the pricing page bills each further 10,000 API operations. The table on the page shows no dollar figure in its text, so use the Azure pricing calculator to estimate the cost.

The page does not describe the service stopping. Plan for the bill to grow, and set an Azure budget alert before you send real traffic.

## Gotchas

- The 1 million free operations count per subscription, not per instance. Several Consumption instances share one allowance.
- The Developer tier has no SLA. The pricing page says it is for evaluation, development, and test, not production.
- The pricing page says an AI Gateway created in Azure AI Foundry is free for up to 100,000 requests. That is a separate offer from the Consumption allowance.

## Questions people ask

### Is Azure API Management free?

Only the Consumption tier has a free amount. It includes the first 1 million API operations per month, per subscription. After that you pay per 10,000 operations.

### What happens when I go over the Azure API Management free limit?

The service keeps running and bills the extra operations. The pricing page does not describe a hard cap, so set an Azure budget alert.

### Can I use Azure API Management Consumption in production?

Yes. The pricing FAQ says the Developer tier has no SLA and is not suitable for production, which leaves the Consumption tier for production traffic. The Developer tier is for tests.
