You create rules in the Requestly web app, which you open from the extension popup. The desktop app adds system-wide and mobile interception.

## What the free plan gives you

The Free HTTP Rules plan costs $0 and covers standard HTTP modifications. It lists 5 rules, of which 3 can be active at once. You get unlimited header rules, 5 API mock endpoints, and 5 files for JS or CSS.

Paid HTTP Rules plans start with Lite at $8 per month, billed $90 a year. Basic costs $15 per month and raises the limit to 10 rules with 5 active. Professional costs $23 per month and removes the rule, group, mock, and file limits.

Requestly also sells an API platform with an API client. Its Team plan costs $10 per user per month, billed annually. You can start a 30 day trial of it with no credit card.

## When you hit a limit

The pricing page does not say what happens when you create more than 5 rules or turn on a fourth rule. It lists the numbers as plan limits, so expect the app to block the change or ask you to upgrade.

You cannot be billed on the Free plan, because it needs no card. Paid plans are flat per-seat prices, not metered. To work inside the cap, keep only the rules you need active and use header rules, which are unlimited.

## Gotchas

- Three active rules is the real working limit on Free. Turn old rules off before you switch on new ones.
- The browser extension has limits that the desktop app does not. For example, it cannot serve local files or modify HTML, JS, and CSS responses, and its delay rule has a maximum delay.
- Requestly is moving toward an API platform. The HTTP Rules pricing sits on a separate page from the API platform pricing.

## Questions people ask

### Is Requestly free?

Partly. The Free HTTP Rules plan costs $0 with 5 rules, of which 3 can be active, plus unlimited header rules. The API platform plans are paid after a 30 day trial.

### Does Requestly need a credit card?

No. The Free plan needs no card, and the API platform trial says no credit card is required.

### Is the Requestly extension the same as the desktop app?

No. The extension runs inside the browser. The desktop app also intercepts mobile devices, terminal tools, and system-wide traffic.
