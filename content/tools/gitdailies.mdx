You install GitDailies as a GitHub app, sign in to its web app, and pick repositories to follow. Results show in the dashboard, in Slack or Telegram, and in a daily digest. It suits small teams on GitHub.

## What the free plan gives you

The Community plan costs $0 per month. It covers 50 PRs per month and 2 repos, with unlimited users. It keeps 7 days of history.

The plan includes daily digests, PR metrics, and DORA metrics in a partial form. It also includes shared alerts, limited to 2 rules. You can send digests by email, Slack, or Telegram.

GitDailies uses only GitHub metadata, such as PR titles, reviewers, timestamps, and status checks. It says it does not clone your repos or read source code.

## When you hit a limit

The pricing section does not say what happens after 50 PRs in a month. It also does not say what happens if you follow a third repo.

The Pro plan lifts the limits. It costs $49 per month and covers 250 PRs per month, 25 repos, and 3 months of history. It adds full DORA metrics, unlimited private alerts, and priority support. The Max plan costs $299 per month and adds the MCP server for AI agents and the Metrics API.

## Gotchas

- You install it from GitHub Marketplace into a GitHub organization, and you choose a plan there. The docs say the app asks for the minimal permissions.
- A user only sees a repo in GitDailies if the user has read access to it on GitHub and GitDailies follows it.
- The MCP server for AI agents is listed on the Max plan, not on Community.

## Questions people ask

### Is GitDailies free?

Yes. The Community plan is free and covers 50 PRs per month and 2 repos, with unlimited users.

### Does GitDailies need a credit card?

The page says you sign in with your GitHub account and shows the Community plan at $0. It lists no card step for the free plan.

### What does GitDailies read from my repositories?

Only GitHub metadata, such as PR titles, reviewers, timestamps, and status checks. It says it does not clone your repos or read your source code.
