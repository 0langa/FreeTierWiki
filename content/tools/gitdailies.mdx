You install GitDailies as a GitHub app, sign in to its web app, and pick repositories to follow. Results appear in dashboards, daily digests, and connected notification tools. The current free offer is an evaluation period for paid plans.

## What the free plan gives you

Pro and Team have a 14-day free trial. The pricing page and GitHub Marketplace listing offer Pro, Team, and Max, with no ongoing free Community plan listed. The old 50-PR and 2-repository allowance should not be used to plan a new account.

Current plans have unlimited repositories and pull requests. Pro includes up to 15 contributors, 3 months of history, daily digests, PR and code review metrics, DORA metrics, up to 50 smart alert rules, and MCP access. A contributor is someone who opened a PR or left a review during the last 30 days; bots do not count.

Team allows 60 contributors and 6 months of history. Max allows 200 contributors, 18 months of history, multiple organizations, and the Metrics API. Ask about Max trials.

GitDailies reads metadata and says it does not clone repositories or read source code.

## When you hit a limit

The trial is time-limited. Through GitHub Marketplace, you need an existing payment method or must add one. GitHub automatically enrolls you in the selected paid plan after 14 days unless you cancel. Canceling a trial ends access immediately. Review the trial end date before enabling it.

Pro costs $59 per month billed monthly, Team $149, and Max $349. The provider offers annual billing at a discount. Marketplace subscriptions use GitHub billing; existing subscriptions can make the first post-trial charge prorated.

Exceeding a contributor band for a month does not immediately break the service: GitDailies says it will notify you and help choose a suitable plan. This is different from a permanent free quota or an automatic per-PR overage fee.

## Gotchas

- The 14-day trial becomes a paid Marketplace subscription unless canceled; signing in with GitHub does not make the ongoing service free.
- Contributor counts include reviewers as well as PR authors, based on the previous 30 days.
- MCP is included on all current plans, while the Metrics API is on Max. They are separate access methods.

## Questions people ask

### Is GitDailies free?

Pro and Team offer a 14-day trial. Current official pricing lists paid subscriptions rather than an ongoing free Community plan.

### Does GitDailies require payment details for the trial?

Yes, through GitHub Marketplace. GitHub requires a payment method and bills the selected plan after the trial unless canceled.

### What does GitDailies read from repositories?

It reads GitHub metadata and says it does not clone repositories or read source code.
