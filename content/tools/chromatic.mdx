You install the `chromatic` npm package, run it in CI, and review the changes in the Chromatic web app. It suits front-end teams that already write stories or end-to-end tests.

## What the free plan gives you

The Free plan costs $0 per month and includes 5,000 billed snapshots. Projects, users, and collaborators are unlimited, and tests run on Chrome. It also includes Git and CI integrations.

A billed snapshot is one captured test result. Visual and accessibility tests use billed snapshots; interaction tests do not. Counts add up across all projects in your account. TurboSnap can cut usage: a copied snapshot counts as 0.2 of a billed snapshot, and a bypassed snapshot counts as 0. Chromatic also says its free Publish Storybook service uses no billed snapshots when UI tests and UI review are off.

## When you hit a limit

On the Free plan, review and testing pause once you use all 5,000 billed snapshots in a month. You can start again by upgrading to a paid plan or by waiting until the count resets at the end of the billing cycle. The free plan does not bill you for extra snapshots.

Paid plans work differently. Their testing does not stop, and extra billed snapshots are charged at the end of the period. The Starter plan costs $179 per month and includes 35,000 billed snapshots. Extra snapshots cost $0.008 each. You can set a usage alert that emails you at a snapshot count you choose.

## Gotchas

- Free tests run on Chrome only. Safari, Firefox, and Edge need the Starter plan.
- One test can create many snapshots, because the count is tests times builds times browsers times modes. A busy repository can use up 5,000 snapshots quickly.
- Projects not linked to a supported Git host miss automatic pull request checks. You must set up statuses yourself in CI.

## Questions people ask

### Is Chromatic free?

Yes. The Free plan costs $0 per month and gives you 5,000 billed snapshots with unlimited projects and users. It needs no credit card.

### What happens when I use all my Chromatic snapshots?

On the Free plan, review and testing pause until your count resets at the end of the billing cycle or you upgrade. You are not billed for extra snapshots.

### Does Chromatic test in Safari and Firefox for free?

No. The Free plan tests on Chrome. Safari, Firefox, and Edge testing starts on the Starter plan.
