You send HTTP requests to the REST API with your key at the end of the URL, or use the official Python SDK. There is also an Excel add-in and an MCP server. It suits students, researchers, and hobby builders who want market history without paying.

## What the free plan gives you

The Free plan costs $0 and allows 300 requests per day. It includes the REST API and the Python SDK. The pricing page lists it under Personal Use.

Free covers a limited set of endpoints. In the documentation, they are stock symbols, international stock symbols, ETF symbols, commodity symbols, and OTC symbols. They also include daily stock prices, commodity prices, OTC prices, and OTC volume. Stock prices give more than 10 years of daily history, with a limit of 300 records per call. Symbol endpoints return up to 500 records per call, and you page with the offset parameter.

Real-time quotes, minute prices, options, futures, and many other data sets need a paid plan. Paid plans are priced by speed, not by volume. Standard is $29 per month, Premium is $69, Professional is $149, and Enterprise is $299.

## When you hit a limit

The documentation says Free includes up to 300 requests per day. It does not say what the API returns after that. The site also says billing is flat-rate, with no overage charges, licensing fees, or other unexpected costs, so you will not get a bill.

Paid tiers raise the rate to 10, 30, or 50 requests per second. The site says there are no bandwidth quotas on any plan. If you need more than 300 requests per day, you must move up.

## Gotchas

- Most endpoints are not free. Check the label next to each endpoint in the documentation before you plan around it.
- Each call to a list or price endpoint returns a capped number of records, so one request may not return a full history. You page with offset, which uses up more of your 300 requests.
- The Free plan sits under Personal Use. Commercial use has its own plans.

## Questions people ask

### Is the Financial Data API free?

Yes, there is a Free plan with 300 requests per day, the REST API, and the Python SDK. It covers symbol lists and daily historical prices.

### Does the Financial Data free plan include real-time prices?

No. The documentation marks real-time stock quotes as a Premium endpoint. The Free plan covers daily historical data and symbol lists.

### Will Financial Data charge me for going over the limit?

The site says billing is flat-rate with no overage charges. The Free plan stops at 300 requests per day, so you move up to a paid plan for more.
