You use the web app to manage repositories, then point your normal package tools at them. A command line tool uploads packages from a folder and migrates a repository from Artifactory.

## What the free plan gives you

The Free cloud plan is for personal use and needs no credit card. It gives you one workspace with 10GB of storage. You can transfer up to 10GB of data each month, and the counter resets at the start of every month.

You can publish up to 100 unique packages. Different versions of the same package count as 1, so 100 packages can hold many releases. You can add unlimited users to the workspace, because RepoFlow does not charge per seat. The plan also includes 10 RepoFlow AI requests per month and email support.

The next plan, Standard, costs $79 per month. It raises storage and bandwidth to 80GB and published packages to 500.

## When you hit a limit

The current pricing FAQ specifies separate stops: full storage blocks uploads, the package limit blocks new unique packages, and AI pauses until the next monthly reset. Bandwidth exhaustion blocks downloads until next month; workspace management and other resources remain available. Delete packages or upgrade to restore capacity.

Workspace admins can see storage, transfer, and local package usage on the Workspace Settings page. The docs say transfer usage can take up to 5 minutes to update. Only packages in local repositories count toward the package limit. Packages cached by remote repositories do not.

## Gotchas

- The Free plan is labeled for personal use. Check the terms if you plan to run a company registry on it.
- Each cloud plan includes one workspace, so Free cannot split teams or projects into separate workspaces.
- Transfer counts all data downloaded from the server. A busy CI job that pulls large packages can use up the 10GB.

## Questions people ask

### Is RepoFlow free?

Yes. The Free cloud plan is for personal use and costs nothing. It has 10GB of storage, 10GB of monthly bandwidth, 100 published packages, and 1 workspace.

### Does RepoFlow need a credit card?

No. The pricing page says you can sign up for free with no credit card required.

### Which package types does RepoFlow support?

The docs list Docker, Maven, Debian, npm, PyPI, NuGet, Go, Helm, RPM, Gem, Composer, Cargo, Conan, Chocolatey, Synology, and a Universal type for other files.
