You use MockAPI in a web dashboard to set up projects and resources, then call the generated endpoints with plain `fetch` or any HTTP client. It suits front-end developers and learners who need an API to talk to.

## What the free plan gives you

The free plan includes 1 project and 2 resources. A project is one API with its own base URL. A resource is one data type, such as tasks or users, and MockAPI generates the usual endpoints for it: list, get by ID, create, update, and delete.

You pick a Faker.js generator for each field and let MockAPI create the records. The page also lists filtering, sorting, pagination, and relations between resources, which add nested URLs. The paid plans cost $5 per month or $35 per year. Both raise the limits to 20 projects and 50 resources. The page also lists customizable responses and collaboration, but does not say which plan includes them.

## When you hit a limit

The pricing page does not say what happens when you try to add a third resource or a second project on the free plan. It lists only the plan limits. It also does not mention a request cap or any overage charge, so check the dashboard before you plan a larger test. The only upgrade path on the page is a paid plan, which costs $5 per month or $35 per year and gives you 20 projects and 50 resources.

## Gotchas

- Two resources go fast. A users and posts setup already uses both of them.
- Custom endpoints and webhooks are marked as coming soon on the pricing page.
- Requests need a `content-type: application/json` header, and data goes in the body as JSON.

## Questions people ask

### Is MockAPI free?

Yes. The free plan includes 1 project and 2 resources. Paid plans start at $5 per month.

### How many resources can I create on the MockAPI free plan?

Two resources in one project. The paid plans allow 50 resources in 20 projects.

### What happens when I go over the MockAPI free limits?

The pricing page does not say. You would need a paid plan to add more projects or resources.
