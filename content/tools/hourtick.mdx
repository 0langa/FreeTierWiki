Hourtick combines project tasks with recording the time people spend on them. A small team can use the same workspace to discuss a task, add time entries and review a report. The free allowance is tied to how the workspace is used.

## What the free plan gives you

The Free plan includes unlimited people, time tracking, tasks, chat, and API and MCP access. It comes with 500 MB of usage in a month, with no credit card required. The provider counts data stored for the workspace and data it sends or receives during the month. That is broader than a count of uploaded files. Workspaces that use the timer and a few small tasks can have a different usage profile from ones that share screenshots or documents every day. Review the meter after a typical week to see what activity takes up the allowance.

## When you hit a limit

At the allowance, only file uploads pause. Timers, timesheets, tasks, comments, chat, reports, approvals and invoicing keep working. Uploads resume on the first of the month or after increasing capacity. Stored data carries over; transferred data resets on the first. The usage meter is an estimate, with storage measured hourly.

Pro costs $29 per month for 5 GB; extra capacity is $10 per GB per month. Billing is monthly only. Canceling returns the workspace to Free at the end of the billing period without deleting data; uploads pause if the workspace exceeds the Free allowance.

## Gotchas

- Unlimited seats do not increase the size of the workspace allowance.
- Time entries, task activity and chat can use the same meter as files.
- If you invoice through your own Stripe account, Stripe’s fees follow that account independently of Hourtick’s plan.

## Questions people ask

### Is Hourtick free for a team?

Yes. The provider lists a no-card Free plan with unlimited people and a shared usage allowance.

### Does 500 MB mean file storage alone?

No. The pricing page counts stored workspace data and data transferred during the month.

### Can I use the API on Free?

The Free feature list includes REST API and MCP access.
