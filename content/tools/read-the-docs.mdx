You connect a Git repository through GitHub, and Read the Docs builds and publishes your docs from a configuration file. The dashboard handles imports and builds, and there is a public REST API. It suits open-source maintainers.

## What the free plan gives you

Read the Docs Community is for free and open-source projects. The pricing page says it is free forever and that open-source documentation is always free. Community clones public repositories only, and the hosting is supported by ads.

Every project gets automatic builds, versioning, search, pull request previews, and CDN hosting. The tutorial shows that pull request builds are on by default for new projects. Read the Docs has hosted open-source documentation since 2010. Read the Docs Business is for commercial and non-free projects, and it adds private repository support and single sign-on.

## When you hit a limit

The pricing page lists no usage caps for Community. The gate is the kind of project: open-source docs from public repositories. Private repositories and commercial docs need Business, which starts at $50 per month.

The Business plans have a 30-day free trial. The pricing FAQ says it does not charge you automatically when the trial ends, so you only pay if you decide to continue.

## Gotchas

- Community hosting is supported by ads. The tutorial says ads are one of the main sources of revenue and asks readers not to block them.
- The `.readthedocs.yaml` configuration file is required in your repository.
- Private repositories, single sign-on, and private documentation are paid Business features.

## Questions people ask

### Is Read the Docs free?

Yes, for open-source projects. Read the Docs Community is free forever and clones public repositories. Hosting is supported by ads.

### Can I host private docs on Read the Docs for free?

No. Private repositories need Read the Docs Business. Plans start at $50 per month and include a 30-day free trial.

### Does Read the Docs build pull request previews?

Yes. Every plan includes pull request previews. The tutorial says pull request builds are enabled by default on new projects.
