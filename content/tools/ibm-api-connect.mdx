You start the trial from the IBM site and sign in with an IBMid. The current getting-started guide uses IBM API Studio or the command line to create APIs, API Manager to manage them, and the Consumer Catalog for subscriptions and testing. Follow the portal instructions for your deployed version. It suits teams evaluating enterprise API management.

## What the free plan gives you

IBM's Enterprise as a Service trial provides one instance for 30 days and up to 100,000 API calls at no cost. The signup page confirms that allowance. It is an evaluation offer with community support, not a permanent free plan.

The pricing table puts trial links under Pay-as-you-Go, Standard SaaS, and Premium SaaS, but the detailed subscription guide says the trial includes Standard features and excludes Premium capabilities. Do not treat the marketing links as a full Premium entitlement. Reserved Instance and self-managed Software offer demos. Paid choices include usage-based AWS hosting, annual SaaS subscriptions, and self-managed software; the trial's card requirement is not confirmed.

## When you hit a limit

The trial counts calls with all response codes, including errors. At the 100,000-call limit, additional calls stop until an upgrade, while view-only access remains. IBM says Enterprise as a Service does not charge call overage. These terms describe that trial and subscription model, not every separate paid offer.

After 30 days, login/access stops. IBM retains the assets for an additional 30-day suspension period so you can upgrade without losing them. Upgrading during the active trial with the same IBMid/email migrates the instance and assets automatically. The pricing page says to use a different IBMid/email if you want a fresh paid instance instead.

## Gotchas

- The extra retention period preserves assets for an upgrade; it does not extend free API access. Export definitions before the trial ends if you will not continue.
- The detailed trial guide excludes Premium capabilities despite trial links in the broader pricing comparison.
- Upgrading with the same IBMid migrates your trial assets. Use another IBMid if you do not want them moved.

## Questions people ask

### Is IBM API Connect free?

Only as a trial. IBM offers a 30-day free trial. After that you need a paid plan, such as pay-as-you-go on AWS.

### What happens when the IBM API Connect trial ends?

Login/access stops after 30 days. Assets remain for another 30-day suspension period to allow a paid upgrade. That retention window does not extend the free trial.

### Can I upgrade the IBM API Connect trial early?

Yes. The pricing page says you can upgrade the trial to a paid subscription at any time during the 30-day trial period.
