Visual Crossing sells weather data through a Timeline Weather API, bulk downloads, and add-ons for tools like Excel and Power BI. It covers 50+ years of history and 15-day forecasts worldwide. The Free plan suits developers and analysts who need a modest amount of history or forecast data each day.

## What the free plan gives you

The plan comparison lists the Free plan with 30,000 records a month, framed as 1,000 records a day. It includes the 15-day weather forecast, 50+ years of history data, weather events such as hail and tornadoes, weather data download, and the Weather API. Each API query can return up to 1,000 records for up to 5 locations, with an API concurrency of 1. Weather maps allow 10,000 requests a month, and the query builder allows datasets of up to 1,000 records and 5 locations. Commercial use is allowed on every plan, including Free, but attribution is required.

## When you hit a limit

Visual Crossing says Free plans include a limit on the number of query records that can be retrieved in any 24 hour period. A single 15-day forecast query counts as one record, while each history record returned counts as one. The current FAQ says exceeded usage,request or concurrency limits return HTTP 429. It does not explicitly specify the daily reset timezone/window or an ongoing Free signup card waiver. Paid options include the Professional plan, with 10,000,000 records a month, and a Metered plan with unlimited records billed per record.

## Gotchas

- History pulls count every returned record, so a year of daily history for one place uses hundreds of records.
- Pricing says any 24-hour period, but does not explicitly distinguish a rolling window from a calendar-day reset; confirm before scheduling boundary-sensitive jobs.
- Attribution with a clickable link to Visual Crossing is required on the Free plan.

## Questions people ask

### Is the Visual Crossing Weather API free?

Yes. The Free plan includes 1,000 records a day through the API and downloads.

### Can I use Visual Crossing's free data commercially?

Yes. The plan comparison lists commercial use for every plan, but the Free plan requires attribution.

### How are records counted?

A 15-day forecast query counts as one record, and each history record returned counts as one record.
