CodeCommit hosts private Git repositories inside your AWS account. Access goes through IAM, and CodePipeline and CodeBuild can read from it directly. AWS stopped taking new customers in July 2024 and reopened sign-ups on November 24, 2025.

## What the free plan gives you

The free tier is counted per account, not per repository. Each month your first five active users are free, and together they get 50 GB-month of storage and 10,000 Git requests. An account can hold 5,000 repositories, or up to 25,000 on request.

AWS says this offer is available indefinitely to new and existing customers and does not end with the 12-month AWS Free Tier term. Usage is added up across all AWS Regions each month, and unused storage and Git requests do not carry over. A user who does not touch CodeCommit during a month is not counted.

## When you hit a limit

Nothing stops a push at the free amount. Each active user past the first five costs $1 a month and adds 10 GB-month of storage and 2,000 Git requests to the pool. Storage beyond the pool is billed at $0.06 per GB-month, and Git requests at $0.001 each.

On a new Free account plan, usage is paid from your sign-up credits. That account closes after six months or when the credits run out, and AWS keeps your data for 90 days in case you upgrade to a Paid plan.

## Gotchas

- An active user is any AWS identity that reaches CodeCommit: IAM users and roles, federated users, the root account, and the identities that CodeBuild and CodePipeline create. A pipeline can push you past five users.
- A Git request is any push or pull that transfers repository objects, including edits in the console or through the API. A fetch with nothing new to transfer does not count.
- The pricing page still shows a banner saying CodeCommit is closed to new customers. The AWS DevOps blog and the user guide's document history both say sign-ups reopened in November 2025.

## Questions people ask

### Is CodeCommit free?

Yes, within limits. Each AWS account gets five active users a month free, sharing 50 GB-month of storage and 10,000 Git requests, and the offer has no end date.

### Can new AWS customers still use CodeCommit?

Yes. AWS closed CodeCommit to new customers in July 2024 and reopened it on November 24, 2025. The CodeCommit user guide's document history records both changes.

### What counts as an active user?

Any unique AWS identity that reaches CodeCommit in a month, through Git, the console, the CLI or an SDK. Identities that other AWS services such as CodeBuild create count too.
