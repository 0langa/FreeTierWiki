TestSprite runs tests against an application and shows the results in a dashboard. You can start with a test environment and later connect a repository to exercise changes when a pull request opens. It fits a project where you want to try AI-assisted testing without changing the deploy stack.

## What the free plan gives you

The Free tier includes 150 credits per month and one environment. Run history stays available for 30 days. The plan also includes the test agent and its CLI and editor integrations. You can connect one repository for automatic pull request testing and set up Slack notifications. Start with an application environment you can safely exercise. For example, you might test navigation to a sign-in page and a successful sign-in with a test account. Reviewing the results gives you a sense of what the chosen tests cover before you turn on automatic runs.

## When you hit a limit

The recurring free credit allowance and the promotional first month of Starter are different offers. The pricing matrix lists larger credit bundles on paid plans. It does not specify the exact free-plan response when a run needs more credits than are left. Check usage before triggering a batch across many changes. Pick one critical flow to keep running when the remaining credit is limited.

## Gotchas

- A free environment is useful for a small target. Test with safe data and credentials before allowing checks to execute on every pull request.
- Scheduled testing and healing of tests as the app changes appear on paid plans.
- The GitHub integration covers one repository on Free. Tests in another repository may need a different arrangement.

## Alternatives in this atlas

- [GitHub Actions](/services/github-actions/) for executing tests you already maintain in your repository.
- [Momentic](/services/momentic/) for AI-assisted test authoring and a monthly usage balance.

## Questions people ask

### How many tests do 150 credits buy?

Treat credits as a usage allowance. Check what a representative run consumes in the product.

### Can I run tests on pull requests?

Free lists PR auto-test on one GitHub repository.

### How long does TestSprite keep results?

The Free plan lists 30 days of run history. Collect the evidence you need from a failure before then.
