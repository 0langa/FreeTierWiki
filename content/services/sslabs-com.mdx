You use it in a browser: enter a hostname and wait for the report. For scheduled or bulk checks, Qualys offers APIs and an open source command-line scanner. It suits anyone who runs a public HTTPS site.

## What the free plan gives you

SSL Server Test is a free online service. It performs a deep analysis of the configuration of any SSL web server on the public internet. The page lists no price and no signup step. The page says the information you submit is used only to provide the service, and that Qualys does not use the domain names or test results.

For automation, SSL Labs APIs expose the full testing function so you can run scheduled and bulk assessments. They are free to use, with restrictions. The site also maintains ssllabs-scan, an open source command-line tool that doubles as the reference API client. A guide called SSL/TLS Deployment Best Practices and an SSL Server Rating Guide explain the results.

## When you hit a limit

The test page lists no daily limit and no price. The free API comes with restrictions that the site points to in its terms and conditions, a PDF that this atlas could not read, so the exact limits are not known here. Read those terms before you build a bulk or scheduled job. The tool only reaches servers on the public internet, so a private or internal host cannot be tested at all.

## Gotchas

- The home page shows recently tested hostnames. The form has a checkbox, "Do not show the results on the boards", so tick it if you do not want your hostname listed.
- Only public servers can be tested. Internal sites are out of reach.
- The APIs are free with restrictions. Read the terms before bulk use.

## Questions people ask

### Is SSL Labs free?

Yes. The SSL Server Test is a free online service. The page mentions no signup step.

### Can I test an internal server with SSL Labs?

No. The service tests servers on the public internet only.

### Does SSL Labs publish my test results?

The home page lists recently tested hostnames, but the form has an option to keep your result off the boards. The page says Qualys does not use the domain names or the test results.
