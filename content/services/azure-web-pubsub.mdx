You create a resource in the Azure portal or with the Azure CLI. Clients connect to it with a Client Access URL, and your servers use the service SDKs or a REST API. It suits developers who want WebSocket features without running connection servers.

## What the free plan gives you

Web PubSub comes in Free, Standard, and Premium tiers, split by concurrent connections, messages, and units. The Free tier gives 20 concurrent connections and 20,000 messages per unit per day. It costs nothing per unit per day and allows 1 unit at most.

The pricing page lists no SLA for Free, while Standard has 99.9% and Premium has 99.95%. Availability zones, auto scaling, custom domain names, and geo-replication are Premium only. The overview says the service also supports Socket.IO on Azure and MQTT clients over WebSocket.

## When you hit a limit

The pricing page does not say what happens when you pass 20 connections or 20,000 messages in a day. You cannot add units to a Free resource, because it is capped at 1 unit.

Standard and Premium work differently. Each unit supports 1,000 concurrent connections, and messages are unlimited. The first 1,000,000 messages are free, and extra messages are sold per million. Billing counts only outbound messages from the service, and a message over 2 KB counts as several messages of 2 KB each.

## Gotchas

- The pricing FAQ says only outbound messages count, and ping messages are ignored. Traffic is counted in bytes.
- Each application server opens five initial connections per hub by default, and each client uses one connection.
- The client SDK in the quickstart is in preview, so its interface may change.

## Questions people ask

### Is Azure Web PubSub free?

There is a Free tier with 20 concurrent connections and 20,000 messages per unit per day. It allows 1 unit and has no SLA.

### What is the difference between Web PubSub and SignalR Service?

Both have the same Free tier numbers. Web PubSub is the base service with connections, users, groups, and events. SignalR Service targets apps built on the SignalR protocol.

### How are Web PubSub connections counted?

Each application server starts with five initial connections per hub by default, and each client has one client connection.
