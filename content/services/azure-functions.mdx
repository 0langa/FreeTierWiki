You write functions in a language such as C#, Java, Node.js, PowerShell, or Python. You build and test them on your computer with Azure Functions Core Tools or Visual Studio Code, then deploy them to a function app. It suits developers who want triggers for HTTP calls, timers, or queues without running servers.

## What the free plan gives you

Free grants apply per subscription, shared across all function apps in it, each month. The legacy Consumption plan includes 1 million requests and 400,000 GB-s of resource use. The Flex Consumption plan, which Microsoft now recommends for new serverless apps, includes 250,000 executions and 100,000 GB-s.

A GB-s is one second of running with 1 GB of memory. Flex Consumption lets you choose instance memory of 512 MB, 2,048 MB, or 4,096 MB. The free grants apply only to paid, consumption subscriptions. The Premium plan is billed per second, and the pricing page lists no free grant for it.

## When you hit a limit

The pricing page does not describe a hard stop. After the free grant, Azure bills the extra executions and GB-s per second of use. That is the pay-as-you-go model, so a busy app costs money instead of stopping.

Flex Consumption has an optional Always Ready setting. It keeps instances enabled, and you pay for the memory of those instances even while they are idle. Leave it off if you want to pay only when functions run.

## Gotchas

- Every function app gets a storage account by default. The free grant does not cover it, and standard storage and network rates apply.
- The Consumption plan is now legacy. The docs say new serverless apps should use Flex Consumption, which has a smaller free grant.
- Free grants apply only to paid consumption subscriptions, so check your subscription type before you count on them.

## Questions people ask

### Is Azure Functions free?

Partly. The legacy Consumption plan includes 1 million requests and 400,000 GB-s each month per subscription. The Flex Consumption plan includes 250,000 executions and 100,000 GB-s.

### Does Azure Functions need a credit card?

Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go. The free grants apply to paid, consumption subscriptions only, so you need a pay-as-you-go subscription to get them.

### What happens when I go over the Azure Functions free grant?

Azure bills the extra executions and GB-s. The pricing page shows no hard cap that stops your app.
