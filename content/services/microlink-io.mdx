You call the API with one HTTP GET request, so it works from a browser, cURL, or any language. A JavaScript SDK and a command line tool wrap the same API, and developers who need previews or screenshots will find it quick to try.

## What the free plan gives you

The free plan costs $0 a month and needs no card. You sign up at dashboard.microlink.io and get a free API key with 100 requests per month. The quota is monthly only, with no daily quota. You get the same toolbox as Pro for screenshots, PDFs, metadata, markdown, search, insights, and the SDK. The request timeout is 60 seconds.

One request is one API call to any Microlink endpoint. Responses served from the cache do not count against your quota. Concurrency is limited and shared, and support comes from the community.

## When you hit a limit

Microlink says you are never billed by surprise. It notifies you at 80% of usage. At 100%, requests pause until the next billing cycle or until you upgrade. There are no overage fees.

Pro costs $49 a month for 46,000 requests a month, and it has no daily quota. Upgrades take effect immediately and are pro-rated. A free account cannot be billed because it has no card, so the worst case is a paused API until the next cycle.

## Gotchas

- 100 requests a month is small. Every call to any endpoint counts, so lean on the cache, since cached responses do not count.
- The free plan has a best-effort SLA, and the 99.9% SLA applies to paid plans.
- The free plan uses the shared global edge cache, and a custom cache key is a Pro feature.

## Questions people ask

### Is Microlink free?

Yes. The free plan is free forever and needs no credit card. You get 100 requests per month with screenshot, PDF, metadata, and SDK access.

### What happens when I exceed the Microlink free quota?

Requests pause until the next billing cycle or until you upgrade. Microlink says there are no overage fees.

### Does Microlink need an API key or credit card for the free plan?

You need a free API key, which you get by signing up at dashboard.microlink.io. No credit card is needed.
