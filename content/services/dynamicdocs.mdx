You call the API from your own code with a template token and a JSON payload, and you get back a PDF. You manage your account and API key in a web dashboard.

## What the free plan gives you

The free plan gives you 50 API calls per month and 0 private LaTeX templates. You can still use every ready-made JSON to PDF template, because those are on all plans. They need no LaTeX knowledge. The JSON you send controls the content. The trade-off is that you cannot change a template beyond what the library already offers.

Paid plans add volume and private templates. Individual gives you 500 calls and 1 private LaTeX template. Startup gives you 3000 calls and 3 templates. Business gives you 20000 calls and 10 templates. The Business plan also lists dynamic charts and custom fonts. Two technical limits apply to every plan: a compile run times out after 60 seconds, and template files can be at most 3Mb.

## When you hit a limit

The pricing page does not say what happens after your 50th call in a month. You never enter a card, so the free plan cannot turn into a bill. Check the dashboard before you rely on a specific behavior.

Two limits are stated clearly. A document that takes longer than 60 seconds to compile stops with a time-out. This protects the API from very long documents. A template file larger than 3Mb breaks the size limit. Large images are the usual cause, so shrink them first. Not every LaTeX package is available, so a package you need may be missing.

## Gotchas

- The free plan includes no private LaTeX templates, so you are limited to the ready-made JSON to PDF library.
- Some LaTeX packages are not available in the compiler, and you must find an alternative if yours is missing.
- Your account needs email verification before you can generate an API key.

## Questions people ask

### Is DynamicDocs free?

Yes, there is a free plan with 50 API calls per month. It includes the ready-made JSON to PDF templates but no private LaTeX templates.

### Does DynamicDocs need a credit card?

The pages we read do not mention a card for the free plan. You register with a valid email address and verify it.

### Can I use my own LaTeX template on the free plan?

No. The free plan lists 0 private LaTeX templates. The Individual plan is the first one with a private template slot.
