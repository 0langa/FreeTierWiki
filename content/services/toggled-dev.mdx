You manage projects, environments, and toggles in the web dashboard. Your app asks the client API for the active toggles, or uses the JavaScript SDK.

## What the free plan gives you

The pricing page calls it an endless free plan, with the complete set of Toggled.dev features. No credit card is required. The free plan covers a single project with up to 10 feature toggles. Unlimited clients and unlimited monthly active users are included, along with realtime notifications.

The docs repeat the project limit. They say the number of projects is limited by your license, and the free license includes one project only. An example project is created when you first set up the workspace. You can delete it and make your own.

The PRO plan costs $49 per month. It includes everything in Free, up to 3 projects, 10 seats, unlimited toggles per project, and helpdesk replies within 1 business day. Enterprise adds unlimited projects and seats, and a dedicated environment, optionally in your private AWS account.

## When you hit a limit

The pricing page says to subscribe to PRO plans to increase service quotas. It does not say what happens if you try to create an eleventh toggle or a second project. The limits are listed as the shape of the free plan, so expect the dashboard to ask for an upgrade.

The free plan needs no card, so there is no bill to run up. MAU are not a limit on any plan listed. To stay within 10 toggles, archive a toggle when its feature is removed from your code.

## Gotchas

- One project means one app or service. If you have a frontend and a backend as two projects, you need PRO.
- Client keys belong to an environment. Your app uses a different key for each environment.
- Session stickiness is an option on client keys. Turn it on when a gradual rollout must not flip a user between on and off at every check.
