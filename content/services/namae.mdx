You type a name into the website, and it shows one card per registry or service. It suits founders, open source authors, and anyone who needs one name that works in many places.

## What the free plan gives you

Namae is free, and its code is open under the Apache-2.0 license. The repository describes it as a way to save time searching around registries to see if a name is ready for use.

The source has 33 provider cards. They cover domains, GitHub, GitLab, npm, PyPI, RubyGems, crates.io, Homebrew, Docker, the Chrome Web Store, Firefox add-ons, the App Store, Google Play, Slack, YouTube, and Reddit, among others. The hosted site at namae.dev has no pricing page, and the repository does not describe any account step, limit, or paid tier.

## When you hit a limit

The pricing page does not say, because Namae has none. The checks run from your browser against each registry, so a registry can slow or block you if you search too fast. That limit comes from the registry, not from Namae.

The hosted site also uses a bot check, so a script cannot fetch it. If you need bulk checks, you must run your own copy of the open-source project.

## Gotchas

- Namae reports availability only. It does not register domains or reserve handles for you.
- The repository lists a card for each provider, and a provider can break or change without notice, because every check calls an outside service.
- To run it yourself, the contribution guide asks for the Vercel CLI, `yarn install`, and `vc dev`.

## Questions people ask

### Is Namae free?

Yes. The hosted app at namae.dev is free, and the source code is open under the Apache-2.0 license. The repository mentions no paid plan.

### Does Namae need an account or a credit card?

The repository describes no sign-in, account, or card step. You open the site and type a name.

### Can I host Namae myself?

Yes. The code is open source. The contribution guide says to install the Vercel CLI, run `yarn install`, and start the dev server with `vc dev`.
