You drive Cloud Build from the Google Cloud console or the `gcloud` command line. Each build is a list of steps, such as building a Docker image, and it fits teams that already use Google Cloud.

## What the free plan gives you

Each billing account gets 2,500 free build-minutes per month. The pricing page says this promotional free tier covers the `e2-standard-2` machine type in the default pool, and that the limit can change. The product page adds that up to 10 concurrent builds are included. Time spent waiting in the queue does not count as build time.

You can also ask for extra SSD storage for the build machine. The first 100GB is free. Every other machine type, and every private pool, has a per-minute price with no free minutes.

## When you hit a limit

Cloud Build does not stop your builds when the free minutes run out. It keeps building and bills the billing account for the extra minutes. On `e2-standard-2` the price is $0.006 per minute. Partial minutes are billed by the second.

Network egress is charged at standard rates. Because billing must be on for the project, set a budget alert in Google Cloud so a runaway build does not surprise you.

## Gotchas

- The free tier is called promotional and the pricing page says the limit is subject to change, so check the page before you rely on the number.
- The free minutes only apply to `e2-standard-2` in the default pool. Bigger or other machine types are billed from the first minute.
- Billing must be enabled on the Google Cloud project before you can run the quickstart builds.

## Questions people ask

### Is Google Cloud Build free?

Partly. Each billing account gets 2,500 free build-minutes per month on `e2-standard-2` machines. Minutes beyond that are billed.

### What happens when I go over the Cloud Build free minutes?

Builds keep running and Google charges the billing account. The pricing page lists $0.006 per minute for `e2-standard-2`.

### Does Cloud Build need a credit card?

You need a Google Cloud project with billing enabled, which means a billing account. The quickstart tells you to verify billing before you start.
