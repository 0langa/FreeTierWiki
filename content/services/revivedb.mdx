ReviveDB stores recovery points outside Supabase. It captures the database and Auth data as well as Storage files and supported Edge Functions, then restores the database dump into an isolated instance so it can compare the result against the source inventory. This gives you a backup to inspect before you need to recover from it.

## What the free plan gives you

The free plan covers one personal Supabase project and one person, with 500 MB each for the database and Supabase Storage. Backup processing has a 5 GB monthly allowance. Pricing still distinguishes backup storage from processing but no longer publishes its capacity, so the former 5 GB storage allowance is not confirmed. The schedule is weekly and the latest three recovery points are retained. Storage defaults to the EU with a US option per project; processing and restore tests run in Amsterdam. A business project serving customers requires Pro or Team.

The processing meter counts the compressed database dump and new Storage bytes. The service reuses unchanged files, so processing does not necessarily match the full size of all your stored objects on every run. Automatic verification does not consume that allowance.

## When you hit a limit

ReviveDB says it skips backups that would exceed the plan limits and sends a notification. There is no automatic overage on its side. Check when the most recent successful recovery point was created, especially after importing a large dataset or adding a Storage bucket. Supabase can count the data read by the backup as outbound traffic on the source project. Any cost for that traffic follows your Supabase plan.

## Gotchas

- In-place rollback requires a fresh verified safety backup; if that backup cannot complete, rollback does not start. Secret values are never copied and must be restored separately.

- Weekly recovery points can leave changes made since the last backup uncovered. Paid plans offer more frequent backups. ReviveDB checks database restores and verifies file and function artifacts separately. Review the recovery report to see what the backup covers.
- The restore guide requires a compatible supported Postgres version on the target. Pause writes before restoring into a project that is in use.

## Questions people ask

### Is ReviveDB free?

Yes. One eligible personal project gets weekly backups and three retained recovery points without a card.

### What happens if my project outgrows the free plan?

ReviveDB skips backups that would exceed the limits and alerts you. You can reduce the size of the source or switch plans.

### Can I restore into another Supabase project?

Yes. Choose a verified recovery point and a compatible empty target. Follow the recovery guide to review which components the restore can apply.
