Workflows lets you write a multi-step process as code in a Cloudflare Worker. Each step runs and is retried on its own, state is saved between steps, and a workflow can sleep or wait on an API response without using CPU time. It suits developers on Cloudflare who need background processes that pick up where they left off after a failure.

## What the free plan gives you

Workflows is included in both the Free and Paid Workers plans. On Workers Free you get 100,000 requests per day, shared with Workers requests, 10 milliseconds of CPU time per invocation, 1 GB-month of storage, and 3,000 steps per day. Billing for steps and storage applies starting August 10th, 2026.

The Free plan allows up to 1,024 steps per Workflow, 100 concurrent instances per account, and 100MB of persisted state per instance. A step.sleep can last up to 365 days, and instance state is retained for 3 days by default.

## When you hit a limit

The Free plan has fixed limits rather than overage charges. An instance that attempts to store state when you have reached the Free plan storage limit throws an error. Deleting instances frees storage, though it may take a few minutes for the limit to update.

On Workers Paid, the plan includes 10 million requests and 30 million CPU milliseconds per month, 1 GB-month of storage, and 500,000 steps. Extra steps cost $0.80 per 100,000, and extra storage $0.20 per GB-month.

## Gotchas

- Storage counts running, errored, sleeping, and completed instances, so set a shorter retention period if you do not need old state.
- Waiting on a response or sleeping uses no CPU time, but each step still counts toward the 3,000 per day.
- Workflows cannot be deployed to Workers for Platforms namespaces.

## Questions people ask

### Are Cloudflare Workflows free?

Yes, on the Workers Free plan, with 3,000 steps per day, 1 GB-month of storage, and 100,000 requests per day shared with Workers.

### What happens when a Workflow runs out of storage on the Free plan?

An instance that tries to store state past the Free plan storage limit throws an error. Deleting instances frees up storage.

### Does a sleeping Workflow use CPU time?

No. A Workflow that is waiting on an API response, paused by step.sleep, or otherwise idle does not incur CPU time.
