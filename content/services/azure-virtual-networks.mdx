You create a virtual network in the Azure portal, or with the CLI, PowerShell, or a template, and then place VMs and other resources in it. It suits anyone who runs more than a single public VM on Azure.

## What the free plan gives you

A virtual network costs nothing to create. Each subscription can hold up to 1,000 virtual networks across all regions. Resources inside a network can reach the internet outbound by default, and you can split the network into subnets and filter traffic between them with network security groups. You can also set your own routes with route tables.

You can link a network to your own site with a point-to-site VPN, a site-to-site VPN, or ExpressRoute. The network spans all availability zones in a region, so you do not split it by zone. Microsoft also says most networking limits are at their maximum values, and some can be raised on request.

## When you hit a limit

The network itself has no usage meter, so you do not get a bill for the network alone. You pay for what you add to it.

Peering links two networks, in one region or in two. The pricing page calls the charge nominal, and it applies to traffic at both ends. Global peering across regions uses zone-based rates. Network appliances that run inside a network, such as VPN Gateway and Application Gateway, are also charged. If you need more than 1,000 networks in a subscription, the pricing page does not say how to get more.

## Gotchas

- The page lists no peering rate in plain text, so price a peering link in the Azure pricing calculator before you build it.
- Peering charges both sides: ingress and egress traffic is billed at each end of the link.
- Peering adds no compute charges, but you still pay for the other resources you run in the network as usual.

## Questions people ask

### Is Azure Virtual Network free?

Yes, creating one is free. You can have up to 1,000 per subscription. Peering, VPN Gateway, and Application Gateway are charged.

### Does Azure Virtual Network need a credit card?

The pages I read do not say. The network runs inside an Azure subscription, so you need an Azure account first.

### Is VNet peering free?

No. Peering carries a charge, and traffic is billed at both ends of the link. Global peering between regions is priced by zone.
