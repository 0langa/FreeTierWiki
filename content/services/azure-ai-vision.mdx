You create a Computer Vision resource in the Azure portal, then call it from the REST API or an SDK. It suits developers who add captions, tags, or text reading to an image feature, and who accept that the current service is on a retirement path.

## What the free plan gives you

The Free (F0) tier includes 5,000 free transactions per month. The pricing page also lists a rate of 20 transactions per minute. The same 5,000 monthly amount and 20 per minute rate appear for Image Analysis model customization inferencing.

Image Analysis returns tags, captions, objects, smart crop regions, and text. The Read API reads printed and handwritten text from photos and documents. Face recognition is a separate Face service with its own pages.

The paid S1 tier bills per 1,000 transactions in volume bands. The price fields on the page are blank dashes, so use the Azure pricing calculator.

## When you hit a limit

The pricing page does not say what happens after 5,000 free transactions. The 20 per minute rate means a burst of calls can be rejected before you reach the monthly count.

Upgrading to S1 is a separate step in the Azure portal. Nothing on the pages says F0 moves up on its own. Space your calls out, keep a count of monthly calls in your own code, and plan a paid tier or a different service before you rely on the feature in production.

## Gotchas

- Microsoft says Image Analysis 4.0 is deprecated and will be retired on September 25, 2028. After that, calls fail, and the docs point to a migration guide.
- The overview now lists Image Analysis and OCR as legacy services.
- Image captioning in version 4.0 works only in certain Azure regions. Version 3.2 covers other regions.

## Questions people ask

### Is Azure AI Vision free?

Yes, within limits. The F0 tier includes 5,000 transactions per month at 20 transactions per minute.

### Is Azure AI Vision being retired?

Microsoft says Image Analysis 4.0 will be retired on September 25, 2028. The docs recommend moving to the alternatives in the migration guide.

### Does Azure AI Vision include OCR?

Yes. The Read API extracts printed and handwritten text, and the OCR service is listed in the overview as a legacy service.
