Mapbox sells maps, search, and navigation as APIs and SDKs. Developers use Mapbox GL JS for interactive web maps, the mobile Maps SDKs for iOS and Android, and web services such as geocoding and directions. Billing is pay-as-you-go, and most products start with a free monthly amount.

## What the free plan gives you

Mapbox accounts are free to create, and every pay-as-you-go account gets a monthly free tier on most services. Each product has its own amount. Mapbox GL JS includes up to 50,000 map loads a month; a map load counts every time the library initializes and covers unlimited vector and raster tile requests for that map. The Directions API includes up to 100,000 requests a month, and the Temporary Geocoding API includes up to 100,000 requests. The Static Images API includes up to 50,000 requests, and the mobile Maps SDKs include up to 25,000 monthly active users. The free tier resets on the first day of the account's billing period.

## When you hit a limit

Service does not stop. Mapbox sends an email the first time an account exceeds a free tier in a billing period, and usage notifications you set never pause your service. Usage beyond the free tier is billed as usual: web map loads past 50,000 cost $5.00 per 1,000, for example. The invoice is finalized on the last day of the billing period and charged to the payment method on file. Mapbox accounts do not support a spending cap; the docs suggest prepaid credit and monitoring to keep spending predictable.

## Gotchas

- Each Mapbox GL JS initialization is a new map load, so pages that recreate the map on every view use the free amount faster.
- The first billing period is shortened when you create an account mid-month, so that first free tier covers fewer days.
- Temporary geocoding results are not for storage; permanently storing results uses the separately priced Permanent Geocoding API.

## Questions people ask

### Is Mapbox free?

Within limits. Most products include a monthly free tier, such as 50,000 web map loads, and you pay for usage beyond it.

### Can I set a spending cap on Mapbox?

No. The docs say Mapbox accounts do not support a spending cap that cuts off services, and usage notifications never pause service.

### When does the Mapbox free tier reset?

It resets on the first day of the account's monthly billing period, which after the first month runs from the first to the last day of the month.
