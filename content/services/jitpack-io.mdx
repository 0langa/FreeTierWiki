You add the JitPack repository and a dependency line to your build file, and the first request triggers a build from Git. It suits open source Java and Android maintainers.

## What the free plan gives you

The pricing page says JitPack is always free for open-source projects. It checks out your code the first time someone requests it, builds it, and serves the build artifacts from a CDN. Maintainers see weekly and monthly download stats.

JitPack builds Gradle, Maven, Sbt, and Leiningen projects. You can ask for a release tag, a commit hash, a branch snapshot, or a pull request build. The docs say builds can take up to 15 minutes. The pages list no cap on the number of public repositories or builds.

## When you hit a limit

The pages describe no usage limits for public repositories, so there is no quota to hit. The limits that exist are about access and time. A build can take up to 15 minutes.

Private repositories need a subscription. The Individual plan is $12 a month for 3 private repos. Larger plans cost $29 a month for 10 private repos, $45 for 25, and $85 for 200. Prices exclude VAT, and enterprise plans are available on request.

## Gotchas

- Public artifacts are frozen after 7 days. Within the first 7 days you can rebuild to fix a release, but the docs recommend a patch release instead.
- If you delete a tag or repository on GitHub after JitPack built it, JitPack keeps serving the existing artifacts.
- Add the JitPack repository last in your Gradle repository list, because Gradle checks repositories in order.

## Alternatives in this atlas

- [GitHub Actions](/services/github-actions/): when you want your own build workflow and release step.

## Questions people ask

### Is JitPack free?

Yes for open-source projects. The pricing page says JitPack is always free for open-source. Private repositories need a paid subscription.

### How much does JitPack cost for private repositories?

The Individual plan is $12 a month for 3 private repos. Larger plans go up to $85 a month for 200 private repos.

### How long can a JitPack build take?

The FAQ says builds can take up to 15 minutes.
