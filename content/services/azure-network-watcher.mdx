You use Network Watcher in the Azure portal, PowerShell, the CLI, or the REST API. It is for people who run virtual machines and virtual networks in Azure and need to see why traffic does or does not flow. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## What the free plan gives you

Each month includes a fixed set of free units. You can collect 5 GB of network security group flow logs and 5 GB of virtual network flow logs. You can run 1,000 network diagnostic checks, which cover the diagnostic tools and the topology view. You can also run 10 Connection Monitor tests.

Network Watcher turns on by itself in a region when you create or update a virtual network there, and Microsoft says that carries no charge. The overview says it covers IaaS resources such as VMs, virtual networks, application gateways, and load balancers. It is not built for PaaS monitoring or web analytics.

## When you hit a limit

Nothing stops your usage at the free units. Azure bills each extra gigabyte of flow logs, each extra diagnostic check, and each extra Connection Monitor test. The pricing page hides the per-unit prices, so check the calculator before you scale up.

Some costs sit outside Network Watcher. Flow logs live in a storage account, and the pricing page says storage, Log Analytics, and event hub charges apply on their own. Traffic Analytics and Network Analytics show no free units. Packet capture on a scale set counts one check for every instance.

## Gotchas

- Connection Monitor tests are billed when you start them from the portal, PowerShell, the CLI, or the REST API, so 10 free tests go fast on a large setup.
- Flow log retention can be set from one day to 365 days. If you set none, the logs are kept forever and the storage bill keeps growing.
- Packet capture on a virtual machine scale set counts one check per instance, and Connection Monitor tests on a scale set count one test per instance, so the free units can go fast.

## Questions people ask

### Is Azure Network Watcher free?

Partly. It includes free monthly units for flow logs, diagnostic checks, and Connection Monitor tests. You pay for anything above them, and for the storage that holds flow logs.

### What happens when I go over the free Network Watcher limits?

Azure bills the extra usage per gigabyte, per check, or per test. It does not stop the service.

### Do I have to enable Network Watcher?

Usually not. Azure turns it on in a region when you create or update a virtual network there. You enable it by hand only if you opted out of automatic enablement.
