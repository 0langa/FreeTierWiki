You add a site from the Sevalla dashboard, connect a Git provider, and Sevalla builds and publishes it. It suits people who already build with Node.js tools or who push pre-built files.

## What the free plan gives you

Static site hosting is free for up to 100 sites per account. The free amounts each month are 100 GB of bandwidth and 600 build minutes. Each site has a build size of 1 GB and 1 concurrent build.

The pricing page lists static site hosting on more than 260 global edge locations. The Static Sites page of the docs lets you add a site from a Git repository, set a build command and publish directory, and read a build and rollout log for each deployment. The docs support GitHub, GitLab, and Bitbucket as Git providers, with auto-deploy on each commit and optional pull request previews.

## When you hit a limit

You can keep going past the free amounts, but usage is billed. After the first 100 GB of bandwidth in a month, Sevalla charges $0.1 per GB, counted by the byte. After the first 600 build minutes, it charges $0.05 per minute.

The invoice covers only bandwidth and build time for static sites. The static site docs say the company needs billing details and a valid payment method before you create any service, even though static sites are free up to the allowances. Pull request previews create a new deployment for each pull request, so they add to build minutes and bandwidth.

## Gotchas

- Sites that need server-side rendering, a database connection, sessions, or a build in a language other than Node.js fit better on Sevalla's paid application hosting.
- A site's permanent name comes from its display name plus a random suffix and never changes. You can edit the display name later.
- Static sites cannot run dynamic features such as contact forms on their own. The docs point to outside form services for that.

## Questions people ask

### Is Sevalla static site hosting free?

Yes, within limits. You get up to 100 sites, 100 GB of bandwidth per month, and 600 build minutes per month.

### What happens when I go over the Sevalla free static site limits?

Sevalla bills the extra. Bandwidth past 100 GB costs $0.1 per GB, and build time past 600 minutes costs $0.05 per minute.

### Which Git providers work with Sevalla?

GitHub, GitLab, and Bitbucket. You pick the repository and branch when you add a site, and you can turn on auto-deploy for each commit.
