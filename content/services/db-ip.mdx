You call the free endpoint straight from `curl`, a browser script, or the PHP client, with no account in the examples. It suits small sites and prototypes that need a visitor's country, state, or city and can live with plain HTTP.

## What the free plan gives you

The free API maps an IP address to country, state, and city. It is limited to 500 requests per day. The free URL uses `free` in place of an API key, for example `http://api.db-ip.com/v2/free/8.8.8.8`. You can also pass `self` to look up the address that sends the request.

The free API does not include the extra data of the paid Basic API, such as GPS coordinates, district, zip code, and timezone. Localized place names are for paid keys only. The Basic API starts at 8.29 EUR a month and adds HTTPS.

## When you hit a limit

The docs list an error `OVER_QUERY_LIMIT` for a key that has used its daily quota. A batch query that would go over the quota also raises it. The docs and pricing pages describe no bill for the free API.

The docs also list `TEMPORARY_BLOCKED` for the free API. DB-IP uses it when its systems see unusual or malicious activity, and it blocks the key for a while.

## Gotchas

- The free API works only over HTTP. Calling it over HTTPS returns the `HTTPS_NOT_ALLOWED` error, so a browser page served over HTTPS may block the call.
- A batch query helps your quota: it gets a 10% bonus, so 10 addresses cost 9 queries.
- Free responses carry less data than paid ones. For coordinates, timezone, or ASN data you need a paid API.

## Questions people ask

### Is the DB-IP API free?

Yes. The free API gives you country, state, and city for an IP address, limited to 500 requests per day.

### Does the DB-IP free API support HTTPS?

No. The docs say encrypted API access is only for paid service, and the free API returns `HTTPS_NOT_ALLOWED` over HTTPS.

### What happens when I go over the DB-IP free limit?

The API returns an `OVER_QUERY_LIMIT` error once you use your daily quota. The paid Starter plan raises the daily limit to between 2,000 and 50,000 requests.
