Speech-to-Text is a Google Cloud API for transcription. You send recorded audio, or stream it, and the API returns text, using models such as default, phone_call, video, and the medical models. It suits developers adding transcription or voice input to an app who want a managed API instead of hosting a model.

## What the free plan gives you

Speech-to-Text is part of the Google Cloud Free Tier. The free amount is 60 minutes per month per account for the Speech-to-Text V1 API, and it lasts after the free trial ends. The V1 pricing tables show the first 60 minutes at $0.00 for the standard models and for the medical models.

Audio is measured in increments of one second, and each request is rounded up to the nearest second. Only audio that the service processes counts. An empty response still counts, but a request that ends in a server error does not. A Google Cloud billing account is required to access the Free Tier.

## When you hit a limit

Nothing stops the API at 60 minutes. After the free minutes, V1 standard recognition with data logging costs $0.016 per minute, and without data logging $0.024 per minute. The medical models cost $0.078 per minute after the free minutes.

The V2 API has its own price table, starting at $0.016 per minute for standard recognition models, with no free minutes listed. Volume discounts apply at higher monthly totals, and you can watch usage in the billing console.

## Gotchas

- The free minutes are for the V1 API, so moving to V2 or its Chirp model means paying from the first minute.
- An empty response counts as processed audio, so sending silence still uses your minutes.
- The free amount is counted per billing account, not per project.

## Questions people ask

### Is Google Speech-to-Text free?

Within limits. The V1 API includes 60 minutes of audio per month for free, and minutes past that are billed.

### Does the V2 API have free minutes?

The Free Tier lists the 60 free minutes for the V1 API. The V2 pricing table starts billing from the first minute.

### Am I charged for failed requests?

Requests that end in a server error are not counted. An empty response, where the audio was processed but nothing was transcribed, does count.
