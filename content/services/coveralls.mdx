You sign in with your Git host, add a repository, and add an upload step to your CI. Coveralls then tracks coverage for every build. It suits open source maintainers who want free coverage history.

## What the free plan gives you

Coveralls says it will always be free for open source. To qualify, a repository only has to be publicly accessible on GitHub, GitLab, or Bitbucket. Coveralls does not look at the license of the project. All plans include unlimited users, and any user with access to a repository at your Git host can see its coverage reports.

The service gives you unlimited history of coverage by build, by subproject, and by source file. It supports push builds, pull request builds, and parallel builds. Notifications include pull request comments and status updates. Official integrations are the Coveralls GitHub Action and the Coveralls Orb for CircleCI. There is also a Universal Coverage Reporter.

## When you hit a limit

The free service has no listed caps on public repositories. The line is private code. Paid plans are tied to one organization at your Git host and are priced by the number of private repositories: Starter costs $10 per month for 1 private repository, Org costs $50 for 10, Org+ costs $100 for 20, and Pro costs $200 for 40. The Unlimited plan costs $400 per month.

Yearly billing gets a 10% discount. Starter has a 30-day free trial. You need to give payment information to start it, but your card is not charged if you cancel before 30 days. The pricing page does not say what Coveralls does if you add a private repository without a plan.

## Gotchas

- The Coveralls bot asks for write access on GitHub because GitHub has no read-only scope for private repositories. It uses the access to send pull request comments.
- You must store the `repo_token` in a CI secret called `COVERALLS_REPO_TOKEN`.
- Pull request comments on a private repository need extra commenting access for the Coveralls bot.

## Questions people ask

### Is Coveralls free?

Yes, for public repositories. Coveralls says it will always be free for open source, and any publicly accessible repository qualifies.

### How much is Coveralls for private repositories?

The Starter plan costs $10 per month for 1 private repository. The Org plan costs $50 per month for 10.

### Does Coveralls need a credit card?

Not for open source. The 30-day Starter trial for private repositories needs payment information, but cancelling before 30 days means no charge.
