You use Cloud Shell from the Google Cloud console in a browser tab. You type commands in a terminal, and it suits anyone who manages Google Cloud and wants no local install.

## What the free plan gives you

The pricing page says Cloud Shell is free for users with a Google Cloud account. The default weekly quota is 50 hours. You can see the hours left and the reset time in Session information, under Usage quota.

Each user gets 5 GB of persistent disk storage, mounted as the home directory. Files there, such as `.bashrc` and `.vimrc`, stay between sessions. Sessions end after 12 hours, and you can start a new one right away. The product page says the virtual machine lets you edit files, work with repositories, and preview web apps.

## When you hit a limit

At the weekly quota, you wait until the reset date and time before you can use Cloud Shell again. Google also offers an upgrade to Cloud Workstations, which has no weekly limit.

Idle sessions do not run forever. The virtual machine ends after 40 minutes of inactivity, and changes outside the home directory are lost. Non-interactive sessions end after 40 minutes. The docs show no bill for any of this, so no charge appears when you hit a limit.

## Gotchas

- Cloud Shell is for interactive use only, so a script left running unattended is cut off after 40 minutes.
- Google deletes your home directory after 120 days without access, or if you delete it, and cannot recover the files. You get an email first, and starting a session prevents it.
- Anything you install outside the home directory is gone when the virtual machine ends.

## Questions people ask

### Is Google Cloud Shell free?

Yes. The pricing page says Cloud Shell is free for users with a Google Cloud account. It has a weekly quota of 50 hours and 5 GB of storage.

### How long can I use Cloud Shell?

A session lasts up to 12 hours, and the weekly quota is 50 hours. An idle virtual machine ends after 40 minutes.

### Does Cloud Shell keep my files?

Files in your home directory stay between sessions, up to 5 GB. Google deletes them after 120 days without access, so start a session now and then.
