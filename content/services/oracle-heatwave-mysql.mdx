MySQL HeatWave is a fully managed MySQL database service on Oracle Cloud that combines transactions, analytics, machine learning, and GenAI services. You create a DB system in the Oracle Cloud Console and connect with any MySQL client. It suits developers who want a free managed MySQL server and are fine creating an Oracle Cloud account.

## What the free plan gives you

All tenancies get a standalone MySQL HeatWave DB system as an Always Free resource, free or paid accounts alike, in the home region. It uses the MySQL.Free shape with a fixed 50 GB of storage for data and log files, plus an extra 50 GB of backup storage. You can add a one-node HeatWave cluster on the HeatWave.Free shape.

MySQL HeatWave AutoML and Lakehouse are supported. HeatWave GenAI is supported from version 9.3.1, but Vector Stores are not. The DB system is created with the latest version and upgraded in each maintenance cycle. Inbound and outbound replication are allowed.

## When you hit a limit

The Always Free system has a fixed shape and storage size, so it does not grow into paid usage. Each tenancy can create one, and Oracle's docs do not describe a charge for it. A second DB system, or one on another shape, is a paid resource.

The limits are about features. High availability and read replicas are not supported. Automatic backup keeps 1 day, and manual backup and point-in-time recovery are not available. The Always Free service has no Service Level Agreement and is not eligible for Oracle Support.

## Gotchas

- You cannot choose the MySQL version; the system always runs the latest one and upgrades during maintenance.
- With only a one-day automatic backup, keep your own exports of important data.
- Database Management and Ops Insights integrations are not available for the Always Free system.

## Questions people ask

### Is Oracle MySQL HeatWave free?

Yes, as an Always Free resource: one standalone DB system per tenancy with 50 GB of storage and an optional one-node HeatWave cluster.

### Does the Always Free MySQL system have backups?

Automatic backups are on with 1 day of retention. Manual backups and point-in-time recovery are not available.

### Can I use high availability on the free system?

No. High availability and read replicas are not supported on the Always Free DB system.
