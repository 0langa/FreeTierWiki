You use IntoDNS.ai in the browser by typing a domain, or from code through its public REST API. It suits site owners and admins who want to fix mail and DNS settings without paying for a tool.

## What the free plan gives you

The pricing page advertises free access with no credit card or trial. Its blanket claim that all features are free conflicts with the API documentation, which mentions paid AI helper endpoints; confirm AI helper costs before using them. Without an account you can scan any domain, run the email security check for SPF, DKIM, and DMARC, check blacklists, export a PDF report, and test email deliverability. You can also use the SPF, DMARC, MTA-STS, and BIMI generators and embed a security badge.

The public API is open. DNS, email, blacklist, and quick-scan endpoints need no API key. The site advertises more than 60 security checks and scans that finish in under 3 seconds.

A free account adds nightly monitoring, AI-assisted explanations, scan history, saved domains, email fix digests, and a CSP Monitor.

## When you hit a limit

Public diagnostic scans and API endpoints are advertised as free, without a numeric scan cap. API bursts, report-snapshot creation and AI helper calls may return HTTP 429 with a Retry-After header. The pricing page lists no paid tier, while the API docs mention paid AI helper endpoints without prices or billing terms; do not assume those helpers share the public diagnostics offer.

If you get a 429, wait for the time in Retry-After and send the request again. The pages give no numbers for the limit, so space out batch jobs.

## Gotchas

- Monitoring, scan history, and fix digests need a free account. Plain scans do not.
- The DKIM check looks for common selectors and a published key. The site says this cannot prove your outgoing mail is signed, so use the email test for that.
- The API page names other sites it does not run, api.intodns.io and intodns.io, so make sure you call intodns.ai.

## Questions people ask

### Is IntoDNS.ai free?

Public scans and diagnostic API access are free without an account or card. A free account adds monitoring. AI helper costs need confirmation because the pricing page and API documentation conflict.

### Does IntoDNS.ai need an account?

No for scans, reports, and the public API. A free account is only needed for nightly monitoring, scan history, and email fix digests.

### Does IntoDNS.ai have an API rate limit?

Yes, but no number is published. The API calls it generous and says bursts may get HTTP 429 with a Retry-After header.
