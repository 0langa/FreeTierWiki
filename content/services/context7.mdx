Context7 retrieves documentation that a coding tool can use as context. It can help when you want an agent to work from a library’s docs while changing a project. Give it the library and version when you can, then compare the retrieved examples with the dependency in your code.

## What the free plan gives you

Free includes 1,000 calls a month across the Search and Context APIs and covers public repositories. When an integration searches first and retrieves a result afterward, consider both operations when reading the usage totals. A focused question about one API can be more useful than retrieving broad documentation for an entire library. The usage dashboard tracks requests against the plan. If your integration repeats the same lookups across related assignments, check how much of the allowance that uses before turning it on for every step of an automated process.

## When you hit a limit

The plans FAQ says it blocks requests at the 1,000-call monthly threshold and then grants 20 bonus calls each day until the month resets. The usage guide describes a stop at quota in simpler terms. Plan for the regular monthly limit and treat the bonus as reduced capacity while blocked. Paid plans list their own per-seat limits and billed usage. Consolidating related documentation questions can leave more room for urgent lookups.

## Gotchas

- The scope of the Free plan is public repositories. Private library access is a paid-plan concern. Check which library version the result covers before copying an example into your project.
- Search and content retrieval share the included balance. Usage resets on the first day of each calendar month in UTC. Before downgrading to Free, review the resources marked for deletion. Unpaid usage is charged before the downgrade.
- Pro is $10 per seat monthly with 2,000 calls per seat, then $5 per 1,000 extra calls. Unused calls from another seat cannot cover an overage. Private parsing costs $5 per million tokens; cached content is not charged again on refresh.

## Questions people ask

### Is Context7 free?

The Free plan includes 1,000 calls per month for public documentation.

### What happens when the monthly limit is used up?

The pricing FAQ documents a block with a small daily allowance until the next monthly reset.

### Can my whole integration use the daily bonus?

The published bonus is 20 calls per day once blocked. Consider the number of calls a search and fetch workflow needs.
