ReadMe is a hosted platform for API documentation. You bring an OpenAPI description or write pages in its editor, and it publishes an interactive API reference, guides, and a developer dashboard. It suits API teams and solo maintainers who want a docs site without running one.

## What the free plan gives you

The Starter plan is $0 a month and the pricing page calls it free for everyone. It covers 1 project with 1 published version. You get Markdown guides, the interactive API reference, bi-directional sync, a custom domain, customizable themes, usage metrics, and documentation metrics.

The included AI features on Starter are the AI dropdown, LLMs.txt, and an MCP server. The Developer Dashboard keeps 24 hours of request history and detailed logs, and the plan has 1 admin. Anything that needs a second editor, such as inviting teammates, multiplayer editing, branching and reviews, or private docs, is part of Pro.

## When you hit a limit

The free plan's limits are counts of projects, versions, and admins, not usage. When you need more, move to Pro at $250 a month billed annually, which adds unlimited published versions and up to 5 admins, with each extra admin at $20.

The pricing table lists Ask AI at $150 a month and extended request history and logs at $100 a month under every plan. The plan guide says add-ons are available on all plans, but the billing guide says Ask AI is available at checkout or after you pay for a plan, and the Developer Dashboard add-on only after you pay. Confirm availability before relying on either add-on on Starter. The pricing page describes no automatic Starter charge.

## Gotchas

- Only one version can be published, so docs for an old and a new API version cannot live side by side on Starter.
- Private docs and end-user login need a paid plan, so Starter docs are public.
- Request history in the Developer Dashboard covers only the last 24 hours unless you pay for extended history.

## Questions people ask

### Is ReadMe free?

Yes. The Starter plan costs $0 a month and covers 1 project with 1 published version, an interactive API reference, and a custom domain.

### Can my team edit docs together on the free plan?

No. Inviting teammates, multiplayer editing, and branching and reviews are Pro features. Starter has 1 admin.

### Is Ask AI included?

No. The pricing table lists a $150 a month Ask AI add-on on Starter, and the plan guide says add-ons are available on all plans, but the billing guide says Ask AI is available at checkout or after you pay for a plan. Confirm availability with ReadMe.
