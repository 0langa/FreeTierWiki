You browse the font catalog on fonts.bunny.net, copy a CSS or HTML snippet, and paste it into your site. If you already use Google Fonts, you can switch by changing the hostname in your source. It suits site owners who want web fonts without visitor tracking.

## What the free plan gives you

Bunny Fonts is free. The product page says no account is needed and that it is always free. You pick a font family, choose weights and styles, and copy a CSS import or an HTML link tag. The site lets you filter fonts by category, such as serif, sans-serif, display, handwriting, and monospace, and by language subset.

The service logs nothing and sets no cookies, according to the product page and FAQ. The API matches the Google Fonts CSS v1 format. All fonts in the collection are open source, so you can use them in commercial projects, though each family has its own license. Bunny.net hosts the fonts on its global CDN.

## When you hit a limit

The pages list no request limit, bandwidth cap, or paid tier for Bunny Fonts. Because no account or payment method is involved, there is nothing to bill. The pages do not say what would happen under extreme traffic, so treat that as unknown.

The practical limits are about content. You can only use fonts that are in the collection. Fonts are not frozen, so a family can change when its authors publish fixes. If your design needs an exact font file that never changes, download it and host it yourself.

## Gotchas

- Not every font shares one license. Some licenses require attribution when you re-distribute the font, and each family page shows its license.
- Fonts are not frozen. Font files change from time to time when their authors make fixes or improvements.
- The migration works because the API is compatible with Google Fonts CSS v1. Check your pages after you swap the hostname.

## Questions people ask

### Is Bunny Fonts free?

Yes. The product page says no account is needed and that it is always free.

### Is Bunny Fonts a drop-in replacement for Google Fonts?

Yes, the FAQ says it uses the same API format. You replace the Google Fonts CSS hostname with fonts.bunny.net in your source.

### Can I use Bunny Fonts commercially?

Yes. The FAQ says all fonts in the collection are open source and can be used without fees in products and projects. Check each family page for its license.
