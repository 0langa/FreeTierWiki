You do not call an API. You copy one import rule or one link tag from the docs and add a font-family rule. Web developers who want open-source fonts without an account are the main audience.

## What the free plan gives you

xz/fonts is a free and open-source service, so there is no free plan to compare with a paid one. The site and the docs list no price, no quota, and no account. It delivers font families to websites using CSS and serves only open-source fonts.

The docs offer two ways to install a font. You can paste an import rule at the top of your main CSS file, which the docs recommend, or you can paste a link tag in your page's head. After that, you add a font-family rule that names the font. The docs say existing CDN links will keep working and that there are no plans to deprecate them.

## When you hit a limit

The pages list no limits, so there is nothing to hit. The service says it is free and open source, and it does not mention rate limits, quotas, or paid tiers.

The one change to watch is hosting. The site says the content delivery network is moving to bunny.net because Vercel ended its open-source sponsorship program. The service now serves font files through bunny.net's global network.

## Gotchas

- The service delivers only open-source fonts. You cannot upload your own font files or use commercial fonts.
- Put the import rule before any rule that uses the font. The docs say it must be declared first, so keep it at the top of the CSS file.
- To get a new font added, open an issue or a pull request on the project's GitHub page.

## Questions people ask

### Is xz/fonts free?

Yes. It is a free and open-source service. The site mentions no account, API key, price, or quota.

### Who hosts the xz/fonts files?

bunny.net. The site says font files are served through bunny.net's global content delivery network, and the move came after Vercel ended its open-source sponsorship program.

### Do old xz/fonts links still work?

Yes. The site says all existing CDN links will continue working, and that there are no plans to deprecate them.
