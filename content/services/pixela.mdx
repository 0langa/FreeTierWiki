You use Pixela entirely through HTTP calls, such as curl, a script, or a webhook. There is no web sign-up form. It suits hobby coders and habit trackers who like to automate.

## What the free plan gives you

Pixela says it provides almost all of its features for free. Some features are only for people who pay for Pixela through Patreon. All operations go through the API.

You create a user with one POST call, then create graphs and post one number per day to each graph. The API also has instant recording calls to increment, decrement, add, or subtract a pixel, and a stopwatch endpoint for recording time. Other endpoints cover webhooks, graph stats, a user profile page, and a remote MCP server.

Features limited to supporters with a valid thanks-code include batch pixel posting and the AI analysis endpoint. They also include a supporter badge and ad hiding on graph and profile pages, Retina display in all periods, graph paging, the isSecret option, and optional data in SVG output.

## When you hit a limit

Pixela has no listed quota and no price. The one hard limit is on requests. The Patreon page says supporters get a change that disables a rule where some APIs reject requests 25% of the time. For free users, that means a call can fail, so handle errors in your code.

If you stop supporting Pixela on Patreon, the limited features stop working, because the account is linked to Patreon.

## Gotchas

- Handle failed calls. Some APIs reject requests from non-supporters about 25% of the time.
- Making a graph secret needs the isSecret option, which is a supporter feature.
- Your token is hashed and saved at sign-up. Pixela stores only a hash of your token, so keep your own copy.

## Questions people ask

### Is Pixela free?

Almost all features are free. A few, such as batch pixel posting and the isSecret option, are only for Patreon supporters.

### How do I create a Pixela account?

You do not use a sign-up form. Send a POST request to the users endpoint with a token, a username, and yes to the terms and not-a-minor fields.

### Why does Pixela reject some of my API requests?

Some APIs reject requests for non-supporters. Supporters have that rule disabled.
