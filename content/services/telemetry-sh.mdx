Telemetry stores app events so you can ask questions in SQL. It suits an app with a few well-defined events that you want to explore, such as how often a background operation finishes or how a timing metric changes after a release.

## What the free plan gives you

The current pricing page lists 1 GB of storage, one user and one query CPU-hour per month. It says you can start without a card. SQL queries, dashboards and alerts are available on Free. To get a feel for the interface, start with its sample data before deciding which fields to send from your app. A query can narrow the event type and time range, then feed a chart that you revisit. The query meter measures CPU time across workers, which can differ from the time a person waits for the response.

## When you hit a limit

There are two allowances to watch. A burst of large events primarily affects storage, while repeated queries over a large dataset affect query time. The expanded pricing FAQ says excess Free storage prompts a request to reduce usage or upgrade. You can selectively delete data by time or column values. It does not specify a precise shutdown threshold or what happens when Free query time is exhausted. Paid storage overage is $0.03 per GB-month and paid query overage is $0.30 per CPU-hour; those rates are not stated as automatic Free charges. Use the usage figures in the product when planning a dashboard or alert with recurring queries.

## Gotchas

- Free is for one user. If teammates need their own access, check the paid plan. Open-source maintainers can request separate unlimited OSS access after creating an account; provider activation is required. Account creators must be over 18, according to the pricing page.
- A small dataset can still use its query allowance through frequent or heavy scans.
- Choose the event fields you need before enabling broad logging. This helps preserve space for the events you actually query.

## Questions people ask

### Is Telemetry free?

Yes. The Free plan has a monthly query allowance and a storage limit, and the provider says it requires no card.

### What does a query CPU-hour measure?

The provider measures time actually spent working across query workers. Waiting for a response and query CPU usage are different measurements.

### Can I try SQL before wiring up my app?

The pricing page offers a sample-query entry point before connecting an application, but its link opens registration; it does not establish account-free access.
