You work in the Chrome extension and the web dashboard. You can also start recipes and fetch results through an API with a Bearer key. It suits people who want data from a page without writing code.

## What the free plan gives you

Scraping one page in the browser is free. That covers the quick job of clicking elements on a page and exporting them. Cloud scraping uses credits instead, and you start with 100 free credits when you sign up. Simplescraper tells you to use them.

Credits are priced by where and how a page runs. One page in the cloud with JavaScript on costs 2 credits, and one page with JavaScript off costs 1. JavaScript is on by default because most modern sites need it. Each page of a multiple-page browser scrape costs 1 credit, and every 500 words read or generated by the AI features cost 1 credit.

## When you hit a limit

The docs do not say what happens when the 100 free credits are used up. The pricing page needs JavaScript to load, so this atlas could not read it. The credits are a starter amount. Credits renew each month only on paid subscriptions.

The docs list single-page browser scraping as free. A crawler recipe can scrape up to 10,000 URLs at a time, and API requests have no concurrency limits.

## Gotchas

- The 100 credits arrive once at sign-up. They do not refill each month on a free account.
- Turning JavaScript off halves the cloud cost of a page, but many modern sites need it to load their data.
- The 1-credit rate for a cloud page applies to single-page runs only, because multi-page runs load a full browser for every page.

## Questions people ask

### Is Simplescraper free?

You can scrape a single page in the browser for free. You also get 100 free credits at sign-up for cloud scraping.

### How do Simplescraper credits work?

Credits pay for cloud scraping, multiple-page browser scrapes, and AI features. A cloud page costs 2 credits with JavaScript and 1 without. Credits renew monthly only on paid plans.

### Does Simplescraper need a credit card?

The docs do not mention a card. You sign up and start with 100 free credits.
