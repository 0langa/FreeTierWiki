ZenRows handles fetching a website for your application. Its credit meter covers a basic page request as well as options for pages that need rendering. A developer can start with a plain request, then choose a more expensive option for pages whose content fails to come through.

## What the free plan gives you

Free includes 5,000 credits a month and five concurrent requests without a card. Credits refresh monthly and do not roll over. The pricing documentation says a standard successful page costs one credit, with higher multipliers for JavaScript rendering and premium proxies. Using both can consume more than adding either one by itself. Free excludes standalone Residential Proxies. Start by checking the response from a standard fetch. If you add a feature to make an extraction work, measure the change in credit use on representative pages before applying it to the whole workload.

## When you hit a limit

A batch can run into a concurrency limit before consuming the balance. The monthly credit allowance can also run out even if you have few concurrent requests. The published Free description states the quota without explaining each account response at exhaustion. Keep a count of successful work and options used so you can see why usage exceeded your estimate. Reserve expensive browser requests for pages where a standard fetch is inadequate.

## Gotchas

- A request with premium features can use several credits. Avoid treating the balance as a uniform number of pages.
- Unused free credits do not carry over to the next month.
- Keep standalone proxy plans separate from scraping options available within the unified credit balance.

## Questions people ask

### Is ZenRows free?

Yes. The published Free plan includes 5,000 credits per month and requires no card.

### Do all requests cost one credit?

A standard successful page has that rate. Browser rendering, proxy options and other work have different costs.

### How many jobs can run at once?

Free lists five concurrent requests. That capacity is separate from the monthly balance.
