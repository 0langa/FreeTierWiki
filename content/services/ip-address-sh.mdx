You call `ipaddress.sh` from a terminal, a script, or a browser, and it answers with the address your request came from. It suits admins and developers who need a quick answer and nothing more.

## What the free plan gives you

The about page shows no pricing, no paid plan, and no sign-up, key, or card step in its examples. It does not use the word free. The about page says it serves more than 5M queries per day.

A plain request returns just the IP address as text. Add `?format=json` for a JSON object with one field named `ip`. Add `?format=jsonp` for a JSONP callback, and add `&callback=` with a name to choose the function name. The page shows code samples for curl, wget, Python, JavaScript, Node.js, Go, Rust, Ruby, PHP, Java, C#, Swift, and Kotlin.

The answer holds your IP address only. It does not give location, provider, or other details.

## When you hit a limit

The about page does not publish a rate limit, a quota, or a paid tier. It also does not say what happens when you send a very large number of requests.

You will not get a bill, because nothing on the page asks for payment. For a script that runs often, cache the result and check it only when you need to.

## Gotchas

- The page gives no uptime promise or SLA, so do not make a production system depend on it alone.
- The answer is the IP address your request arrives from. Behind a proxy, VPN, or shared network, that is not your own machine's address.
- The page shows no rate limit, so keep your script from calling it in a tight loop.

## Questions people ask

### Is IP address.sh free?

It looks that way. The about page shows no sign-up, key, card, or paid plan, but it does not state a price either way.

### Does IP address.sh have a rate limit?

The about page does not publish one. Cache the result in scripts so you do not call it more often than needed.

### How do I get my IP as JSON from IP address.sh?

Request `https://ipaddress.sh?format=json`. The response is a JSON object with one `ip` field.
