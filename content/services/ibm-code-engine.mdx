Code Engine is IBM Cloud's fully managed, serverless platform for containerized workloads: web apps, microservices, event-driven functions, and batch jobs. It can build container images for you from source code. You group apps, jobs, and builds in a project. It suits developers who want to run containers without managing a Kubernetes cluster.

## What the free plan gives you

Code Engine has an always free tier that renews each month and applies globally. It covers 100,000 vCPU seconds per month, which IBM describes as 27+ vCPU hours, 200,000 GB seconds of memory, and 100,000 incoming HTTP requests.

You pay only for resources your workloads consume. If an app scales to zero, or a job or build is not running, it uses no resources and is not charged. Internal HTTP traffic between workloads in the same project is excluded from the billable HTTP call total.

## When you hit a limit

Nothing stops your apps at the free amounts; charges apply for consumption beyond the monthly free tier. For applications and functions, the catalog lists $0.00003431 per vCPU second, $0.00000356 per GB second, and $0.538 per 1 million HTTP requests. Jobs and builds pay the same CPU and memory rates.

IBM's example: an app with 2 GB of memory and 1 vCPU at a fixed scale of 1 is charged 1 vCPU hour and 2 GB hours every hour. Scaling it to 2 instances doubles both.

## Gotchas

- Setting a minimum scale above zero keeps an instance running and billing around the clock.
- IBM Cloud registration asks for credit card information for security and identity verification, even if you use only free plans.
- A promotion for net-new accounts cuts container runtime costs by 50 percent for six months, but it is separate from the always free tier.

## Questions people ask

### Is IBM Code Engine free?

Within limits. Each month 100,000 vCPU seconds, 200,000 GB seconds, and 100,000 HTTP requests are always free.

### Am I charged when my app is idle?

Not if it scales to zero. An app that has scaled to zero, or a job that is not running, uses no resources and is not charged.

### Does IBM Cloud need a credit card?

Yes. IBM says you provide credit card information at registration for account security and identity verification.
