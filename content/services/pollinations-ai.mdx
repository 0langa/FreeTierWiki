You call a plain HTTP API at gen.pollinations.ai, point an OpenAI SDK at it, or run the `npx @pollinations/cli` command line tool. You create keys on the enter.pollinations.ai site. This page covers how the free Pollen credits work.


## What the free plan gives you

The pages list no flat free quota. Pollinations uses Pollen credits instead, and the docs put the price at about $1 per Pollen. You can earn free Pollen by completing Quests.

The FAQ says no credit card is required to earn Quest Pollen. Check the Quests dashboard for eligibility and reward amounts; there is no fixed free allowance for every account. Paid-only models require Paid Pollen, so earned credits do not unlock every model.

One key can reach image, text, audio, and video models. You can also limit a key to chosen models. Keep personal secret keys (`sk_`) on your backend. For client apps, an App Key identifies the app in Connect User Wallets; each user authorizes a scoped secret key and budget for their own wallet.

## When you hit a limit

A 402 error means an account balance or per-key budget cannot fund a request. Each request uses one balance: regular models use Quest Pollen if it covers the estimate, otherwise Paid Pollen. Paid-only models need Paid Pollen. The final cost can exceed the estimate and make the selected balance negative; this is not a strict spending cap.

The API can also return 429 or 503. The `Retry-After` header tells you how long to wait. The API docs describe legacy raw `pk_` keys as limited to 1 Pollen per IP per hour. The dashboard announces that from November 1 they will only identify apps; new integrations should use Connect User Wallets.

## Gotchas

- The free Pollen amount is not published. Check the Quest list and your balance on enter.pollinations.ai before you plan a project.
- Never publish a personal `sk_` key in client code or a repository. Client apps should obtain user-authorized scoped keys through the wallet flow.
- Model IDs now follow the publisher/model form, such as `black-forest-labs/flux.1-schnell`. Old IDs still work as aliases.

## Questions people ask

### Is Pollinations free?

Partly. You can earn free Pollen through Quests with no credit card. After that, usage costs about $1 per Pollen.

### What happens when I run out of Pollen?

Unfunded requests fail with 402. The final cost of an already admitted request can still make the selected balance negative.

### Does Pollinations need a credit card?

No. The project says you can earn Pollen by contributing, with no credit card required.
