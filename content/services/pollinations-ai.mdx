You call a plain HTTP API at gen.pollinations.ai, point an OpenAI SDK at it, or run the `npx @pollinations/cli` command line tool. You create keys on the enter.pollinations.ai site. This page covers how the free Pollen credits work.


## What the free plan gives you

The pages list no flat free quota. Pollinations uses Pollen credits instead, and the docs put the price at about $1 per Pollen. You can earn free Pollen by completing Quests.

The project says you can earn Pollen by contributing and that no credit card is required. The pages do not publish how much free Pollen a new account gets.

One key can reach image, text, audio, and video models. You can also limit a key to chosen models. Secret keys that start with `sk_` work for backend use. App keys let your users pay for their own usage, so you pay nothing for them.

## When you hit a limit

When a key has no balance left, the API returns a 402 error. The docs say this means the account balance or the per-key budget is used up. Earn more Pollen or buy a pack to continue.

The API can also return 429 or 503. The `Retry-After` header tells you how long to wait. Older public keys that start with `pk_` have a rate limit of 1 Pollen per IP per hour.

## Gotchas

- The free Pollen amount is not published. Check the Quest list and your balance on enter.pollinations.ai before you plan a project.
- Never put an `sk_` key in browser code, a repository, or a public URL. Use an app key with the user wallet flow for client apps.
- Model IDs now follow the publisher/model form, such as `black-forest-labs/flux.1-schnell`. Old IDs still work as aliases.

## Questions people ask

### Is Pollinations free?

Partly. You can earn free Pollen through Quests with no credit card. After that, usage costs about $1 per Pollen.

### What happens when I run out of Pollen?

Requests fail with a 402 error until you earn or buy more Pollen.

### Does Pollinations need a credit card?

No. The project says you can earn Pollen by contributing, with no credit card required.
