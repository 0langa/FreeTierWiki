You call a plain HTTP API at gen.pollinations.ai, point an OpenAI SDK at it, or run the `npx @pollinations/cli` command line tool. You create keys on the enter.pollinations.ai site. This page covers how the free Pollen credits work.

## What the free plan gives you

No fixed free quota is published. Pollinations now shows prepaid prices and balances directly in dollars. You can fund your Quest balance by completing eligible Quests and claiming the rewards. Requests spend according to each model's tokens, images, seconds or other usage unit.

The FAQ says no credit card is required to earn Quest Pollen. Check the Quests dashboard for eligibility and reward amounts; there is no fixed free allowance for every account. Paid-only models require Paid Pollen, so earned credits do not unlock every model.

One key can reach image, text, audio, and video models. Keys can restrict model access. Keep personal secret keys (`sk_`) on your backend. For client apps, an App Key identifies the app in Pollinations Pay, and through Pollinations Pay each user authorizes a scoped secret key and budget for their own wallet.

## When you hit a limit

A 402 error means an account balance or per-key budget cannot fund a request. Each request uses one balance: regular models use Quest Pollen if it covers the estimate, otherwise Paid Pollen. Paid-only models need Paid Pollen. The final cost can exceed the estimate and make the selected balance negative; this is not a strict spending cap.

The API can also return 429 or 503. Slow down for 429 and use backoff for 503; honor a `Retry-After` header when one is provided. The current official repository lists `pk_` App Keys as identifiers for Pollinations Pay that cannot authenticate requests. Use the user-wallet authorization flow for client apps; secret `sk_` keys remain for server-side use.

## Gotchas

- No fixed free credit amount is published, and Quest rewards can change. Check the Quest list and your balance before planning a project. Paid top-ups are one-time Stripe purchases; optional automatic top-up can charge a saved supported payment method. The service does not require a monthly subscription.
- Never publish a personal `sk_` key in client code or a repository. Client apps should obtain user-authorized scoped keys through the wallet flow.
- Model IDs now follow the publisher/model form, such as `black-forest-labs/flux.1-schnell`. Old IDs still work as aliases.

## Questions people ask

### Is Pollinations free?

Partly. You can earn free Pollen through Quests with no credit card. Usage is metered at each model's current price; credits and balances are shown in dollars.

### What happens when I run out of Pollen?

Unfunded requests fail with 402. The final cost of an already admitted request can still make the selected balance negative.

### Does Pollinations need a credit card?

No. The project says you can earn Pollen by contributing, with no credit card required.
