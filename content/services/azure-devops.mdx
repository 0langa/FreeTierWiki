You use Azure DevOps in the browser, with Git on your machine and pipelines defined in YAML. It has separate services for Repos, Pipelines, Boards, Test Plans, and Artifacts.

## What the free plan gives you

The Basic plan is free for the first 5 users. Azure Repos gives you unlimited private Git repositories. Azure Artifacts includes 2 GiB of free storage per organization.

For Azure Pipelines, each organization gets one parallel job with 1,800 minutes (30 hours) of build time per month on Microsoft-hosted agents. It also gets one free self-hosted parallel job with unlimited minutes. Users beyond the first five are assigned the Stakeholder tier by default, which is free but has less access. The FAQ says you can add unlimited users to an organization and they get access to Azure Pipelines or Azure Artifacts at no extra charge.

## When you hit a limit

If you need more time or more concurrent jobs, you buy pipelines. A Microsoft-hosted parallel job costs $40 and a self-hosted one costs $15 per extra job. The FAQ explains that buying your first Microsoft-hosted pipeline keeps the job count at one and only removes the time limit. To run two jobs at once, buy two.

The create-organization docs add that if you go over the free tier limits, you pay for the extra usage through your linked Azure subscription. For more users who need Repos and Boards, buy Basic licenses. The FAQ says a credit card is not needed to get started, and that the card is set up when you buy more.

## Gotchas

- The create-organization docs say you need an active Azure subscription to create a new organization. Existing organizations and free tier limits are not affected.
- The 1,800 free minutes apply to Microsoft-hosted agents only, and buying one pipeline does not add a second parallel job.
- Users after the first 5 become Stakeholders by default and cannot use Repos and Boards fully until you buy them a Basic license.

## Questions people ask

### Is Azure DevOps free?

Yes, for the first 5 users on the Basic plan. You get unlimited private Git repos, 2 GiB of Artifacts storage, and one Microsoft-hosted job with 1,800 free minutes a month.

### Do I need a credit card for Azure DevOps?

The pricing FAQ says a card is not needed to get started. The docs also say creating a new organization needs an active Azure subscription, so this atlas marks a card as required.

### How many free build minutes does Azure DevOps give?

Each organization gets one Microsoft-hosted parallel job with 1,800 minutes per month, plus one self-hosted parallel job with unlimited minutes.
