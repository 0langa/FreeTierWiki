Unkey is an API key management service. Your backend creates keys for your users through Unkey, and on each incoming request it asks Unkey whether the key is valid. That spares you from building key storage, hashing, expiry, and revocation yourself. Unkey also sells Compute, a separate app hosting product with its own plans.

## What the free plan gives you

On the pricing page's API Management tab, the Free plan is described as everything you need to start fast, with the core tools to protect and manage your API. It includes 1k API keys, 150K valid requests per month, 7-day log retention, 30-day audit log retention, and unlimited APIs.

Pro raises that to 1M API keys and 250K valid requests a month, with 90-day log retention, 90-day audit log retention, and workspaces with team members. Enterprise adds custom quotas, IP whitelisting, and a dedicated Slack channel.

## When you hit a limit

Current API Management docs define valid billable operations as successful key verifications and standalone rate-limit operations. Invalid, expired and over-limit calls are not billed. Usage covers a calendar month in UTC. On Free, passing the quota emails your workspace admins. If the workspace is still on Free 5 days later, requests to the Unkey API are limited to 5 per minute until you upgrade. Paid tiers are not limited when they pass their quota.

Every workspace starts on Free. The billing guide requires a card before upgrading, but does not give an explicit Free no-card guarantee. API tiers are separate from compute plans and their usage credits.

## Gotchas

- Logs on the free plan are kept for 7 days, so older failed verifications cannot be inspected.
- A workspace using only Free API Management has one owner. Team members need a paid API tier or Compute Pro or Business.
- The pricing page has two tabs, Compute plans and API Management, and their limits are different; this entry covers API Management.

## Questions people ask

### Is Unkey free?

Yes. The free API management plan includes 1k API keys and 150K valid requests a month, with unlimited APIs.

### What counts toward Unkey's request limit?

Successful key verifications and standalone rate-limit operations count. Invalid, expired, and over-limit calls are not billed. Usage follows calendar months in UTC.

### How long does Unkey keep logs on the free plan?

7 days for logs and 30 days for audit logs. Pro keeps both for 90 days.
