Unkey is an API key management service. Your backend creates keys for your users through Unkey, and on each incoming request it asks Unkey whether the key is valid. That spares you from building key storage, hashing, expiry, and revocation yourself. Unkey also sells Unkey Deploy, a separate hosting product with its own plans.

## What the free plan gives you

On the pricing page's API Management tab, the Free plan is described as everything you need to start fast, with the core tools to protect and manage your API. It includes 1k API keys, 150K valid requests per month, 1-day log retention, 3-day audit log retention, and unlimited APIs.

Pro raises that to 1M API keys and 250K valid requests a month, with 7-day log retention, 14-day audit log retention, and workspaces with team members. Enterprise adds custom quotas, IP whitelisting, and a dedicated Slack channel.

## When you hit a limit

The limit is counted in valid requests per month, and the pricing page does not define the term further. The pricing page's FAQ answer about plan limits describes Unkey Deploy, where a new deployment that would exceed a limit fails with a clear error. It does not say what happens when an API management account passes 150K valid requests, so check your usage in the dashboard as traffic grows.

The page describes Pro as usage-based billing with included credits, so moving up means your bill follows your traffic rather than a fixed price.

## Gotchas

- Logs on the free plan are kept for 1 day, so debugging yesterday's failed verifications is not possible.
- The free plan has no workspaces with team members, so a second developer cannot share the dashboard.
- The pricing page has two tabs, Unkey Deploy and API Management, and their limits are different; this entry covers API Management.

## Questions people ask

### Is Unkey free?

Yes. The free API management plan includes 1k API keys and 150K valid requests a month, with unlimited APIs.

### What counts toward Unkey's request limit?

The plans count valid requests per month. The pricing page does not define a valid request further, so check the docs or dashboard for how verifications are counted.

### How long does Unkey keep logs on the free plan?

1 day for logs and 3 days for audit logs. Pro keeps logs for 7 days and audit logs for 14 days.
