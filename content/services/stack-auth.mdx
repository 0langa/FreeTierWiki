Stack Auth was rebranded to Hexclave; the same authentication platform is now offered under the Hexclave name at hexclave.com (the API and dashboard still live under stack-auth.com). The free plan covers up to 10,000 auth users with one dashboard admin, and the core is open source and self-hostable.
