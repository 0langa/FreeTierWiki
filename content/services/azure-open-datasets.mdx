You browse the dataset catalog, then load a dataset with the Python SDK from Azure Machine Learning, Azure Databricks, or any Python environment. It suits data scientists and students who want ready-made public data for models and demos.

## What the free plan gives you

There is no plan to sign up for. The pricing page says there is no additional charge for using most Open Datasets. Microsoft pays for the storage that hosts the data, and the page says storage will always remain free.

The catalog covers public-domain data for weather, census, holidays, public safety, location, transportation, and labor and economics. Examples include the New York City yellow and green taxi trip records and US Labor Force Statistics. Microsoft copies the data to Azure and preprocesses it, so it is ready for machine learning. It also pulls updates from sources such as NOAA at regular intervals.

The docs say you do not need an Azure account to read the datasets from a Python environment.

## When you hit a limit

The datasets have no usage quota on the pages. The cost risk sits in what you do with the data. The pricing page says egress costs for reading large datasets can be charged to the Azure subscription that reads them. Egress means the cost of read operations and network bandwidth for data that leaves the Azure region.

Most datasets are free to access. Where egress charges apply, the dataset overview page shows them. You also pay for any virtual machines, storage, networking, and Azure Machine Learning services you use to work with the data.

## Gotchas

- Reading large datasets can create egress charges on your subscription, and the dataset page lists them where they apply.
- Compute is not free. Your subscription pays for virtual machines and any Azure Machine Learning service you use.
- Some dataset classes need the azureml-dataprep package, which works only with 64-bit Python.

## Questions people ask

### Is Azure Open Datasets free?

Mostly. The pricing page says there is no additional charge for most Open Datasets, and Microsoft pays for hosting storage.

### Do I need an Azure account to use Azure Open Datasets?

No. The docs say you can access the datasets from any Python environment. An account helps when you use Azure Machine Learning.

### Can Azure Open Datasets cost me money?

Yes, in two ways. Egress charges can apply for large reads, and you pay for the compute you use to process the data.
