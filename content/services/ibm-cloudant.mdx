You create a Cloudant instance in the IBM Cloud dashboard, then use the REST API or an official SDK to read and write JSON documents. It suits developers who like CouchDB-style replication and want a managed service.

## What the free plan gives you

The Lite plan is free and meant for evaluation, with limited capacity and storage. It includes 1 GB of data storage. You can have 1 Lite instance per IBM Cloud account. Storage counts JSON data, secondary indexes, and attachments.

New users of IBM Cloudant can also get a USD 250 credit by applying the code DSFREE250. The pricing page shows this offer separately from the Lite plan. The Standard plan includes 20 GB of storage and is billed by the hour for provisioned throughput.

## When you hit a limit

At 1 GB, Cloudant blocks creating and updating documents. New writes return a 402 error saying the account exceeded its data usage quota and needs a paid plan. Reads and deletes still work, so you can pull data out or free space.

You can upgrade to Standard for immediate write access. If you delete data to get under 1 GB, access returns within 24 hours. When requests exceed your throughput, Cloudant returns HTTP 429 responses.

## Gotchas

- The Lite plan limits you to one instance per IBM Cloud account.
- The official client libraries do not retry a 429 response by default, so handle it in your app.
- Storage counts indexes and attachments, not only documents.

## Questions people ask

### Is IBM Cloudant free?

Yes. The Lite plan is free and includes 1 GB of storage. You can have one Lite instance per IBM Cloud account.

### What happens when I hit the Cloudant Lite storage limit?

Creating and updating documents is blocked, and writes return a 402 error. Reads and deletes keep working. Upgrade to Standard or delete data to restore writes.

### How do I get the IBM Cloudant USD 250 credit?

New users can apply the code DSFREE250 on the Cloudant page. The pricing page lists it as a credit for new users.
