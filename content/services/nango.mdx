Nango connects an app to third-party accounts so you can keep the authorization and integration work in one place. You can use the connection for a sync, process a webhook, or make a tool call. This helps when several features rely on access to the same external account.

## What the free plan gives you

The Free limits are ten connections, ten compute hours per month, and 10 GB of data transfer per month. A connection is an authorized user account in the external system. Several users connecting the same product can therefore consume several slots. Compute measures execution work from operations such as syncs and tool calls. Transfer measures data processed through integrations. Start with one account and one small sync, then observe which meters move. A job that runs often on a small dataset can have a different profile from one that moves a large dataset occasionally.

## When you hit a limit

Nango describes the free limits as hard caps that reset monthly. It publishes a separate pay-as-you-go plan with rates for connections, compute and data. Treat each free allowance as a constraint when choosing the sync schedule and deciding which records to transfer. Re-running a backfill can use more compute or transfer even if it does not add another connection. Pause unnecessary backfills and tune the sync cadence when compute is the constrained resource.

## Gotchas

- An integration type is not the count used for authorized connections. Each separate account can take a slot.
- Frequent tool calls and webhooks can share compute time with scheduled syncs.
- Plan transfer around the data actually processed, including any initial imports.

## Alternatives in this atlas

- [Pipedream](/services/pipedream/) for hosted workflows around API and webhook triggers.

## Questions people ask

### What is a connection?

It represents one authorized account in an external service.

### Can I pay for excess usage on Free?

Free is described as hard-capped. Nango lists billed usage under its separate pay-as-you-go plan.

### Do the free usage allowances reset?

The pricing page says the Free limits reset monthly. Watch the runtime and data meters separately.
