You define checks as code in a TypeScript project and deploy them with the `checkly` command line tool, or you create monitors in the web app. It suits developers who want API and browser checks kept in their repo.

## What the free plan gives you

The Hobby plan costs $0 per month, needs no credit card, and gives access to almost all of Checkly's features. It includes 10 Uptime Monitors, 10,000 API check runs per month, and 1,000 browser check runs per month. Uptime Monitors cover URL, TCP, DNS, ICMP, SSL, gRPC, and Traceroute types, plus Heartbeats for cron jobs.

Browser checks run real Playwright scripts in a browser, and each run has a 4 minute timeout. The free plan also includes 1 status page with 20 services and up to 250 subscribers who get email notifications. Hobby has no SMS or phone alert credits and no maintenance windows.

## When you hit a limit

The Hobby plan is hard-capped. Checkly says it stops running your checks when your credits are exhausted, and it points you to the Starter or Team plan if you need more. Checks do not turn into a bill.

Once you reach the 10 Uptime Monitors limit, you cannot create more unless you buy more. Starter and Team plans work differently: they keep running past their included amount and charge overage rates, such as $2.60 per 10k extra API runs on Starter.

## Gotchas

- A Multistep check counts every request as one run, so a script with 3 requests uses 3 runs each time it executes.
- Playwright Check Suites use one run for every 30 seconds of execution time.
- Hobby has no SMS or phone alerts, so use email, Slack, or webhook alerts.

## Questions people ask

### Is Checkly free?

Yes. The Hobby plan costs $0 per month and needs no credit card. It includes 10 Uptime Monitors, 10,000 API check runs, and 1,000 browser check runs per month.

### What happens when I go over the Checkly free limits?

Nothing is billed. The Hobby plan is hard-capped, and Checkly stops running your checks when your credits are used up.

### Does Checkly need a credit card?

No. The pricing FAQ says you do not need a credit card to start on the Hobby plan.
