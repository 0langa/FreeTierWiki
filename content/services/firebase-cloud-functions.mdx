You write functions in Node.js or Python, test them with the Firebase emulators, and deploy them with the Firebase CLI. They can run on HTTPS requests or on events from Firebase features such as Cloud Firestore. It suits app developers who already use Firebase and need a little server-side code.

## What the free plan gives you

Firebase has two pricing plans. Cloud Functions is marked not applicable on the no-cost Spark plan, and the docs say your project must be on the pay-as-you-go Blaze plan to deploy functions. You can still emulate functions on any project.

On Blaze, the pricing page lists no-cost usage of 2M invocations, 400K GB-seconds, and 200K CPU-seconds per month. It also lists 5 GB of outbound networking per month, 120 minutes per day of Cloud Build, and 500MB of container storage in Artifact Registry. Firebase may also give $300 in free credit if you are eligible.

## When you hit a limit

Blaze has no hard stop. After the no-cost amounts, Firebase charges $0.40 per million invocations and $0.12 per GB of outbound networking. GB-seconds and CPU-seconds above the no-cost amount follow Google Cloud pricing, and so does container storage.

Because a card is required for Blaze, a runaway function or a traffic spike turns into a bill. Watch your usage in the console.

## Gotchas

- Deploying functions needs the Blaze plan, so you must attach a billing account even if you expect to stay under the no-cost amounts.
- Build time counts. Cloud Build has a no-cost amount of 120 minutes per day, and container images use Artifact Registry storage.
- The docs support Node.js versions 20 and 22 and Python versions 3.10 through 3.13, so check your runtime before you deploy.

## Questions people ask

### Is Firebase Cloud Functions free?

Partly. On the Blaze plan, the first 2M invocations, 400K GB-seconds, and 200K CPU-seconds each month have no cost. You pay above that.

### Does Firebase Cloud Functions need a credit card?

Yes. The docs say you must be on the Blaze pricing plan to deploy functions, and Blaze is a pay-as-you-go plan.

### What happens when I go over the Cloud Functions no-cost amount?

Firebase bills the extra usage, for example $0.40 per million invocations beyond 2M. Nothing on the pricing page shows a hard cap.
