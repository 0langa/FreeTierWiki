You write functions in Node.js or Python, test them with the Firebase emulators, and deploy them with the Firebase CLI. They can run on HTTPS requests or on events from Firebase features such as Cloud Firestore. It suits app developers who already use Firebase and need a little server-side code.

## What the free plan gives you

Firebase has two pricing plans. Cloud Functions is marked not applicable on the no-cost Spark plan, and the docs say your project must be on the pay-as-you-go Blaze plan to deploy functions. You can still emulate functions on any project.

The Firebase table lists 2M invocations, 400K GB-seconds, 200K CPU-seconds and 5 GB outbound monthly. These are not a universal estimate: second-generation functions run on Cloud Run, whose request-based tier has 2M requests, 180K vCPU-seconds, 360K GiB-seconds and 1 GiB North America outbound monthly. Builds and stored container images are separate services. Their allowances depend on the applicable product and SKU.

## When you hit a limit

Blaze has no spending cap at the free allowance. The Firebase table lists $0.40 per million excess invocations and $0.12/GB outbound, while second-generation workloads follow Cloud Run pricing. Compute, builds, networking and container storage can each add charges. Check your generation, region and billing SKUs rather than applying one table to every deployment.

Because Blaze needs a Cloud Billing account, and those require a payment method, a runaway function or a traffic spike turns into a bill. Watch your usage in the console.

## Gotchas

- Deploying functions needs the Blaze plan, so you must attach a billing account even if you expect to stay under the no-cost amounts.
- Firebase lists 120 build minutes/day, while Cloud Build lists 2,500 promotional e2-standard-2 minutes/month. Check the applicable machine and SKU; container images also use Artifact Registry storage.
- The docs support Node.js versions 20 and 22 and Python versions 3.10 through 3.13, so check your runtime before you deploy.

## Questions people ask

### Is Firebase Cloud Functions free?

Blaze includes no-cost usage, but second-generation functions use Cloud Run pricing. Firebase’s table lists older invocation and compute counters, so check your deployed generation and related build and storage costs.

### Does Firebase Cloud Functions need a credit card?

Yes. The docs say you must be on the Blaze pricing plan to deploy functions, and Blaze is a pay-as-you-go plan. The Firebase pricing plans page says Cloud Billing accounts require a payment method.

### What happens when I go over the Cloud Functions no-cost amount?

Firebase bills the extra usage, for example $0.40 per million invocations beyond 2M. Nothing on the pricing page shows a hard cap.
