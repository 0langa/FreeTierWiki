Blacksmith supplies the machines that execute a GitHub Actions job. You keep the workflow in GitHub and select the new runner using its label. The dashboard's migration wizard helps map existing jobs to Blacksmith runners. Start with a representative build or test so you can see whether the integration suits your workflow.

## What the free plan gives you

Blacksmith advertises 3,000 free minutes per month and says signup does not require a card. The pricing page shows that allowance on its Ubuntu x64/ARM, Windows x64, and macOS M4 cards; it does not establish separate 3,000-minute pools for each platform. Choose the instance in the price table before comparing the cost of moving a workflow. Different operating systems and machine sizes can have different per-minute prices.

The runner executes the steps you already define in your GitHub Actions file. The quickstart shows how to install the integration, select the organization, and use the migration wizard. To move a single job, you can update its runner label and leave the other jobs on their current runners.

## When you hit a limit

Blacksmith publishes per-minute rates for billed use. The public pricing page does not specify whether a no-card organization can continue to schedule jobs when the free minutes run out. Check your usage and payment settings in the dashboard before moving a workload that relies on running continuously. Add-ons such as sticky disks and dedicated static IPs have separate listed prices.

## Gotchas

- The free figure is for runner usage in Blacksmith. Changing the runner label determines which jobs run on that service. Paid rates vary by instance. Confirm the allowance and rate for the runner label you choose before changing every job in a workflow.
- Personal repositories are unsupported; the integration requires a GitHub organization.
- The GitHub app needs permission to run jobs for the selected organization. If your organization uses an allowlist or SSO, check the requirements in the quickstart.

## Questions people ask

### Is Blacksmith free to try?

Yes. The pricing page advertises a recurring 3,000-minute allowance and says you can start without a credit card.

### Do I need to migrate away from GitHub Actions?

You keep GitHub Actions and select a Blacksmith runner for the jobs you want it to execute.

### Can I assume all runner sizes have the same price?

Use the pricing table for the exact platform and size. The default runner and larger instances have different rates.
