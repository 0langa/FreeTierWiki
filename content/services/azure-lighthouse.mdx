You set up Lighthouse in the Azure portal or with templates, and then work on customer resources from your own tenant using the tools you already know. Customers keep control of what they delegate.

## What the free plan gives you

Azure Lighthouse is free. The pricing page says it is available at no additional charge. Microsoft built it on Azure delegated resource management, and no tier or quota is listed for it.

You can manage delegated subscriptions and resource groups in a customer's Microsoft Entra tenant from your own tenant. Customers choose the scopes and permissions they delegate, can audit what the service provider does, and can remove access at any time. Enterprises that manage several tenants of their own can use the same setup.

## When you hit a limit

The pricing page lists no limit or paid tier for Lighthouse itself. What you pay for is the services you use through it. Partners who use these capabilities on Azure services, such as Log Analytics and Microsoft Defender for Cloud, keep paying for those underlying services.

If an underlying service is free, such as Azure Policy or Azure Resource Health, it stays free. So the cost risk is low, but it depends on which services you run in the customer's tenant. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## Gotchas

- The customer tenant must have an active Azure subscription to be onboarded.
- Onboarding takes action in both the service provider's tenant and the customer's tenant.
- Microsoft recommends assigning the Managed Services Registration Assignment Delete Role, so your users can remove the delegation later. Without it, only a user in the customer's tenant can remove delegated resources.

## Questions people ask

### Is Azure Lighthouse free?

Yes. Microsoft says Azure Lighthouse is available at no additional charge. You still pay for the underlying services you use through it.

### Does Azure Lighthouse need an Azure subscription?

Yes. The customer tenant needs an active Azure subscription to be onboarded.

### Can customers remove Azure Lighthouse access?

Yes. The docs say customers can audit service provider actions and remove access completely at any time.
