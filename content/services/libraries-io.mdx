On November 23, 2026, Libraries.io’s homepage and About page redirected to Sonar. Its API documentation remained readable and advertised free registered-user access, but that does not confirm working signup or API access. The full entry comparison remains unresolved. Historically, you could search packages in the browser or call its REST API with a key. It suits developers and researchers who need public package information.

## What the free plan gives you

The earlier catalog described free package search across package managers, with license and language filters. The current homepage redirect no longer supports treating that interface or its previous package-manager count as confirmed. Use the still-readable API documentation as a reference, and confirm current account access before depending on the service.

The API documentation says access is free to all registered users. You create a login, take the API key from your account page, and pass it as the `api_key` parameter. The earlier site also offered limited dependency insights without accuracy validation.

## When you hit a limit

All API requests share a limit of 60 requests per minute for each API key. Extra requests in that minute get a 429 response. The pages describe no charge for the free API.

For larger scale access to the data, the API page points you to Tidelift. The previously cited homepage description of a paid Tidelift Subscription is no longer available at that URL; current commercial availability and terms need confirmation.

## Gotchas

- The data is scraped and not validated, corrected, or curated for accuracy, so check anything important before you rely on it.
- Earlier free dependency insights were limited and unvalidated; current availability is unconfirmed.
- Earlier signup used GitHub, GitLab or Bitbucket with terms/privacy acceptance; current new-account access is unconfirmed.

### What is the Libraries.io API rate limit?

All requests are limited to 60 requests per minute for each API key. Going over gets a 429 response.

Earlier guidance described scraped, unvalidated data and pointed to Tidelift for curated information. Current commercial availability requires confirmation.
