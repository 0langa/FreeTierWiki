You use Libraries.io in the browser to search for packages, or call its REST API with a key. It suits developers and researchers who need public package information.

## What the free plan gives you

The home page calls Libraries.io a free service that collects publicly available open source package information from the internet. You can search 9.96M packages by license and language, or look at new, trending, or popular packages. It tracks packages across 32 package managers.

API access is free to all registered users. You create a login, take the API key from your account page, and pass it as the `api_key` parameter. The site offers dependency insights too, but it says they are limited and not validated for accuracy.

## When you hit a limit

All API requests share a limit of 60 requests per minute for each API key. Extra requests in that minute get a 429 response. The pages describe no charge for the free API.

For larger scale access to the data, the API page points you to Tidelift. The home page says the paid Tidelift Subscription has curated, human-validated data, more complete dependency insights, and rate limits you can customize.

## Gotchas

- The data is scraped and not validated, corrected, or curated for accuracy, so check anything important before you rely on it.
- Dependency insights on the free site are limited and carry the same accuracy warning.
- You log in with GitHub, GitLab, or Bitbucket, and you accept the terms of service and privacy policy when you do.

## Questions people ask

### Is Libraries.io free?

Yes. The home page calls it a free service for searching open source packages. API access is free to registered users.

### What is the Libraries.io API rate limit?

All requests are limited to 60 requests per minute for each API key. Going over gets a 429 response.

### Is Libraries.io data accurate?

The site says its data is scraped from the internet and not validated, corrected, or curated for accuracy. It offers the paid Tidelift Subscription for curated data.
