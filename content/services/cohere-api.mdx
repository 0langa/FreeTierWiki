You get an API key from the Cohere dashboard and call the Chat, Embed, and Rerank endpoints from the Python SDK or the REST API. It suits developers who prototype search and retrieval apps.

## What the free plan gives you

Every new account gets a Trial API key automatically. Calls made with a trial key are free. The docs cap it at 1,000 API calls a month.

Each endpoint has its own trial rate limit. Chat models are limited to 20 requests per minute. Rerank is limited to 10 requests per minute. Embed allows 2,000 inputs per minute for text, and image embedding allows 5 inputs per minute. Tokenize allows 100 requests per minute, and audio transcription allows 5 requests per minute.

The models include the Command family for chat, Embed for search and classification, and Rerank for improving search results. Trial keys may not be used for production or commercial work.

## When you hit a limit

The docs say trial keys are rate limited, and the monthly cap is 1,000 API calls. They do not describe the exact error you will see. The Trial key never bills you, because calls with a trial key are free.

To go further, ask for a Production key. The account Owner opens the Billing and Usage page in the dashboard and fills out the Go to Production workflow. Production keys bill pay-as-you-go. Bills arrive at the end of each calendar month, or when the balance reaches $250.

## Gotchas

- Trial keys cannot be used for production or commercial purposes.
- Every new account starts as a personal account that can only use Trial keys. Organizations do not get production access automatically.
- Production keys on newer chat model variants, such as Command A Reasoning, work like trial keys. Contact sales to use those in production.

## Questions people ask

### Is the Cohere API free?

Yes, with a Trial key. Calls are free, but the key is capped at 1,000 API calls a month and is not for production use.

### Can I use the Cohere trial key for a commercial app?

No. The pricing page says trial keys are not permitted for production or commercial purposes. You need a Production key.

### Does Cohere need a credit card for the trial?

The pricing page says an account gets a Trial key automatically when it is created. It lists no card step for the trial key.
