You search the library list on cdnjs.com, copy a script or link tag, and paste it into your page. A free API also lists libraries and files. It suits front-end developers who want a library on the page with no build step.

## What the free plan gives you

There is no paid plan. cdnjs calls itself a free, open-source CDN for JavaScript, CSS, and font resources, and the site lists 4,616 libraries. Files are served from Cloudflare's global network, with support for HTTP/3, HTTP/2, QUIC, and Brotli and GZIP compression. The about page says cdnjs is trusted by 12.5% of all websites and serves more than 250 billion requests per month from over 330 edge locations.

Every script and link tag comes with a Subresource Integrity hash, and the service is preloaded for HSTS so requests use HTTPS. The API at api.cdnjs.com needs no authentication. The project started in 2011.

## When you hit a limit

The pages list no request limit, bandwidth cap, or paid tier. No account or payment method is involved, so there is nothing to bill. The pages do not say what would happen if one site sent extreme traffic, so treat that as unknown.

The real limit is the catalog. cdnjs is curated and does not pull libraries on demand from npm. If your library is missing, you add it by opening a pull request to the cdnjs packages repository on GitHub with a small JSON file. After it is merged, new versions are picked up on their own from npm or GitHub.

## Gotchas

- cdnjs serves only libraries that the community added. It does not fetch an arbitrary npm package for you.
- The main cdnjs GitHub repository says it is no longer updated because it grew too large. The assets now live in a Cloudflare R2 bucket.
- Mirror operators should note that syncing from the old GitHub repository no longer works; the repository asks them to open an issue to request access to the bucket.

## Questions people ask

### Is cdnjs free?

Yes. cdnjs describes itself as a free, open-source CDN for JavaScript, CSS, and font resources. No account is needed to copy a tag.

### Who runs cdnjs?

Cloudflare provides the infrastructure and project maintenance, and the project is community driven. The about page lists several other sponsors.

### Can I upload my own files to cdnjs?

Not directly. You can add an open-source library by opening a pull request with a JSON file, and cdnjs then picks up new versions automatically.
