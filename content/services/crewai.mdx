You use CrewAI from the command line and from config files in a Python project: create a project, define agents, and run it. It suits developers who are comfortable with Python and want to script agent workflows themselves. A hosted platform exists for teams that prefer not to run everything on their own.

## What the free plan gives you

There are two free routes. The framework is open source under the MIT license, so you can install it and run it yourself with no usage limits from CrewAI. You still pay for any model API your agents call.

The hosted platform has a free Basic plan. The pricing page lists GitHub integration and 50 workflow executions per month. It does not list any other Basic features. The Custom plan is for large organizations. It adds governance tools such as SSO, RBAC, workload identity, PII redaction, and policies, plus engineering and training help that you buy as needed. Pricing for Custom is by request.

## When you hit a limit

The pricing page does not say what happens when you use all 50 workflow executions on Basic. It gives no overage price and no upgrade rule. The self-hosted framework has no execution cap, so you can move heavy runs there. The Custom plan has no public price, so you would need to contact CrewAI to scale up the hosted platform.

## Gotchas

- Self-hosted use is free, but the model calls your agents make are billed by whichever model provider you use.
- The Basic cloud plan lists only 50 workflow executions and GitHub integration. Check the pricing page before you rely on other features.
- The pricing page does not say whether Basic needs a credit card, and it describes no pause or expiry for the free plan.

## Questions people ask

### Is CrewAI free?

Yes. The open-source framework is free under the MIT license, and the hosted Basic plan is free with 50 workflow executions per month.

### What happens when I go over the CrewAI Basic limit?

The pricing page does not say. For unlimited runs, install the open-source framework and run it yourself.

### Can I self-host CrewAI?

Yes. The framework is open source on GitHub, and you can run it on your own machine or servers. The pricing page lists no usage limits for that route.
