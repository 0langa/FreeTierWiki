You set up Firestore in the Firebase console and use it through Firebase client SDKs for web, Apple platforms, and Android, or through server client libraries. It suits app developers who want realtime data without running a server.

## What the free plan gives you

Firestore has a daily free quota on the no-cost Spark plan. Each project gets 1 GiB of stored data, 50,000 document reads per day, 20,000 writes per day, and 20,000 deletes per day. Outbound data transfer is 10 GiB per month. The Firebase pricing page describes this as the no-cost Spark plan, with generous no-cost usage limits.

Firestore allows exactly one free database per project. Daily quotas reset around midnight Pacific time. Some features have no free usage at all and need billing: TTL deletes, point-in-time recovery data, backups, restore operations, and clone operations.

## When you hit a limit

If you need more quota, you must enable billing for your Google Cloud project. On the Blaze pay-as-you-go plan, usage past the free amounts is billed at Google Cloud pricing. The Firebase pricing page says no-cost limits are enforced daily.

The pages do not describe the exact error your app sees when the free daily quota runs out. Plan for failed reads and writes late in a busy day.

## Gotchas

- Reads, writes, and deletes reset daily, but network egress is counted per month.
- Only one free database is allowed per project.
- Backups, point-in-time recovery, and clones are not part of the free usage.

## Questions people ask

### Is Firebase Firestore free?

Yes, within a daily quota. Each project gets 1 GiB of storage, 50,000 reads, 20,000 writes, and 20,000 deletes per day, plus 10 GiB of egress per month.

### What happens when I exceed the Firestore free quota?

You need to enable billing on the Google Cloud project to get more quota. Past the free amounts, usage is billed at Google Cloud pricing on the Blaze plan.

### Does Firestore need a credit card?

Not for the free quota. Enabling billing for more quota, or for backups and point-in-time recovery, needs a billing account.
