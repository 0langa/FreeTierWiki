You manage servers and uptime checks in the SyAgent web dashboard. On each Linux server you install a small Bash agent that sends data once a minute. It suits hobbyists with a few servers.

## What the free plan gives you

SyAgent is free, and the FAQ says alarms are free too. The listed limits are 25 servers and 25 uptime monitors per user. Metrics are stored for 7 days, and unread alarms are stored for 2 months.

Notifications go out by email, Telegram, Pushsafer, Pushover, and webhook, and the FAQ says more will be added soon. The site is marked beta. It covers Linux servers, processes, disks, network, and uptime, with charts and alarms in the dashboard. The agent runs as an unprivileged user, collects host data every minute, and sends it over HTTPS.

## When you hit a limit

The FAQ lists the limits as current limitations, but it does not say what happens when you reach 25 servers or 25 uptime monitors. It describes no paid plan, so there is no bill to fear.

The FAQ explains why the service is free: it is a hobby project run by one person. It answers yes to the question of whether it will stay free. There is no SLA, so keep a second alert path for anything important.

## Gotchas

- Metrics are kept for only 7 days, so you cannot look back far.
- Unread alarms are stored for 2 months, so read important alarms within that time.
- The service is in beta and one person runs it. The agent installs from a public script, and the GitHub readme says the simple flow trusts GitHub and the main branch; it also describes a signed-release flow.

### Is SyAgent free?

Yes. The site says it is free because the project is a hobby run by one person, and it says it will stay free. The limits are 25 servers and 25 uptime monitors per user.

### How long does SyAgent keep my metrics?

Metrics are stored for 7 days. Unread alarms are stored for 2 months.

### What does the SyAgent agent need?

It is a Bash-based agent for Linux. It runs as its own unprivileged user and sends host data over HTTPS once a minute.
