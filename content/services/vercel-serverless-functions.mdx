You add an API route or a function file to your project, such as app/api/hello/route.ts in Next.js or an api/ file in other setups. Vercel builds it on every push or CLI deploy. It suits front-end and full-stack developers who want backend routes and webhooks next to their site.

## What the free plan gives you

The Hobby plan is free and meant for personal, non-commercial projects. Its included usage covers the first 1,000,000 function invocations each month. It also includes 4 CPU-hrs of Active CPU and 360 GB-hrs of provisioned memory, which Vercel measures under Fluid compute.

A function on Hobby can use up to 2 GB of memory and run for up to 300 seconds. Functions run in one region by default, iad1, and you can change it. The size limit for a function bundle is 250 MB uncompressed, or 500 MB for Python. Hobby also includes 1,000,000 CDN requests and 100 GB of Fast Data Transfer.

## When you hit a limit

Hobby is a free tier with no billing cycle. The docs say that if you go over your usage limits, you will in most cases have to wait until 30 days have passed before you can use the feature again. Some limits have shorter pauses.

A function that runs longer than its maximum duration gets a 504 error with the code FUNCTION_INVOCATION_TIMEOUT. To get more room, upgrade to Pro, which includes $20 of usage credit and extends the duration to a maximum of 800 seconds.

## Gotchas

- Hobby is for non-commercial, personal use only under Vercel's fair use guidelines.
- Caching a response means the function does not run, so it does not use an invocation, though the request still counts as a CDN request.
- Hobby functions cannot run in several regions. Pro and Enterprise teams can set multiple regions.

## Questions people ask

### Are Vercel Serverless Functions free?

Yes, on the Hobby plan for personal, non-commercial use. It includes the first 1,000,000 function invocations, 4 CPU-hrs of Active CPU, and 360 GB-hrs of provisioned memory per month.

### What happens when I go over the Vercel Hobby limits?

In most cases you must wait until 30 days have passed before you can use the feature again. Upgrading to Pro removes the wait.

### How long can a Vercel Function run on the free plan?

On Hobby, the default and maximum duration is 300 seconds. A function that runs longer returns a 504 error.
