You call a small HTTP API from your sign-up code, or install the WordPress or Ghost plugin. The service takes only the email domain, never the full address. It suits developers who run sign-up forms and free trials.

## What the free plan gives you

The Free plan gives 200 lookups per month. It resets monthly, needs no card, and includes the WordPress and Ghost plugins. Each call returns a risk score from 0 to 100 and some details about the domain, such as whether it is on the block list, how old it is, whether its website resolves, and whether it is a forwarding service. The docs advise blocking a score of 75 or higher.

The service says it never stores user emails, because it needs only the domain. If a domain is new, it analyzes it and gives you a risk score.

## When you hit a limit

When your key runs out of lookups, the API returns a 402 Payment Required status with the message no_lookups_remaining. That is a hard stop, so your sign-up code should handle it. Free lookups come back each month. The Pro tier is pay as you go at $0.005 per lookup, excluding VAT, and the lookups you buy never expire. A quota endpoint shows your remaining lookups and overage settings, so you can track use in code.

## Gotchas

- Send only the domain. The service strips the user part if you send a full address. Split on the at sign so sub-domains and country domains such as co.uk work.
- It is not a bulk email validation service, and it does not check if a mailbox can receive mail.
- You decide what to do with a flagged sign-up. You can hard reject it or let the user continue as a shadow-banned account.

## Questions people ask

### Is TempMailDetector free?

Yes, within limits. The Free plan gives 200 lookups per month with no credit card.

### What happens when I run out of TempMailDetector lookups?

The API returns a 402 status with no_lookups_remaining. Free lookups reset monthly, and Pro lookups cost $0.005 each.

### Does TempMailDetector store my users' email addresses?

No. The service needs only the domain, and the docs say you should never send a full customer email.
