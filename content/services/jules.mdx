Jules can take an assignment for a connected repository and work on it asynchronously. A developer can review the proposed changes and decide whether to bring them into the main project. It suits a task that you can describe with a clear result and a way to test it.

## What the free plan gives you

Google’s limits table lists 15 free tasks in a rolling 24-hour period and up to three tasks running concurrently. The task allowance is for Jules activity. The limits page describes higher task ceilings as benefits of Google AI Pro and Ultra plans. For a first assignment, choose a repository and request one well-defined change. Give Jules context such as the command that reproduces the issue or the relevant test. Review the output after it has finished and decide whether to continue in another task or work from the proposed change yourself.

## When you hit a limit

The rolling task limit counts a moving period. If you submit many assignments together, you may need to wait until earlier tasks fall out of that window. Running tasks also occupy concurrency slots, so a new job can encounter the concurrency limit before you reach the daily one. Google lists paid plans separately for more capacity. Queue independent assignments across time if your work can wait, and leave room for follow-up on a proposed change.

## Gotchas

- A task is a unit of work. A large request can be harder to review even if it uses a single task slot.
- Check repository access before assigning work involving more than one project.
- Review the diff and run the relevant checks before accepting a suggested change.

## Questions people ask

### Is Google Jules free?

Google lists a free plan with its own task and concurrency allowances.

### How many tasks can work at the same time?

The current table lists three concurrent tasks on Free.

### When can I submit more after the daily limit?

The daily window rolls over the previous 24 hours. As earlier submissions leave that window, capacity becomes available again.
