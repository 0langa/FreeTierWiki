Editors work in the Prismic dashboard with the Page Builder, and developers connect a framework through a starter command and the API. It suits solo makers and small sites more than large editorial teams.

## What the free plan gives you

The Free plan is $0 per month, and it applies to each repository. A repository is a separate working space with its own content, users, endpoint, and subscription. Your account is always free, and you can have as many repositories as you want on different plans.

Each free repository has 1 user, 4 million API calls per month, and 100 GB of built-in CDN bandwidth per month. Both the API calls and the bandwidth have no overages. You also get unlimited documents, types, and assets, a Visual Page Builder, and image optimization and processing.

## When you hit a limit

On the Free plan, a project that passes its CDN bandwidth allowance is locked automatically. The pricing page lists no overage charge for the free API calls or the bandwidth, so no bill appears.

Paid plans work differently. They enter a soft limit and bill overage until a hard limit, and then Prismic moves the repository to the next plan level. The Starter plan costs $10 per month and adds 3 users.

## Gotchas

- The free plan allows 1 user. Adding a second editor means paying for a plan with more users.
- A locked project stops serving when the bandwidth runs out, so watch large images and video.
- The plan applies per repository, so a second site is a second repository with its own plan.

## Questions people ask

### Is Prismic free?

Yes. The Free plan is $0 per month for each repository and includes 1 user, 4 million API calls, and 100 GB of CDN bandwidth per month. It needs no credit card.

### What happens when I go over the Prismic free limit?

If you exceed the CDN bandwidth allowance on the free plan, your project is automatically locked. The free API calls and bandwidth carry no overages.

### Does Prismic work with Next.js?

Yes. The docs have guides for Next.js, Nuxt, and SvelteKit. For Next.js, the setup instructions run `prismic init` and walk you through creating the project.
