You write functions as TypeScript files that run on Supabase's Deno-based Edge Runtime. You create them with the Supabase CLI, test them locally, and deploy them from the CLI or the dashboard. They suit developers who already use Supabase and want webhooks or API endpoints near their database.

## What the free plan gives you

The Free organization shares 500,000 Edge Function invocations per month across its projects. A function can use up to 256MB of memory. The wall-clock limit is 150s on Free and 400s on paid plans. A request gets up to 2s of CPU time, which does not count time spent waiting on async input and output. The request idle timeout is 150s.

A function bundle can be up to 20MB when built locally with the CLI, or 5MB when bundled server-side. The Free plan allows up to 100 functions per project. Free projects pause after 1 week of inactivity, and you can have 2 active projects.

## When you hit a limit

Free usage is not charged. The billing FAQ says continued quota excess can restrict all projects after a grace period, including 402 API responses; restrictions lift after the next billing-cycle reset. It does not give a separate invocation-specific response. Paid plans include 2 Million invocations and then charge $2 per 1 Million.

For runtime limits, the docs say that a function that sends no response before the idle timeout returns a 504 Gateway Timeout. Paused projects stop until you restore them. Plan for a short wait on a first request, because the docs warn that cold starts are possible.

## Gotchas

- Free projects pause after 1 week of inactivity, so a webhook receiver on a quiet project can stop working.
- The CPU limit is 2s per request. Heavy work, and libraries that need multithreading such as sharp, are not supported.
- Outgoing connections on ports 25 and 587 are blocked, so you cannot send mail over SMTP directly. Use an email API instead.

## Questions people ask

### Are Supabase Edge Functions free?

Yes, within limits. The Free plan includes 500,000 invocations per month.

### Do Supabase Edge Functions sleep or pause?

Free projects pause after 1 week of inactivity. Cold starts can also happen, so expect a slower first request.

### What is the Supabase Edge Function time limit?

The wall-clock limit is 150s on the Free plan and 400s on paid plans. CPU time is 2s per request.
