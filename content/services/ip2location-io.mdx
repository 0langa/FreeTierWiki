You call a single REST endpoint, `api.ip2location.io`, with an IP address and an optional API key. It suits small sites and apps that want location data for visitors.

## What the free plan gives you

The Free plan costs $0 a month. Each month it includes 50,000 IP Geolocation API queries, 500 Domain WHOIS API queries, and 50 Hosted Domain API queries. The response carries 11 IP attributes, and the database updates daily.

You can also skip the key. The keyless API allows up to 1,000 queries a day, and the docs suggest the Free plan once you need more. Both routes require attribution: a visible line that says your site or product uses IP2Location.io IP geolocation web service.

Paid plans start with 150K geolocation queries a month and return 20 attributes. The higher plans return up to 79 attributes.

## When you hit a limit

On the Free plan, the web service stops once you run out of queries. You are not billed. Unused queries do not carry into the next month, and the allowance renews each month.

The keyless API works the same way each day. After 1,000 queries, further calls fail until the limit resets at 00:00 UTC.

Paid plans differ. They keep working and bill overage queries instead of stopping. For example, one paid plan lists $10 for every extra 30K geolocation queries.

## Gotchas

- Attribution is required on the Free plan and on the keyless API. Paid plans do not need it.
- The free response has 11 IP attributes. Fields such as extra network or security data need a paid plan.
- The Hosted Domain allowance is small, at 50 queries a month, and WHOIS is capped at 500, so do not build a bulk job on them.

## Questions people ask

### Is IP2Location.io free?

Yes, there is a Free plan with 50,000 IP Geolocation queries a month. You must show an attribution line. There is also a keyless mode with 1,000 queries a day.

### What happens when I go over the IP2Location.io free limit?

On the Free plan the web service stops until the next month. You are not charged. Paid plans keep working and bill overage queries.

### Does IP2Location.io need a credit card?

No. The home page says no credit card is required to create a free account. The pricing page also says no credit card is needed for the 7-day trial of the top plan.
