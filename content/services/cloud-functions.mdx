You deploy a Cloud Run function from the Google Cloud console with the Write a function button, or with the gcloud CLI. Triggers can be HTTP calls or events from services such as Pub/Sub and Cloud Storage. It suits developers who want small event handlers on Google Cloud.

## What the free plan gives you

Google's Free Tier page lists Cloud Run functions with 2 million invocations per month, covering both background and HTTP calls. It also lists 400,000 GB-seconds and 200,000 GHz-seconds of compute time, plus 5 GB of outbound data transfer per month. The same page links this entry to the 1st gen pricing page.

New functions run on Cloud Run. Cloud Run's own free tier for request-based billing is 2 million requests, 360,000 GiB-seconds of memory, and 180,000 vCPU-seconds of compute, based on us-central1 pricing. It also gives 1 GiB of free data transfer within North America. The Free Tier has no end date, and it is calculated per billing account.

## When you hit a limit

Nothing stops your function at the free amounts. Google says usage above the Free Tier limits is billed at standard rates on a Paid billing account. On a Free Trial billing account, your $300 welcome credit pays for the overage, and you are limited to $300 worth of usage.

You need a Cloud Billing account to use any Free Tier product. Google can also change or remove Free Tier limits with 30 days of advance notice.

## Gotchas

- Free Tier limits are per billing account, not per project. All your projects share one allowance.
- The numbers differ between Cloud Run functions (1st gen) and Cloud Run. Check which one your function uses before you plan around a limit.
- The quickstart asks you to verify that billing is enabled and to enable the Artifact Registry, Cloud Build, Cloud Run Admin API, and Cloud Logging APIs.

## Questions people ask

### Is Cloud Run functions free?

Partly. Google's Free Tier page lists 2 million invocations, 400,000 GB-seconds, and 200,000 GHz-seconds per month. You pay standard rates above that.

### Does Cloud Run functions need a credit card?

You need a Cloud Billing account to use the Free Tier. New customers can start a Free Trial with $300 in credit to get one.

### What happens when I go over the Cloud Run functions free tier?

Google bills the overage at standard rates on a Paid billing account. On a Free Trial account, the $300 welcome credit pays for it.
