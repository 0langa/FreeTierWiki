You add a small reporter or library to your test setup and read results in a web app. There are also iOS and Android apps for viewing results, and an API for CI.

## What the free plan gives you

The Free plan costs $0 for a lifetime, with no time limit. It allows 5 targets and 100 test cases per run. A target is one test job, such as a suite or an environment.

You get 50GB of total file storage, 100K file uploads in total, and 30 days of results history. Users and third-party integrations are unlimited. The site says all plans, including Free, support SSO through SAML 2.0, and Google OAuth.

The Standard plan costs $19 per active user per month if paid yearly, with a limit of 50GB per user. The site calls this a Fair Billing Policy: Tesults automatically stops charging for inactive users. Plus costs $37 per active user per month.

## When you hit a limit

The pricing page does not say what happens when a run has more than 100 test cases or when you add a sixth target. The limits are listed per plan, so expect to be asked to upgrade. Standard and Plus list unlimited test cases per run.

The Free plan needs no card, so nothing is billed by accident. Paid plans are billed per active user, and inactive users stop counting.

## Gotchas

- The 50GB of file storage on Free is a total for the account. On Standard it is 50GB per user each month.
- Free keeps results history for 30 days. Standard keeps 90 days, and Plus keeps 365 days.
- The web app is built for desktop browsers. Set up your project on a laptop or desktop.

## Questions people ask

### Is Tesults free?

Yes. The Free plan has no time limit and costs $0. It allows 5 targets, 100 test cases per run, and unlimited users.

### Does Tesults have a free plan for open source?

Yes, on request. Independent and community-driven open source projects can apply for complimentary access to the Standard plan.

### How does Tesults charge for paid plans?

Per active user only. Standard costs $19 per active user per month when paid yearly, and inactive users are not charged.
