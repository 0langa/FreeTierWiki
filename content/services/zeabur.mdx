Zeabur gives you one place to deploy applications and check what is running. That can help when a repository contains an app and you have a Linux server ready for it. The Free offer here is for managing a server you bring.

## What the free plan gives you

The current plan includes one manageable server that you already own or rent. Zeabur supplies a build environment with two CPUs and 4 GB of memory. That capacity is for the build step. A running app shares the resources of the connected machine with anything else you deploy there. The Free dashboard also keeps 48 hours of logs and supports uploading a single file of up to 50 MB through the container file manager. Connect a machine in My Servers first, then choose it when you create a project and deploy your services.

## When you hit a limit

The pricing table puts more managed servers, larger uploads and longer log retention on paid plans. The public pages describe the limits and upgrade path without explaining the exact response from every screen at quota. You can handle a large transfer directly on your own server if that suits your setup. Your server provider may keep billing you while the machine is running.

## Gotchas

- The old shared cluster is closed to new projects. Start by registering your own server. The Free-plan guide says services automatically sleep after inactivity and wake on the next request, causing a cold start. It does not publish an inactivity duration or explain how that policy applies to every bring-your-own-server setup.
- Zeabur may ask you to verify the account when you create a project. The quickstart lists phone verification as one option.
- Free has no SLA, automated database backup/import or log forwarding. If an application issue surfaces after the retention window, you will need logs collected elsewhere. The optional 14-day Dev or Pro trial is available once per user, with the selected plan automatically renewing and charging afterward. Team has no trial. This is separate from staying on the Free dashboard plan.

## Questions people ask

### Does Zeabur Free include a VPS?

You supply the server. The free dashboard deploys to it and gives you build and service management tools.

### Do I need a card for the Free plan?

The plan guide says no card is needed. Project creation can still trigger identity verification, for which the quickstart lists several options.

### Can a free project send through Zeabur Email?

The plan lists no daily sending quota for Zeabur Email on Free. An app can connect to an external mail service under that service’s terms.
