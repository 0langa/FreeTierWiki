Sherlo captures React Native screens defined in Storybook and puts expected and changed appearances side by side. You can use it in a pull request to spot a layout shift before it reaches users. Developers still decide whether a difference is intentional.

## What the free plan gives you

The Free card lists 1,000 snapshots, unlimited projects and users, and cloud capture on iOS and Android. It also includes the review app, a code inspector, and integrations with Figma and Slack. Free jobs use a low-priority queue. Use a few representative stories to establish how many snapshots one capture run uses. You can capture components with different states, such as a screen before and after a validation error, and review differences over time. The project arrangement is flexible, but the snapshot allowance still controls the amount of hosted capture you get.

## When you hit a limit

The provider lists higher snapshot allowances and separately priced extra snapshots on paid plans. The free pricing card does not describe exactly how an excess snapshot request is handled, and signup is advertised without a card. If a run spans a pull request that must ship soon, check whether its captures finished before treating an empty report as approval. Capture only the devices you need for routine checks, then run broader coverage before a release.

## Gotchas

- Sherlo needs a simulator-compatible native build. With EAS Update, subsequent JavaScript changes can reuse that build.
- Add meaningful stories for states you want reviewed. A missing state cannot appear in a screenshot comparison.
- Expect waits on the low-priority queue when scheduling checks before a release. A screenshot can reveal a visual regression while leaving event handling, network behavior and accessibility to other checks.

## Questions people ask

### Is Sherlo Free available on both platforms?

The Free card lists iOS and Android in its hosted visual testing feature set.

### What does a snapshot represent?

It is a captured view of one of your stories. Running more stories across devices can create more snapshots.

### Can multiple developers review?

Sherlo lists unlimited users on Free, with the snapshot allowance applying separately.
