KMS is the AWS service that stores encryption keys and runs cryptographic operations with them. You call it from an AWS SDK or let services such as S3 and EBS call it for you. It suits developers on AWS who need encryption with keys controlled through IAM, without running their own key server.

## What the free plan gives you

KMS has a free tier of 20,000 requests per month, counted across all Regions where the service runs. Requests include calls such as Encrypt, Decrypt, and GenerateDataKey.

Some things cost nothing at all. AWS managed and AWS owned keys, which AWS services create on your behalf when you first encrypt a resource, have no creation or storage charge. Data keys and data key pairs that KMS generates have no monthly charge beyond the API call. Customer managed keys that are scheduled for deletion are not charged.

## When you hit a limit

On Paid accounts without optional project controls, requests continue past the free amount. Past 20,000 requests a month, the pricing page examples bill $0.03 per 10,000 requests.

The bigger cost is often the keys. Each KMS key you create costs $1/month, prorated hourly, whether or not you use it. Rotating a key adds $1/month for the first and second rotation, and later rotations are not billed. An S3 example on the pricing page with one key and 2,000,000 decrypt requests comes to $6.97/month.

## Gotchas

- Requests to GenerateDataKeyPair, and requests such as Sign, Verify, Encrypt, and Decrypt that use asymmetric keys, are excluded from the free tier.
- Canceling a scheduled key deletion bills the key as though it was never scheduled for deletion.
- You cannot manage the lifecycle or the permissions of AWS managed keys; you need a paid customer managed key for that.

## Questions people ask

### Is AWS KMS free?

The first 20,000 requests each month are free, and AWS managed keys have no storage charge. Each key you create yourself costs $1/month.

### Do AWS managed keys cost money?

No. Creating and storing AWS managed or AWS owned keys is free; you pay only for requests past the free tier.

### Do asymmetric key operations count toward the free tier?

No. Requests such as Sign and Verify that use asymmetric keys are excluded from the free tier.
