You add the Edge runtime to a Vercel Function by setting its config, or you write middleware in a framework such as Next.js. You deploy from Git or with the Vercel CLI. Edge code uses web standard APIs like fetch, Request, and Response. Vercel now recommends Node.js for most new work.

## What the free plan gives you

The Hobby plan is free and for non-commercial, personal use. Its included usage covers Edge-runtime functions the same way as other Vercel Functions: the first 1,000,000 function invocations, 4 CPU-hrs of Active CPU, and 360 GB-hrs of provisioned memory. It also includes the first 1,000,000 CDN requests and the first 100 GB of Fast Data Transfer.

An Edge runtime function must begin sending a response within 25 seconds, and it can keep streaming for up to 300 seconds. Hobby allows 200 projects and 100 deployments per day. Runtime logs on Hobby are kept for 1 hour.

## When you hit a limit

Hobby has no billing cycle, because it is a free tier. The docs say that if you pass your usage limits, you will in most cases have to wait until 30 days have passed before you can use the feature again. Some limits have shorter pauses. For example, Web Analytics collection can resume after 7 days.

To get more room, upgrade to Pro. It includes $20 of usage credit, and upgrading means entering your card details. Hobby itself does not bill overage.

## Gotchas

- Vercel recommends migrating from the Edge runtime to Node.js, and Next.js 16.3 no longer supports the edge runtime setting on routes and pages.
- Hobby is for non-commercial, personal use only under the fair use guidelines.
- Edge code runs on V8 with a subset of Web APIs, so many Node.js libraries do not work there.

## Questions people ask

### Are Vercel Edge Functions free?

Yes, on the Hobby plan for personal, non-commercial use. It includes the first 1,000,000 function invocations and 100 GB of Fast Data Transfer.

### What happens when I go over the Vercel Hobby limits?

In most cases you must wait until 30 days have passed before you can use the feature again. You can upgrade to Pro for more room.

### Does Vercel Edge Functions need a credit card?

Not for Hobby. Upgrading to Pro asks for your card details.
