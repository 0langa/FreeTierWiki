You work through a dashboard and a REST API: you define event types and subscriptions, then send events with one API call. Hook0 then delivers them to the endpoints you registered. It suits developers who add webhooks to their own product.

## What the free plan gives you

The Developer plan is free forever and needs no credit card. It includes 100 webhook events a day, HMAC signatures, and delivery monitoring, with community support. Subscriptions and retries are free, because one event can trigger several subscriptions and each can be retried.

Your account can belong to up to 2 free organizations. An organization on a paid plan does not count toward that limit. Hook0 Cloud is hosted in France by default.

The server is open source under SSPL-1.0, and you can self-host it with Docker Compose or Kubernetes at no cost. The client SDKs use the MIT license. When you self-host, you run the infrastructure, scaling, and updates yourself.

## When you hit a limit

On the free Developer plan, extra events past the daily limit are blocked with an HTTP 429 error. You get no bill. The Organization Dashboard shows your event use for the current day and earlier days, so you can watch it.

Paid plans work differently. They never block events. The Startup plan costs €59 a month and covers up to 30,000 events a day, then charges €0.003 per event. The Pro plan costs €190 a month, covers up to 100,000 events a day, then charges €0.0001 per event.

## Gotchas

- The 100 events a day limit is a hard stop with HTTP 429 on the free plan, so a traffic spike drops events until the next day.
- Every event needs at least one label, and the API rejects an empty labels object.
- An application API token can read and manage everything in that application, so treat it as a credential.

## Questions people ask

### Is Hook0 free?

Yes. The free Developer plan has 100 webhook events a day, HMAC signatures, and delivery monitoring, with no credit card. You can also self-host the open-source server for free.

### What happens when I go over the Hook0 free limit?

Extra events are blocked with an HTTP 429 error until the next day. Paid plans never block events and bill per event instead.

### Can I self-host Hook0 for free?

Yes. The server is open source under SSPL-1.0, and you can run it with Docker Compose or Kubernetes. You manage the infrastructure yourself.
