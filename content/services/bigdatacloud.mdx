BigDataCloud sells location APIs in packages: reverse geocoding, IP geolocation, phone and email validation, and network engineering. Each package has its own plans, and every package starts with a free Base plan. It suits apps that need to turn coordinates or IP addresses into a city, region, and country.

## What the free plan gives you

Every package has a free tier, and the Base plan needs no credit card. For reverse geocoding, Base includes 50k requests a month; the API resolves GPS coordinates to city, locality, postcode, and region in over 100 languages, at locality level with no street addresses by design. For IP geolocation, Base includes 10k requests a month with city-level geolocation, confidence areas, hazard detection, and ASN data. BigDataCloud says every plan gets all endpoints and all response fields, REST and GraphQL access, and no rate limits. The quotas are separate per package.

## When you hit a limit

By default, the API returns an HTTP 402 error when your quota is exhausted. If you enable pay-as-you-go, the API keeps working and you are charged for additional queries at your plan's overage rate. Pay-as-you-go is an account-wide setting that covers all your package subscriptions together. Leave it off if you want a hard stop at the free quota. The next reverse geocoding plan, Bronze, costs $19.95 a month for 500k requests.

## Gotchas

- Reverse geocoding returns locality-level results, so you will not get a street address from coordinates.
- Free tiers are per package, so reverse geocoding and IP geolocation each have their own quota.
- Turning on pay-as-you-go applies to every package on the account, not just one.

## Questions people ask

### Is BigDataCloud free?

Yes. Every package has a free Base plan, such as 50k reverse geocoding requests a month, with no credit card.

### What happens when I use up the free quota?

The API returns an HTTP 402 error, unless you enable pay-as-you-go, which bills extra queries.

### Does BigDataCloud return street addresses?

No. Its reverse geocoding is locality-level, with no street addresses by design.
