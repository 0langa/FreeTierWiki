You use Jina Reader by adding `https://r.jina.ai/` in front of a web address, with curl, a script, or a browser. An API key is optional and raises the limits. It suits developers who need page text for LLMs, agents, and RAG systems.

## What the free plan gives you

Reader is free for basic use. Without an API key, you can call `r.jina.ai` at 20 requests per minute, counted per IP address. A free API key raises that to 500 requests per minute, and every new key comes with 10M free tokens. With a key, the limit follows the key instead of the IP.

The search endpoint, `s.jina.ai`, is blocked without a key. A free key gets 100 requests per minute there. Each search request costs a fixed number of tokens, starting from 10,000. Reader uses tokens based on the length of the output. Tokens are not deducted for failed requests.

## When you hit a limit

You hit a rate limit when either the requests per minute or the tokens per minute threshold is reached first. Without a key, you can add a key to raise the limit. When your 10M free tokens run out, the pricing section lets you top up a key with more tokens, and the page lists 500 requests per minute for a paid key and 5000 for a premium key. The page does not say what the API returns when a free key has no tokens left. You can set `X-Token-Budget` to cap tokens on one request. A request that goes over the budget fails.

## Gotchas

- Pages that need an interactive login, MFA, or a token the page fetches itself are out of scope. You can forward session cookies, but those requests are not cached.
- The ReaderLM-v2 and jina-vlm models use a CC-BY-NC 4.0 license, so commercial production use needs a commercial license.
- If a website blocks the request, Reader respects that outcome and does not work around it.

## Questions people ask

### Is Jina Reader free?

Yes. Reader is free for basic use with no key at 20 requests per minute. A free API key adds 10M tokens and a limit of 500 requests per minute.

### Does Jina Reader need an API key?

Not for basic use. Put `r.jina.ai` in front of a URL. The search endpoint needs a key, and a key also raises your rate limit.

### What happens when I go over the Jina Reader rate limit?

The limit triggers when either the requests or the tokens per minute are reached. Add a key or wait a minute. A premium key lists a higher limit.
