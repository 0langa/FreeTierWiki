You use the tools in a web browser, with no software to install, and each tool has its own page, such as TTF to WOFF2 or the @font-face generator. A separate REST API for automated conversion is a paid product.

## What the free plan gives you

The site says its browser tools are free. They cover font conversion, an @font-face generator, font editing, hinting and subsetting tools, font info tools such as `ttfdump`, and unit converters for px, em, pt, and more. Converters support formats such as TTF, OTF, WOFF, WOFF2, SVG, and EOT.

Upload size is the limit you will meet. The converter page lists a font upload limit of 400 kb for guests and unverified registered users. Verified users get 1000 kb. The @font-face generator page lists different limits: 0.4 MB for guests, 0.5 MB for unverified registered users, and 2 MB for verified users. The site offers an upgrade if you want more. A converted file is available to save right after conversion.

## When you hit a limit

The converter pages say that a font above your upload limit needs a higher limit, which you get by verifying your account or upgrading. The pages do not describe a daily cap on conversions, and nothing on them shows a charge for the free tools.

For automated or high-volume work, the Font Conversion API is paid. The Basic plan costs $9.99 a month for 1000 API calls a day. Premium costs $24.99 a month for 4000 calls a day, and Ultra costs $49.99 a month for 12000 calls a day.

## Gotchas

- The tools may refuse some conversions. The site says that not all format conversions work well.
- Each converter page asks you to confirm that the font license allows the conversion. Check your font license before you convert.
- The API runs at a separate endpoint with an API key. The free browser tools do not give you API access.

## Questions people ask

### Is Everything Fonts free?

Yes, for the browser tools. They work as a guest with a 400 kb upload limit, which rises to 1000 kb for verified users. The REST API is paid.

### How much does the Everything Fonts API cost?

The Basic plan costs $9.99 a month and allows 1000 API calls a day. Premium costs $24.99 a month and Ultra costs $49.99 a month, with higher daily limits.

### Does Everything Fonts need an account?

No for the browser tools, since the converter page names limits for guests. A verified account raises the upload limit.
