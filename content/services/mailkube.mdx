Mailkube delivers email that your application generates, such as a receipt or a contact-form notification. Your code can call its API or use the SMTP relay if the software already supports SMTP. Start by verifying a sending domain and use the dashboard to follow what happens after you submit a message.

## What the free plan gives you

Free accounts can send up to 4,000 emails per month and 140 per day. Both the API and SMTP relay are included. The comparison table lists unlimited sending domains, so you can use separate domains for different projects without buying a plan just to add one. The sending limits still apply to the account.

Basic analytics and seven days of delivery logs are included. Use the logs to look up a test message and see whether the service accepted it, delivered it, or recorded a bounce. If you need to investigate a message later, check the dashboard while the log is still available.

## When you hit a limit

Mailkube says it pauses sending when the allowance runs out and alerts you as you approach the limit. Its free signup needs no card, so exhausting the monthly allowance does not start paid sending. You can upgrade if you need to resume before the limit resets. The daily cap also applies, so a large batch can run into a pause even with monthly volume left.

## Gotchas

- Each sending domain needs to be verified. Follow the provider's DNS instructions before wiring up production mail.
- The daily cap affects batch jobs as well as traffic from users. Scheduled notifications can use the same allowance as your other application mail.
- Free delivery logs are retained for a week. The plan is a poor fit if you depend on older logs for routine support investigations.

## Questions people ask

### Is Mailkube free?

Yes. The ongoing Free plan includes 4,000 emails a month without a credit card.

### Can I send from several domains on Free?

Yes. Mailkube lists unlimited domains, subject to verification and the sending quota.

### Does Mailkube support SMTP on Free?

Yes. The pricing table includes both SMTP and API access, so either can submit mail on the Free plan.
