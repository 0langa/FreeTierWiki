Momentic lets you author a test and follow the results after it runs. The test can go through part of a web app that you want to protect from regressions. Its usage meter lets you observe what that test costs against your monthly balance before running it more often.

## What the free plan gives you

Free includes $50 of usage per month, 30 days of results, and the core test authoring features. No card is required. Usage can include ordinary test steps, AI or recovery actions, and hosted runtime. Those items have different rates. An editor step and a hosted action can affect the balance differently, so avoid estimating capacity by counting tests alone. Start with a stable test flow, run it under the conditions you expect to use, then read the usage details. This is particularly useful if you want to put a test on a schedule after proving it works.

## When you hit a limit

Runs pause when the balance reaches zero. Momentic says it does not bill beyond the balance or roll unused included usage into the next month. Free cannot add funds. Wait for the next reset or select a paid plan if you need more capacity. Retention is separate from usage, so a run can disappear from history while your balance still has room.

## Gotchas

- Recovery and authoring actions can consume a different amount from ordinary execution.
- The pricing FAQ lists up to two concurrent devices of each mobile platform on Free, with a 15-minute session limit. Mobile usage draws from the balance by the minute.
- Save the result of a failure you need to investigate after the free retention window.

## Questions people ask

### Does Momentic need a card?

The free plan is advertised without a credit card.

### Is the monthly balance a fixed test count?

It pays for usage categories with separate rates. The number of tests it buys depends on their steps, runtime and AI actions.

### Where do I start?

Pick a brief regression case and watch it run once. Compare the execution result and usage with what you expect before adding a larger suite.
