HERE is a location platform with map rendering, geocoding and search, routing, traffic, transit, and weather APIs. The Base Plan is the self-serve option: you sign up, pay per transaction, and each API starts with a free monthly allowance. It suits developers building routing, address search, or map features who want to start without a sales contract.

## What the free plan gives you

The Base Plan gives access to the HERE Explore SDK and the HERE Maps API for JavaScript, with a free monthly allowance per API and no daily transaction limits. Map rendering includes 30K free transactions a month each for vector tiles, raster tiles, and map images. Geocode and reverse geocode include 30K a month, autocomplete 30K, and discover or search 5K. Car, bicycle, and pedestrian routing include 30K a month, truck routing 5K, and matrix routing 2.5K. Data IO includes 20 GB free. HERE says the listed prices are indicative estimates, not final quotes.

## When you hit a limit

The Base Plan uses a pay-per-transaction model. The sign-up page says you start with free monthly transactions and pay only when you go over the free limits. The pricing page does not say whether requests stop at the free amount or whether you can set a spending cap, so plan on usage past the free allowance being billed. Watch your monthly transactions per API, since each API has its own free amount and some are much smaller than others.

## Gotchas

- Permanent Geocoding is not included in the Base Plan; HERE asks you to contact them for pricing.
- Asset management, fleet optimization, and similar use cases are excluded from the Base Plan.
- One app ID can only be used for one application, so separate apps or customers need separate app IDs.

## Questions people ask

### Is HERE free to use?

The Base Plan starts free. Each API has a free monthly allowance, such as 30K geocoding transactions, and you pay per transaction above it.

### Does the HERE Base Plan have daily limits?

No. The pricing page lists no daily transaction limits for the Base Plan; the free allowances are monthly.

### Can I use the Base Plan for fleet tracking?

No. Asset management, fleet optimization, and some telematics uses are excluded from the Base Plan, with HERE Tour Planning as an exception for optimization.
