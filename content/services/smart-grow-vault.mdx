You manage organizations, apps, and environments in a web dashboard, and pull values with the `smart-grow` command-line tool. A scoped API key does the same in a pipeline. It suits small teams that share .env files today.

## What the free plan gives you

The Free plan costs $0 and needs no credit card. It covers 1 organization, 3 apps per organization, and 2 environments per app. Each environment holds 50 variables and 2 secure files, such as a .pem or .p12 certificate. You can create 2 API keys.

Every plan includes encryption, versioning, the CLI, and the activity log. You can compare versions and roll back a change, and you can download your variables as a JSON or .env file whenever you want. Access can be set by role and by environment.

## When you hit a limit

The site does not say what happens when you reach a cap, such as a fourth app or a variable beyond the 50 in an environment. The free plan is a fixed set of numbers and needs no card, so the page shows no way to get billed. Paid plans start at $4.99 a month and add more apps, environments, and members. Moving up is the only path the site describes, so plan to upgrade or split projects before you reach a cap.

## Gotchas

- Smart Vault is not end-to-end encrypted. The service decrypts values to answer authorized requests.
- Values are masked in the dashboard, but anyone who can read an environment can download its values with the CLI.
- A CLI session lasts 7 days, and you can have up to 5 devices. Sign in again when a session ends.

## Questions people ask

### Is Smart Vault free?

Yes. The Free plan costs $0 with no credit card. It covers 1 organization, 3 apps, and 2 API keys.

### Does Smart Vault work in CI/CD?

Yes. Create an API key limited to the environments your pipeline needs, and run the `cloud_sync` command in your runner.

### Is Smart Vault end-to-end encrypted?

No. The service decrypts values to answer authorized requests. Values are encrypted at rest and travel over a post-quantum encrypted channel on top of HTTPS.
