UNPKG is a content delivery network for everything on npm. You load a file with a URL made of the package name, a version, and a path, and UNPKG serves it from Cloudflare's edge network.

## What the free plan gives you

UNPKG has no plans. Its home page shows no prices, no sign-up, and no API keys: you request a URL. It is an open-source project from @mjackson, and it mirrors everything on npm, so every file is available within minutes of being published.

You can use an exact version, an npm dist-tag, or a semver range in the URL; without a version you get the latest tag. The esm.unpkg.com subdomain turns packages that are not browser-ready into ES modules, transforming TypeScript and JSX, bundling package internals, and rewriting dependency imports to permanent UNPKG URLs. Appending ?meta returns a package's file list with sizes, types, and subresource integrity values.

## When you hit a limit

The home page states no request limits, bandwidth limits, or fair use terms, and it does not say what happens to very heavy users. UNPKG runs on Cloudflare Workers, which it says lets it serve billions of requests a day and scale for traffic spikes.

The practical limit is caching. Files are cached by their permanent URL with the full version. A URL with a range or tag, like a major version only, always redirects to the permanent URL first, so it is not a direct cache hit and is slower. Use full version numbers and file paths.

## Gotchas

- UNPKG is not affiliated with or supported by npm, and npm cannot help with UNPKG problems.
- There is no stated SLA, so a production site depends on a community-run service.
- URLs without a fixed version change when a new release ships, which can break a page without warning.

## Questions people ask

### Is UNPKG free?

The site shows no prices, plans, or sign-up; you load files by URL. It is an open-source project.

### Is UNPKG part of npm?

No. UNPKG says it is not affiliated with or supported by npm in any way.

### How do I get the best cache performance from UNPKG?

Use a full package version and file path in the URL. Ranges and tags redirect to the permanent URL first.
