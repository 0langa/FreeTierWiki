UNPKG is a content delivery network for everything on npm. You load a file with a URL made of the package name, a version, and a path, and UNPKG serves it from Cloudflare's edge network.

## What the free plan gives you

UNPKG has no plans. Its home page shows no prices for the CDN, and serving files requires no account: you request a URL. The About page explicitly describes it as free, open source, and available without an account. It serves files from public npm packages under their maintainers’ licenses. UNPKG Shield is a separate optional beta for supply-chain protection; it is not part of the base service.

You can use an exact version, an npm dist-tag, or a semver range in the URL; without a version you get the latest tag. The esm.unpkg.com subdomain turns packages that are not browser-ready into ES modules, bundling package internals and rewriting dependency imports to UNPKG URLs. Appending ?meta returns a package's file list with sizes, types, and subresource integrity values.

## When you hit a limit

The home page states no request limits, bandwidth limits, or fair use terms, and it does not say what happens to very heavy users. The network guide describes Cloudflare edge and Worker caches backed by file origins in 11 regions. It explicitly notes that using one edge provider means there is no multi-provider failover.

The practical limit is caching. Files are cached by their permanent URL with the full version. A URL with a range or tag, like a major version only, always redirects to the permanent URL first, so it is not a direct cache hit and is slower. Use full version numbers and file paths.

## Gotchas

- UNPKG is not affiliated with or supported by npm, and npm cannot help with UNPKG problems.
- The About page expressly excludes a contractual SLA. Questions and abuse reports can go to support@unpkg.com or the public repository.
- URLs without a fixed version change when a new release ships, which can break a page without warning.

## Questions people ask

### Is UNPKG free?

The CDN shows no prices, plans, or sign-up; you load files by URL. It is an open-source project.

### Is UNPKG part of npm?

No. UNPKG says it is not affiliated with or supported by npm in any way.

### How do I get the best cache performance from UNPKG?

Use a full package version and file path in the URL. Ranges and tags redirect to the permanent URL first.
