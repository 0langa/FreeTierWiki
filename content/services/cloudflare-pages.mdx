You connect a GitHub or GitLab repository in the Cloudflare dashboard, or use Direct Upload or the C3 command line tool. Each push builds and deploys your site. The docs now say to start new projects with Workers, so Pages suits existing projects and simple static sites.

## What the free plan gives you

The Free plan allows 500 builds per month and 1 build at a time. A build times out after 20 minutes. You can have 100 projects per account, 100 custom domains per project, and up to 20,000 files per site, each up to 25 MiB. Preview deployments are unlimited, and an unlimited number of users can manage a site through the dashboard.

Requests to Pages Functions count toward your Workers plan quota. A `_headers` file can hold 100 rules, and a `_redirects` file can hold 2,000 static and 100 dynamic redirects. The Pro plan raises builds to 5,000 per month, and Business raises them to 20,000.

## When you hit a limit

The limits page lists the caps but does not say what happens when you reach the build count. No card is needed for the Free plan, so the page shows no bill from Pages itself. To raise a limit, you can fill in the Limit Increase Request Form, or move to a paid Cloudflare plan.

The project cap is firm. The page says it is not routinely increased, and points to Workers for Platforms if you need to host many sites. New accounts also face a short guard: Cloudflare limits how many new Pages projects you can create in the first 48 hours.

## Gotchas

- Cloudflare says Workers supports most Pages use cases and is its primary platform, so check Workers before you start a new project.
- A project created with Git integration cannot be switched to Direct Upload later.
- On GitLab you need the Maintainer role or higher on the repository to deploy with Pages.

## Questions people ask

### Is Cloudflare Pages free?

Yes. The Free plan allows 500 builds per month, 100 projects per account, and unlimited preview deployments.

### Does Cloudflare Pages have a build limit?

Yes. The Free plan allows 500 builds per month and one build at a time. The Pro plan allows 5,000 builds per month.

### Should I use Cloudflare Pages or Workers for a new site?

Cloudflare says Workers is its primary platform and supports most Pages use cases. It tells you to start new projects with Workers.
