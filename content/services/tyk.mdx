Tyk is an API gateway and API management platform. It sits in front of your APIs to handle access, policies, and a developer portal, and it runs as a hosted cloud service, a hybrid setup, or software you manage yourself. Tyk Cloud is the fully managed SaaS version, and its free offer is a short trial for teams evaluating a gateway.

## What the free plan gives you

The pricing page offers a 48-hour free trial of Tyk Cloud, which it calls its fully featured SaaS product. During the trial you get full access to all Tyk features and capabilities, with no installation, no credit card, and no calls required: you sign up and start building.

The FAQ says Tyk also provides a free version of its open-source API gateway through GitHub and guided proofs of concept with solution architects. The open-source gateway is software you run yourself, so it is not a hosted free tier. All paid tiers, Core, Professional, and Enterprise, support cloud, hybrid, and self-managed deployments.

## When you hit a limit

The trial ends after 48 hours. The pricing page does not say what happens to your trial setup afterwards, and it lists no public prices for the paid tiers.

Core is described as a flexible, usage-based plan, Professional as a flat rate with unlimited APIs and unlimited API requests a month, and Enterprise as custom pricing. Because the trial needs no card, it does not turn into a charge by itself.

## Gotchas

- 48 hours is short, so prepare your test APIs and questions before you start the trial.
- Pricing for Core and Professional is behind a get pricing form rather than on the page.
- The free open-source gateway needs your own servers; it is not a free Tyk Cloud plan.

## Questions people ask

### Is Tyk Cloud free?

Only for 48 hours. Tyk offers a 48-hour free trial of Tyk Cloud with full features and no credit card.

### Do I need a credit card for the Tyk trial?

No. The pricing page says the trial needs no installation, no credit card, and no calls.

### Is there a free version of Tyk I can keep using?

Yes, the open-source Tyk gateway on GitHub is free, but you host it yourself.
