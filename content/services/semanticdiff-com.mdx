You use it as a VS Code extension or as a GitHub App with its own review page. Language support is built rule by rule, and unsupported files fall back to a plainer diff.

## What the free plan gives you

The Free plan costs 0€ and is always free for 3 seats. It includes the minimap, pull request review, and review comments.

Seats count the developers whose pull requests in private or internal repositories are analyzed. Free seats are assigned automatically the first time a pull request from a GitHub user is analyzed. Seats are shared across all repositories owned by one GitHub user or organization.

Open source is different. The site says that as an open source project you can choose the Free plan and use SemanticDiff with as many public repositories and contributors as you like, with no seats. This covers personal and commercial use.

The Professional plan is for teams of 4 or more. It costs 9€ per seat per month, or 7€ per seat per month when billed yearly, excluding VAT.

## When you hit a limit

If you run out of seats, only pull requests from authors who already have a seat are analyzed. You can upgrade your plan, or remove an existing seat assignment to make room for a new author.

Nothing is billed unless you upgrade. Upgrades go through a checkout where you choose the number of seats and the billing interval. The Free plan gets community support through GitHub, with no guaranteed response time.

## Gotchas

- Seats apply to private and internal repositories only. Public repositories do not use seats.
- Plans belong to a GitHub installation, not to one person. You cannot buy an individual license.
- Review comments only work in the GitHub App, and the app must be installed on the repository. The VS Code extension cannot post them.

## Questions people ask

### Is SemanticDiff free?

Yes. The Free plan covers 3 seats for private repositories, and open source projects can use it with no seats. The Professional plan starts at 7€ per seat per month when billed yearly.

### What happens when I run out of SemanticDiff seats?

Only pull requests from authors with a seat are analyzed. You can upgrade or free up a seat for a new author.

### Can I try SemanticDiff without installing it?

Yes. Open app.semanticdiff.com and enter the URL of any public pull request. Features such as writing comments need the repository maintainer to have enabled the app.
