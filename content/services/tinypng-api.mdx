The TinyPNG Developer API, run by Tinify, compresses images from your server. You send an image, the API compresses it, and it responds with a URL where you can download the result. It can also resize, convert between AVIF, JPEG XL, WebP, JPEG, and PNG, and store results in Amazon S3. HEIC uploads are compressed to JPEG.

## What the free plan gives you

The developers page offers 500 free compressions each month and says no payment method is required. You register with your name and email address, click the button in the activation email, and find your API key in the API dashboard.

Official client libraries are available for Ruby, PHP, Node.js, Python, Java, and .NET, and any HTTPS client works too. You can create several API keys in the dashboard to track compressions separately for each site or app. Most responses include a Compression-Count header for the current key. The monthly allowance is shared across every key in the account.

## When you hit a limit

Free accounts stop at 500 compressions per UTC calendar month and return HTTP 429 with a message identifying the monthly limit. Wait for the next calendar month or explicitly upgrade. Paid usage costs $0.009 per compression for the next 9,500, then $0.002 each beyond 10,000; adding paid billing removes the free cap.

Plan for how operations are counted. Each request that resizes, converts, or stores a result counts as one additional compression, even if it combines several actions. The API reference gives an example: uploading one image and retrieving the optimized version plus 2 resized versions counts as 3 compressions.

## Gotchas

- Each resize or format conversion uses another compression, so the 500 go faster than the number of images suggests.
- Requests are rate limited; on a rate limit error the reference says to add some delay between requests.
- The API key is the only credential, sent with HTTP Basic Auth, so keep it on your server.

## Questions people ask

### How many free compressions does the TinyPNG API give?

500 free compressions each month, with no payment method required.

### Does resizing count as a compression?

Yes. A resize request adds one compression. If you also convert the image in that same request, the two actions together add one compression.

### Which languages have official clients?

Ruby, PHP, Node.js, Python, Java, and .NET, and you can call the API from any HTTPS client.
