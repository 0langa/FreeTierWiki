You call one HTTP endpoint with an API key, from cURL, Python, Node, or any client. An MCP server also lets AI coding agents fetch pages through the same credits. It suits developers who want a rendered page without running their own browsers.

## What the free plan gives you

The free plan gives you 10,000 API credits every month and needs no credit card. Browser rendering and proxy rotation are included. ScrapingAnt says there is no concurrency cap on any plan.

Credits are what you spend. Most requests cost between 1 and 25 credits, depending on the options you switch on, such as proxy type and JavaScript rendering. The default request uses Chrome rendering with standard proxies and costs 10 credits. At that rate the free credits cover about 1,000 default requests. ScrapingAnt says you pay only for successful scrapes, and failed requests cost 0.

## When you hit a limit

The pricing section does not say what happens when the free credits run out. It does say you can restart your plan mid-month, and credits refresh the moment you pay, so scraping never has to stop. You only enter payment details if you upgrade, so a free account has no card to charge.

The first paid plan gives 100,000 credits a month for $19 a month. Proxy plans are separate and are billed by the gigabyte, not with API credits.

## Gotchas

- Options raise the price of a request. Rendering and better proxies can push a single request well above the 10-credit default.
- A request stops after at most 60 seconds by default, and you can set a timeout from 5 to 60 seconds.
- The default proxy type is datacenter. Pick another proxy type or a country in the request if a site blocks you.

## Questions people ask

### Is ScrapingAnt free?

Yes. The free plan includes 10,000 API credits every month with no credit card. Browser rendering and proxy rotation are included.

### How many requests do the ScrapingAnt free credits cover?

It depends on the options. A default request costs 10 credits, and most requests cost between 1 and 25 credits.

### Does ScrapingAnt need a credit card?

No. You only enter payment details if you upgrade to a paid plan.
