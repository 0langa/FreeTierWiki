You call one HTTP endpoint with an API key, from cURL, Python, Node, or any client. An MCP server also lets AI coding agents fetch pages through the same credits. It suits developers who want a rendered page without running their own browsers.

## What the free plan gives you

The free plan gives you 10,000 API credits every month and needs no credit card. Browser rendering and proxy rotation are included. The homepage says concurrency is unlimited, but API docs limit Free to one active request.

Credits are what you spend. Documented base scrape costs range from 1 to 125 credits, depending on browser and proxy options. The default request uses Chrome rendering with standard proxies and costs 10 credits. At that rate the free credits cover about 1,000 default requests. ScrapingAnt says you pay only for successful scrapes, and failed requests cost 0.

## When you hit a limit

The API error guide documents HTTP 403 when credits are exhausted. Pause requests until credits are available again or choose a paid plan. The homepage says payment details are entered only when upgrading. Unused credits do not roll over.

The homepage advertises no concurrency cap on any plan, but the API docs explicitly allow one active Free request and return HTTP 409 for overlap. Queue requests sequentially until the provider clarifies this contradiction. Paid plans are documented as having no concurrency cap.

## Gotchas

- Options raise the price of a request. Rendering and better proxies can push a single request well above the 10-credit default.
- A request stops after at most 60 seconds by default, and you can set a timeout from 5 to 60 seconds.
- The default proxy type is datacenter. Pick another proxy type or a country in the request if a site blocks you.

## Questions people ask

### Is ScrapingAnt free?

Yes. The free plan includes 10,000 API credits every month with no credit card. Browser rendering and proxy rotation are included.

### How many requests do the ScrapingAnt free credits cover?

It depends on the options. A default request costs 10 credits, covering about 1,000 requests a month. Base scrape costs range from 1 to 125 credits, with extra credits for AI extraction.

### Does ScrapingAnt need a credit card?

No. You only enter payment details if you upgrade to a paid plan.
