Semaphr lets a mobile developer apply rules to app versions. You can tell users that an update is available, show a maintenance message, or block a version that should no longer be used. Add the SDK so your application can present the appropriate message on the device.

## What the free plan gives you

The provider describes Startup as free forever without a card for startups and small companies, with unlimited apps. Use a separate app and API key for each environment. The plan lists native and cross-platform SDKs, usage analytics, block and update messages, unlimited logs and unlimited team members. Test your configuration in a controlled app version and verify what the device displays for each rule you plan to use. An update prompt is useful when you want to steer people toward a release without immediately disabling the version they have installed. A blocking rule has a different effect. Consider what the user sees and whether the new version is available before applying that type of rule.

## When you hit a limit

The public pricing section lists Enterprise for features such as priority delivery, advanced analytics and custom branding. It does not describe a fixed request allowance or a clear cutoff for Startup. Before relying on it for a large rollout, verify its current behavior with your integration and make sure the app handles an unavailable policy response sensibly. Test the message with a release installed on a device, including the path where the store has not yet made the new version available.

## Gotchas

- A device needs a version of the app with the SDK integration to act on configured rules; older versions without it cannot be managed.
- Startup messages appear when the user brings the app to the foreground. Real-time alerts are an Enterprise feature. The free feature list includes usage analytics. Advanced analytics and exports are listed on Enterprise.
- Test a rule on an intended version before enabling it broadly.

## Questions people ask

### Is Semaphr free?

Yes, for startups and small companies, without a card. Large enterprises should request a custom plan.

### Can Semaphr force an update?

It can apply a version block and show an update message once the app is integrated.

### Can several teammates use it?

Startup lists unlimited team members. Confirm role and security requirements separately if your workflow needs enterprise controls.
