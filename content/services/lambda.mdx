You work in the Lambda console or deploy code from your own tools, and a trigger such as a web endpoint or a storage event starts each run. It suits developers who want to run small pieces of backend code without keeping a server online.

## What the free plan gives you

Lambda Event Functions have a monthly free tier. It includes one million requests and 400,000 GB-seconds of run time each month. A GB-second is one second of running with 1 GB of memory, so a function with more memory uses the allowance faster.

You pick the memory for each function, from 128 MB up to 10,240 MB, and CPU power grows with the memory you choose. Ordinary Event Function invocations run up to 15 minutes. Managed Instances asynchronous and eligible event-source invocations can run up to 90 minutes, with separate deployment/pricing considerations. The listed default limit is 1,000 concurrent executions per Region. New AWS accounts start with lower concurrency and memory quotas, and AWS raises them as you use the service.

## When you hit a limit

Free-account excess usage consumes credits without an overage bill. At 6 months or depleted credits, AWS suspends the account and retains data for 90 days for a Paid upgrade and recovery. Paid usage incurs standard rates after eligible credits; optional project limits from $20 can pause resources. These controls are not automatic caps on every Paid account. Most new customers need no payment method, but identity verification may require one.

Concurrency quotas separately cause throttling; retry with exponential backoff. The FAQ has conflicting six- and twelve-month credit-expiry text, so check the expiry shown for your account and signup cohort.

## Gotchas

- The free tier does not apply to functions that use Provisioned Concurrency. Provisioned Concurrency and other features have their own prices.
- New accounts have reduced concurrency and memory quotas until AWS raises them based on your usage.
- Memory sets both cost and speed, because CPU grows with memory and the GB-second allowance is shared across all your functions.

## Questions people ask

### Is AWS Lambda free?

Partly. Event Functions include one million requests and 400,000 GB-seconds per month. Account type and remaining credits determine whether extra usage creates a bill.

### What happens when I go over the Lambda free tier?

On the Free account plan, extra usage consumes remaining credits and the account is suspended at credit exhaustion or 6 months. On a Paid plan, standard rates apply after eligible credits run out.

### How long can a Lambda function run?

Ordinary Event invocations run up to 15 minutes. Managed Instances asynchronous and event-source invocations can run up to 90 minutes, except Amazon MQ and DocumentDB mappings; review separate pricing before choosing that route.
