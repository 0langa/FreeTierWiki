You work in the Lambda console or deploy code from your own tools, and a trigger such as a web endpoint or a storage event starts each run. It suits developers who want to run small pieces of backend code without keeping a server online.

## What the free plan gives you

Lambda has a monthly free tier on Functions. It includes one million requests and 400,000 GB-seconds of run time each month. A GB-second is one second of running with 1 GB of memory, so a function with more memory uses the allowance faster.

You pick the memory for each function, from 128 MB up to 10,240 MB, and CPU power grows with the memory you choose. One call can run for up to 15 minutes. The listed default limit is 1,000 concurrent executions per Region. New AWS accounts start with lower concurrency and memory quotas, and AWS raises them as you use the service.

## When you hit a limit

The pricing page does not describe a hard stop. It shows that usage above the free amounts is billed. The examples subtract the free 1 million requests and 400,000 GB-seconds from the bill, then charge for the rest. Nothing on the page says AWS blocks your functions when the free amounts run out, so treat overage as a bill and watch your usage. The AWS Free Tier page adds that the Free plan incurs no charges unless you upgrade to a Paid plan.

Quotas are different. When requests exceed your concurrency limit, Lambda throttles them, and the docs tell you to retry with exponential backoff. You can ask for higher quotas.

## Gotchas

- The free tier does not apply to functions that use Provisioned Concurrency. Provisioned Concurrency and other features have their own prices.
- New accounts have reduced concurrency and memory quotas until AWS raises them based on your usage.
- Memory sets both cost and speed, because CPU grows with memory and the GB-second allowance is shared across all your functions.

## Questions people ask

### Is AWS Lambda free?

Partly. The free tier includes one million requests and 400,000 GB-seconds per month, and you pay for usage above that.

### What happens when I go over the Lambda free tier?

AWS bills the usage above the free amounts. The pricing page does not describe a hard cap that stops your functions.

### How long can a Lambda function run?

A single call can run for up to 15 minutes. For longer jobs, split the work or use another service.
