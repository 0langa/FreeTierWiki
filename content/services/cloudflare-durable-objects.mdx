You write a Durable Object as a JavaScript or TypeScript class inside a Cloudflare Worker, then call it from the Worker by name. It suits developers who need one place to hold shared state, such as a chat room or a game lobby, without running a database server.

## What the free plan gives you

Durable Objects work on the Workers Free plan, but only with the SQLite storage backend. The daily free limits are 100,000 requests and 13,000 GB-s of compute duration. A GB-s is one second of running with 1 GB of memory, and duration billing counts 128 MB of memory per object.

For storage, the free plan allows 5 million rows read per day, 100,000 rows written per day, and 5 GB of SQL stored data in total. Key-value methods such as get and put count as rows read and rows written. Daily limits reset at 00:00 UTC.

## When you hit a limit

On the Workers Free plan, a hard stop applies. If you pass any one of the free limits, further operations of that type fail with an error.

The limits reset at 00:00 UTC each day, so the errors end after the reset. Duration also counts while an object sits idle in memory and cannot hibernate. Open WebSocket connections are the usual cause. The WebSocket Hibernation API can sharply cut those duration charges, so it also stretches your free duration.

## Gotchas

- An object that calls accept on a WebSocket pays duration for as long as that connection stays open. Use the Hibernation API for chat-style apps.
- Pending input and output work can keep an object in memory for up to 15 minutes, and that time counts as duration.
- The free plan cannot use key-value backed Durable Objects. New classes must use the SQLite backend.

## Questions people ask

### Are Cloudflare Durable Objects free?

Yes, on the Workers Free plan, with SQLite storage only. The daily limits are 100,000 requests and 13,000 GB-s of duration.

### What happens when I go over the Durable Objects free limits?

Further operations of the type you exceeded fail with an error. The limits reset at 00:00 UTC.

### Do Durable Objects need a credit card?

The getting started guide lists only a Cloudflare account and Node.js as prerequisites. On the free plan, operations that pass a limit fail with an error.
