Workers Analytics Engine gives your Cloudflare Workers a built-in API to write data points and a SQL API to query them. Cloudflare describes it as unlimited-cardinality analytics at scale. It suits developers who want custom metrics per customer or per user, such as usage for billing, without running a time series database.

## What the free plan gives you

Analytics Engine is priced on two metrics: data points written and read queries. On Workers Free, 100,000 data points written and 10,000 read queries are included per day. Workers Paid includes 10 million data points and 1 million read queries per month.

Right now you will not be billed for Analytics Engine at all. Cloudflare publishes the prices in advance so you can estimate costs once it starts billing in the coming months. Data you write is stored for three months, and you can query it from the SQL API, from Grafana, or from a Worker.

## When you hit a limit

The pricing page does not say what happens past the daily amounts on Workers Free. Billing has not started, so there is no charge today.

Per-write limits are fixed. Each call to writeDataPoint takes up to twenty blobs, twenty doubles, and one index. The blobs in a data point must not exceed 16 KB in total, and each index must be 96 bytes or less. A Worker can write a maximum of 250 data points per invocation. Once billing starts, Workers Paid adds $0.25 per million extra data points written and $1.00 per million extra read queries.

## Gotchas

- Data is kept for three months, so export anything you need for longer.
- Each call to writeDataPoint counts toward the 250 per invocation limit, so batch carefully in busy request handlers.
- Pricing could change when billing starts, since the published prices are an advance notice.

## Questions people ask

### Is Workers Analytics Engine free?

Yes, for now. Cloudflare does not bill for it yet, and Workers Free includes 100,000 data points written and 10,000 read queries per day.

### How long is data kept?

Data written to Workers Analytics Engine is stored for three months.

### How many data points can one request write?

A Worker can write up to 250 data points per invocation, and each data point can hold up to twenty blobs, twenty doubles, and one index.
