Azure Healthcare Agent Service (formerly Azure Health Bot) provides a compliant, healthcare-specific conversational AI platform. The free (F0) tier is rate-limited to 15 requests per second for evaluation and development; production use needs the pay-as-you-go Agent (C1) tier, billed per action.
