You create an instance in the Azure portal, then build healthcare scenarios in its management portal. It suits developers at providers, health insurers, and digital health companies who want a proof of concept before they pay.

## What the free plan gives you

The Free (F0) tier is for evaluation and development, and Microsoft calls it the recommended place to start. The pricing page says it gives a limited amount of free actions per month in non-production deployments. You can try all features to build a proof of concept or a demo. The page does not publish how many free actions you get.

The Free tier is limited to 15 requests per second. An action is the unit the service uses to measure agent usage. The number of actions depends on how you design the agent and which features users touch.

## When you hit a limit

The pricing page does not say what happens when free actions run out. For production, you need the Agent (C1) pay-as-you-go tier. It bills every action at $0.01. A classic rule-based message uses 1 action, and a response grounded in your own sources uses 2 actions. The Agent tier supports up to 50 requests per second.

The older Standard (S1) tier is deprecated. You cannot create new S1 instances. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## Gotchas

- The free tier is not for production use.
- You choose the region when you create the instance, and the docs say it cannot be changed later.
- The instance name allows only lowercase letters and hyphens, and it must be between 2 and 30 characters long.

## Questions people ask

### Is Azure Healthcare Agent Service free?

There is a Free (F0) tier for evaluation and development. It is limited to 15 requests per second and is not meant for production.

### What is the difference between Azure Health Bot and Healthcare Agent Service?

The fetched Microsoft pages only use the name healthcare agent service and do not mention a rename. The documentation address still says health-bot, so treat both names as the same service.

### How much does Healthcare Agent Service cost after the free tier?

The Agent (C1) tier bills each action at $0.01. Different features use different numbers of actions.
