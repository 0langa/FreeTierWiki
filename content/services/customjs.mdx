You get an API key from the CustomJS app and send authenticated HTTP requests to its endpoints. You can also add its MCP server URL to an AI client such as Claude or Cursor. It suits people who wire up no-code automations and need PDFs, screenshots, or custom code steps.

## What the free plan gives you

The Free plan has no cost and the pricing page says no credit card is needed. It allows 20 requests per day, which the site describes as 600 requests per month. Each JavaScript execution or PDF rendering counts as 1 request. The MCP server says the 600 free operations a month are shared across all tools.

JavaScript runs with a request timeout of 30 seconds. PDF output includes a small watermark. The plan also includes 3 forms with 500 form responses per month, and 5 hosted pages. Forms and hosted pages carry the CustomJS logo. Bandwidth is unlimited under a fair usage policy.

## When you hit a limit

The pricing page does not say what happens after the 20th request in a day. Every API response carries rate limit headers that show the limit, the requests used, and the requests remaining. Watch those headers in your automation.

The free plan has no card on file, so it cannot bill you. Paid plans start at $9 per month for 100 requests a day. The fair usage note says CustomJS may throttle or suspend accounts that use more than 100 GB of bandwidth per month or abuse the service.

## Gotchas

- Each JavaScript execution and each PDF rendering counts as 1 request, so a workflow that does both uses 2.
- Free PDFs include a small watermark, and free forms and hosted pages show the CustomJS logo.
- The 30 second request timeout on the free plan is half of the 60 seconds on paid plans.

### Is CustomJS free?

Yes. The Free plan includes 20 requests per day, described as 600 requests per month, with no credit card.

### Does CustomJS need a credit card?

No. The pricing page says no credit card is required for the free plan.

### What happens when I go over the CustomJS free limit?

The pricing page does not say. Check the rate limit headers on each response, and upgrade if you need more than 20 requests a day.
