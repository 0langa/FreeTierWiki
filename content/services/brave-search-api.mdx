The Brave Search API gives developers results from Brave's own web index, the same index behind Brave Search. Apps use it for traditional search features, AI search, and agents that need fresh web data. Brave says every result comes from its own index, with no fallback to Google or Bing.

## What the free plan gives you

Each plan includes $5 in free credits every month. Brave's help page explains the $20 headline: it is $5 on each of four plans, not $20 for Search alone. Search costs $5 per 1,000 requests, so its credit covers about 1,000 searches a month. Results include URLs, text, news, images, extra LLM context, alternate snippets, and Goggles for reranking. Search supports up to 50 queries per second.

The Answers plan costs $4 per 1,000 requests plus $5 per million input and output tokens, with capacity of 2 queries per second. It returns answers grounded on one or more searches with citations, supports streaming, and is OpenAI SDK compatible. The same $5 monthly credit applies, but tokens make each answer cost more than a plain search.

## When you hit a limit

On new prepaid plans, requests use the included credit and any purchased balance, then pause at $0. For free-only use, set the prepay amount to $0 and disable auto-reload. Auto-reload can charge your card whenever the balance crosses its trigger; a monthly reload cap is optional, and leaving it empty allows repeated uncapped reloads. Existing postpaid plans still bill usage beyond their included credit. Set usage limits and check which billing model your key uses before running automated searches.

## Gotchas

- A card is required even for free-only use. Auto-reload and legacy postpaid billing can charge it; prepaid credits alone do not guarantee a spending cap.
- Answers requests use the credit faster than Search requests because tokens are billed on top.
- An agent that retries or searches in a loop can use a month's free credit in minutes, and any prepaid credits after it.

## Questions people ask

### Is the Brave Search API free?

Each plan includes $5 in free credits every month. On the Search plan that is about 1,000 requests.

### Why does Brave ask for a credit card?

To prevent abuse. Free-only signup allows a $0 prepay amount, but the card receives a $0 or $1 authorization hold that Brave says is immediately refunded. Keep auto-reload disabled to avoid automatic purchases.

### How fast can I send requests?

Up to 50 queries per second on Search and 2 queries per second on Answers.
