The Brave Search API gives developers results from Brave's own web index, the same index behind Brave Search. Apps use it for traditional search features, AI search, and agents that need fresh web data. Brave says every result comes from its own index, with no fallback to Google or Bing.

## What the free plan gives you

Each plan on the pricing page includes $5 in free credits every month, applied to your account automatically. The page header says up to $20 in free calls a month, without explaining the gap. The Search plan costs $5 per 1,000 requests, so the credit covers about 1,000 searches a month. It returns complete results with URLs, text, news, and images, extra LLM context, alternate snippets, Goggles for custom reranking and filtering, and capacity of 50 queries per second.

The Answers plan costs $4 per 1,000 requests plus $5 per million input and output tokens, with capacity of 2 queries per second. It returns answers grounded on one or more searches with citations, supports streaming, and is OpenAI SDK compatible. The same $5 monthly credit applies, but tokens make each answer cost more than a plain search.

## When you hit a limit

Brave now bills through prepaid credits, not subscriptions. The FAQ says you are only charged for credits you choose to buy, and the page promises no minimums and no surprise bills. It does not say exactly what happens to requests once the free credit is gone, so plan to load credits before you need them. The rate caps are fixed per plan: 50 queries per second for Search and 2 for Answers.

## Gotchas

- You must add a credit card even to use the free credits. Brave says it asks for the card to prevent abuse, and it charges only for prepaid credits you choose to buy.
- Answers requests use the credit faster than Search requests because tokens are billed on top.
- An agent that retries or searches in a loop can use a month's free credit in minutes, and any prepaid credits after it.

## Questions people ask

### Is the Brave Search API free?

Each plan includes $5 in free credits every month. On the Search plan that is about 1,000 requests.

### Why does Brave ask for a credit card?

To prevent abuse. Brave says it uses prepaid credits, not subscriptions, so you are only charged for credits you choose to buy.

### How fast can I send requests?

Up to 50 queries per second on Search and 2 queries per second on Answers.
