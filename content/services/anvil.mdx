Anvil is a platform for building full-stack web apps with nothing but Python. You drag components onto forms, write browser and server code in Python, store data in Anvil's Data Tables, and Anvil hosts the result. It suits Python developers, data people, and teachers who want a working web app without JavaScript.

## What the free plan gives you

Anvil's Free plan is free forever. It includes 1 developer account, unlimited apps, cloud hosting, and the ability to install any Python library. You also get static file storage and AI in the IDE.

Apps on Free run with light CPU and RAM. Data Tables hold up to 50,000 rows and 100 MB of storage. Background tasks time out after 30 seconds. Free apps show the Anvil banner. The Hobby plan, for one developer, removes the banner and adds scheduled tasks and one custom domain, from $14 a month billed annually. Anvil also offers free Educational Licences for students and educators.

## When you hit a limit

The pricing page does not say what happens when an app reaches 50,000 Data Table rows or 100 MB of Data Table storage, or what users see when the light CPU allowance is busy. Background tasks on Free are cut off at 30 seconds. The Free plan has no billing, so there is no overage charge; larger limits come with Hobby, which allows 150,000 rows and 10 GB of storage.

## Gotchas

- Every Free app shows the Anvil banner, and removing it needs a paid plan.
- Scheduled tasks are not available on Free, so periodic jobs need Hobby or an outside scheduler.
- The 30-second background task timeout rules out long data processing on Free.

## Questions people ask

### Is Anvil free?

Yes. The Free plan is free forever with unlimited apps, cloud hosting, and 50,000 Data Table rows.

### Can I use a custom domain on Anvil's Free plan?

No. Custom domains start on the Hobby plan, which allows one.

### Can I install Python packages on Anvil's Free plan?

Yes. The Free plan lets you install any Python library.
