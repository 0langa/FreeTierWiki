Rendi accepts an FFmpeg command and file inputs over an API. It runs the command and makes the result available to the calling application. That fits small media tasks such as extracting a thumbnail, trimming a clip, or converting a file from a workflow that has no FFmpeg installation.

## What the free plan gives you

The Free plan includes 50 GB of processing per month and 5 GB-month of storage. Each command can run for up to one minute. The account has four vCPUs and accepts up to four commands per minute. These are different limits, so a file can fit the monthly volume and still take too long to process.

The pricing FAQ says processing counts bytes from both the inputs and outputs of a command. Keep that in mind when testing variants of the same clip. The API reference shows how to send input and output names in the command request and get an ID for the job.

## When you hit a limit

Work within the published runtime and rate limits and track the monthly processing allowance as you build a pipeline. The cited pricing and API pages do not specify the exact response for a free account that has exhausted its monthly processing. The pricing page offers extra processing credits to Pro accounts. It says the Free tier has no recurring fee and the verification card is not charged.

## Gotchas

- Set `vcpu_count: 4` and `max_command_run_seconds: 60` explicitly on Free: the general API examples/defaults use eight CPUs and 300 seconds, which exceed Free's limits. Parallel commands share the account's CPU allowance. The processing quota is a volume allowance. Even a short command can use a lot of it if the input and output files are large.
- Rendi lists private storage and presigned URLs as Pro features. Check output access before sending media that needs to stay private.
- Longer commands and result webhooks are paid features. For the Free plan, build around brief jobs and retrieve their results through the API.

## Questions people ask

### Does Rendi require a credit card?

Yes. Rendi says it validates the card through Stripe without charging it. The hosted Free plan has no recurring fee, and each verification card can be used for only one free account.

### Does the processing quota count the output file?

Yes. Rendi's pricing FAQ counts both the input and output bytes.

### Can I run an overnight encoding job on Free?

Each free command has a one-minute runtime limit. Use the plan for short jobs that complete within that window.
