Backendless is a backend platform with a database, user management, real-time messaging, push notifications, file storage, and Cloud Code, plus a visual UI Builder and Codeless logic. You can use it hosted as Backendless Cloud or install Backendless Pro yourself. This entry covers the Backendless Cloud Free Plan.

## What the free plan gives you

Backendless says you can register and start building on the Free Plan with no credit card, and that it is designed for exploring and learning the platform. Every plan has unlimited developer seats, and pricing is per application.

The Free Plan allows 50 API requests per minute, 20 data tables with up to 15,000 data objects in a table, and 1 GB of file storage. It includes 5 real-time connections, 100,000 pub/sub messages, 100,000 push notifications, and 2 email templates. Cloud Code gets 2 scripts with a 5-second execution time and timers every 300 seconds. The Scale Plan starts at $15 per month.

## When you hit a limit

The Free Plan has fixed limits, while the Scale Plans have flexible limits that can be raised with Function Packs. The pricing page does not describe what a request past 50 per minute or a table past 15,000 objects does on the Free Plan, but there is no card on file and no overage pricing for Free. Backendless says the Scale Plans are where you develop, publish, and manage a live app.

## Gotchas

- The limit is 50 API requests per minute rather than a monthly total, so short bursts of traffic hit it first.
- Only 5 real-time connections are allowed, which rules out live features for more than a few users at once.
- The Free Plan has no daily backups.

## Questions people ask

### Is Backendless free?

Yes. Backendless Cloud has a Free Plan with fixed limits and no credit card required, meant for exploring and learning.

### How many API requests does the Backendless Free Plan allow?

50 API requests per minute.

### Can I raise the limits on the Backendless Free Plan?

No. The Free Plan has fixed limits; Function Packs that raise limits apply to the Scale Plans.
