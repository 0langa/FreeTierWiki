SambaCloud gives applications a hosted API for running language models. The documentation now labels every SambaCloud model as Preview, for evaluation and experimentation rather than production. Pick an exact model ID and check its limits before deciding how to spread work across a day.

## What the free plan gives you

The Free tier applies to accounts with no payment method linked. The current documentation lists 20 requests per minute, 20 requests a day, and 200,000 tokens a day for each model in its Free table: gpt-oss-120b and gemma-4-31B-it. Treat these as separate limits. Several short requests can reach the daily request ceiling long before using the tokens, while a smaller number of long requests can have a different profile. The provider publishes model-specific tables, so consult the one for your chosen model instead of extrapolating to every endpoint that appears in the console.

## When you hit a limit

The API returns an error when a rate limit is hit. Read the rate headers and wait for the applicable window before retrying. If the daily request allowance is gone, small prompts will still count as requests. The Developer tier applies when a payment method is linked, with different limits. Review its billing separately before adding a payment method. If you run evaluations, start with the cases that answer the most important question. Save the remaining cases for a later window or choose a model with enough capacity.

## Gotchas

- All SambaCloud models are now Preview and can be removed at short notice. Meta-Llama-3.3-70B-Instruct was removed from cloud service on November 17, 2026; do not assume a named migration replacement is included in Free.
- Limit handling should respect both the request count and tokens remaining.
- Keep the free account without a payment method if you need its documented no-card tier.

## Alternatives in this atlas

## Questions people ask

### Does SambaCloud have a cardless tier?

Yes. The rate-limit policy ties Free to accounts without a payment method.

### How many calls can I make?

Check the model’s row. The current Free table lists gpt-oss-120b and gemma-4-31B-it at 20 requests per day each.

### Will a failed rate check bill me?

The no-card Free tier returns an error when its documented rate limits are reached.
