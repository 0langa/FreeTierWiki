Cloud Vision API analyzes images you send it and returns what it finds: labels, printed text, faces, landmarks, logos, objects, and explicit-content flags. You choose the features for each request. It suits developers who need image tagging or text extraction in an app without training a model.

## What the free plan gives you

Cloud Vision API is part of the Google Cloud Free Tier. Pricing is tiered, and the first 1,000 units used each month are free; the price table lists that free block for every feature, including Label Detection, Text Detection, Document Text Detection, Facial Detection, Web Detection, and Object Localization.

A unit is one feature applied to one image. If you apply Face Detection and Label Detection to the same image, that is one unit of each. For files with several pages, such as PDF files, each page is treated as an individual image. Safe Search detection is free when you also run Label Detection on the image.

## When you hit a limit

Nothing stops your requests after the free units. Units 1,001 to 5,000,000 each month are billed per 1,000 units: $1.50 for Label Detection, Text Detection, Document Text Detection, and Facial Detection, $2.25 for Object Localization, and $3.50 for Web Detection.

Past 5,000,000 units the price drops, for example to $0.60 for Text Detection. The final block of 1,000 units is prorated, so you pay only for the units you use in it.

## Gotchas

- Every feature on an image is billed separately, so asking for three features on one image uses three units.
- Each page of a PDF counts as one image, so OCR on long documents uses the free units quickly.
- Safe Search is free only alongside Label Detection; on its own it is billed like the other features.

## Questions people ask

### Is the Google Cloud Vision API free?

Partly. The first 1,000 units each month are free, and units past that are billed per 1,000 at the feature's price.

### What counts as one unit?

One feature applied to one image. Each page of a PDF counts as a separate image.

### Is Safe Search detection free?

It is free when you run Label Detection on the same image. Otherwise it is billed like the other features.
