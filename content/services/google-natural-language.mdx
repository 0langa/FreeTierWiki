The Natural Language API takes a block of text and returns analysis: entities such as people and places, sentiment, syntax with parts of speech, content categories, and moderation labels for harmful content. You call it from a client library or the REST API. It suits developers who want text analysis features without training or hosting a model.

## What the free plan gives you

The Cloud Natural Language API is part of the Google Cloud Free Tier, which lists 5,000 units per month. The pricing page shows the free units by feature: the first 5,000 units each month are free for entity analysis, sentiment analysis, syntax analysis, and entity sentiment analysis. Content classification is free up to 30,000 units, and text moderation up to 50,000 units.

A unit is 1,000 Unicode characters for most features and 100 characters for text moderation. Whitespace and markup such as HTML tags count as characters. A Google Cloud billing account is required to access the Free Tier.

## When you hit a limit

Nothing stops the API at the free units. Past them, each feature is billed per unit at its own listed price. In the price table, entity sentiment analysis costs twice as much as entity or sentiment analysis, and syntax analysis half as much. Prices drop at 1,000,000 units and again at 5,000,000 units a month.

Requests are rounded up per request. Google's example: three sentiment requests of 800, 1,500, and 600 characters are charged as four units, not three. Prices are computed monthly per feature.

## Gotchas

- An annotateText call that asks for several features is charged as if you requested each one separately.
- Short texts round up to a full unit each, so many tweets or titles use more units than their total length.
- The free units are counted per billing account, not per project.

## Questions people ask

### Is the Google Natural Language API free?

Within limits. Entity, sentiment, and syntax analysis each include 5,000 free units per month, classification 30,000, and moderation 50,000.

### What is a unit?

A unit is 1,000 Unicode characters, or 100 characters for text moderation, rounded up per request.

### Does annotateText cost less than separate calls?

No. An annotateText request is charged as if you had requested each feature separately.
