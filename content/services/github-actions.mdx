You write workflows as YAML files in your repository and watch runs in the Actions tab. GitHub offers workflow templates, and the web interface is enough to start. It suits anyone who keeps code on GitHub.

## What the free plan gives you

Using standard GitHub-hosted runners in public repositories is free. Self-hosted runners are free too. For private repositories, the GitHub Free plan includes 2,000 minutes per month, 500 MB of artifact storage, and 10 GB of Actions cache per repository.

GitHub Pro raises the minutes to 3,000 and the storage to 1 GB. The artifact storage is shared with GitHub Packages, so both together cannot pass the included amount. Cache storage is a separate allowance.

Your minutes reset at the start of each month. Minutes are charged to the repository owner, not to the person who triggered the run.

## When you hit a limit

If your account has no valid payment method, usage is blocked once you use up the quota. Larger runners are blocked until you add a payment method.

With a payment method on file, usage above the quota is billed to your account. Linux minutes cost less than Windows and macOS minutes. A failed run still uses the minutes it ran, and a re-run uses more. Deleting artifacts lowers your current storage, but the storage already accrued in the month stays on the bill.

## Gotchas

- Larger runners are always charged, even in public repositories and even when you have quota left.
- Copilot code review uses Actions minutes on private repositories.
- Anyone with write access can run actions, and the cost goes to the repository owner.

## Questions people ask

### Is GitHub Actions free?

Yes, within limits. Standard runners are free for public repositories. Private repositories on GitHub Free get 2,000 minutes per month.

### What happens when I use up my GitHub Actions minutes?

Without a payment method, usage is blocked once the quota is used up. With one on file, extra usage is billed to your account.

### Does GitHub Actions need a credit card?

Not for the free quota. GitHub blocks usage at the limit unless you add a payment method.
