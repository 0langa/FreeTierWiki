You write workflows as YAML files in your repository and watch runs in the Actions tab. GitHub offers workflow templates, and the web interface is enough to start. It suits anyone who keeps code on GitHub.

## What the free plan gives you

Using standard GitHub-hosted runners in public repositories is free. Self-hosted runners are free too. For private repositories, GitHub Free includes $12 of compute per month, 500 MB of artifact storage, and 10 GB of Actions cache per repository. Compute is shared with cloud sandbox compute and memory. At $0.006 per minute for a standard Linux 2-core runner, $12 covers 2,000 minutes only if nothing else draws from the allowance.

GitHub Pro raises included compute to $18 per month and artifact storage to 1 GB. The artifact storage is shared with GitHub Packages, so both together cannot pass the included amount. Cache storage is separate; raising its repository limit above 10 GB enables paid excess storage.

Included compute resets with the monthly billing cycle. Runner costs are charged to the repository owner, not to the person who triggered the run.

## When you hit a limit

If your account has no valid payment method, usage is blocked once you use up the quota. Larger runners are blocked until you add a payment method.

With a payment method, extra usage is billed unless a configured stop-usage budget blocks it. Windows and macOS cost more than Linux. A failed run still uses the minutes it ran, and a re-run uses more. Deleting artifacts lowers your current storage, but the storage already accrued in the month stays on the bill.

## Gotchas

- Larger runners require a payment method and are billed in public repositories. Where available, eligible larger-runner costs can draw from included compute on GitHub Team and Enterprise Cloud.
- Copilot code review uses Actions compute on private repositories in addition to AI credits.
- Anyone with write access can run actions, and the cost goes to the repository owner.

## Questions people ask

### Is GitHub Actions free?

Yes, within limits. Standard runners are free for public repositories. GitHub Free includes $12 of monthly compute shared with cloud sandboxes, equivalent to 2,000 standard Linux 2-core minutes if used exclusively for that runner.

### What happens when I use up my GitHub Actions compute allowance?

Without a payment method, usage is blocked once the quota is used up. With one on file, extra usage is billed to your account.

### Does GitHub Actions need a credit card?

Not for the free quota. GitHub blocks usage at the limit unless you add a payment method.
