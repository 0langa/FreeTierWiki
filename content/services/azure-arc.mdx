You work in the Azure portal. For servers, you run a generated script on each machine, and the same machines then show up next to your Azure resources.

## What the free plan gives you

The Azure Arc core control plane is free. The pricing page lists three free parts. Inventory lets you tag resources, group them into resource groups, subscriptions, and management groups, and query them at scale with Azure Resource Graph. Manage covers administering servers with SSH Arc, Run Command, and the Custom Script Extension.

VM self-service is the third. It covers create, resize, update, and delete, plus start, stop, and restart for VMware vCenter and System Center Virtual Machine Manager virtual machines. All three show a price of FREE.

## When you hit a limit

The pricing page lists no quota on the core control plane. The cost comes from add-ons. Add-on management services, such as Azure Update Manager, Azure Policy guest configuration, Azure Monitor, Microsoft Defender for Cloud, and Microsoft Sentinel, are charged for Azure Arc-enabled servers when you enable them.

The monthly price of an Arc-enabled server depends on how many management and security services you run on it and on the plan you buy. Check each add-on's pricing page before you switch it on. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## Gotchas

- Add-on services are charged when enabled, so a connected server can start costing money after you turn on monitoring or security.
- Defender for Cloud Plan 2 includes Azure Policy guest configuration and Azure Update Manager at no extra cost, but Plan 1 does not.
- Windows Server licenses with active Software Assurance or an active subscription license can use some features at no additional cost, though log ingestion, compute, and storage may still be charged.

## Questions people ask

### Is Azure Arc free?

The core control plane is free: inventory, management with SSH Arc and Run Command, and VM self-service. Add-on services such as Azure Monitor and Defender for Cloud are billed when you enable them.

### Does Azure Arc need an Azure subscription?

Yes. The docs tell you to create an Azure account if you do not have a subscription before you connect machines.

### Which services cost extra with Azure Arc?

Azure Update Manager, Azure Policy guest configuration, Azure Monitor, Microsoft Defender for Cloud, and Microsoft Sentinel are charged for Arc-enabled servers when you enable them.
