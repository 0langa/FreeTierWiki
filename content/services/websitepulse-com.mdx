You open a tool page, type a URL or address, and read the result. There is nothing to install and no registration for the free tools. They suit site owners and admins who need a quick answer.

## What the free plan gives you

The free tools page lists test tools for websites, DNS services, servers, and networks. The examples include a Website Test, Web Page Test, HTTP Headers Test, PING Test, Traceroute Test, Port Scan Test, WHOIS Test, SPF Lookup Test, and an SLA Uptime Calculator. The Website Test checks server status, downloads the full HTML, and measures DNS lookup, connect, first byte, and total download times.

Each free test allows only 3 location options: New York, Munich, and Melbourne. Subscription accounts feature up to 40 locations.

## When you hit a limit

The pages we read state no usage limit on the free tools, and they do not mention a daily cap. They list no charge for the free tests.

The real limit is what the tools do. They run once when you click Test Now. There is no schedule, no alert, and no history. For continuous testing, each tool page offers a 30-day free trial of website monitoring, which is a separate paid service.

## Gotchas

- Free tests run only on demand and give no alerts or stored history.
- The free tools allow 3 monitoring locations, while paid accounts can use up to 40.
- The 30-day offer on the tool pages is a trial of the paid monitoring service, not an always-free plan.

## Questions people ask

### Are WebSitePulse tools free?

Yes. The test tools are free to use and need no registration. They run on demand from 3 locations.

### Does WebSitePulse offer continuous monitoring for free?

Not permanently. The tool pages offer a 30-day free trial of website monitoring. After the trial, monitoring is a paid service.

### Which locations can I test from?

The free tests offer New York in the United States, Munich in Germany, and Melbourne in Australia. Paid accounts feature up to 40 locations.
