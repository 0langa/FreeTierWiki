You sign up in the dashboard, copy an API key, and call REST or GraphQL endpoints, or use the MCP server from an AI agent. It suits developers who want Amazon listing data without building a scraper or waiting for Amazon's official access.

## What the free plan gives you

The Hobby plan is free forever and gives you 100 requests per month. The pricing page says it has no additional charges. Canopy says it covers real-time data for any of 350 million products, including pricing, Buy Box data, sales and stock estimates, and reviews.

You get the same API key for REST, GraphQL, and MCP. The paid plans add volume. The pay-as-you-go plan includes the same 100 free requests and adds $0.01 per extra request. The Premium plan starts at $99 a month and includes 20K requests.

## When you hit a limit

On the Hobby plan, the pricing page lists no additional charges, so the plan does not turn into a bill by itself. The pricing page does not say exactly what the API returns once you use up the 100 requests.

To get more requests, move to the pay-as-you-go plan or to Premium. Both are billed monthly, and the page says volume discounts apply automatically as you grow. Check the dashboard before you run a large batch.

## Gotchas

- Both API styles need your key in an `API-KEY` header or an `Authorization: Bearer` header. The docs say not to share the key.
- Pay-as-you-go starts billing after the first 100 requests each month. Switching to it turns the free plan into a metered one.
- Canopy covers Amazon data only. The home page describes data from Amazon.com, and the request takes a `domain` parameter; the pages do not list other marketplaces or other shops.

## Questions people ask

### Is Canopy API free?

Yes, within limits. The Hobby plan gives you 100 requests per month, forever, with no additional charges.

### What happens when I go over the Canopy free limit?

The pricing page lists no additional charges on the Hobby plan and does not say how the API responds past 100 requests. Move to pay-as-you-go to get extra requests at $0.01 each.

### Does Canopy have an MCP server for AI agents?

Yes. The pricing page says one API key works for REST, GraphQL, and MCP, and it lists an MCP server and Skills for AI agents.
