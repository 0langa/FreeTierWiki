You call Cloudmersive from code, through an SDK or a plain web request, and you track your usage in an account portal. One account and one API key work for every API in the portfolio. It suits developers who want to try file and data APIs fast.

## What the free plan gives you

The free tier gives you 600 API calls per month, and the sign-up page calls it always free. It has no expiration. One key reaches all the APIs, including document conversion, data validation, virus scanning, language processing, and OCR. Each call to an API uses one API call. Some jobs use several calls behind the scenes. For example, an OCR run on a multi-page PDF can cost more than one call.

Free plans can send only one simultaneous request at a time. Cloudmersive describes the free tier as a way to try the service, with lower availability than the paid plans. Premium plans start at $19.99 per month. Cloudmersive says premium plan APIs have uptime of about 99.99% or better.

## When you hit a limit

The pages do not say what happens after your 600th free call. They say the free tier has limits on the number of API requests per month. You never add a card, so no bill can follow. You can see your current use in the account administration portal.

The queue rule is different. On premium plans, calls that go over the included amount wait in a queue. Free plans instead cap you at one request at a time, so send your requests one after another.

## Gotchas

- The free tier allows one request at a time, so parallel jobs will not work.
- One action can use more than one API call, as with OCR on a multi-page PDF, so 600 calls can run out sooner than you expect.
- The main pricing page now points to business plans and sales contact. The self-serve free key is on the sign-up and FAQ pages.

## Questions people ask

### Is Cloudmersive free?

Yes, there is a free tier with 600 API calls per month and no expiration. It is meant for trying the service.

### Does Cloudmersive need a credit card for the free tier?

The pages we read do not ask for a card on the free sign-up.

### Can I send requests at the same time on the free tier?

No. Free plans are limited to one simultaneous request. Premium plans do not limit concurrent calls.
