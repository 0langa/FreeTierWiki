Use Logo.dev when an app needs to show the logo associated with a brand or company. A small directory might fetch logos beside company names and use a placeholder when one is missing. The provider also has a separate API for requests that need more than an image URL.

## What the free plan gives you

Community includes 500,000 logo CDN requests each month and a separate $5 monthly API allowance. A standard logo display uses the CDN side of the plan. Brand API and MCP requests spend API credits according to the rates on the pricing page. Use the relevant meter when estimating capacity for a project. Personal projects can use the free plan without a link back, according to the pricing FAQ. For commercial projects on Community, add attribution where the logos appear or in another permitted public location. The published plan does not require a card.

## When you hit a limit

The CDN request count has a hard limit. If your app needs a higher number, consider the paid CDN allowances and make sure it can display a fallback in the meantime. The Community plan excludes purchasing more API credits, so budget data calls as well as image delivery. A busy page that loads several logos can use several CDN requests during a single view. Cache artwork only as permitted by the provider and give missing logos a usable fallback.

## Gotchas

- Follow the commercial attribution instructions before you embed logos in a public product.
- Separate the CDN budget from the API balance when forecasting usage.
- An MCP request can draw from the same credit balance as direct API requests.

## Questions people ask

### Do I need a credit card?

The Community plan does not require one.

### Is API usage included in the CDN quota?

Each has its own allowance. Look up the applicable rate if your request uses a data endpoint or MCP.

### Do commercial projects need attribution?

Yes, on the Community plan. The provider publishes placement rules for the credit link.
