You open the site in a browser and the page shows your address at once. Developers can call a text, JSON, or XML endpoint instead of reading the HTML page.

## What the free plan gives you

The service is free, with no account, no ads, and no ad trackers. The home page shows your public IPv4 and IPv6 address, which can be one or both. For each address it shows the country, the ISP name, the ASN, and whether the connection is primary or a fallback.

Below that, a privacy section compares signals your browser sends with your IP location. It checks language, time zone, the browser and operating system from the HTTP header and from JavaScript, and the HTTP version. This helps when a site shows the wrong country or a CAPTCHA.

The site also has a Ping Test page, a FAQ with over 100 short answers about IP addresses, and a Tools page. The Tools page lists three endpoints for scripts and CLI tools: text, JSON, and XML.

## When you hit a limit

The site publishes no price, quota, or rate limit, so there is no stated point where you are billed or blocked. It also gives no uptime promise.

One rule does apply. The service says automated requests to the web page get an Automated Access Notice page instead of your IP. It tells scripts to use the official tools, the text, JSON, and XML endpoints, and not to crawl HTML pages. If you still see the notice from the official tools, the site asks you to contact it.

## Gotchas

- Do not scrape the home page. A script that requests it gets a notice page, not your address.
- Behind a VPN, proxy, or shared network, the page shows the address of that network, not your own machine.
- The pages state no rate limit for the endpoints, so cache the result in any script that runs often.

## Questions people ask

### Is WhatIsMyIP.HELP free?

Yes. It needs no account, shows no ads, and uses no ad trackers.

### Can I get my IP address in a script?

Yes. Use the text, JSON, or XML endpoint listed on the Tools page. The site asks scripts not to crawl the HTML page.

### Does WhatIsMyIP.HELP show IPv6?

Yes. It shows your IPv4 and IPv6 addresses, and says when an IPv6 address is not available.
