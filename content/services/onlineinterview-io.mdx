You use it entirely in the browser: you create a room, share its link, and everyone joins from that page. It suits recruiters and engineers who run coding interviews.

## What the free plan gives you

The site calls itself a free remote tech interview platform. You create a free virtual room with one click and start a coding session with several users at the same time. Each room has an embedded video chat, a code editor that shows what each person types, and a canvas drawing tab.

You can run the code in the editor to see the output. All participants see the same code, the same data, and the same drawings. The site shows no paid plan, no usage limits, and no sign-up step.

## When you hit a limit

The site does not say. It lists no limits, no quotas, and no paid tier, so nothing here can trigger a charge. The About page says the site is built by a solo developer who intends to keep it free. There is no support plan to rely on, and the site does not describe what happens if a room is overloaded or a session runs long. Open a test room with your co-interviewers before a real interview, and keep a backup video link ready.

## Gotchas

- The site does not publish room size, session length, or recording rules, so test with your own group before the interview.
- It is a one-person project, and the About page gives only an email address and a social account for contact.
- The pages describe the editor and video features but do not list supported programming languages.

## Questions people ask

### Is OnlineInterview.io free?

Yes. The site advertises free rooms and shows no paid plan. The About page says the owner intends to keep it free.

### Does OnlineInterview.io need an account?

The site shows no sign-up step. You choose Create Free Room, copy the page URL, and send it to the other participants.

### Can I run code in OnlineInterview.io?

Yes. The How It Works page says you can run the code in the shared editor to see the output. Everyone in the room sees the same code.
