You create and manage the server in the Azure portal, then connect with any MySQL client or driver. It suits developers who are new to Azure and want a managed MySQL server to learn or test on.

## What the free plan gives you

The MySQL pricing page says you can use Azure Database for MySQL Flexible Server with limited resources for testing and development for 12 months as a first time user. The Azure account page lists the amount: 750 hours of a Flexible Server Burstable B1MS instance, 32 GB of storage, and 32 GB of backup storage each month, for 12 months, for new customers only.

You get this through a pay-as-you-go account or the Azure free account. The free account adds a $200 credit to use within 30 days. Azure says the card is not charged on the free account, though a temporary $1 authorization may appear during sign-up.

## When you hit a limit

The free amount is a monthly allowance, not a hard cap. Hours, storage, and backup storage above it are billed at pay-as-you-go rates, and the same applies once the 12 months end. One B1MS server running all month fits inside the 750 hours.

The Azure portal's default server settings are Burstable, Standard_B1ms, 10 GiB of storage, 100 IOPS, and 7 days of backup retention. Changing the size or adding servers can move you outside the free amount, so check the cost summary before you create.

## Gotchas

- The 12-month free amount is only for new Azure customers.
- A stopped server still bills for storage, since you pay only for storage while the database is stopped.
- A second server, or a size other than B1MS, falls outside the free amount and is billed.

## Questions people ask

### Is Azure Database for MySQL free?

It is free for new Azure customers for 12 months, within 750 hours of a B1MS Burstable instance, 32 GB of storage, and 32 GB of backup storage each month.

### What happens after the 12 months?

Standard pay-as-you-go prices apply to the server, as they do for any usage above the monthly free amounts during the 12 months.

### Does the Azure MySQL free tier need a credit card?

Yes. Azure sign-up asks for card verification, and a temporary $1 authorization may appear on the card, which is reversed after verification.
