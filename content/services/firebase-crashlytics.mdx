Crashlytics is the crash reporter in Firebase. You add its SDK to an Apple, Android, Flutter, or Unity app, and crashes from your users' devices show up in the Firebase console, grouped into issues. It suits app developers who want to know which crashes hurt the most users without paying for a monitoring service.

## What the free plan gives you

The Firebase pricing page lists Crashlytics for mobile apps as no-cost. It costs nothing on the no-cost Spark plan and on the pay-as-you-go Blaze plan, and the page lists no usage limits for it. Web apps are marked not applicable on Spark.

Google describes Crashlytics as a lightweight, realtime crash reporter. It groups crashes intelligently and highlights the circumstances that led up to them. You can see whether a crash affects many users, get alerts when an issue suddenly increases in severity, and find which lines of code are causing crashes. You do not need a billing account for a mobile app.

## When you hit a limit

The pricing page shows no paid tier and no usage cap for mobile apps, so there is no bill to reach. Collection depends on SDK configuration and connectivity; the public product page does not promise indefinite delivery or publish a universal ingestion allowance.

Web apps are different. They need Blaze, and the product page says they use Google Cloud pricing; the pricing table lists Cloud Logging and Cloud Storage rates. Costs can also come from other Firebase products you pair it with. For example, if you use Cloud Functions to react to new issues, Cloud Functions is billed on the Blaze plan. AI assistance in Crashlytics is part of Gemini in Firebase and listed separately on the pricing page.

## Gotchas

- Crashlytics for web needs the Blaze plan and bills through Google Cloud, so the no-cost mobile terms do not carry over.
- Crashlytics groups events that share a failure point into one issue, so check the events inside an issue before assuming it is a single bug.
- Readable reports depend on your build's mapping information, such as dSYM files for Apple apps.

## Questions people ask

### Is Firebase Crashlytics free?

For mobile apps, yes. The Firebase pricing page lists mobile apps as no-cost on both the Spark and Blaze plans. Web apps need Blaze and use Google Cloud pricing.

### Which platforms does Crashlytics support?

The docs list Apple platforms, Android, Flutter, and Unity. The product page also lists web apps.

### Do I need a credit card for Crashlytics?

Not for a mobile app, because Crashlytics for mobile apps works on the no-cost Spark plan. Web apps need Blaze, which needs a billing account.
