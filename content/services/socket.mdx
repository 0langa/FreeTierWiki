You mostly use Socket through its GitHub app, which comments on pull requests, or through the Socket CLI and the VS Code extension. The dashboard shows alerts and policies. It suits maintainers and small teams that add dependencies often.

## What the free plan gives you

The Free plan costs $0 and includes 1 developer seat, unlimited dashboard users, unlimited public and private repositories, 1,000 scans per month, and 500 API requests per hour. You get 1 repository label and 1 API token. The plan detects 70+ risk types, including malware, vulnerabilities, and license issues. It blocks malicious dependencies automatically and adds AI analysis that flags hidden dependency behavior.

The comparison table also lists unlimited public and private repositories, a GitHub integration, an MCP server, 10,000 dependencies, and 14 days of scan retention for Free.

## When you hit a limit

Socket's API quota documentation says requests return HTTP 429 when the token's hourly quota is exhausted. The Retry-After header tells your client how long to wait. This is separate from the 1,000 monthly scans; the reviewed pages do not describe that cap's enforcement or publish a Free overage price. The Team plan includes 5,000 monthly scans and a minimum of 5 developer seats, but its headline and comparison table disagree on API quota. Confirm paid quotas before upgrading.

## Gotchas

- Reachability analysis, which cuts false positives, starts on the Team plan. Slack alerts also start there.
- Developer seats and dashboard users are different. Only active committers who trigger scans consume developer seats; inviting someone to read alerts or triage findings is free.
- Socket watches package manifest files such as package.json. It focuses on what a package does, such as install scripts, telemetry, and obfuscated code.

## Questions people ask

### Is Socket free?

Yes. Free includes 1 developer seat, unlimited dashboard users and repositories, 1,000 scans per month, and 500 API requests per hour.

### What does Socket check in a pull request?

Socket watches manifest files and analyzes newly added packages. It comments if a package shows risks such as typosquats, install scripts, telemetry, native code, or known malware.

### Does Socket need a credit card?

The reviewed pricing and billing documentation do not explicitly confirm whether Free requires a payment card. That requirement remains unconfirmed.
