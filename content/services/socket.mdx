You mostly use Socket through its GitHub app, which comments on pull requests, or through the Socket CLI and the VS Code extension. The dashboard shows alerts and policies. It suits maintainers and small teams that add dependencies often.

## What the free plan gives you

The Free plan costs $0 per month, per developer. It lists unlimited developers and repositories, 1,000 scans per month, and 500 API requests per hour. You get 3 members and 1 repository label. The plan detects 70+ risk types, including malware, vulnerabilities, and license issues. It blocks malicious dependencies automatically and adds AI analysis that flags hidden dependency behavior.

The comparison table also lists unlimited public and private repositories, a GitHub integration, an MCP server, 10,000 dependencies, and 14 days of scan retention for Free.

## When you hit a limit

The pricing page does not say what happens when you use all 1,000 scans or all 500 requests in an hour. The limits reset on a monthly and an hourly basis. The Free plan shows no card and no overage price, so the page shows no way to get billed by accident. The Team plan costs $25 per developer per month, with a minimum of 5 developers. It raises the limits to 5,000 scans per month and 2,500 API requests per hour.

## Gotchas

- Reachability analysis, which cuts false positives, starts on the Team plan. Slack alerts also start there.
- The plan card says 3 members for Free, while a cell in the comparison table says 5 members. Check your dashboard.
- Socket watches package manifest files such as package.json. It focuses on what a package does, such as install scripts, telemetry, and obfuscated code.

## Questions people ask

### Is Socket free?

Yes. The Free plan has unlimited developers and repositories, 1,000 scans per month, and 500 API requests per hour.

### What does Socket check in a pull request?

Socket watches manifest files and analyzes newly added packages. It comments if a package shows risks such as typosquats, install scripts, telemetry, native code, or known malware.

### Does Socket need a credit card?

The pricing page shows a Get started button for the Free plan and no card step.
