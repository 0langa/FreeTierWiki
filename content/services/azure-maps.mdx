You create the account in the Azure portal, then call the REST APIs with an account key, as the quickstart does. It suits developers who build map, search, and routing features, especially on Azure.

## What the free plan gives you

Azure Maps now has one pricing tier, Gen2, and each meter has its own free monthly amount. The pricing page lists 5,000 free transactions each for Base Map Tiles, Traffic Tiles, Geolocation, Search, Spatial Calculations, and Time Zone. It lists 1,000 free transactions each for Imagery Tiles, Weather Tiles, Static Map Images, Routing, Traffic, and Weather.

A transaction is not always one request. For map tiles, 15 tiles count as one transaction, so 5,000 Base Map Tile transactions cover up to 75,000 tiles. For Search, every 10 autocomplete requests count as one transaction.

## When you hit a limit

The pricing page does not describe a hard stop. It says Azure Maps uses consumption-based pricing and that billing is calculated monthly, so usage above a free amount becomes billable. The page lists no per-transaction prices in its table, and it points to the pricing calculator.

The pricing page says volume discounts begin at 100,000 transactions per month and that you should contact sales for details. Each meter is billed on its own, so one busy service can bill while the others stay free. Watch the Metrics report in the Azure portal.

## Gotchas

- The Gen1 tier, including the old S0 free amounts, retired on September 15, 2026. Old accounts were converted to Gen2 automatically.
- Batch calls and matrix calls use up transactions faster. Each query in a batch search counts as a Search transaction, and every 4 cells of a route matrix count as one Routing transaction.
- You need an Azure subscription to create the account.

## Questions people ask

### Is Azure Maps free?

Partly. Every meter has a free monthly amount, such as 5,000 transactions for Search and 1,000 for Routing. Usage above that amount is billed.

### What happens when I go over the Azure Maps free limit?

The pricing page does not describe a hard stop. It describes consumption-based pricing, so extra transactions are billable. Check your usage in the Azure portal metrics.

### Does Azure Maps need a credit card?

Yes. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.
