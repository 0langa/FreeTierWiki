restdb.io is a hosted NoSQL database that gives every database an instant REST API. It includes a data editor, collaborators, hosted web pages, and server code through Codehooks and jobs. It suits developers who want a backend for a prototype or a small app without running a database.

## What the free plan gives you

restdb.io accounts are free, and prices are per database. The Development plan is free and needs no credit card. A free database allows 3 developers, editors, or users and up to two thousand five hundred records, shown as 2.500 on the pricing page.

API use is capped at 1 call per second and 500 calls per day. You get 100 MB of media storage with a 1 MB maximum file size, hosted web pages with 1 limited custom secure domain, and Codehooks and jobs for server code. Support is limited. The Standard plan costs $19 per month billed yearly, or $29 monthly, and allows 10 API calls per second.

## When you hit a limit

The pricing page states the free API limits as maximums, 1 call per second and 500 a day, but does not say what a client sees when it passes them, or what happens when the record count is full. The free plan needs no credit card, so there is no overage bill; more capacity means moving that database to a paid plan.

## Gotchas

- The free plan has no automatic backup; you take manual snapshots yourself.
- The 1 MB file size limit rules out larger images, videos, and documents.
- Pricing is per database, so each additional paid database has its own plan.

## Questions people ask

### Is restdb.io free?

Yes. The Development plan is free with no credit card, and accounts are free.

### How many API calls does the restdb.io free plan allow?

A maximum of 1 API call per second and 500 per day.

### Does restdb.io back up free databases?

No. The free plan has no automatic backup, only manual snapshots.
