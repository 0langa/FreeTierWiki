Bleemeo is a hosted monitoring service for servers, containers, and cloud resources. You install its open source agent, Glouton, which discovers the services on each machine and sends metrics to dashboards with default alert thresholds. It suits developers who want server monitoring without running Prometheus and Grafana themselves.

## What the free plan gives you

The Free plan costs 0 € per month and is meant for personal projects and experiments. It covers up to 3 servers, with 60s resolution, 1 day of data retention, and basic dashboards.

A server is any machine running the monitoring agent: a physical server, a virtual machine, or a cloud instance. The FAQ says users, dashboards, alerts, and API access are never billed. The agent natively scrapes Prometheus exporters, and Bleemeo exposes a PromQL-compatible API that Grafana can query. Metrics and logs are stored in the EU, in the Paris region.

## When you hit a limit

The pricing page does not say what happens if you install the agent on a fourth server while on the Free plan. The limits are plan limits rather than metered usage, so moving past them means choosing Starter or Professional, which are priced per server per month and billed hourly. A 1 day retention window means older data is simply gone on the Free plan.

## Gotchas

- 1 day of retention makes the Free plan useless for comparing this week with last week.
- SMS alerts are listed on the paid plans, not on Free.
- Logs are pay-as-you-go on paid plans, so turning on log collection later adds cost.
