Bleemeo is a hosted monitoring service for servers, containers, and cloud resources. You install its open source agent, Glouton, which discovers the services on each machine and sends metrics to dashboards with default alert thresholds. It suits developers who want server monitoring without running Prometheus and Grafana themselves.

## What the free plan gives you

The Free plan costs 0 € per month and is meant for personal projects and experiments. It covers up to 3 servers, with 60s resolution, 1 day of metric retention, and 100 metrics per server. It also includes uptime monitoring with 5 monitors checked every 5 min, real-time and custom dashboards, and email, push, and webhook alerts.

Every signup starts with a 15-day free trial with no card, then moves to Free unless you added a payment method.

A server is any machine running the monitoring agent: a physical server, a virtual machine, or a cloud instance. The FAQ says users, dashboards, alerts, and API access are never billed. The agent natively scrapes Prometheus exporters, and Bleemeo exposes a PromQL-compatible API that Grafana can query. Metrics and logs are stored in the EU, in the Paris region.

## When you hit a limit

The pricing page does not say what happens if you install the agent on a fourth server while on the Free plan. Free quota enforcement is not described. Starter and Professional are billed hourly per server, and adding a payment method during the trial moves the account to paid Professional when it ends. A 1 day retention window means older data is simply gone on the Free plan.

## Gotchas

- 1 day of metric retention makes the Free plan useless for comparing this week with last week.
- SMS alerts are listed on the paid plans, not on Free.
- If you add a payment method during the 15-day trial, the account moves to the paid Professional plan instead of Free when the trial ends.
