Google Maps Platform covers Google's Maps, Routes, and Places products: interactive maps, geocoding, directions, place search, and more. Pricing is pay-as-you-go per SKU, and each core SKU comes with a monthly free amount. It suits developers who want Google's map data and place details in a web or mobile app.

## What the free plan gives you

Google sorts SKUs into Essentials, Pro, and Enterprise categories, and each includes free billable events every month. Essentials SKUs get 10K free calls per SKU monthly, Pro SKUs get 5K, and Enterprise SKUs get 1K. In the global price list, Dynamic Maps, Geocoding, and Compute Routes Essentials each have a free usage cap of 10,000 events. Some SKUs, such as Embed and the Maps SDK, are listed as unlimited at no cost. Free usage resets on the first day of each month at midnight Pacific time. To prototype without billing information, a Maps Demo Key gives no-cost access to select Maps JavaScript API and Places UI Kit features.

## When you hit a limit

With a standard API key, usage past a SKU's free cap is billed per 1,000 events at tiered rates. Dynamic Maps costs $7.00 per 1,000 loads in the first paid tier, and Geocoding costs $5.00 per 1,000 requests. Google aggregates use across all projects linked to the billing account. You can set budget alerts and usage quotas in the Google Cloud console to control spend. A Maps Demo Key behaves differently: if you reach its daily limit, usage is paused until the following day with no risk of charges.

## Gotchas

- Setting up a Cloud project requires a billing account, even for no-charge products like the Embed API.
- The free caps are per SKU, so one feature can use different SKUs; check which one your request bills.
- The Maps Demo Key is for testing only and supports a limited set of features.

## Questions people ask

### Is Google Maps Platform free?

Within limits. Each core SKU includes free monthly calls, such as 10,000 Dynamic Maps loads, and usage past that is billed.

### Can I try Google Maps without a credit card?

Yes, with a Maps Demo Key. Google says it lets you prototype select features without entering billing information.

### Does the free usage reset every month?

Yes. Free usage resets on the first day of each month at midnight Pacific US time.
