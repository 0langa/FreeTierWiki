You use FreePO in the browser. You drop in a PO file, translate the entries, and download the result. It suits translators and maintainers who work with gettext files.

## What the free plan gives you

FreePO editor has no plans. The site describes it as a simple online tool that helps translators edit PO files, at no cost. The editor page says you drop your PO file, translate it to the target language, and download the updated file.

A PO file is a text file with the translations for one language. GNU gettext is the set of tools that extracts messages into a template file, lets translators fill in the PO files, and compiles the result for the app. The site says specialized editors reduce errors, give suggestions, and run validation. FreePO is its own editor for that job.

The pages list no limits on file size, number of files, or use. They also show no sign-up step and no paid tier.

## When you hit a limit

The pricing page does not say. The site shows no price, no quota, and no paid plan, so no bill is possible from what the pages show. The pages also do not say how large a file can be.

The site does not describe any storage. Download your updated PO file when you finish, because nothing on the pages promises that the editor keeps it for you.

## Gotchas

- The pages do not say whether your file stays in the browser or goes to a server. Read the Privacy Policy before you upload private text.
- The editor handles PO files only. A project with JSON, XLIFF, or other formats needs another tool.
- The site shows no accounts, teams, or shared projects, so each translator works on a downloaded copy.

## Questions people ask

### Is FreePO editor free?

Yes. The site calls it a free editor for PO files, at no cost. The pages show no paid plan.

### Do I need an account to use FreePO editor?

The editor page does not show a sign-up step. You drop a PO file on the page, translate it, and download the file.

### What is a PO file?

A PO file is a text file that holds the translations of an app for one language. It comes from GNU gettext, a set of internationalization tools.
