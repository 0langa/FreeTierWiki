You work from the Terramate CLI inside a Git repository, and your existing CI runs the commands. Terramate Cloud is an optional dashboard that adds previews, drift, and asset views.

## What the free plan gives you

The Terramate CLI is open source and runs on your own machine or in your own CI. The GitHub README says it needs no access to your state or cloud accounts. It supports Terraform, OpenTofu, and Terragrunt.

Terramate Cloud has a Community plan that is free forever. It allows up to 2 users and up to 1000 resources, with 30 days of data retention. It includes deployment workflows, pull request previews, and drift management. Support is through Discord.

The Teams plan costs $449 per month and has a 14 day free trial. It raises the limits to unlimited users, up to 5000 resources, and 90 days of data retention, and it adds asset management and a 24 hour support response.

## When you hit a limit

The pricing page lists the Community limits but does not say what happens if you pass 2 users or 1000 resources. Resources are the things Terramate Cloud manages and observes.

The limits belong to Terramate Cloud. The CLI is open source and runs in your own CI. Community is listed as free forever, so nothing is billed. If you outgrow it, the Teams plan is the next step. The FAQ says additional seats are not sold for Teams, so larger teams are pointed to a custom Enterprise offer from sales.

## Gotchas

- Terramate is not a CI/CD platform. You still need GitHub Actions, GitLab CI/CD, Bitbucket Pipelines, or similar to run the workflows.
- Change detection works by comparing Git commits. The quickstart tells you to make an empty first commit so there is something to compare.
- The CLI signs in to Terramate Cloud with Google by default. Use the github option for GitHub. Microsoft Entra ID is not supported in the CLI yet.

## Questions people ask

### Is Terramate free?

Yes. The CLI is open source, and the Terramate Cloud Community plan is free forever for up to 2 users and 1000 resources.

### Does Terramate need a credit card?

The pricing page lists the Community plan as free forever and does not ask for payment. The Teams plan has a 14 day free trial.

### Which tools does Terramate work with?

Terraform, OpenTofu, and Terragrunt. Terramate is not a CI/CD platform, so it works with GitHub Actions, GitLab CI/CD, and Bitbucket Pipelines.
