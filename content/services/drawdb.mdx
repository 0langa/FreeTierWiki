You use drawDB in the browser editor, or you run it yourself from the open-source code. It suits people who want a quick schema diagram without creating an account.

## What the free plan gives you

The free editor costs nothing and needs no account. You get unlimited local diagrams, templates, and support for MySQL, PostgreSQL, SQLite, MariaDB, SQL Server, Oracle, and a generic dialect. You can import a DDL script to build a diagram, and export to SQL, DBML, JSON, or an image.

The home page says drawDB is, and stays, free and open source. Diagrams live in your browser storage (IndexedDB). They are not synced anywhere. You can also run drawDB yourself: clone the GitHub repository and start it with Docker Compose.

## When you hit a limit

The free editor has no usage cap on the pricing page, so there is no bill to run up. The limit is where your data lives. If you clear your browser data, your diagrams go with it, so export them first.

Pro plans add cloud storage and sync, version history, public sharing, a GitHub integration, an AI assistant, an MCP server, and priority support. Team Pro adds live collaboration, diagram permissions, and team management. Both Pro plans offer a 7-day trial with no card needed.

## Gotchas

- Free diagrams are stored only in your browser, so back them up before clearing browser data.
- Cloud sync, public sharing, and version history need a Pro plan.
- Live collaboration is on Team Pro only.

## Questions people ask

### Is drawDB free?

Yes. drawDB is free and open source, and the full editor runs in your browser with no account.

### Where does drawDB save my diagrams?

In the free editor, diagrams are stored locally in your browser. Back them up before you clear browser data. Pro syncs diagrams to the cloud.

### Do I need an account to use drawDB?

No. Open the editor and start drawing. You only sign in for Pro features such as cloud sync, sharing, and team collaboration.
