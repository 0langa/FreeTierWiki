You use Fizzy in the browser: sign in with your email, make a board, and add cards. A webhook feature and an API connect it to other tools, and the source code is public if you want to run your own copy.

## What the free plan gives you

Fizzy is free for everyone. 37signals says the two paid products, Basecamp and HEY, cover the cost, so there is no paid Fizzy plan. The one stated limit is file space: 1 GB.

Boards hold cards for bugs, issues, ideas, and small projects. Auto close prunes old cards for you. You can make a board public so anyone can follow it. Webhooks send events such as a new, assigned, or completed card to Slack, Campfire, or any tool that accepts webhooks. An API is available for custom integrations.

## When you hit a limit

The pricing page does not say what happens when you reach the 1 GB of file space. It calls the space plenty for almost anyone, and there is no price to pay for more, because no paid tier exists. The pricing page lists no paid plan, so there is nothing to upgrade to. If file space is a real problem, you can host your own copy, because the code is open source.

## Gotchas

- There is no paid plan, so you cannot buy more file space or priority support from 37signals.
- The pricing page says the product can import data from other services, but the answer on the page is not clear, so check before you plan a migration.
- Self-hosting is possible with the ONCE installer, a Docker image, or Kamal, but then you run and update the server yourself.

## Questions people ask

### Is Fizzy really free?

Yes. 37signals says Fizzy is entirely free and that Basecamp and HEY, its paid products, cover the cost. The only stated limit is 1 GB of file space.

### Does Fizzy need a credit card?

The pricing page does not mention a card and lists no paid plan. The sign-in page asks for your email address.

### Can I host Fizzy myself?

Yes. The source code is public on GitHub. The README names three ways to run it: the ONCE installer, a pre-built Docker image, or Kamal.
