You create the service in the Azure portal, copy its connection string, and connect your app with the SignalR SDK. It has native support for ASP.NET Core and ASP.NET, and any client library that speaks the SignalR protocol can connect.

## What the free plan gives you

SignalR Service has three tiers: Free, Standard, and Premium. The Free tier includes 20 concurrent connections and 20,000 messages per unit per day. It costs nothing per unit per day and is limited to 1 unit.

The quickstart labels the tier Free (Dev/Test Only). The pricing page lists the SLA for Free as N/A, while Standard has 99.9% and Premium has 99.95%. Custom domain names, geo-replication, and auto scaling are Premium features, so you do not get them on Free.

## When you hit a limit

The pricing page does not say what happens when you pass 20 concurrent connections or 20,000 messages in a day. The Free tier has only one unit, so you cannot add capacity there.

The paid tiers work differently. Standard and Premium give 1,000 concurrent connections per unit, and their messages are unlimited. The first 1,000,000 messages are free, and you can buy additional messages per million. To get more capacity, you create a Standard or Premium instance. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## Gotchas

- Tutorials use the Free tier unless they say otherwise, so a quickstart instance is a Dev/Test instance.
- Treat the connection string like a root password. The docs say to keep access keys out of code and plain text, for example by using Azure Key Vault.
- The Free tier supports 1 unit at most, so it has no way to scale out.

## Questions people ask

### Is Azure SignalR Service free?

There is a Free tier with 20 concurrent connections and 20,000 messages per unit per day. It is limited to 1 unit and is marked Dev/Test Only.

### Does Azure SignalR Service need an Azure account?

Yes. You create the resource in an Azure subscription. The quickstart tells you to create a free Azure account first if you do not have one.

### What is the difference between Free and Standard SignalR?

Standard allows 1,000 concurrent connections per unit, up to 100 units, and has a 99.9% SLA. Free allows 20 connections, 1 unit, and has no SLA.
