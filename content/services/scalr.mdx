You manage Scalr in a web console and through the Terraform or OpenTofu CLI. Your code stays in your own repository and the runs execute in Scalr.

## What the free plan gives you

Scalr prices by runs, not by users or resources. A run is either an apply or a dry run, which is the same as a plan. The Free plan covers up to 50 runs per month. There are no charges for users, workspaces, resources under management, private agents, or SAML.

The Free and Business plans are the same product. The only difference is volume. Both start with five concurrent runs by default, and Scalr raises that for free if you ask with a valid use case. Self-hosted agents add five more concurrent runs each.

Everything else is the same on both plans, including role-based access control, SAML 2.0 single sign-on, drift detection, policy enforcement, and the module and provider registries.

## When you hit a limit

The pricing pages do not say what a Free account sees after run 50. Business is usage-based at $0.99 per run, and 100 runs cost $99 per month. The billing FAQ says customers are never blocked from running. Runs past a prepaid amount are billed at the same $0.99 rate at the end of the period.

Some runs do not count. These include drift detection runs, local execution runs, and runs that fail early, for example during init. You can also cut run counts by skipping dry runs on pull requests, or by adding a skip tag to a commit message.

## Gotchas

- Plans on pull requests count as runs. A busy repository can use 50 runs quickly if every push triggers a plan.
- Runs do not roll over. Unused runs in a period are lost.
- The Scalr backend gives the full feature set. A different backend, such as S3, limits some features and removes Terraform CLI runs from Scalr.

## Questions people ask

### Is Scalr free?

Yes, up to 50 runs per month. There are no charges for users, workspaces, resources, private agents, or SAML.

### What counts as a run in Scalr?

A run is an apply or a dry run, which is a plan. Drift detection runs, local execution runs, and several kinds of failed runs are not billed.

### How much does Scalr cost after the free runs?

The Business plan is $0.99 per run, with volume discounts. For example, 100 runs cost $99 per month.
