You use the Mistral API from the Studio console, where you create an API key, then call it with curl, an SDK, or the playground. It suits developers who want to try Mistral's models, document OCR, and speech models before they pay.

## What the free plan gives you

The Free plan includes access to Mistral Studio. In Free mode, API access is on by default and no credit card is needed. The tier docs say Free mode lets you create API keys and use included monthly usage within the limits shown on the Limits page. The pricing page does not state a dollar amount for that usage.

Rate limits are listed per model in the Admin Panel under API and Limits. Completion limits cover tokens per minute and requests per second. Audio limits can include audio seconds per minute and per month, and OCR limits can include pages per minute. The Free plan also gives limited access to Vibe, with limited messages, web searches, and coding sessions.

## When you hit a limit

The docs say pay-as-you-go lets you extend usage beyond your included monthly usage, and that it is not a separate plan for the API. You turn it on in the billing settings, and an Organization spending limit caps API and Vibe consumption. The pages do not say exactly what the API returns when a Free key passes its included usage. To get higher rate limits, contact support with the models, the requests per second, and the tokens per minute you need. The Pro plan costs $14.99 per month and has higher limits for Vibe.

## Gotchas

- The full API key shows only once when you create it, so copy it right away.
- Free mode limits are low, and the exact numbers appear only inside your Admin Panel.
- Pay-as-you-go extends usage past the included amount, so leave it off if you want to stay within Free mode.

## Questions people ask

### Is the Mistral API free?

Yes, in Free mode. API access is on by default with no credit card, with included monthly usage and low rate limits.

### Does the Mistral API need a credit card?

No. The quickstart says Free mode needs no credit card. Payment methods are managed in the Billing page.

### Where do I find my Mistral API rate limits?

In the Admin Panel under API and Limits. They are listed per model.
