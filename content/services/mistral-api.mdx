You use the Mistral API from the Studio console, where you create an API key, then call it with curl, an SDK, or the playground. It suits developers who want Mistral's models, document OCR, and speech models and are ready to turn on billing.

## What the free plan gives you

The Free plan includes limited access to Vibe and access to Mistral Studio. The usage docs say Free mode includes a monthly usage budget for trying Vibe and Studio and does not include API access. Creating API keys and using the API require billing activation and pay-as-you-go. The quickstart points you to billing setup to add a payment method. The pricing page states no dollar amount for Free usage.

Included monthly usage is shared across Studio, the API, and Vibe Code, and is consumed first. Once API access is active, rate limits are listed per model in the Admin Panel under API and Limits. The API rate-limit help article still describes Free mode as having the lowest API limits, so plan on the stricter reading in the usage docs.

## When you hit a limit

The official help article says request, token-throughput, and monthly token limits return HTTP 429 when exceeded. Without pay-as-you-go, included usage can stop until the next billing period or until an admin changes the settings.

Paid continuation requires pay-as-you-go enabled and positive prepaid credits. Exhausted paid credits return HTTP 402, but processing delays can leave a small negative balance payable on the next invoice. Optional automatic recharge buys credits from a payment method. Organization spending limits can suspend access; they do not eliminate delayed accounting. Pro costs $14.99 monthly and raises Vibe limits.

## Gotchas

- The usage docs say Free mode alone does not include API access, so plan on adding a payment method before you can create a key.
- The full API key shows only once when you create it, so copy it right away.
- Leave automatic recharge off if you want spending to stop at your prepaid balance; a small overage can still reach the next invoice.

## Questions people ask

### Is the Mistral API free?

Not on its own. The Free plan covers limited Vibe and Studio use, and the usage docs say API access requires billing activation and pay-as-you-go.

### Does the Mistral API need a credit card?

Yes, in practice. The docs say to add a payment method to activate API access beyond Free mode. Pay-as-you-go is prepaid, and credits can also come from a gift code.

### Where do I find my Mistral API rate limits?

In the Admin Panel under API and Limits. They are listed per model.
