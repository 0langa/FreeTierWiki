You write the UI in Java on top of a Spring Boot and Maven project, and Vaadin renders it in the browser. It suits Java developers who build internal tools and business apps.

## What the free plan gives you

The Free plan is free forever. The framework is open source under the Apache 2.0 license, and the pricing page says it is free for commercial use. It includes the Vaadin Framework and all of the open-source UI components, more than 50 in total, such as Grid, Tree Grid, Combo Box, Date Picker, Tabs, Dialog, and Upload.

Free also lists full access to Vaadin Copilot, Figma libraries, browserless UI testing, and the Collaboration Kit. You get docs, community help, cookbooks, tutorials, and a directory of more than 2,000 add-ons. Support is through the Vaadin forum.

## When you hit a limit

The Free plan has no usage meter, so nothing runs out. The pricing page lists no quota, no trial clock, and no overage for the open-source parts.

The limit is in features and support. Commercial UI components, including Charts, Dashboard, Map, CRUD, and Grid Pro, need the Pro plan, as does TestBench for automated browser tests. Pro costs $159 per developer per month and has a 30-day free trial with no credit card.

## Gotchas

- Free and Pro versions get fixes for 3 months after release. Only the Enterprise Edition lists 15 years of maintenance per major release.
- Expert chat and ticket-based support belong to the paid plans. Free users get the forum.
- Vaadin is a framework, so you still need your own place to run the finished Java app.

## Questions people ask

### Is Vaadin free?

Yes. The open-source framework and more than 50 UI components are free under Apache 2.0, including for commercial use. Some components and TestBench need the paid Pro plan.

### How much does Vaadin Pro cost?

The pricing page lists Pro at $159 per developer per month. It includes all commercial UI components and TestBench, and a 30-day free trial is available without a credit card.

### How do I start a Vaadin project?

The docs recommend Vaadin Start. It generates a ready-to-run Spring Boot and Maven project that you download as a ZIP file and open in your IDE.
