You create an account, generate an API key in the dashboard, and call HTTPS endpoints from any language. It suits developers who want a small IP lookup with a choice of server region and no card on file.

## What the free plan gives you

The Hobby plan costs $0 a month and needs no credit card. It gives you 2,000 requests per day at a rate of 100 requests per minute. The data level is Essentials, and the free plan can use the US and Asia API servers.

The limits apply across all endpoints together. Paid plans start at $25 a month for 50,000 requests per day at 800 requests per minute. The Growth plan costs $49 for 150K a day, and the Scale plan costs $99 for 350K a day.

## When you hit a limit

The API answers with HTTP 429. The `RateLimitExceeded` code means you passed the per-minute rate. The `DailyLimitExceeded` code means you used the daily quota, and requests stay blocked until the reset time. Response headers such as `Daily-Request-Remaining` show how much is left.

The pricing page lists no overage charge, and the docs describe blocked requests, not extra bills. If you need more room, upgrade the plan or contact Geolocated.io about a custom setup.

## Gotchas

- Every request needs an API key. The key is tied to the API server you choose, so switching the server region invalidates the key.
- The dashboard shows the 40 character key once. Geolocated.io stores only a hash, so a lost key must be regenerated.
- The FAQ allows commercial use but forbids reselling the IP data or service as a standalone offering. The batch lookup accepts at most 25 addresses per request and is a feature of the paid tiers.

## Questions people ask

### Is Geolocated.io free?

Yes. The Hobby plan is $0 a month and gives you 2,000 requests per day, with no credit card required.

### Does Geolocated.io need an API key?

Yes. The docs say all requests need an API key, which you generate in the dashboard after you log in.

### Can I use Geolocated.io in a commercial project?

The FAQ says yes, if it fits their terms of service. You may not resell the IP geolocation data or service as a standalone offering.
