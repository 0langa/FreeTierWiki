You use E2B through its Python or JavaScript SDK with an API key from the dashboard. Your code starts a sandbox, runs code in it, and reads the results. It suits developers who build AI agents and code interpreters and need a safe place for generated code to run.

## What the free plan gives you

The Hobby plan has a base price of $0 per month and a one-time $100 usage credit. No credit card is required. You can run up to 20 concurrent sandboxes. Each sandbox can use up to 8 vCPUs and 8 GiB of memory, and it can run for 1 hour before you must pause it.

E2B bills by the second for a running sandbox, and the credit pays for it. The pricing guide marks 2 vCPUs as the default size. A paused sandbox is kept with no time limit, and you pay only while a sandbox runs.

## When you hit a limit

If you run out of credits, E2B blocks your account. You must add a payment method to keep using the service. The credit does not refill, and moving to the Pro plan does not add credits. API requests that go over a rate limit get an HTTP 429 response with a `Retry-After` header. The newer SDK versions retry these requests for you. Pro costs $150 per month plus usage and raises limits such as runtime and concurrency.

## Gotchas

- The $100 credit is a one-time gift, not a monthly allowance.
- A sandbox stops being continuous after 1 hour on Hobby. Pause and resume it to reset the clock.
- Pausing, killing, or timing out a sandbox stops billing at once, so end sandboxes you do not need.

## Questions people ask

### Is E2B free?

Partly. The Hobby plan is free and comes with a one-time $100 usage credit. After the credit is gone you must add a payment method.

### Does E2B need a credit card?

No. The pricing page says no credit card is required to start on the Hobby plan.

### What happens when I run out of E2B credits?

Your account is blocked. You add a payment method to continue using E2B.
