You use E2B through its Python or JavaScript SDK with an API key from the dashboard. Your code starts a sandbox, runs code in it, and reads the results. It suits developers who build AI agents and code interpreters and need a safe place for generated code to run.

## What the free plan gives you

The Hobby plan has a base price of $0 per month and a one-time $100 usage credit. The pricing footnote says some accounts must make a non-refundable $5 card verification payment to prevent abuse; that payment becomes project usage credit. You can run up to 10 concurrent sandboxes. Each sandbox can use up to 8 vCPUs and 8 GiB of memory, and it can run for 1 hour before you must pause it.

E2B bills by the second for a running sandbox, and the credit pays for it. The pricing guide marks 2 vCPUs as the default size. A paused sandbox is kept with no time limit, and you pay only while a sandbox runs.

## When you hit a limit

Without a payment method, exhausted credits cause every project in your workspace to be blocked shortly afterwards. Add a payment method to continue; subsequent usage is billed. The credit does not refill, and moving to the Pro plan does not add credits. API requests that go over a rate limit get an HTTP 429 response with a `Retry-After` header. The newer SDK versions retry these requests for you. Pro costs $150 per month plus usage and raises limits such as runtime and concurrency.

## Gotchas

- The $100 credit is a one-time gift, not a monthly allowance.
- A sandbox stops being continuous after 1 hour on Hobby. Pause and resume it to reset the clock.
- Pausing or killing a sandbox stops compute billing, so end sandboxes you do not need.

## Questions people ask

### Is E2B free?

Hobby is free with a one-time $100 usage credit, but some accounts require a $5 verification payment. Without a payment method, projects are blocked after credits run out; adding one enables billed usage.

### Does E2B need a credit card?

Usually not, but some accounts must make a one-time $5 card verification payment. It is non-refundable and added to project usage credits.

### What happens when I run out of E2B credits?

Without a payment method, your workspace projects are blocked shortly after credits run out. Adding a payment method enables continued billed usage.
