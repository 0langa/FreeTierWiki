You create an account, copy an API key from the dashboard, and call one HTTPS endpoint, `/v3/ipgeo`, from any language. It suits developers who want one call that returns location, currency, ASN, and time zone for testing or a small side project.

## What the free plan gives you

The Free plan costs $0 and gives you 1000 API credits per day, for life. The pricing page says no credit card is required. A successful lookup charges 1 credit, so the plan covers up to 1000 basic lookups a day.

The free plan returns location, country metadata, currency, ASN, and time zone. Lookup by domain, hostname, company data, security flags, bulk lookup, and translated responses need a paid plan. The first paid plan, Starter, costs $19 a month for 150000 credits. The page says to use the free plan only for testing and small projects, and its FAQ describes evaluation, testing, and prototypes.

## When you hit a limit

The free plan, which the docs also call the Developer plan, has no surcharge and no overage. It stays capped at its daily credits. The pricing page says there are no overages on Free. The IP Geolocation API error reference explicitly returns HTTP 429 when a free subscription reaches its usage limit.

Paid plans can keep serving requests after their credits run out if overage is turned on, and they are billed in blocks. The free plan never bills you.

## Gotchas

- Paid modules can cost multiple credits: security adds 2 and abuse contact adds 1. These modules are unavailable on Free, where a successful basic lookup costs 1 credit.
- Asking for a language other than English with a free key returns a 401 response.
- The current pages describe Free for evaluation, testing, prototypes, and small projects. They no longer publish the former blanket non-commercial restriction; choose paid capacity for production needs.

## Questions people ask

### Is IPGeolocation.io free?

Yes, for testing, prototypes, and small projects. The Free plan gives you 1000 API credits per day and needs no credit card.

### What happens when I go over the IPGeolocation.io free limit?

The free plan stays capped at its daily credits and has no overage billing. The API error reference specifies HTTP 429 when a free subscription reaches its usage limit.

### Can I use the IPGeolocation.io free plan commercially?

The current pages describe evaluation, testing, prototypes, and small projects. They do not repeat the former blanket non-commercial restriction. Confirm your intended production use with the provider.
