You work in the SmartParse web app: you define the field mapping, upload a CSV in the browser, and SmartParse sends the rows to your API. The site's documentation address did not load, so this page relies on the main site. It suits developers who do bulk imports into a REST API.

## What the free plan gives you

The Intro plan is free and has up to 300 processing units available each month. The pricing page describes it as suitable for testing and small uploads, and its only upload method is the browser.

The site does not define a processing unit. Its usage calculator asks for files per month, lines per file, API response time, and concurrency. Treat the free amount as a test allowance.

The first paid plan allows up to 8000 processing units for $119 a month and adds SFTP uploads and downloads. Higher plans cost $299 and $499 a month and add custom throttling.

## When you hit a limit

The pricing page does not say what happens when you use up the 300 processing units on the Intro plan. This entry lists the free plan as a hard cap with no overage charge, and the site shows no pay-as-you-go option.

Separate from plan limits, the site says SmartParse has circuit breakers that stop it from flooding your API when the API is down. It also quarantines failed records so you can reprocess them once your API is back. The plan list shows data quarantining, circuit breakers, and notifications on the Intro plan too.

## Gotchas

- The free plan is limited to browser uploads. SFTP starts on the first paid plan.
- SmartParse only connects CSV data to an existing API that accepts JSON. It does not create an API from your CSV file.
- The site gives no definition of a processing unit, so you cannot easily predict how far 300 will go.

## Questions people ask

### Is SmartParse free?

Yes, the Intro plan is free with up to 300 processing units available each month and browser uploads only.

### What kinds of APIs does SmartParse support?

Any REST API endpoint that accepts JSON payloads. The site names Salesforce, Shopify, and custom internal APIs as examples.

### What happens if my API goes down while SmartParse runs?

SmartParse uses circuit breakers to stop flooding the API, and it quarantines failed records. You can reprocess them when the API is back.
