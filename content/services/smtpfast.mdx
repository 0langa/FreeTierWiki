SMTPfast is a transactional email API for developers, built on AWS SES. You verify a domain, get an API key, and send over a REST API or SMTP, and the dashboard traces every send, bounce, open, and webhook for each email.

## What the free plan gives you

The Free plan is $0 forever and is aimed at testing and side projects. It includes 3,000 emails a month, up to 1,000 contacts, 2 contact segments, 2 broadcasts a month, 1 sending domain, email logs, 30-day content retention, basic analytics, and community support. The site says no card is required to start.

Sending works over the JSON REST API or through the SMTP bridge, where your API key is the SMTP password, so older apps can send without code changes. The sending API is Resend-compatible, and the site also lists contact forms, a hosted MCP server, and an OpenAPI spec.

## When you hit a limit

The pricing section does not say what happens on the Free plan when you use the 3,000 emails in a month. It does not describe a hard stop or automatic charges.

If you only need extra volume for a spike, active accounts can buy prepaid email credits at $0.001 per extra email, which works out at $1 for 1,000 extra emails. For a steady increase, the Starter plan is $9 a month for 10,000 emails, 5,000 contacts, and 3 sending domains.

## Gotchas

- Only 1 sending domain is free, so a second project needs Starter or a shared domain.
- Broadcasts are capped at 2 a month, so the free plan is not a newsletter tool for regular sends.
- Message content is kept for 30 days, so older logs lose the body of the email.

## Questions people ask

### Is SMTPfast free?

Yes. The Free plan is $0 forever with 3,000 emails a month.

### Do I need a credit card for SMTPfast?

No. The site says no credit card is required to start.

### Can I use SMTPfast over SMTP?

Yes. You can point an SMTP client at the SMTP bridge and use your API key as the password.
