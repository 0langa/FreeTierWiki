Appish works with a Docker image you already have. The dashboard supplies a private registry push URL, and Appish runs the image at a different public URL. Anyone with the push URL can replace the deployment, so share only the public app URL. That makes it useful for a project review where someone needs to try the app in a browser without building it on their own machine.

## What the free plan gives you

Each account has one free demo slot with shared resources and a public address under appi.sh. Build an image for linux/amd64, use the dashboard's push command and set the port tag to match the port your container serves. An Active dashboard status only means the image has arrived and is being processed; Healthy confirms the app is reachable. The clock starts on the first push. Subsequent pushes replace the running image without changing the public URL or extending the timer.

A free session lasts up to four hours. If you need the link to stay live for a little longer, extend the slot from the dashboard. The docs say each extension starts a fresh four-hour window.

## When you hit a limit

At expiry Appish stops the containers and marks the slot as expired. The image remains in the registry, so you can reuse it. During the first eight hours after expiry, use Renew slot in the dashboard before pushing again. Later, a new push can restart it by itself. The provider lists paid slots separately for longer-lived demos. It does not publish a clear card requirement for signing up on Free.

## Gotchas

- The URL is public. Put only the intended demo and demonstration data behind it.
- Updating the image leaves the old expiry time in place. Extend the slot before a review if the current session will run out during the meeting.
- Appish documents using an external database for an app that needs one. Its free container slot does not include a built-in database.

## Questions people ask

### Is Appish free?

Yes. The Free plan includes one public demo slot for four hours at a time and supports manual extensions.

### What happens when the Appish slot expires?

The container stops and the image stays in the registry. Renew the slot in the dashboard if you want to restart it before an ordinary push will work.

### Do I need to connect a Git repository?

The documented deployment uses a Docker push. You can build the image locally and send it straight to the registry address Appish gives you.
