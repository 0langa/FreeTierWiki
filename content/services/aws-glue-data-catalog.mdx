The Data Catalog is the metadata store inside AWS Glue. It holds databases, tables, and partitions that describe where your data lives and what its columns are, and Amazon Athena and other AWS services read those definitions to query the data. It suits developers who keep data files in S3 and want to query them with SQL.

## What the free plan gives you

You can store up to a million metadata objects in the Data Catalog for free. A metadata object is a table, table version, partition, partition index, statistics, database, or catalog. The first million metadata access requests each month are also free; common requests include CreateTable, CreatePartition, GetTable, and GetPartitions.

The pricing page example: if you store a million metadata objects and make 1 million metadata requests in a month, you pay $0, because the Data Catalog free tier covers that usage. Usage of the AWS Glue Schema Registry is offered at no additional charge.

## When you hit a limit

Nothing stops the catalog at the free amounts. Past a million objects stored, you pay $1.00 per 100,000 objects per month. Past a million requests in a month, you pay $1.00 per million requests.

Other parts of Glue are billed from the first second. Crawlers and ETL jobs are billed at an hourly rate by the second, based on the Data Processing Units they use, and Spark jobs need a minimum of 2 DPUs.

## Gotchas

- Every table version and partition counts as an object, so a table with many partitions uses the free million faster than the table count suggests.
- Filling the catalog with a crawler is convenient but billed; you can add tables by hand or through the API instead.
- A new AWS account on the Free plan closes after 6 months or when its credits run out, unless you upgrade to a Paid plan.

## Questions people ask

### Is the AWS Glue Data Catalog free?

Within limits. The first million objects stored and the first million requests each month are free.

### Are Glue crawlers free?

No. Crawlers are billed at an hourly rate, by the second, and are not part of the Data Catalog free amount.

### What counts as a metadata object?

A table, table version, partition, partition index, statistics, database, or catalog each counts as one object.
