You build a badge in the web page or write its URL by hand, then paste the image link into Markdown or HTML. There is no account to create.

## What the free plan gives you

There are no plans on Shields.io. The service is free to use. The home page asks visitors to consider donating to sustain the project, and the community page thanks the people and companies who donate money, services, or time. The docs describe no account or API key for the public service.

The service supports dozens of services: continuous integration, package registries, app stores, social networks, code coverage, and code analysis. The project README says it serves over 1.6 billion images each month.

You can also make a static badge from the URL alone. The static badge takes a label, a message, and a color separated by dashes, and it supports styles such as flat, flat-square, plastic, for-the-badge, and social.

## When you hit a limit

The Shields.io pages do not publish a usage limit, a rate limit, or a bill. There is no paid tier to move to. The badge docs list a cacheSeconds parameter for the HTTP cache lifetime. Values below the default are ignored.

If you need more control, the home page offers a self-hosted option. You run the official Docker image behind your own firewall. The self-hosting guide also covers running from source, which needs Node 24, and deploying to Heroku or Vercel.

## Gotchas

- The public service is a community project, not a paid product. The pages show no uptime promise.
- Many badges read data from other services, such as CI tools or package registries. If that service is down, the badge fails too.
- Private or sensitive data should not go through the public service. Host your own server for that.

## Questions people ask

### Is Shields.io free?

Yes. There are no paid plans. The service runs on donations, and the code is open source.

### Do I need an account for Shields.io?

No. You build a badge in the page or write its URL, then copy it into your README. No sign-up is described in the docs.

### Can I host Shields.io myself?

Yes. The project publishes a Docker image on Docker Hub and on the GitHub Container Registry. You can also run the server from source.
