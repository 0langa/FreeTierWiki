The Hacker News API is a useful alternative when your project needs public technology discussions rather than Reddit specifically. Switching APIs also changes the community and content your app represents; it is not a way to retain access to Reddit posts.

## What the free plan gives you

The official API exposes public Hacker News data in near real time through Firebase JSON endpoints. Stories, comments, jobs and polls use item IDs, and user profiles have their own endpoint. Public reads do not require an API key, account or payment card.

The [official repository](https://github.com/HackerNews/API) documents feeds for top, new and best stories, plus Ask, Show and job lists. A feed returns identifiers rather than complete articles: fetch the items you need and follow child IDs to load comments. The API gives you discussion records and links; it does not supply the full text of every external article mentioned in a story.

## When you hit a limit

The documentation says there is currently no rate limit. That statement is not a service-level agreement or a promise that unlimited concurrent requests will always work. Treat failures as temporary errors: retry carefully, cache records where appropriate, and avoid repeatedly downloading an unchanged discussion tree.

There is no published metered overage plan in the reviewed API documentation. You still pay for any hosting, storage or network service you choose for your own application. For a small reader, load the visible stories first instead of fetching every comment before showing the page.

## Gotchas

- This is a different dataset from Reddit. A product that depends on particular subreddits cannot preserve that coverage merely by switching to Hacker News.
- Story and comment fields can be absent, and items can be marked deleted or dead. Treat returned HTML as untrusted content when rendering a reader.
- The documented interface exposes reads, not posting, voting or a built-in full-text search engine. Design those requirements separately instead of assuming endpoint parity.

## Alternatives in this atlas

- [Reddit Developer Platform (Devvit)](/services/reddit-devvit/): for supported apps and moderation workflows inside Reddit, rather than a standalone discussion reader.

## Questions people ask

### Is the Hacker News API free?

Public JSON reads are available without a key or payment details. The official documentation currently states no rate limit. Your own application's infrastructure remains separate, so a free upstream API does not make every deployment free.

### Can it replace the Reddit API?

Only if changing the dataset fits your project. It can support a reader for technology discussions, but it returns Hacker News stories and comments. It cannot supply the Reddit history, user relationships or subreddit coverage that an existing Reddit integration may require.

### How should I load a comment thread?

Fetch the story item, then follow its child IDs and their descendants. Render incrementally and handle missing records. This avoids making readers wait for every branch of a large discussion and keeps network work proportional to what they actually open.
