You use Robohash with a URL. Put your text in the path and the service returns a PNG image, so the examples need no SDK. It suits developers who want default avatars or placeholder pictures.

## What the free plan gives you

Robohash has no plans. The home page says the service is provided for free, and the examples use plain URLs with no account or API key step. The same text always produces the same image, so you can key avatars to a username, email, or ID.

You can change the look with URL options. Different sets give robots, monsters, floating heads, kittens, humans, and gorillas. You can request other file formats, use `size` for dimensions such as 200x200 or 500x500, add a background with `bgset`, or ask Robohash to use a Gravatar when one exists.

## When you hit a limit

No numeric quota is published. The official README says to use exponential backoff after errors or too-many-requests responses, so anonymous access is not an unlimited-service guarantee. The homepage also warns about bandwidth. The owner says that if bandwidth gets crazy, a small banner might be added to the bottom of the images.

For high-volume or production use, the project README suggests hosting your own instance with Docker. The code is available under the MIT license, and there are pre-built Docker images on GitHub's container registry. Artwork licenses vary: sets 1–4 use CC-BY, set5 allows personal/commercial use, and set6 is CC0.

## Gotchas

- The homepage gives a broad CC-BY notice, while the README lists licenses by set. Credit sets 1–4 and check the selected artwork license.
- If you use `set=any`, new sets may change existing hashes. Name a set or list of sets to keep an image stable.
- The site makes no uptime promise, so cache images or host your own copy for anything important.

## Questions people ask

### Is Robohash free?

Yes. The site provides its service for free, and its examples use plain URLs with no account or API key step. Artwork licenses vary by set; attributed sets need credit.

### Does Robohash have a rate limit?

There is no published numeric quota. The README says to back off after too-many-requests responses and suggests self-hosting for high volume. The homepage may add a banner if bandwidth grows.

### Can I use Robohash images in a commercial project?

Check the set-specific license: sets 1–4 require attribution, set5 permits personal/commercial use, and set6 is CC0. The public service is best-effort; self-host for production volume.
