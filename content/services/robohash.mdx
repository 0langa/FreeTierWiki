You use Robohash with a URL. Put your text in the path and the service returns a PNG image, so the examples need no SDK. It suits developers who want default avatars or placeholder pictures.

## What the free plan gives you

Robohash has no plans. The home page says the service is provided for free, and the examples use plain URLs with no account or API key step. The same text always produces the same image, so you can key avatars to a username, email, or ID.

You can change the look with URL options. Different sets give robots, monsters, floating heads, kittens, humans, and gorillas. You can request other file formats, use `size` for dimensions such as 200x200 or 500x500, add a background with `bgset`, or ask Robohash to use a Gravatar when one exists.

## When you hit a limit

The site states no rate limit and no quota. The only warning is about bandwidth. The owner says that if bandwidth gets crazy, a small banner might be added to the bottom of the images.

For high-volume or production use, the project README suggests hosting your own instance with Docker. The code is available under the MIT license, and there are pre-built Docker images on GitHub's container registry. The artwork sets carry their own Creative Commons licenses.

## Gotchas

- The images are CC-BY. Credit Robohash when you embed them, for example with the line "Robots lovingly delivered by Robohash.org".
- If you use `set=any`, new sets may change existing hashes. Name a set or list of sets to keep an image stable.
- The site makes no uptime promise, so cache images or host your own copy for anything important.

## Questions people ask

### Is Robohash free?

Yes. The site provides its service for free, and its examples use plain URLs with no account or API key step. The images are CC-BY licensed, so you should credit Robohash.

### Does Robohash have a rate limit?

The site states none. It says it might add a small banner to images if bandwidth gets very high, and it suggests self-hosting with Docker for high-volume use.

### Can I use Robohash images in a commercial project?

The site says you are free to embed the images under the CC-BY license, with credit. The README calls the service best-effort, not a commercial offering. Check the license of each artwork set.
