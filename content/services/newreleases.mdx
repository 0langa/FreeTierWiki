NewReleases.io follows versions from package registries and code hosts. You select the projects that matter to your work, then use notifications to find out when something changes upstream. It can help if you maintain a project with dependencies that release through several different ecosystems.

## What the free plan gives you

The pricing page says all features are free, requires no card, and asks for donations. It lists GitHub, GitLab, Codeberg, and package registries such as PyPI and npm among the supported sources. The service also offers an HTTP API. Start with a small set of dependencies and select where you want notifications to go. A release signal can tell you when to review the new version and its notes. Keep your own compatibility check in that process, since receiving the notification says nothing about whether the latest version works in your environment.

## When you hit a limit

The pricing page does not give a universal quota, delivery guarantee or timing for every supported source. For a project with many transitive dependencies, start by tracking the few that require attention and check how many notifications arrive. If an upstream release is time-sensitive, check its original repository or package registry directly when you need confirmation. Keep alert delivery separate from your deployment process so a missed alert cannot trigger or prevent an upgrade.

## Gotchas

- The service watches releases on supported platforms. A private or unusual source may need a different integration.
- Read the upstream notes before treating any new version as a routine upgrade.
- Track packages you can act on. Subscribing to every dependency may make important releases harder to notice.

## Alternatives in this atlas

- [GitHub Actions](/services/github-actions/) for running your own release or compatibility checks.
- [GitLab](/services/gitlab/) for releases and repository activity hosted in GitLab.

## Questions people ask

### Does NewReleases.io require a paid plan?

The provider offers its features for free and accepts voluntary donations.

### Can I watch both repositories and packages?

Yes. See the supported source list for the hosts and registries you use.

### Can it update my dependency files?

The offer tracks versions and sends notifications. Apply and test an upgrade through your development workflow.
