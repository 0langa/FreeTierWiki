FCM is the push messaging service in Firebase. You add the SDK to an Android, Apple, web, Flutter, Unity, or C++ app, collect a registration token, and send messages from the Firebase console or your server through the HTTP v1 API. It suits app developers who need push notifications without running their own delivery service.

## What the free plan gives you

The Firebase pricing page lists Cloud Messaging as a no-cost product. It costs nothing on the no-cost Spark plan and on the pay-as-you-go Blaze plan, so you do not need a billing account to send messages.

You can send notification messages, which the device shows to the user, or data messages, which your app handles in code. For uses such as instant messaging, a message can carry a payload of up to 4096 bytes. You can send to one device, to device groups, or to every device subscribed to a topic.

## When you hit a limit

There is no bill to hit. The limit is a sending rate: the HTTP v1 API has a per-project quota for downstream messages, with a default of 600k messages per minute, which Google says covers over 99% of FCM developers.

Over the quota, FCM returns HTTP status 429 RESOURCE_EXHAUSTED until the quota refills in the following minute. The quota counts messages, not requests, and client errors in the 400 to 499 range count too, except 429s. You can view quota and usage in the Google Cloud console.

## Gotchas

- Quota minutes are not aligned to the clock, so a burst near the top of the minute can still be throttled.
- Collapsible messages are limited to a burst of 20 messages per app per device.
- FCM is free, but the backend that sends messages is not; Cloud Functions, for example, needs the Blaze plan.

## Questions people ask

### Is Firebase Cloud Messaging free?

Yes. The Firebase pricing page lists Cloud Messaging as no-cost on both the Spark and Blaze plans.

### Is there a limit on how many push messages I can send?

Yes, a rate limit. The default quota is 600k messages per minute per project, and FCM returns 429 errors above it until the next minute.

### Do I need the Blaze plan to use FCM?

No. FCM is no-cost on the Spark plan, though a backend such as Cloud Functions that sends the messages needs Blaze.
