TinaCMS is an open-source, Git-backed headless CMS. Your content stays as Markdown, MDX, and JSON files in your repository, and TinaCMS adds an editing interface and a queryable content API on top. A developer would pick it to give a blog or docs site a visual editor without moving content into a proprietary database.

## What the free plan gives you

To run TinaCMS in production you connect it to a hosted backend. TinaCloud is Tina's hosted option: it provides a hosted GraphQL endpoint for your content, Git integration, user management, and a data layer that indexes your Markdown and JSON files and stays in sync with your GitHub repository.

The TinaCloud Free plan is $0 forever and includes 2 users, 2 roles, and community support. The comparison table lists unlimited documents and a 100 MB asset size cap. The Team plan costs $24 per project per month and includes 3 users, with up to 10 users at $90 per additional seat per year.

## When you hit a limit

The Free plan's user limit is 2, and the comparison table shows the same figure for included users and the user limit. A third editor means moving to Team or above. The pricing page does not say what happens if you try to add one on Free.

The asset size cap is 100 MB on every plan. The page lists no overage charges for the Free plan. If TinaCloud's limits do not fit, the docs say you can set up the backend with your preferred hosting provider and self-host it instead.

## Gotchas

- TinaCloud is not the source of truth for your content; your Git repository is, so repository access matters.
- The editorial workflow is on Team Plus and above, so drafts and reviews are limited on Free.
- Paid plans are billed per project, so several sites each need their own plan.

## Questions people ask

### Is TinaCMS free?

Yes. TinaCMS is open source, and TinaCloud's Free plan is $0 forever with 2 users and 2 roles.

### Where does TinaCMS store my content?

In your Git repository, as Markdown, MDX, and JSON files. TinaCloud indexes those files and syncs with GitHub.

### Do I have to use TinaCloud?

No. The docs say you can connect TinaCMS to TinaCloud or set up a self-hosted backend on your own infrastructure.
