Umami is an open-source web analytics tool, and Umami Cloud is its hosted service. It counts pageviews and custom events without cookies, so it suits developers who want simple site stats without a consent banner.

## What the free plan gives you

The Hobby plan costs $0 a month. It covers up to 100K events per month on 1 website, keeps data for 6 months, and comes with community support.

Usage is counted in events. Each website pageview counts as one event, and if you save event properties, each data property stored counts as one event. Hobby includes custom events, event and session properties, funnel analysis, user retention, UTM parameters, goals, user journeys, realtime events, and custom dashboards. Umami lists it as GDPR and CCPA compliant with no cookie banners required. API access, team members, email reports, heatmaps, and session replays are left out.

## When you hit a limit

Umami's FAQ says that if you exceed the events included in your plan, additional events are billed at a per-event rate, and data collection is not interrupted. The rates it lists are for paid plans: $0.00003 per event on Pro and $0.00002 per event on Business.

The Hobby plan shows no additional-event rate, and the page does not say what happens when a Hobby site passes 100K events in a month. You can monitor usage from the Umami Cloud dashboard. Pro costs $20 a month with 1 million events included.

## Gotchas

- Saving event properties uses the allowance faster, because each stored property counts as an event.
- Hobby keeps only 6 months of data, while Pro keeps 2 years.
- Hobby covers a single website, so a second site needs Pro.

## Questions people ask

### Is Umami Cloud free?

Yes, on the Hobby plan: $0 a month for 1 website and up to 100K events per month.

### What counts as an event in Umami?

Each pageview counts as one event, plus custom events, and each stored event property counts as one event.

### Can I self-host Umami instead?

Umami is open source, but this entry covers the hosted Umami Cloud; self-hosting is a separate setup you run yourself.
