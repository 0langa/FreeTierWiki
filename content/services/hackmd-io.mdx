You use HackMD in the browser to write Markdown notes together, and from code through a REST API or CLI. It suits small teams, student groups, and open source communities that want shared notes without a heavy setup.

## What the free plan gives you

The Free plan costs $0 forever. You get unlimited notes and up to 3 invitees. You also get the GitHub integration with 20 pushes per month, a custom permalink for a note, and 400 API calls per month. Version history keeps the 10 most recent versions. Free users can upload images up to 1 MB.

The editor supports real-time editing with multiple cursors, comments and mentions, templates, and slide mode. You start on the Free plan by default when you sign up.

## When you hit a limit

The pricing page lists the numbers but does not describe what happens after the 20th GitHub push or the 400th API call in a month. Older versions beyond the 10 most recent are not kept on Free. To lift these limits, move to Prime at $5 per seat per month, billed annually. Prime adds full-text search, PDF export, unlimited invites, unlimited versions, unlimited GitHub pushes, and 20K API calls per month. The pricing page does not mention a card for the Free plan.

## Gotchas

- Only 3 invitees, so a team of five cannot all join on the Free plan.
- Version history stops at the 10 most recent versions, so old drafts are lost.
- Full-text search is a Prime feature, which makes a large note collection hard to search.

## Questions people ask

### Is HackMD free?

Yes. The Free plan costs $0 forever, with unlimited notes, 3 invitees, and the GitHub integration at 20 pushes per month.

### How many people can edit on HackMD Free?

You can invite up to 3 teammates on the Free plan. Prime has unlimited invites.

### Does HackMD have an API?

Yes. Free allows 400 API calls per month, and Prime allows 20K per month. You can pull any note as Markdown through the REST API.
