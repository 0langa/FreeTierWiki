InsForge bundles the backend pieces a web or mobile app needs in one hosted project. Your app can use Postgres for its data, the authentication service for sign-in, and file storage for uploads. Use the project console to set up the backend and link your local code with the CLI.

## What the free plan gives you

The pricing page lists 500 MB for the database, 50,000 monthly active users, 1 GB for file storage, and 5 GB of bandwidth. You also get 100,000 edge function calls. These are separate allowances. For an app with uploads, the storage allowance covers the files you keep, while bandwidth measures data moving out to readers. The usage report exposes these meters alongside auth and edge function usage.

Custom compute is a separate feature for running containers. The Free plan includes 120 hours per month on the default spec. A prototype using the ordinary database, auth, and storage services can start without deploying a custom container.

## When you hit a limit

The CLI can print usage for the current billing period and show its reset date. Check which resource is limiting your app before changing plans. InsForge documents a cap for custom compute and a pause after one week of project inactivity. Its public pricing FAQ does not clearly specify whether every other free-plan resource blocks or throttles requests at its allowance. Pro explicitly bills above the included amounts.

## Gotchas

- Free projects pause after a week of inactivity. An occasional demo may need attention before you share it again.
- Storage and bandwidth are separate. Repeatedly downloading a file uses bandwidth even if the stored copy stays the same size.
- The pricing FAQ describes compute credits for Pro separately from the free monthly custom compute hours.

## Questions people ask

### Is InsForge free to start?

Yes. The hosted Free plan costs nothing per month and InsForge says no card is necessary for free access.

### Does InsForge keep free projects running when idle?

Free projects pause after one week without activity.

### Where can I check my current usage?

Run the organization usage command documented in the pricing FAQ from the InsForge CLI. It reports the current billing period, resource totals, and reset date.
