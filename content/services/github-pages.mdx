You push files to a GitHub repository and turn on Pages in the repository settings. The quickstart builds a user site from a repository named after your username, and you can also publish with a GitHub Actions workflow. It suits developers who already keep their work on GitHub.

## What the free plan gives you

GitHub Pages costs nothing on GitHub Free. It works with public repositories on GitHub Free and GitHub Free for organizations. Private repositories need a paid GitHub plan. A published site may be no larger than 1 GB, and the source repository has a recommended limit of 1 GB.

The docs list a soft bandwidth limit of 100 GB per month and a soft limit of 10 builds per hour. The build limit does not apply if you publish with a custom GitHub Actions workflow. Deployments time out after 10 minutes. You can create one user or organization site per account. Custom domains are supported, and GitHub has guides to configure and verify them.

## When you hit a limit

The limits are soft, and the docs do not describe a charge. If your site exceeds the usage quotas, GitHub says it may not be able to serve your site, or you may get an email from GitHub Support with ways to reduce your load. The email may suggest a CDN in front of your site, other GitHub features such as releases, or a different host.

Rate limits may also apply for consistent quality of service. If a request triggers them, you receive an HTTP 429 response. The docs describe a degraded or unserved site and an email from GitHub Support, not a bill.

## Gotchas

- GitHub says Pages must not be used as free hosting for an online business, an e-commerce site, or a site mainly for commercial transactions or SaaS.
- Sites should not be used for sensitive transactions such as sending passwords or credit card numbers.
- Changes can take up to 10 minutes to publish after you push them.

## Questions people ask

### Is GitHub Pages free?

Yes, for public repositories on GitHub Free. Published sites may be up to 1 GB, with soft limits of 100 GB of bandwidth per month and 10 builds per hour.

### Can I use GitHub Pages for a business site?

No. The docs say Pages is not intended or allowed as free hosting to run an online business, an e-commerce site, or a mainly commercial SaaS site.

### Can I use a custom domain with GitHub Pages?

Yes. GitHub documents how to configure, manage, and verify a custom domain for Pages.
