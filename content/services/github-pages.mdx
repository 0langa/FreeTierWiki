GitHub Pages is a free static site hosting service that lets you publish websites directly from your GitHub repositories, ideal for personal, project, or documentation sites. Sites are limited to 1 GB each, with soft limits of 100 GB of bandwidth per month and 10 builds per hour — GitHub Free requires the source repository to be public.
