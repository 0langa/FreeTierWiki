jsDelivr is a public CDN for open-source files. It is tightly integrated with npm and GitHub, so almost any published package or public repository file has a CDN URL without any setup, and it has been operating since 2012.

## What the free plan gives you

There is no plan to choose. jsDelivr's acceptable use policy says that, as long as you follow its rules, using the CDN is free for both personal and commercial use, and there are no limits on bandwidth or number of requests. The documentation adds that there are no premium features and that the CDN can be used in production on sites with huge amounts of traffic.

You load files by URL from npm or GitHub, with version ranges, automatic minification when you add .min, a default file when you omit the path, and a combine endpoint for several files in one request. Once a file is first accessed it is stored permanently, so it keeps working even if the package is later deleted.

## When you hit a limit

jsDelivr has hard limits on file size, files per package, package size, and some file extensions. The docs say packages larger than 150 MB or single GitHub files larger than 20 MB are not supported by default. A request past a hard limit gets an error response with the reason, and limits can be raised for legitimate projects on request.

For the GitHub proxy there are soft limits that are not enforced automatically: it recommends at most ten thousand actively accessed files per repository and sets a soft limit of one hundred thousand files.

## Gotchas

- Using the CDN as storage for an image hosting site, for videos, or for file backups is prohibited.
- Omitting the version gets the latest release, which the docs say you should not do in production.
- Purging a cached file is rate limited, and the docs say purge access is given after an email request.

## Questions people ask

### Is jsDelivr free for commercial use?

Yes. The acceptable use policy says jsDelivr is free for personal and commercial use as long as you follow its rules.

### Does jsDelivr have bandwidth limits?

No. The policy says there are no limits on bandwidth or number of requests, though files and packages have size limits.

### Can I host my images on jsDelivr?

Not as an image host. Using jsDelivr as storage for an image hosting site, or for videos and backups, is prohibited.
