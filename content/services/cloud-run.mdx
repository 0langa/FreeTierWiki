You deploy a container image or your source code to Cloud Run with the Google Cloud console or the gcloud CLI. Cloud Run gives the service an HTTPS URL and runs it for you. It suits developers who want to host web apps and APIs without managing servers or clusters.

## What the free plan gives you

Cloud Run has a monthly free tier that Google applies as a spending discount. For services with request-based billing, the free tier is the first 180,000 vCPU-seconds, 360,000 GiB-seconds of memory, and 2 million requests each month. These figures use us-central1 pricing.

For services with instance-based billing, the free tier is the first 240,000 vCPU-seconds and 450,000 GiB-seconds each month. Outbound data transfer has a free tier of 1 GiB within North America per month. Google aggregates the free tier across projects by billing account, and it resets every month.

## When you hit a limit

Nothing stops your service at the free amounts. You are billed only for usage past the free tier, rounded up to the nearest 100 milliseconds. Google Cloud needs a billing account for the Free Tier, and a Free Trial billing account uses its $300 welcome credit for any overage.

With request-based billing, you pay while an instance handles requests. If you set minimum instances, Google bills a lower idle rate for those warm instances. Idle instances that are not minimum instances are not charged.

## Gotchas

- The free amounts are shared by all your projects under one billing account. A second service uses the same pool.
- Setting minimum instances keeps instances warm and adds idle charges, even with no traffic.
- Deploying from source uses Cloud Build and Artifact Registry. Artifact Registry has its own free tier of storage.

## Questions people ask

### Is Google Cloud Run free?

Within limits. The request-based free tier is 2 million requests, 360,000 GiB-seconds, and 180,000 vCPU-seconds per month. You pay for use beyond that.

### Does Cloud Run need a credit card?

It needs a Cloud Billing account, which is how you reach the Free Tier. New customers can start a Free Trial with $300 in credit to get one.

### What happens when I go over the Cloud Run free tier?

Google bills only the usage past the free tier. Nothing in the pricing docs says your service stops.
