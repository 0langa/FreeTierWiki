You work with the `pijul` command line tool on your machine, and the Nest holds the shared copy of your repository. It suits developers who want to try Pijul or host a Pijul project without paying for hosting.

## What the free plan gives you

The Pijul home page links to the Nest as free hosting. The Nest terms confirm that free use needs no credit card. To register, you enter a handle, an email address, and a password. The Nest page lists neither repository limits nor storage limits.

You can clone a repository over https without an account. Cloning over ssh needs a Nest account. The Pijul client installs with `cargo`, which needs the Rust toolchain, and the installation manual also lists distribution packages. Pijul itself lives on the Nest, so the Pijul project uses the same hosting.

## When you hit a limit

The pages do not state any limits, so they say nothing about what happens when you pass one. The terms say that an elected upgrade to a paid plan is charged immediately. The site lists no prices. There is also no stated service level, so back up important work. Keep a second copy of anything you cannot lose, and check the Nest support page, which the Nest site links, if you need an answer from the people who run it.

## Gotchas

- The Nest is described as Pijul's own repository hosting platform. The pages mention no Git hosting.
- The public site gives no prices, quota, or support promise. Treat it as a community service.
- The client needs a Rust toolchain to install with `cargo`, which adds setup time compared with a Git install.

## Questions people ask

### Is the Pijul Nest free?

The Pijul home page links to the Nest as free hosting. The Nest terms also mention paid upgrades, and the site lists no prices.

### Does Pijul hosting need a credit card?

The Nest terms say free use needs no credit card. The registration form asks for a handle, email, and password.

### Can I host Git repositories on the Pijul Nest?

The pages describe the Nest as Pijul's own repository hosting platform and mention no Git hosting. Use a Git host for Git repositories.
