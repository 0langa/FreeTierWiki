You install a Chrome extension, record clicks on your site, and replay the test from the BugBug app. It suits one person who wants to check a few key flows without writing code.

## What the free plan gives you

The Free plan costs $0 per month. It allows 1 user, 1 project, 4 suites, and 15 tests. A suite is a group of tests that you run together. You can run tests as often as you like, but only locally, in your own Chrome browser. BugBug runs every test in an incognito window so each run starts clean.

The plan keeps 7 days of run history and lets you import and export tests without a limit. It does not include variables, custom JavaScript steps, conditional logic, email-inbox testing, or integrations such as Slack, CI/CD, API, or MCP. BugBug works with Chromium-based browsers only.

## When you hit a limit

The limits on users, projects, suites, and tests are fixed caps. The pricing page does not say what the app shows when you try to add a 16th test. It also gives no bill for the Free plan, because the plan needs no card.

If you need more, you move up a plan. Cloud runs, scheduling, and alerts start on the Core plan at $99 per month billed annually. Core also raises the limits to 3 users, 3 projects, and 50 tests. Paid plans have a 14-day trial with no credit card. If you do not subscribe, the account moves back to Free and keeps its tests, within the Free limits.

## Gotchas

- Tests run only on your machine, so the browser must be open and the computer on. The Free plan has no cloud runs and no schedules.
- You must install the Chrome extension and allow it in incognito mode before you can record or run a test.
- Run history lasts only 7 days on Free, so old results are gone after a week.

## Questions people ask

### Is BugBug free?

Yes. The Free plan costs $0 and gives you 1 user, 1 project, 4 suites, and 15 tests, with unlimited local runs. Cloud runs need a paid plan.

### Does BugBug need a credit card?

No. You can sign up and use the Free plan without a card. The 14-day trial of paid plans also needs no card.

### Can I run BugBug tests in the cloud for free?

No. The Free plan runs tests only in your own browser. Unlimited cloud runs start with the Core plan.
