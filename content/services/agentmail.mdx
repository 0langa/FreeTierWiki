AgentMail gives a program its own mailbox. It can receive messages, read threads and reply by API, which fits an approval workflow or an assistant that needs to handle email. A webhook can notify your application about incoming mail without repeatedly asking the inbox for new messages.

## What the free plan gives you

The pricing table gives Free accounts three inboxes, 3 GB of storage, and a daily limit of 100 emails. The plan supports signed webhooks and needs no payment card. New Free accounts can use one custom domain. To send or receive on that domain, add the DNS records AgentMail supplies, start verification in the Console, and wait for Verified status. Use a subdomain if the root domain already receives mail elsewhere; for send-only use, disabling inbound mail preserves the existing receiving provider.

The pricing table lists 3,000 emails per month. The separate rate-limit guide says Free has no distinct monthly cap, so the public pages disagree about how the monthly figure is enforced. Use the pricing allowance for planning and account for the documented daily send cap as well.

## When you hit a limit

The signup limits guide documents an HTTP 429 response when a send would exceed the daily limit. Check the retry header before sending again. Sending to several recipients uses allowance for each recipient. The inbox and domain limits are also enforced by API errors. Applications that create accounts through the agent signup API start with stricter sending and inbox rules until a human verifies or claims the account.

## Gotchas

- Use the documented daily limit even if the pricing table suggests there is room left for the month.
- Free custom-domain messages include a "Sent via AgentMail" footer; paid plans remove it. The Free organization includes two team members, and capacity add-ons start on Developer. Older Free organizations may need to contact support to enable a custom domain. The release note gives the eligibility date.
- A newly verified agent signup has limits on how quickly it can contact new recipients. Plan a small test before attaching it to an automated flow.

## Questions people ask

### Is AgentMail free?

The Free plan lists three inboxes and needs no card. It supports both receiving and sending with the same inbox.

### Can I use my own domain on AgentMail Free?

New Free accounts include one custom domain. An older account may need the provider to enable it.

### What happens after the daily send limit?

The API rejects the send with a rate-limit response. Wait until the window resets before retrying.
