You work with Lockit inside Slack by mentioning `@Lockit`, in Discord with `/lockit` slash commands, or in Microsoft Teams, which is available on request. On paid plans a script can also use its REST API and MCP server. It suits teams that share a few environments or devices.

## What the free plan gives you

The Free plan costs $0 forever and covers up to 2 resources. A resource is anything your team shares, such as a staging server or a test phone. The plan lists unlimited locks, unlimited members, alerts and takeovers, and Slack and Discord; Microsoft Teams is on request. The home page says the free plan needs no credit card.

In Slack, you create a resource with `@Lockit new`, list resources with `@Lockit list`, and lock or release one by name. The Starter plan costs $17 a month, covers up to 100 resources, and adds the REST API and MCP server. Custom plans add unlimited resources, a white-labelled bot, and custom Slack workflows.

## When you hit a limit

On the Free plan, creating a third resource is refused, from chat and from the API alike. Your existing resources and locks keep working. To go further, upgrade or delete a resource you no longer need. Any plan can be tried free for 15 days, so you can test the 100-resource limit before you pay, and annual billing saves 20%.

## Gotchas

- The REST API and MCP server are on paid plans. API keys are created in Slack, so Discord and Teams workspaces cannot create keys yet.
- Microsoft Teams is available on request, so check before you plan around it.
- The docs say there are no refunds, full or partial, for time already paid for, but you can cancel at any time.

## Questions people ask

### Is Lockit free?

Yes, the Free plan covers up to 2 resources with unlimited members and locks, and the home page says it needs no credit card. Paid plans start at $17 a month.

### What happens when I go over 2 resources on Lockit?

Creating a third resource is refused, from chat or the API. Existing resources and locks keep working, and you can upgrade or delete a resource.

### How do I lock a resource in Lockit?

In Slack, mention `@Lockit lock` with the resource name, and use `@Lockit release` to free it. Discord uses the `/lockit lock` and `/lockit release` commands.
