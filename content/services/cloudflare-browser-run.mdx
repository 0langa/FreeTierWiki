Browser Run, formerly known as Browser Rendering, runs headless browser instances on Cloudflare's network. Quick Actions handle simple, stateless tasks such as screenshots, PDFs, Markdown, and scraping with no code to deploy. Browser Sessions give you direct control through Puppeteer, Playwright, CDP, or Stagehand from a Worker. It suits developers who need a browser in the cloud for small jobs.

## What the free plan gives you

Browser Run is available on the Workers Free plan. You get 10 minutes of browser time per day, shared across Quick Actions and Browser Sessions. Browser Sessions can use 3 concurrent browsers per account and start 1 new browser instance every 20 seconds. Quick Actions allow 1 request every 10 seconds.

The /crawl endpoint has extra limits on the free plan: 5 crawl jobs per day, with a maximum of 100 pages per crawl. A browser times out after 60 seconds of inactivity by default, and you can extend that to up to 10 minutes with the keep_alive option.

## When you hit a limit

On the Workers Free plan, usage stops instead of being billed. Once you use the 10 minutes, new browsers fail with a 429 Browser time limit exceeded for today error until the next UTC day. Going over the per-second rate limits returns a 429 Too many requests response with a Retry-After value.

Workers Paid includes 10 hours per month, then $0.09 per additional hour, and 10 concurrent browsers averaged monthly, then $2.00 per additional browser. Failed Quick Actions requests that time out are not charged.

## Gotchas

- A browser left open keeps using time; wrap your code in try/finally so browser.close() always runs.
- After upgrading from Workers Free, redeploy your Worker if you still hit the 10-minute daily limit.
- Sessions also close when Browser Run rolls out a new release, so long jobs need to handle reconnects.

## Questions people ask

### Is Cloudflare Browser Run free?

Yes, on the Workers Free plan, with 10 minutes of browser time per day and 3 concurrent browsers.

### What happens when I use up the 10 minutes?

New browsers fail with a 429 Browser time limit exceeded for today error until the next UTC day. You are not billed on the free plan.

### Is Browser Run the same as Browser Rendering?

Yes. Cloudflare says Browser Run was formerly known as Browser Rendering.
