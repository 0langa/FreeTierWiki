Sitelemetry gathers evidence about a website’s security posture and presents it in an audit. You can run checks on a project you control and inspect what the service observed. Its free offer covers a subset of the security modules, which is useful for an initial review of one site.

## What the free plan gives you

The Free tier lists 10 security scans each month, 10 of the provider’s 27 security modules, one project and one seat. The remote MCP server can run the security work within that allowance. You can use the account dashboard to review the results as well. The page distinguishes the included security checks from broader audit areas such as accessibility, performance, search and AI visibility. Use the available checks to examine a particular concern, then review the underlying evidence against what your application actually serves.

## When you hit a limit

The official page lists a monthly scan allocation without detailing the exact response when you try another scan after using it up. Paid plans offer additional modules and scheduled monitoring. If you have limited scans left, make the intended site change before repeating a check. The report reflects the target observed at the time of the scan. Compare it with your deployment history if the observed configuration changes.

## Gotchas

- Active probes require verification and authorization. Use a target you control or have explicit permission to test.
- Free includes security checks only from the larger audit suite. Scheduled monitoring is a paid feature.
- Keep a record of a reported issue before making changes if you need to compare the evidence later.

## Questions people ask

### Is Sitelemetry free?

Its Free plan covers one site project and includes 10 security scans per month.

### Can I use an assistant to run those checks?

Remote MCP security access is included. Requests still use the Free plan’s scan allowance.

### Are SEO and accessibility audits included?

The provider lists them outside the free security tier. Choose a plan that covers the audit areas you need.
