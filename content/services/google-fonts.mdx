You pick a font on fonts.google.com, add a stylesheet link to your page, and use the font name in CSS. The docs say no programming is needed. It suits web developers and designers who want good type with little setup.

## What the free plan gives you

Google Fonts has no paid tier on the pages we read. The Google Fonts home page says all fonts are released under open source licenses and that you can use them in any non-commercial or commercial project. The getting-started examples use the stylesheet link with no API key.

The stylesheet URL can ask for several families separated by a pipe character, plus styles and weights after a colon. You can add a `display` parameter to control what happens while the font loads, and a `subset` parameter to pick script subsets. The `text` parameter loads only the characters you need. The API serves a stylesheet made for the browser that asks for it.

## When you hit a limit

The pages we read list no quota, rate limit, bandwidth cap, or paid plan. The pages mention no account, card, or bill. The pages do not describe what would happen under extreme traffic, so treat that as unknown.

The limits that matter are about fonts and files. You can only use families in the library, and the pages say only that they have open source licenses. Asking for many families can make your pages slow, and the docs warn that most pages do not need many fonts. Google's font repository README says the fonts are licensed with permission to redistribute, so you can download and self-host them, subject to each family license. Self-hosting gives you responsibility for updates and delivery.

## Gotchas

- The docs say requesting a lot of fonts may make your pages slow to load, so ask only for the families, styles, and weights you use.
- Always list a fallback font such as serif or sans-serif in your CSS, so the browser can fall back while the font loads.
- Browsers differ while a font loads. Some show blank space and others show the default font first, so set the `display` parameter on purpose.

## Questions people ask

### Is Google Fonts free?

Yes. The Google Fonts home page says all fonts are released under open source licenses and can be used in any non-commercial or commercial project.

### Does Google Fonts need an API key?

The getting-started stylesheet examples use no API key. Separate developer APIs can have different requirements.

### Can I use Google Fonts on a commercial site?

Yes. The home page says you can use the fonts in commercial projects. Check the license of each family before you redistribute it.
