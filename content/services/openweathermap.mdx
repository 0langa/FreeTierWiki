OpenWeatherMap, run by OpenWeather, is a weather data platform with APIs for current conditions, forecasts, air pollution, weather maps, and history. It has a Free plan for everyone, a free plan for students, and paid subscriptions. Developers use it to add weather to dashboards, travel apps, and smart home projects.

## What the free plan gives you

The Free plan covers current weather and forecasts with 60 API calls a minute and 1,000,000 calls a month. It includes the Current Weather API, the 3-hour Forecast for 5 days, the Air Pollution API, Weather Maps with 15 layers, and the Geocoding API. A separate free plan for students adds historical data, such as the Weather History API, with the same call limits. One Call API is a different product: its pay-per-call subscription includes the first 1,000 API calls per day free, and each additional call costs 0.0015 USD.

## When you hit a limit

On the Free plan, making more than 60 API calls a minute returns a 429 error. If you go past the plan's limits, OpenWeather says it will notify you and ask you to move to a subscription or reduce your calls, and expects you to act to avoid your account being suspended. One Call API works differently: calls above 1,000 a day are summed and charged automatically at the end of your subscription month. A default limit of 2,000 calls per day is set, and you can change it in the Billing plan tab.

## Gotchas

- Call limits are applied at the account level, so usage from all your API keys counts toward the same limits.
- One Call API is not part of the Free plan; it needs its own subscription with billing details.
- The 60 calls a minute limit is easy to hit when many users load a page at once, so cache responses.

## Questions people ask

### Is the OpenWeatherMap API free?

Yes, there is a Free plan. It allows 60 API calls a minute and 1,000,000 calls a month for current weather, forecasts, air pollution, maps, and geocoding.

### Is One Call API free?

Partly. Its pay-per-call subscription includes 1,000 free calls a day, and calls above that are charged.

### What does a 429 error mean on the Free plan?

It means you made more than 60 API calls in a minute, which is the Free plan's limit.
