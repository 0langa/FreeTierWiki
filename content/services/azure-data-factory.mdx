freeTierDetails:
  summary: >-
    Azure gives Data Factory its own always-free amount: 5 low-frequency
    activity runs per month, separate from any Azure trial credit.
  limits:
    - 5 low-frequency activity runs/month (at most once per day each)
  caveats:
    - Runs beyond the free amount, and all data movement/data flow activity, are billed.
    - A low-frequency activity is one that runs no more than once a day.
  resetPeriod: monthly
  requiresCard: true
  freeTierType: always-free

  overageRisk: medium
  billingRiskNotes:

quickstartSteps:
  - Sign in to the Azure Portal and create a Data Factory instance.
  - Set up linked services to connect to your data sources and destinations.
  - Create a pipeline and add activities for data movement or transformation.
  - Configure triggers to schedule pipeline runs.
  - Monitor pipeline execution and review run history.
