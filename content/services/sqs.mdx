You work with SQS through the AWS console, the AWS SDKs, or the API. You create a queue, send messages, and write a consumer that receives and deletes them. It suits developers who already build on AWS.

## What the free plan gives you

All customers get 1 million SQS requests per month for free, and the page says this is not limited to new accounts. The free amount is the same for Standard queues and FIFO queues. There is no minimum fee.

Every SQS action counts as a request. One request can carry 1 to 10 messages, up to 1 MiB in total. Messages stay in a queue for 4 days by default. You can set retention from 1 minute up to 14 days. Standard queues support nearly unlimited calls per second, and each FIFO partition is limited to 300 transactions per second per action in non-high-throughput mode.

## When you hit a limit

The pricing page lists no hard stop at the free amount. You pay per million requests after the first 1 million each month, and the page shows the rates in a calculator. Standard and FIFO queues have their own rates.

Payload size changes the count. Each 64 KB chunk of a payload is billed as one request, so a request with a 1 MiB payload is billed as 16. Sending and receiving in the same region has no data transfer charge. Cross-region traffic and traffic to or from the internet use standard AWS data transfer charges.

## Gotchas

- Receiving and deleting messages are requests too, so a message that you send, receive, and delete uses several requests unless you batch them.
- A FIFO queue needs a message group ID on every send. The send fails without one.
- Standard queues deliver at least once, so a consumer can see the same message twice.

## Questions people ask

### Is Amazon SQS free?

Partly. All customers get 1 million requests per month free for Standard and FIFO queues. After that you pay per million requests.

### What counts as a request in SQS?

Every SQS action is a request, and each 64 KB chunk of a payload counts as one. A single request can hold up to 10 messages.

### How long does SQS keep messages?

By default a message stays in the queue for 4 days. You can set the retention between 1 minute and 14 days.
