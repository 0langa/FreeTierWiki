You set it up in the Azure portal, the Azure CLI, PowerShell, an Azure Resource Manager template, or the REST API. Your code then asks for a token through the Azure.Identity library or MSAL. It suits developers who already run workloads on Azure.

## What the free plan gives you

Microsoft's overview says managed identities can be used at no extra cost. There are two types. A system-assigned identity is created with a resource and deleted with it. A user-assigned identity is a standalone resource that several resources can share.

You can assign an identity to an Azure virtual machine, a virtual machine scale set, a Service Fabric cluster, an Azure Kubernetes cluster, or any app hosting platform that Azure supports. Then you grant it access to services such as a storage account, SQL database, or Cosmos DB. The resources that use the identity are billed as usual, and you need an Azure subscription.

## When you hit a limit

You pay nothing for identities, so a limit cannot create a bill. The limits are technical. The FAQ says requests to the managed identity endpoint are limited to 20 per second and 5 concurrent requests, and requests over the instance metadata limit get 429 responses.

Each identity also counts toward your tenant's directory object quota. Creating a new identity is blocked once usage would reach 98 percent of that quota. An administrator then has to raise the quota or delete objects. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## Gotchas

- Tokens are cached for around 24 hours, so a role change can take several hours to work. You cannot force a refresh.
- Managed identities do not work across directories or tenants. After you move a subscription to another directory, you must re-create them and grant roles again.
- Deleted identities are soft deleted for 30 days, but you cannot restore or permanently delete them in that time.

## Questions people ask

### Are Azure managed identities free?

Yes. Microsoft says managed identities can be used at no extra cost. You still pay for the Azure resources that use them, and you need an Azure subscription.

### What is the difference between system-assigned and user-assigned managed identities?

A system-assigned identity belongs to one resource and is deleted with it. A user-assigned identity is its own resource, has its own life cycle, and can be shared by several resources.

### Are there limits on Azure managed identities?

Yes. The FAQ lists a rate limit of 20 requests per second with 5 concurrent requests for the managed identity endpoint. It also lists a tenant directory object quota, with creation blocked at 98 percent.
