Open-Meteo is a weather API that serves forecasts from 30+ weather models, from agencies such as ECMWF, NOAA, and DWD, along with historical weather from 1940. The server code is open source under AGPLv3 and the data is licensed CC BY 4.0. It suits hobby apps, research, and prototypes, and offers paid subscriptions for commercial use.

## What the free plan gives you

The free API needs no API key, no sign-up, and no credit card. Non-commercial use up to 10,000 daily API calls is free, and the plan table also lists 600 calls a minute plus an hourly limit. All APIs use plain HTTP GET requests and return JSON, with CSV and XLSX output also available. One API call usually means one request, but requests with more than 10 weather variables or more than 2 weeks of data for a location count as multiple calls; 2 weeks of data with 15 variables counts as 1.5 calls. Attribution is required under the CC BY 4.0 data licence.

## When you hit a limit

The free API is rate-limited to 10,000 calls a day and carries no uptime guarantee. The terms say Open-Meteo reserves the right to block applications and IP addresses that misuse the service without prior notice. There is no account on the free API, so there is nothing to bill. For more calls or commercial use, the Standard plan includes 1M calls a month with a commercial use licence and an API key for a dedicated customer endpoint, where the request syntax is identical apart from the domain and key.

## Gotchas

- The free API is for non-commercial use only; a commercial app needs a subscription even at low volume.
- Large requests count as more than one call, so many variables over long periods use the daily limit faster.
- The data is free to redistribute under CC BY 4.0, but only with attribution.

## Questions people ask

### Is Open-Meteo free?

Yes, for non-commercial use. The free API needs no API key or sign-up and allows up to 10,000 calls a day.

### Can I use Open-Meteo in a commercial app?

Not on the free API. Commercial use needs a subscription, which adds a commercial use licence and an API key.

### Do I need to credit Open-Meteo?

Yes. The weather data is licensed under CC BY 4.0, which requires attribution.
