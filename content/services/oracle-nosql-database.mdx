Oracle NoSQL Database Cloud Service is a fully managed NoSQL database on Oracle Cloud Infrastructure, with no data servers for you to run. Tables can use a fixed schema or schema-less JSON. It suits developers who want a free managed NoSQL table and are already using, or willing to use, Oracle Cloud.

## What the free plan gives you

All Oracle Cloud tenancies get Oracle NoSQL Database in the Always Free resources, for the life of the account. The free amount is up to 133 million reads per month, 133 million writes per month, and 3 tables with 25 GB of storage per table.

Each Always Free table has a read capacity of 50 read units and a write capacity of 50 write units, and neither can be changed. You can have both Always Free and regular tables in the same region, and the Always Free ones show an Always Free label in the console. Always Free NoSQL tables are currently available only in the Phoenix region.

## When you hit a limit

Always Free tables have fixed capacity, so they do not grow into paid usage. When you already have three Always Free tables, the toggle to create another is disabled until you delete one. Oracle's docs do not describe a charge for an Always Free table itself.

Idle tables are the real risk. A table that is not used for 30 days becomes inactive, with a notice to the tenancy administrator and a reminder at 75 days. A table that stays inactive for 90 days is deleted. Any get, put, or delete on a row makes it active again; schema changes do not.

## Gotchas

- An Always Free table cannot be changed to a regular table or the other way around.
- Schema (DDL) operations do not count as use, so an app that only alters tables can still let them go inactive.
- Most users need a mobile phone number and a credit card to create the Oracle Cloud account, though the card is not charged unless you upgrade.

## Questions people ask

### Is Oracle NoSQL Database free?

Yes, within the Always Free amount: 3 tables with 25 GB each and up to 133 million reads and 133 million writes per month.

### Will Oracle delete my Always Free NoSQL table?

Only if it sits unused. A table becomes inactive after 30 days without use and is deleted after 90 days inactive.

### Which region can I use?

Always Free NoSQL tables are only available in the Phoenix region.
