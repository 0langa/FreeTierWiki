You write Wolfram Language in notebooks, either in the Wolfram Cloud in a browser or in desktop products. You press Shift+Enter to run each input. The free cloud plan suits students and hobbyists who work alone.

## What the free plan gives you

Wolfram Cloud Basic is free, introductory access to the Wolfram Cloud for non-organizational use. It includes 200 MB of cloud storage and 5,000 Cloud Credits per month.

Storage is temporary. Each file, deployment, and API expires after 60 days. If you want to keep something, copy it elsewhere before then.

The plan is for personal use only. Wolfram's support page names three kinds of organizational use that are not allowed: running a class, doing collaborative group research, and building a commercial product for a business.

## When you hit a limit

The support article does not say what happens when you use all 5,000 Cloud Credits in a month. It also describes no paid upgrade for individuals. It points you to your school's site license, and tells organizations to contact Wolfram.

Files, deployments, and APIs simply expire after 60 days. The pages do not mention a credit card for the Basic plan.

## Gotchas

- Cloud Credits reset each month, but your files do not last: everything expires after 60 days.
- Teaching a course is organizational use, so a free account is not allowed for class material.
- Storage is small at 200 MB, so large datasets will not fit.

## Questions people ask

### Is Wolfram Language free?

You can use it free in the cloud through Wolfram Cloud Basic. The plan has 200 MB of storage and 5,000 Cloud Credits per month, for personal use.

### How long do my Wolfram Cloud Basic files last?

Each file, deployment, and API expires after 60 days.

### Can I use Wolfram Cloud Basic to teach a class?

No. The plan does not allow organizational use, including teaching a course. Ask whether your school has a Wolfram site license.
