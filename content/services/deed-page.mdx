deed.page hosts static sites that are published by a single HTTP request. Send an HTML file or a tarball of a folder with PUT or POST to the sites endpoint, or call the remote MCP server, and the JSON response returns a live HTTPS address on a subdomain plus a token. It is aimed at AI agents and scripts that need to put a page online without a human step.

## What the free plan gives you

The pricing page lists a Free plan at $0 with 25 sites, 25 MB per site, 60 publishes an hour, 10 versions kept, 1 custom domain, public sites only, and 1 webhook. It says there is no signup and that an email is never required. Cookieless analytics, the MCP server and subdomains are included on every plan, and sites are permanent rather than expiring.

Paid plans attach to the same token. Hobby is $3 a month for 250 sites and 100 MB per site, and Pro is $15 a month for 2,500 sites and 500 MB per site. An agent requests a Stripe checkout link and a human pays once.

## When you hit a limit

The docs list the plan errors. A publish past the site limit returns quota_sites with status 403, and a site bigger than the plan allows returns quota_bytes with status 413. A single request body over 4 MB returns request_too_large; larger sites have to use the manifest upload, which creates an upload session, puts each file directly and then finalizes, and the result must still fit the per-site cap.

Going past the hourly publish limit returns rate_limited with status 429, a retry_after value and a Retry-After header. Nothing is billed on the free plan, so hitting a limit stops the request instead of adding a charge.

## Gotchas

- The token is shown once and the service keeps only a hash of it. Without the optional recovery email, a lost token cannot be restored, and the sites can no longer be updated.
- Publishing new slugs with the same token keeps them under one owner, so the 25-site limit applies per token.
- Free sites are always public; the site password is a Hobby and Pro feature, and only static files are served.

## Questions people ask

### Is deed.page free?

Yes. The Free plan is $0 with 25 sites of up to 25 MB each, and the pricing page says it needs no signup and no email.

### Do I need an account to publish?

No. The first publish returns a token in the response. Keep it and send it as a Bearer header to update, list or delete your sites.

### What happens when I reach 25 sites?

New sites are refused with quota_sites and status 403 until you delete a site or move the token to a paid plan. Existing sites stay online.
