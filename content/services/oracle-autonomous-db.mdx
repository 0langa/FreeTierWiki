You create and manage instances in the Oracle Cloud Console, then connect with Oracle APEX, Database Actions, or a SQL client. It suits learners and developers who already want an Oracle database and are fine giving Oracle a card at sign-up.

## What the free plan gives you

Every tenancy can create up to two Always Free Autonomous AI Database instances. Each has 1 OCPU and 20 GB of storage, and neither can be scaled by hand or automatically. You choose a workload type for each one: Transaction Processing, JSON, APEX, or Lakehouse. The two instances can use the same type or different types.

Oracle's docs cap simultaneous sessions at 20 on one page and 30 on another. The web tools are also rate limited, with about 3 to 6 simultaneous users across APEX, REST Data Services, and Database Actions. You can create the databases only in your home region, which you pick at sign-up.

## When you hit a limit

Oracle says you are never billed for an Always Free instance until you update it to a paid database. If you go over the session or user limits, you see errors, such as HTTP status 429 on the web tools. Oracle suggests upgrading to a paid service to get more resources.

Inactivity is the bigger risk. After 7 days of inactivity Oracle stops the database and keeps the data. If it stays inactive or stopped for 90 days, Oracle may reclaim and permanently delete it. Starting the instance from the console resets the count.

## Gotchas

- Most users need a mobile phone number and a credit card to create the account. Oracle says the card is not charged unless you upgrade.
- Always Free databases do not support long-term backups, manual backups to object storage, or restore. Back up your data yourself.
- You cannot create an Always Free database in a region you subscribe to later. It must live in your home region, and not every region supports it.

## Questions people ask

### Is Oracle Autonomous Database free?

Yes, through Always Free. Every tenancy can create two instances with 1 OCPU and 20 GB of storage each. Oracle says you are never billed for them until you upgrade.

### Does Oracle Autonomous Database need a credit card?

Most users need a mobile phone number and a credit card to create an Oracle Cloud account. The docs say the card is not charged unless you upgrade.

### Does an Always Free Autonomous Database stop?

Yes. Oracle stops it after 7 days of inactivity and keeps the data. If it stays inactive or stopped for 90 days, Oracle may delete it permanently.
