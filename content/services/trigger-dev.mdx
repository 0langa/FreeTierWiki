You write tasks as TypeScript code in a /trigger folder of your project. The CLI links your project to Trigger.dev Cloud, runs a dev server, and deploys the tasks. Your app then triggers them from its own code. It suits web and AI developers who need long background jobs without running workers.

## What the free plan gives you

The Free plan costs $0 per month and includes $5 of free compute credits each month. It has 20 concurrent runs, unlimited tasks, and 5 team members. Concurrency is set per environment. Free allows 20 in production, 10 in staging, 10 in preview, and 25 in development.

Tasks run on Trigger.dev's managed workers, and you only pay while they run. The smallest machine costs $0.0000169 per second. Each run that starts also costs an invocation fee of $0.25 per 10,000 runs, except runs in the DEV environment. Waits longer than 5 seconds are checkpointed and do not count toward compute use.

## When you hit a limit

The pricing FAQ says that on the Free plan, you need to upgrade to keep running tasks once the included $5 of credits is used. On paid plans, tasks keep running and extra compute is billed at the usage rates. So the free plan stops instead of billing you.

You can also hit other limits. The API allows 1,500 requests per minute on every plan. Each queue holds up to 500 runs in development and 10,000 in staging or production on Free. When a queue is full, new triggers to it are rejected.

## Gotchas

- A task that triggers a subtask and waits is checkpointed, so the waiting time does not count toward compute usage or your concurrency limit.
- Calling trigger in a loop can hit the API rate limit. Use batchTrigger, which fits up to 1,000 tasks in a single call.
- Every run that starts on the managed workers has a per-run fee on top of compute, so many tiny runs add up. Runs in the DEV environment are not charged.

## Questions people ask

### Is Trigger.dev free?

Yes, to start. The Free plan costs $0 and includes $5 of compute credits each month and 20 concurrent runs.

### What happens when I use up my Trigger.dev credits?

On the Free plan, you must upgrade to keep running tasks. Paid plans keep running and bill the extra compute.

### Is Trigger.dev open source?

Yes. The pricing page says it uses the Apache 2.0 license, and you can self-host it.
