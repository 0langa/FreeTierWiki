You write Python functions with a decorator, and Modal builds the container and runs it in the cloud with the CPU or GPU you ask for. You launch work with the modal run command or deploy it as a web endpoint or scheduled job. It suits developers who run AI inference, batch jobs, or fine-tuning without owning GPUs.

## What the free plan gives you

The Starter plan costs $0 plus compute, and it comes with $30 of free credits every month. It includes 3 workspace seats, 100 containers, and 10 GPU concurrency. It also covers limited scheduled and web functions, 5 deployed cron jobs, real-time metrics and logs, region selection, and 1 TiB per month of free network egress.

Modal bills per second, with no minimum usage increment. For example, an Nvidia T4 costs $0.000164 per second and CPU costs $0.0000131 per core per second. The credit pays for that compute, so it lasts longer on small CPU work than on large GPUs.

## When you hit a limit

Modal bills usage after the credit ends. The billing docs say each workspace is billed monthly and auto-charged for usage, less credits. It also charges incrementally the first time you pass certain thresholds.

You can cap this. A workspace budget sets a monthly limit on total usage. A spend limit stops workloads that would add out-of-pocket charges once it is reached. If you set none, the default spend limit is the usage limit minus your credits.

## Gotchas

- Modal requires a payment method on file to use the service, and using a GPU requires a valid one. The pricing page does not say this.
- Network egress above the included 1 TiB per month is billed at $0.04 per GiB.
- Containers have a minimum request of 128 MiB of memory and 0.125 CPU cores, and you pay for whichever is higher, what you request or what you use.

## Questions people ask

### Is Modal free?

Partly. The Starter plan includes $30 of free compute credits every month, and you pay for usage beyond that.

### Does Modal need a credit card?

Yes. The billing docs say you must have a payment method on file to use Modal, and GPU use requires a valid one.

### What happens when I use up the Modal free credits?

Modal auto-charges the usage that exceeds your credits at the end of the billing cycle. You can set a workspace budget or spend limit to cap it.
