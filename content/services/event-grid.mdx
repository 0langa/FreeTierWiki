You set Event Grid up in the Azure portal or the Azure CLI. You create a topic or a namespace, add subscriptions, and publish over HTTP or MQTT. It suits teams that build event-driven apps on Azure. Azure sign-up asks for a phone number and a credit or debit card (not prepaid) to verify your identity. It may place a temporary one-dollar hold, and it does not charge you unless you move to pay-as-you-go.

## What the free plan gives you

Event Grid has two tiers. The Basic tier is pay-per-use for events on custom topics, system topics, partner topics, and domains. It includes 100,000 operations per month for free.

The Standard tier uses an Event Grid namespace. It gives you an MQTT broker, plus push and pull delivery of events. Each month it includes 1,000,000 MQTT operations and 1,000,000 event operations for free. Operations are counted per 64 KB of data, so an event of 256 KB counts as 4 operations.

## When you hit a limit

The pricing page lists no hard stop at the free amounts. You pay per million operations after them. The pricing page shows the rates in a calculator, so check the live page.

A Standard namespace has a second cost. You pre-purchase throughput units, and they are billed per hour per unit. The free amounts cover operations only, so a namespace that sits idle can still cost money. You can choose up to 40 throughput units for each namespace. Each throughput unit allows 10,000 MQTT client connections.

## Gotchas

- Event retention is free for 1 day on Basic. On a namespace topic it is free for 7 days.
- On Basic, event type matching and filtering on the start of the subject are free. Advanced filtering on the data payload counts as operations.
- MQTT client connections have no extra charge, but connects, subscribes, and publishes are MQTT operations.

## Questions people ask

### Is Azure Event Grid free?

Partly. The Basic tier includes 100,000 operations per month. A Standard namespace includes 1,000,000 MQTT operations and 1,000,000 event operations per month.

### What counts as an operation in Event Grid?

On Basic, published events, advanced filtering, and delivery attempts count. Each operation covers up to 64 KB of data, so larger events count as several.

### What is the difference between Basic and Standard Event Grid?

Basic publishes and subscribes to discrete events through topics and domains. Standard adds a namespace with an MQTT broker and pull delivery.
