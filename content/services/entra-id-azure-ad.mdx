You manage Entra ID in the Microsoft Entra admin center, or through the Azure portal and Microsoft Graph. It fits teams that run on Azure or Microsoft 365 and need a cloud directory.

## What the free plan gives you

Microsoft Entra ID Free comes with Microsoft cloud subscriptions such as Azure and Microsoft 365. It supports multifactor authentication, unlimited single sign-on across any SaaS app, basic reports, and self-service password change for cloud users.

The pricing page lists a 500,000 resource limit for the Free tier. The service limits page sets a lower default quota: 50,000 Microsoft Entra resources per tenant for the Free edition. With at least one verified domain, the quota rises to 300,000. A new tenant has a temporary quota of 600 directory objects for its first two days. The paid P1 plan is listed at $7.00 and P2 at $10.00 per user.

## When you hit a limit

To go beyond the default resource quota, you must contact Microsoft Support. The service limits page does not describe an automatic charge for it. Resources include users, groups, applications, and service principals, and soft-deleted objects can still count while you can restore them.

A non-admin user can create no more than 250 Microsoft Entra resources. If developers hit this often, an admin can give them a custom role that allows unlimited app registrations. Features such as conditional access are not part of the Free edition. They need a paid plan.

## Gotchas

- The pricing page and the service limits page give different resource numbers. Use the lower default quota when you plan.
- Only paid customers can create more workforce tenants. Free tenants and trial subscriptions cannot add them.
- You need an Azure or Microsoft 365 subscription. Azure's account page says sign-up needs a phone and a credit or debit card for identity verification.

## Questions people ask

### Is Microsoft Entra ID free?

Yes, the Free edition is included with Azure and Microsoft 365 subscriptions. It covers unlimited SSO across SaaS apps and MFA for cloud users.

### Does Entra ID need a credit card?

The Free edition is included with a Microsoft cloud subscription such as Azure or Microsoft 365. Azure's account page says sign-up needs a phone and a credit or debit card for identity verification, so plan for a card.

### How many objects can Entra ID Free hold?

The default quota is 50,000 resources per tenant, and 300,000 with a verified domain. To go further, contact Microsoft Support.
