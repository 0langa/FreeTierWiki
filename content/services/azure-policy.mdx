You work in the Azure portal, where you assign built-in or custom definitions and read a compliance dashboard. Definitions are written in JSON, so you can also manage them as code. It suits cloud administrators and security engineers.

## What the free plan gives you

The pricing page says there are no charges for using Azure Policy on Azure resources. You can use the built-in definitions, assign them to a management group, subscription, resource group, or resource, and read the compliance results. You can also set an effect such as deny, audit, or modify.

Azure Automanage machine configuration, which audits settings inside servers, is free for Azure resources. For Arc resources it costs $6 per server per month, billed pro-rated by the hour. The FAQ says you can use as many guest configuration policies as you want per server for the same price.

## When you hit a limit

The pricing page does not list usage limits for Azure Policy itself. The only charge is for machine configuration on Arc-enabled servers. By default, Azure Arc machines are not included, and you must opt in. Azure Automation users are not billed extra for machine configuration.

You can turn machine configuration off for your servers if you do not want the charge. A deny effect can stop a deployment that breaks a rule, so test with audit first.

## Gotchas

- Even if you assign a policy at the management group level, only resources at the subscription or resource group level are evaluated.
- Compliance is evaluated when a resource changes, when an assignment changes, and in a regular cycle once every 24 hours.
- Microsoft recommends starting with an audit effect before an enforcement effect, because enforcement can hinder existing automation.

## Questions people ask

### Is Azure Policy free?

Yes for Azure resources. The pricing page says there are no charges for using Azure Policy on Azure resources. You still need an Azure account.

### How much does Azure Policy cost for Arc servers?

Azure Automanage machine configuration costs $6 per server per month for Arc resources. Arc machines are not included by default, so you have to opt in.

### How often does Azure Policy check my resources?

It checks when a resource is created or updated, when an assignment changes, and in a standard cycle once every 24 hours.
