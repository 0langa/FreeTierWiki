Ahrefs Web Analytics gives website owners a traffic dashboard and a way to report events. You install a script on a verified website and use the dashboard to see visits and actions. It can serve a documentation site, portfolio, or other site you maintain.

## What the free plan gives you

An Ahrefs Free account can track up to one million events per verified project per month. You can verify multiple websites, with the allowance applying per project. The product includes traffic analytics and can track actions such as form submissions or downloads. Its documentation says it uses no cookies and does not store IP addresses with the analytics data. Think about which events are useful to your site before enabling many of them. The website allowance is measured by events, so recording extra actions can consume more than one event during a visit.

## When you hit a limit

Ahrefs shows a prompt to purchase more capacity after the free event threshold. The help article explains how to buy an add-on per project, with higher monthly event allowances. It does not specify the exact handling of every event received before you purchase more. Review the current usage for the affected website if a campaign drives an unusual increase in site traffic.

## Gotchas

- Ownership verification is necessary. A site you merely visit or consult for another team needs the owner’s cooperation.
- The service does not follow a visitor across days. Keep this in mind if you need long-lived visitor identity.
- A download or form interaction can draw from the same event budget as other activity on the site.

## Questions people ask

### Is Ahrefs Web Analytics free?

The web analytics included in Ahrefs Free cover up to one million events monthly for each verified site project.

### Can I use it on more than one website?

Yes. Verify each site you control and set up tracking for its project.

### Where do I get more event capacity?

Ahrefs offers project-specific event add-ons and shows a purchase prompt after the free allowance is exceeded.
