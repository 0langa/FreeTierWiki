You run the Keploy CLI in front of your app, send some requests, and it saves them as tests and mocks. It suits backend and QA engineers who want regression tests built from real traffic.

## What the free plan gives you

The free Playground plan is called the perfect starting place to try Keploy and generate your first tests, and it is free forever. Per month it includes 30 test suite generations, 100 test runs, and 5,000 integration and sandbox runs. You also get 5 AI credits for bug detection and self-healing.

The plan generates API tests from OpenAPI or Postman specs, expands edge cases with AI, and produces human-editable YAML. The pricing page says no credit card is needed for Playground. The plan comparison also lists an open-source column.

## When you hit a limit

The pricing page lists the Playground limits but does not say what happens when you reach them. The pricing page says there is no credit card for Playground.

Moving up means the Pro plan at $19 per user per month with $19 of included usage. After that, overage prices apply: $0.16 per test generation, $0.22 per test run, and $10 for each 10,000 integration and sandbox runs. Pro takes credit cards only.

## Gotchas

- On macOS, start your app itself, not a launcher such as `npm start`, or Keploy cannot record it.
- `keploy login` has a `--manual-login` option, and in CI you sign in with an API key.
- The install guide says a free account is all you need for the CLI.

## Questions people ask

### Is Keploy free?

Yes, in part. The Playground plan is free forever and includes 30 test suite generations and 100 test runs a month. The Pro plan costs $19 per user per month.

### Does Keploy need a credit card?

No. The pricing page says there is no credit card for Playground. The docs say a free account is all you need for the CLI.

### Does Keploy need code changes in my app?

The home page FAQ says Keploy captures requests and dependency calls with eBPF and network-level interception, without application code changes.
