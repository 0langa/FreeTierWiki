Greptile adds automated review to pull requests. It can use context from the repository to point out problems in a change and leave feedback for a developer to inspect. It fits a workflow where you already use pull requests even on projects you usually maintain alone.

## What the free plan gives you

Starter includes 50 credits in a month for one active developer and can cover unlimited repositories. The credit balance limits reviews across those repositories. Greptile's pricing page describes different credit costs for review modes, so the same allowance can buy different numbers of reviews depending on what you request. Start with a representative change and look at the findings. Useful feedback on a real change is a better basis for deciding how often to run the tool than assuming that every pull request needs several automatic passes.

## When you hit a limit

The provider publishes prepaid rates on Pro and a separate Starter allowance. Its public pricing page does not clearly describe what happens to a Starter review after the credit balance is exhausted or whether a card is requested during Starter signup. Review your balance and the mode configured for automatic reviews before turning it on for several repositories at once.

## Gotchas

- One active developer is the limit on Starter. Unlimited repositories still draw from the same plan.
- Read automated findings alongside the change and its tests. A suggestion can miss information outside the tool's available context.
- A new review after several pushes can consume more credits than a single pass at the end of a change.

## Alternatives in this atlas

- [GitHub Actions](/services/github-actions/) to run deterministic lint, test, or build jobs on pull requests.
- [CodeRabbit](/tools/coderabbit/) for another AI code review option with different free coverage.

## Questions people ask

### Is Greptile free?

Starter is free for one active developer and includes 50 monthly review credits.

### Do 50 credits equal 50 pull requests?

It depends on the review modes and how often the tool reviews each pull request. Consult the pricing breakdown before calculating expected usage.

### Can I use it across multiple repositories?

Yes. Starter lists unlimited repositories, subject to the shared credit allowance and active-developer limit.
