Greptile adds automated review to pull requests. It can use context from the repository to point out problems in a change and leave feedback for a developer to inspect. It fits a workflow where you already use pull requests even on projects you usually maintain alone.

## What the free plan gives you

Starter includes 50 credits in a month for one active developer and can cover unlimited repositories. The credit balance limits reviews across those repositories. Base reviews cost 1 credit, Plus 3 and Apex 10; Auto charges for the tier that actually ran. Only completed reviews spend credits. A TREX run adds 3 credits only when at least one flow reaches a pass or fail. CLI reviews are excluded from Free. Start with a representative change and look at the findings. Useful feedback on a real change is a better basis for deciding how often to run the tool than assuming that every pull request needs several automatic passes.

## When you hit a limit

The billing guide says new reviews pause when credits run out. Pro uses prepaid credits at $1 each, shared across the organization; optional automatic recharge buys more when the balance runs low. The public pages do not establish whether Starter signup requires a card. Review your balance and the mode configured for automatic reviews before turning it on for several repositories at once.

## Gotchas

- One active developer is the limit on Starter. Unlimited repositories still draw from the same plan.
- Read automated findings alongside the change and its tests. A suggestion can miss information outside the tool's available context.
- A new review after several pushes can consume more credits than a single pass at the end of a change.

## Questions people ask

### Is Greptile free?

Starter is free for one active developer and includes 50 monthly review credits.

### Do 50 credits equal 50 pull requests?

Fifty credits cover 50 Base reviews, 16 Plus reviews with 2 credits left, or 5 Apex reviews. Repeat passes and optional TREX runs consume more of the same balance.

### Can I use it across multiple repositories?

Yes. Starter lists unlimited repositories, subject to the shared credit allowance and active-developer limit.
