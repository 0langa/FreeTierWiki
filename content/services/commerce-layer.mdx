You manage setup in the Commerce Layer Dashboard and use the Core REST API from your own frontend or backend. The docs also describe a CLI for configuring an organization. It suits developers building a custom storefront or checkout, not shop owners who want a ready-made site.

## What the free plan gives you

The free plan is called Developer. The pricing page lists 1 organization, 2 users, 2 markets, 1,000 SKUs, and 10 links. It includes unlimited test orders and 100 free live orders per month, plus core API access and community support. The docs say Commerce Layer is free for developers and will stay that way.

A market is a place or sales strategy with its own prices and inventory. Your plan limits count only active markets. A SKU is one distinct item for sale, so a t-shirt in several sizes and colors counts as many SKUs. Links are shareable product or order links that open a microstore or a checkout.

## When you hit a limit

The pricing page does not say what happens after 100 live orders in a month. It also lists no price for extra orders. The only other plan shown is Enterprise, with a custom quote, unlimited organizations, users, markets, SKUs, and links, and dedicated support. You would contact sales to get past the Developer limits.

For markets, the FAQ gives a clear rule. If you reach the market limit, disable one active market before you enable a new one. The Developer plan lists no card requirement, and test orders cost nothing, so you can build and test freely before real sales start.

## Gotchas

- Each user has an Admin or Read-only role. Custom roles are only on Enterprise.
- The Metrics API and Provisioning API are listed under Enterprise, not Developer.
- The docs say the default API version will be phased out over time and will only get bug fixes, while newer features go to a newer version.

## Questions people ask

### Is Commerce Layer free?

Yes. The Developer plan is free and includes unlimited test orders and 100 free live orders per month.

### What happens after 100 live orders on Commerce Layer?

The pricing page does not say. It lists only the free Developer plan and a custom Enterprise plan, so more volume means talking to sales.

### Does Commerce Layer need a credit card?

The pricing page lists no card requirement for the Developer plan. You sign up for free and start with the setup wizard or the API.
