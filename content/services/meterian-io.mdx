You run Meterian as a command-line client, a Docker image, or a GitHub Action, and read the results in a web dashboard or an HTML report. It suits open source maintainers and small teams who want a first dependency scan.

## What the free plan gives you

The Free plan covers unlimited open source projects and 1 closed-source project. You get 10 analyses per day and HTML reports. Meterian says all plans include the codebase scanner and the container scanner.

A report scores each project from 0 to 100 on security, stability, and licensing. It names the component, the CVE number, and the dependencies the issue touches. The next plan, called Bootstrap, raises the limits to 10 closed-source projects and 100 analyses per day, and adds text and JSON reports, CI integration, and basic API access. It is listed at 2300 pounds a year.

## When you hit a limit

The plans page does not say what happens when you pass 10 analyses in a day or add a second closed-source project. The limits are written as fixed numbers per plan, and the paid plans are priced per year, so the page shows no pay-as-you-go charge. If you need more, the next step on the page is the Bootstrap plan.

## Gotchas

- The Free plan lists HTML reports only. JSON, text, and PDF reports come with paid plans.
- The limit is counted in analyses per day, so a busy pipeline that scans on every push can reach 10 quickly.
- The Docker client needs an API token from your account before it can run.

## Questions people ask

### Is Meterian free?

Yes, within limits. The Free plan covers unlimited open source projects, 1 closed-source project, and 10 analyses per day.

### Does Meterian scan private repositories for free?

One closed-source project is free. For more, the plans page points you to the Bootstrap plan, which covers 10.

### How do I run my first Meterian scan?

Get an API token from your dashboard, set it as `METERIAN_API_TOKEN`, and run the Docker client or the GitHub Action in your project.
